# 第一章：MongoDB 基础入门

## 1.1 MongoDB 简介

MongoDB 是一个基于分布式文件存储的 NoSQL 数据库，由 C++ 语言编写。它是一个面向文档的数据库，数据以 BSON（Binary JSON）格式存储。

### 核心概念对比

| SQL 术语 | MongoDB 术语 | 说明 |
|---------|-------------|------|
| Database | Database | 数据库 |
| Table | Collection | 集合（表） |
| Row | Document | 文档（行） |
| Column | Field | 字段（列） |
| Index | Index | 索引 |
| Primary Key | _id | 主键 |

## 1.2 安装 MongoDB

### Windows 安装

1. 下载 MongoDB Community Server：https://www.mongodb.com/try/download/community
2. 运行安装程序，选择 "Complete" 安装
3. 安装完成后，MongoDB 会自动启动

### Docker 安装（推荐）

```bash
# 拉取 MongoDB 镜像
docker pull mongo:latest

# 运行 MongoDB 容器
docker run -d \
  --name mongodb \
  -p 27017:27017 \
  -v mongodb_data:/data/db \
  mongo:latest

# 进入 MongoDB shell
docker exec -it mongodb mongosh
```

### 验证安装

```bash
# 检查 MongoDB 版本
mongod --version

# 启动 MongoDB 服务（Windows）
net start MongoDB

# 连接 MongoDB
mongosh
```

## 1.3 基本操作

### 数据库操作

```javascript
// 显示所有数据库
show dbs

// 切换/创建数据库（如果不存在会自动创建）
use mydb

// 查看当前数据库
db

// 删除数据库
db.dropDatabase()
```

### 集合操作

```javascript
// 创建集合（显式创建）
db.createCollection("users")

// 查看所有集合
show collections

// 删除集合
db.users.drop()
```

### 文档操作（CRUD）

#### Create - 插入文档

```javascript
// 插入单个文档
db.users.insertOne({
  name: "张三",
  age: 25,
  email: "zhangsan@example.com",
  hobbies: ["读书", "游泳"],
  address: {
    city: "北京",
    district: "朝阳区"
  }
})

// 插入多个文档
db.users.insertMany([
  { name: "李四", age: 30, email: "lisi@example.com" },
  { name: "王五", age: 28, email: "wangwu@example.com" }
])
```

#### Read - 查询文档

```javascript
// 查询所有文档
db.users.find()

// 格式化输出
db.users.find().pretty()

// 查询单个文档
db.users.findOne({ name: "张三" })

// 条件查询
db.users.find({ age: { $gt: 25 } })  // 年龄大于 25

// 限制返回字段
db.users.find({}, { name: 1, email: 1 })  // 只返回 name 和 email
```

#### Update - 更新文档

```javascript
// 更新单个文档
db.users.updateOne(
  { name: "张三" },
  { $set: { age: 26 } }
)

// 更新多个文档
db.users.updateMany(
  { age: { $lt: 30 } },
  { $set: { status: "active" } }
)

// 替换文档
db.users.replaceOne(
  { name: "张三" },
  { name: "张三", age: 26, email: "zhangsan@example.com" }
)

// 使用更新操作符
db.users.updateOne(
  { name: "张三" },
  { 
    $set: { age: 26 },
    $inc: { score: 10 },  // 增加 10
    $push: { hobbies: "编程" }  // 添加到数组
  }
)
```

#### Delete - 删除文档

```javascript
// 删除单个文档
db.users.deleteOne({ name: "张三" })

// 删除多个文档
db.users.deleteMany({ age: { $lt: 25 } })

// 删除所有文档（保留集合）
db.users.deleteMany({})
```

## 1.4 数据类型

MongoDB 支持以下数据类型：

- **String** - 字符串
- **Integer** - 整数（32位或64位）
- **Double** - 浮点数
- **Boolean** - 布尔值
- **Date** - 日期
- **ObjectId** - 对象ID（主键）
- **Array** - 数组
- **Object** - 嵌套文档
- **Null** - 空值
- **Binary Data** - 二进制数据
- **Code** - JavaScript 代码
- **Regular Expression** - 正则表达式

### 嵌套文档（Object）详解

嵌套文档是 MongoDB 的核心特性之一，允许在一个文档中嵌入另一个文档。这使得 MongoDB 可以表示复杂的数据结构，而无需使用多个集合和关联查询。

#### 什么是嵌套文档？

嵌套文档是指文档中的一个字段的值本身也是一个文档（对象）。这类似于关系型数据库中的 JOIN 操作，但在 MongoDB 中，相关数据可以直接存储在同一个文档中。

#### 创建嵌套文档

```javascript
// 基本嵌套文档
db.users.insertOne({
  name: "张三",
  age: 25,
  email: "zhangsan@example.com",
  address: {                    // 嵌套文档
    city: "北京",
    district: "朝阳区",
    street: "建国路88号",
    zipCode: "100020"
  }
})

// 多层嵌套文档
db.products.insertOne({
  name: "笔记本电脑",
  price: 5999,
  specifications: {             // 第一层嵌套
    cpu: "Intel i7",
    memory: "16GB",
    storage: {
      type: "SSD",              // 第二层嵌套
      capacity: "512GB"
    },
    display: {
      size: "15.6英寸",
      resolution: "1920x1080"
    }
  },
  warranty: {
    period: "2年",
    service: {
      type: "上门服务",
      coverage: "全国"
    }
  }
})

// 嵌套文档数组
db.users.insertOne({
  name: "李四",
  contacts: [                    // 数组中的嵌套文档
    {
      type: "phone",
      value: "13800138000",
      isPrimary: true
    },
    {
      type: "email",
      value: "lisi@example.com",
      isPrimary: false
    }
  ]
})
```

#### 查询嵌套文档

```javascript
// 查询包含特定嵌套字段的文档
db.users.find({ "address.city": "北京" })

// 查询嵌套文档的多个字段
db.users.find({
  "address.city": "北京",
  "address.district": "朝阳区"
})

// 使用点号访问嵌套字段（必须用引号）
db.users.find({ "address.zipCode": "100020" })

// 查询多层嵌套
db.products.find({ "specifications.storage.capacity": "512GB" })

// 查询嵌套文档数组
db.users.find({ "contacts.type": "phone" })

// 查询数组中的嵌套文档
db.users.find({
  "contacts": {
    $elemMatch: {
      type: "phone",
      isPrimary: true
    }
  }
})
```

#### 更新嵌套文档

```javascript
// 更新嵌套文档的字段
db.users.updateOne(
  { name: "张三" },
  { $set: { "address.city": "上海" } }
)

// 更新整个嵌套文档
db.users.updateOne(
  { name: "张三" },
  { 
    $set: { 
      address: {
        city: "上海",
        district: "浦东新区",
        street: "陆家嘴路100号",
        zipCode: "200120"
      }
    }
  }
)

// 更新多层嵌套文档
db.products.updateOne(
  { name: "笔记本电脑" },
  { $set: { "specifications.storage.capacity": "1TB" } }
)

// 在嵌套文档中添加新字段
db.users.updateOne(
  { name: "张三" },
  { $set: { "address.country": "中国" } }
)

// 删除嵌套文档字段
db.users.updateOne(
  { name: "张三" },
  { $unset: { "address.zipCode": "" } }
)
```

#### 嵌套文档的优势

1. **减少查询次数**：相关数据存储在一起，一次查询即可获取
2. **数据局部性**：相关数据物理上存储在一起，提高读取性能
3. **原子性操作**：嵌套文档的更新是原子的
4. **灵活性**：可以表示复杂的数据结构

#### 嵌套文档的注意事项

1. **文档大小限制**：MongoDB 文档最大为 16MB，嵌套文档也会计入此限制
2. **查询性能**：深度嵌套可能影响查询性能
3. **数据冗余**：如果嵌套数据需要频繁更新，可能导致数据冗余
4. **索引**：可以为嵌套字段创建索引

```javascript
// 为嵌套字段创建索引
db.users.createIndex({ "address.city": 1 })
db.users.createIndex({ "address.city": 1, "address.district": 1 })

// 查看索引
db.users.getIndexes()
```

#### 嵌套文档 vs 引用文档

**嵌套文档**（适合）：
- 数据关系紧密，经常一起查询
- 嵌套数据不会无限增长
- 嵌套数据不需要独立查询

**引用文档**（适合）：
- 数据关系松散，需要独立查询
- 数据可能无限增长（如评论）
- 需要跨文档查询和更新

```javascript
// 嵌套文档示例（适合）
db.users.insertOne({
  name: "张三",
  address: {              // 地址信息嵌套在用户文档中
    city: "北京",
    district: "朝阳区"
  }
})

// 引用文档示例（适合）
db.users.insertOne({
  name: "张三",
  addressId: ObjectId("...")  // 引用独立的地址文档
})

db.addresses.insertOne({
  _id: ObjectId("..."),
  city: "北京",
  district: "朝阳区"
})
```

## 1.5 在 Node.js 中连接 MongoDB

### 使用 Mongoose

```javascript
const mongoose = require('mongoose');

// 连接 MongoDB
mongoose.connect('mongodb://localhost:27017/mydb', {
  useNewUrlParser: true,
  useUnifiedTopology: true
});

// 监听连接事件
mongoose.connection.on('connected', () => {
  console.log('MongoDB 连接成功');
});

mongoose.connection.on('error', (err) => {
  console.error('MongoDB 连接错误:', err);
});

mongoose.connection.on('disconnected', () => {
  console.log('MongoDB 断开连接');
});
```

### 使用原生驱动

```javascript
const { MongoClient } = require('mongodb');

const uri = 'mongodb://localhost:27017';
const client = new MongoClient(uri);

async function connect() {
  try {
    await client.connect();
    console.log('连接成功');
    const db = client.db('mydb');
    return db;
  } catch (error) {
    console.error('连接失败:', error);
  }
}
```
