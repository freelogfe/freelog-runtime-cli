# 第四章：聚合管道

## 4.1 聚合管道简介

聚合管道是 MongoDB 中强大的数据处理工具，类似于 SQL 中的 GROUP BY、JOIN 等操作。

### 基本语法

```javascript
db.collection.aggregate([
  { $stage1: { ... } },
  { $stage2: { ... } },
  { $stage3: { ... } }
])
```

## 4.2 常用聚合阶段

### $match - 过滤文档

```javascript
// 类似于 find()
db.users.aggregate([
  { $match: { age: { $gte: 25 } } }
])
```

### $project - 字段投影和转换

```javascript
// 选择字段
db.users.aggregate([
  { $project: { name: 1, age: 1, _id: 0 } }
])

// 字段重命名
db.users.aggregate([
  { $project: { userName: "$name", userAge: "$age" } }
])

// 计算字段
db.users.aggregate([
  {
    $project: {
      name: 1,
      age: 1,
      birthYear: { $subtract: [2024, "$age"] }
    }
  }
])
```

### $group - 分组聚合

```javascript
// 按年龄分组，统计每组的数量
db.users.aggregate([
  { $group: { _id: "$age", count: { $sum: 1 } } }
])

// 按多个字段分组
db.users.aggregate([
  { $group: { _id: { age: "$age", city: "$address.city" }, count: { $sum: 1 } } }
])

// 分组统计
db.users.aggregate([
  {
    $group: {
      _id: "$age",
      count: { $sum: 1 },
      avgScore: { $avg: "$score" },
      maxScore: { $max: "$score" },
      minScore: { $min: "$score" },
      totalScore: { $sum: "$score" }
    }
  }
])
```

### $sort - 排序

```javascript
db.users.aggregate([
  { $sort: { age: 1, name: -1 } }
])
```

### $limit 和 $skip - 限制和跳过

```javascript
// 分页
db.users.aggregate([
  { $skip: 10 },
  { $limit: 10 }
])
```

### $unwind - 展开数组

```javascript
// 展开 hobbies 数组
db.users.aggregate([
  { $unwind: "$hobbies" }
])

// 保留空数组
db.users.aggregate([
  { $unwind: { path: "$hobbies", preserveNullAndEmptyArrays: true } }
])
```

### $lookup - 关联查询（类似 JOIN）

```javascript
// 关联 orders 集合
db.users.aggregate([
  {
    $lookup: {
      from: "orders",
      localField: "_id",
      foreignField: "userId",
      as: "orders"
    }
  }
])

// 关联后过滤
db.users.aggregate([
  {
    $lookup: {
      from: "orders",
      let: { userId: "$_id" },
      pipeline: [
        { $match: { $expr: { $eq: ["$userId", "$$userId"] } } },
        { $match: { status: "completed" } }
      ],
      as: "completedOrders"
    }
  }
])
```

### $addFields / $set - 添加字段

`$addFields` 是聚合管道的一个阶段，用于在聚合过程中**临时添加新字段**或**修改现有字段**。`$set` 是 `$addFields` 的别名，在聚合管道中功能完全相同。

**⚠️ 重要说明**：
- `$addFields` **不会修改数据库中的原文档**
- 它只是在聚合管道中临时添加字段，只在查询结果中可见
- 原文档保持不变，字段只存在于聚合结果中
- 如果要在数据库中真正添加字段，需要使用更新操作（如 `updateMany` 配合 `$set`）

**基本语法**：

```javascript
db.users.aggregate([
  {
    $addFields: {
      新字段名: 字段值或表达式,
      另一个字段: 另一个值
    }
  }
])
```

**工作原理**：
- 如果字段已存在，会在结果中**覆盖**原值（但原文档不变）
- 如果字段不存在，会在结果中**创建**新字段（但原文档不变）
- 可以使用表达式计算字段值
- **原文档不会被修改**，字段只存在于聚合结果中

**示例对比**：

```javascript
// 原始数据
db.users.insertOne({ name: "张三", hobbies: ["读书", "游泳", "编程"] })

// 使用 $addFields（聚合管道）
db.users.aggregate([
  {
    $addFields: {
      hobbiesCount: { $size: "$hobbies" }
    }
  }
])
// 查询结果：{ name: "张三", hobbies: [...], hobbiesCount: 3 }
// ⚠️ 数据库中的原文档仍然是：{ name: "张三", hobbies: [...] }
// hobbiesCount 只存在于查询结果中

// 验证：查询原文档
db.users.findOne({ name: "张三" })
// 结果：{ name: "张三", hobbies: [...] }  // 没有 hobbiesCount

// 如果要在数据库中真正添加字段，使用更新操作
db.users.updateMany(
  {},
  [
    {
      $set: {
        hobbiesCount: { $size: "$hobbies" }  // MongoDB 4.2+ 支持表达式
      }
    }
  ]
)
// ✅ 现在数据库中的文档被真正修改了
db.users.findOne({ name: "张三" })
// 结果：{ name: "张三", hobbies: [...], hobbiesCount: 3 }
```

**基本示例**：

```javascript
// 添加计算字段
db.users.aggregate([
  {
    $addFields: {
      fullName: { $concat: ["$firstName", " ", "$lastName"] },
      isAdult: { $gte: ["$age", 18] }
    }
  }
])

// 示例数据
db.users.insertMany([
  { firstName: "张", lastName: "三", age: 25 },
  { firstName: "李", lastName: "四", age: 17 }
])

// 结果：
// { firstName: "张", lastName: "三", age: 25, fullName: "张 三", isAdult: true }
// { firstName: "李", lastName: "四", age: 17, fullName: "李 四", isAdult: false }
```

**常用表达式示例**：

```javascript
// 1. 计算数组长度
db.users.aggregate([
  {
    $addFields: {
      hobbiesCount: { $size: "$hobbies" }
    }
  }
])

// 2. 字符串拼接
db.users.aggregate([
  {
    $addFields: {
      fullName: { $concat: ["$firstName", " ", "$lastName"] },
      emailDomain: { $substr: ["$email", { $indexOfBytes: ["$email", "@"] }, -1] }
    }
  }
])

// 3. 数学运算
db.orders.aggregate([
  {
    $addFields: {
      totalPrice: { $multiply: ["$price", "$quantity"] },
      discountPrice: { $subtract: ["$price", "$discount"] },
      taxAmount: { $multiply: ["$price", 0.1] }
    }
  }
])

// 4. 条件判断
db.students.aggregate([
  {
    $addFields: {
      isAdult: { $gte: ["$age", 18] },
      grade: {
        $cond: {
          if: { $gte: ["$score", 90] },
          then: "A",
          else: {
            $cond: {
              if: { $gte: ["$score", 80] },
              then: "B",
              else: "C"
            }
          }
        }
      }
    }
  }
])

// 5. 修改现有字段
db.users.aggregate([
  {
    $addFields: {
      age: { $add: ["$age", 1] }  // 年龄加1
    }
  }
])

// 6. 嵌套字段操作
db.users.aggregate([
  {
    $addFields: {
      "address.fullAddress": {
        $concat: [
          "$address.city",
          "$address.district",
          "$address.street"
        ]
      }
    }
  }
])

// 7. 数组操作
db.users.aggregate([
  {
    $addFields: {
      firstHobby: { $arrayElemAt: ["$hobbies", 0] },
      lastHobby: { $arrayElemAt: ["$hobbies", -1] },
      hobbiesCount: { $size: "$hobbies" }
    }
  }
])
```

**$addFields vs $project**：

| 特性 | $addFields | $project |
|------|------------|----------|
| 保留其他字段 | ✅ 是 | ❌ 否（除非显式指定） |
| 添加新字段 | ✅ 是 | ✅ 是 |
| 修改现有字段 | ✅ 是 | ✅ 是 |
| 修改数据库 | ❌ 否（只在结果中临时添加） | ❌ 否（只在结果中临时添加） |
| 用途 | 添加字段，保留所有字段 | 选择字段，排除其他字段 |

**⚠️ 重要：聚合管道不修改数据库**

```javascript
// $addFields：保留所有字段，添加新字段
db.users.aggregate([
  {
    $addFields: {
      fullName: { $concat: ["$firstName", " ", "$lastName"] }
    }
  }
])
// 结果：包含所有原字段 + fullName
// ⚠️ 数据库中的原文档不变

// $project：只返回指定字段
db.users.aggregate([
  {
    $project: {
      firstName: 1,
      lastName: 1,
      fullName: { $concat: ["$firstName", " ", "$lastName"] }
    }
  }
])
// 结果：只包含 firstName、lastName、fullName
// ⚠️ 数据库中的原文档不变
```

**聚合管道 vs 更新操作**：

```javascript
// 聚合管道：不修改数据库，只在结果中临时添加字段
db.users.aggregate([
  { $addFields: { hobbiesCount: { $size: "$hobbies" } } }
])
// ✅ 查询结果包含 hobbiesCount
// ❌ 数据库中的原文档不变

// 更新操作：真正修改数据库（MongoDB 4.2+）
db.users.updateMany(
  {},
  [
    {
      $set: {
        hobbiesCount: { $size: "$hobbies" }
      }
    }
  ]
)
// ✅ 数据库中的文档被真正修改，添加了 hobbiesCount 字段
```

```javascript
// $addFields：保留所有字段，添加新字段
db.users.aggregate([
  {
    $addFields: {
      fullName: { $concat: ["$firstName", " ", "$lastName"] }
    }
  }
])
// 结果：包含所有原字段 + fullName

// $project：只返回指定字段
db.users.aggregate([
  {
    $project: {
      firstName: 1,
      lastName: 1,
      fullName: { $concat: ["$firstName", " ", "$lastName"] }
    }
  }
])
// 结果：只包含 firstName、lastName、fullName
```

**实际应用场景**：

```javascript
// 场景1：计算数组大小并过滤
db.users.aggregate([
  { $match: { hobbies: { $all: ["读书", "游泳"] } } },
  { $addFields: { hobbiesCount: { $size: "$hobbies" } } },
  { $match: { hobbiesCount: { $gte: 3 } } }
])

// 场景2：计算订单总价
db.orders.aggregate([
  {
    $addFields: {
      totalAmount: {
        $reduce: {
          input: "$items",
          initialValue: 0,
          in: {
            $add: [
              "$$value",
              { $multiply: ["$$this.price", "$$this.quantity"] }
            ]
          }
        }
      }
    }
  }
])

// 场景3：添加状态字段
db.orders.aggregate([
  {
    $addFields: {
      status: {
        $switch: {
          branches: [
            { case: { $eq: ["$paid", true] }, then: "已支付" },
            { case: { $eq: ["$shipped", true] }, then: "已发货" }
          ],
          default: "待处理"
        }
      }
    }
  }
])
```

### $facet - 多管道处理

```javascript
// 同时执行多个聚合管道
db.users.aggregate([
  {
    $facet: {
      "byAge": [
        { $group: { _id: "$age", count: { $sum: 1 } } }
      ],
      "byCity": [
        { $group: { _id: "$address.city", count: { $sum: 1 } } }
      ],
      "topScores": [
        { $sort: { score: -1 } },
        { $limit: 10 }
      ]
    }
  }
])
```

## 4.3 聚合操作符

### 算术操作符

```javascript
{
  $add: [1, 2, 3],           // 加法
  $subtract: [10, 5],        // 减法
  $multiply: [2, 3],         // 乘法
  $divide: [10, 2],          // 除法
  $mod: [10, 3],             // 取模
  $abs: -5,                  // 绝对值
  $ceil: 2.3,                // 向上取整
  $floor: 2.7,               // 向下取整
  $round: [2.5, 0]           // 四舍五入
}
```

### 比较操作符

```javascript
{
  $eq: ["$age", 25],
  $ne: ["$age", 25],
  $gt: ["$age", 25],
  $gte: ["$age", 25],
  $lt: ["$age", 25],
  $lte: ["$age", 25],
  $cmp: ["$a", "$b"]  // 返回 -1, 0, 1
}
```

### 逻辑操作符

```javascript
{
  $and: [{ $gt: ["$age", 18] }, { $lt: ["$age", 65] }],
  $or: [{ $eq: ["$status", "active"] }, { $eq: ["$status", "pending"] }],
  $not: { $gt: ["$age", 65] }
}
```

### 字符串操作符

```javascript
{
  $concat: ["$firstName", " ", "$lastName"],
  $substr: ["$name", 0, 3],
  $toLower: "$name",
  $toUpper: "$name",
  $strLenCP: "$name",
  $indexOfBytes: ["$name", "张"]
}
```

### 日期操作符

```javascript
{
  $year: "$createdAt",
  $month: "$createdAt",
  $dayOfMonth: "$createdAt",
  $dayOfWeek: "$createdAt",
  $hour: "$createdAt",
  $minute: "$createdAt",
  $second: "$createdAt",
  $dateToString: {
    format: "%Y-%m-%d",
    date: "$createdAt"
  }
}
```

### 条件操作符

```javascript
// $cond - 三元运算符
{
  $cond: {
    if: { $gte: ["$age", 18] },
    then: "adult",
    else: "minor"
  }
}

// $ifNull - 如果为 null 则使用默认值
{
  $ifNull: ["$email", "unknown@example.com"]
}

// $switch - 多条件判断
{
  $switch: {
    branches: [
      { case: { $lt: ["$score", 60] }, then: "F" },
      { case: { $lt: ["$score", 70] }, then: "D" },
      { case: { $lt: ["$score", 80] }, then: "C" },
      { case: { $lt: ["$score", 90] }, then: "B" }
    ],
    default: "A"
  }
}
```

### 数组操作符

```javascript
{
  $size: "$hobbies",                    // 数组长度
  $arrayElemAt: ["$hobbies", 0],        // 获取数组元素
  $slice: ["$hobbies", 0, 2],          // 数组切片
  $concatArrays: ["$arr1", "$arr2"],    // 合并数组
  $filter: {                            // 过滤数组
    input: "$hobbies",
    as: "hobby",
    cond: { $ne: ["$$hobby", "读书"] }
  },
  $map: {                               // 映射数组
    input: "$scores",
    as: "score",
    in: { $multiply: ["$$score", 2] }
  }
}
```

### 案例 1：统计用户年龄分布

```javascript
db.users.aggregate([
  {
    $group: {
      _id: {
        $switch: {
          branches: [
            { case: { $lt: ["$age", 20] }, then: "0-19" },
            { case: { $lt: ["$age", 30] }, then: "20-29" },
            { case: { $lt: ["$age", 40] }, then: "30-39" },

        }
      },

    }
  },
  { $sort: { _id: 1 } }
])
```

```javascript
      as: "activities"

  },
  {
    $addFields: {
```

### 案例 3：时间序列分析

```javascript
db.orders.aggregate([
  {
    $match: {
      createdAt: {
        $gte: ISODate("2024-01-01"),
        $lt: ISODate("2024-02-01")

  },

    $group: {
      _id: {
```

## 4.5 性能优化

### 1. 尽早使用 $match

```javascript
// ✅ 好：先过滤再处理
db.users.aggregate([
  { $match: { age: { $gte: 25 } } },
  { $group: { ... } }
])

// ❌ 差：先处理再过滤
db.users.aggregate([
  { $group: { ... } },
  { $match: { age: { $gte: 25 } } }
])
```

### 2. 使用索引

```javascript
// 为聚合管道中的 $match 字段创建索引
db.users.createIndex({ age: 1, createdAt: 1 })
```

### 3. 限制中间结果

```javascript
// 使用 $limit 减少处理的数据量
db.users.aggregate([
  { $match: { ... } },
  { $limit: 1000 },
  { $group: { ... } }
])
```

### 4. 使用 $project 减少字段

```javascript
// 只保留需要的字段
db.users.aggregate([
  { $project: { name: 1, age: 1 } },
  { $group: { ... } }
])
```
