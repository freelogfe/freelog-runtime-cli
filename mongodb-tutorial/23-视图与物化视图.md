# 第二十三章：MongoDB 视图与物化视图

## 23.1 视图（Views）基础

### 什么是视图？

视图是基于聚合管道的只读集合，不存储数据，每次查询时动态计算。

### 视图特性

- ✅ **只读**：不能直接写入视图
- ✅ **动态计算**：基于聚合管道实时计算
- ✅ **简化查询**：封装复杂查询逻辑
- ✅ **权限控制**：可以单独设置视图权限

## 23.2 创建视图

### 基本语法

```javascript
// 创建视图
db.createView(
  "viewName",           // 视图名称
  "sourceCollection",  // 源集合
  [                    // 聚合管道
    { $match: { ... } },
    { $project: { ... } },
    { $group: { ... } }
  ]
)
```

### 简单视图示例

```javascript
// 创建活跃用户视图
db.createView(
  "activeUsers",
  "users",
  [
    { $match: { status: "active" } },
    { $project: { name: 1, email: 1, createdAt: 1 } }
  ]
)

// 使用视图
db.activeUsers.find()
db.activeUsers.find({ name: /张/ })
```

### 复杂视图示例

```javascript
// 创建用户统计视图
db.createView(
  "userStats",
  "users",
  [
    {
      $group: {
        _id: "$status",
        count: { $sum: 1 },
        avgAge: { $avg: "$age" }
      }
    },
    {
      $project: {
        status: "$_id",
        count: 1,
        avgAge: { $round: ["$avgAge", 2] },
        _id: 0
      }
    }
  ]
)

// 查询视图
db.userStats.find()
```

## 23.3 视图操作

### 查看视图

```javascript
// 查看所有视图
db.getCollectionInfos({ type: "view" })

// 查看视图定义
db.getCollectionInfos({ name: "activeUsers" })

// 查看视图统计
db.activeUsers.stats()
```

### 修改视图

```javascript
// MongoDB 不支持直接修改视图，需要删除后重建
db.activeUsers.drop()

// 重新创建视图
db.createView(
  "activeUsers",
  "users",
  [
    { $match: { status: "active", age: { $gte: 18 } } },
    { $project: { name: 1, email: 1 } }
  ]
)
```

### 删除视图

```javascript
// 删除视图
db.activeUsers.drop()
```

## 23.4 视图查询

### 基本查询

```javascript
// 视图支持所有查询操作
db.activeUsers.find()
db.activeUsers.findOne({ name: "张三" })
db.activeUsers.countDocuments()
db.activeUsers.distinct("email")
```

### 聚合查询

```javascript
// 视图可以进一步聚合
db.activeUsers.aggregate([
  { $group: { _id: "$status", count: { $sum: 1 } } }
])
```

### 索引使用

```javascript
// 视图可以使用源集合的索引
// 如果视图的 $match 阶段匹配索引字段，可以使用索引

// 源集合索引
db.users.createIndex({ status: 1, age: 1 })

// 视图查询可以使用索引
db.activeUsers.find({ age: { $gte: 18 } })  // 可以使用索引
```

## 23.5 物化视图（Materialized Views）

### 什么是物化视图？

物化视图是存储计算结果的实际集合，需要定期刷新。

### 创建物化视图

```javascript
// 方法 1：使用定时任务更新
// 创建物化视图集合
db.userStatsMaterialized.insertOne({
  _id: "stats",
  activeCount: 0,
  inactiveCount: 0,
  lastUpdated: new Date()
})

// 定时更新函数
function updateMaterializedView() {
  const stats = db.users.aggregate([
    {
      $group: {
        _id: "$status",
        count: { $sum: 1 }
      }
    }
  ]).toArray();
  
  const activeCount = stats.find(s => s._id === "active")?.count || 0;
  const inactiveCount = stats.find(s => s._id === "inactive")?.count || 0;
  
  db.userStatsMaterialized.updateOne(
    { _id: "stats" },
    {
      $set: {
        activeCount,
        inactiveCount,
        lastUpdated: new Date()
      }
    },
    { upsert: true }
  );
}

// 定时执行（使用 cron 或应用层定时任务）
```

### 使用变更流更新物化视图

```typescript
// 使用变更流自动更新物化视图
async function createMaterializedView() {
  const changeStream = User.watch();
  
  changeStream.on('change', async (change) => {
    // 根据变更更新物化视图
    if (change.operationType === 'insert') {
      await updateStats('increment', change.fullDocument.status);
    } else if (change.operationType === 'update') {
      const oldStatus = await getOldStatus(change.documentKey._id);
      const newStatus = change.updateDescription?.updatedFields?.status;
      
      if (oldStatus !== newStatus) {
        await updateStats('decrement', oldStatus);
        await updateStats('increment', newStatus);
      }
    } else if (change.operationType === 'delete') {
      await updateStats('decrement', change.fullDocument?.status);
    }
  });
}

async function updateStats(operation: string, status: string) {
  const field = `${status}Count`;
  const update = operation === 'increment' ? { $inc: { [field]: 1 } } : { $inc: { [field]: -1 } };
  
  await UserStatsMaterialized.updateOne(
    { _id: 'stats' },
    { ...update, $set: { lastUpdated: new Date() } },
    { upsert: true }
  );
}
```

## 23.6 实际应用场景

### 场景 1：报表视图

```javascript
// 创建销售报表视图
db.createView(
  "salesReport",
  "orders",
  [
    {
      $match: {
        status: "completed",
        createdAt: { $gte: new Date("2024-01-01") }
      }
    },
    {
      $group: {
        _id: {
          year: { $year: "$createdAt" },
          month: { $month: "$createdAt" }
        },
        totalSales: { $sum: "$amount" },
        orderCount: { $sum: 1 },
        avgOrderValue: { $avg: "$amount" }
      }
    },
    {
      $sort: { "_id.year": 1, "_id.month": 1 }
    }
  ]
)

// 查询报表
db.salesReport.find()
```

### 场景 2：用户活动视图

```javascript
// 创建用户活动视图
db.createView(
  "userActivity",
  "activities",
  [
    {
      $lookup: {
        from: "users",
        localField: "userId",
        foreignField: "_id",
        as: "user"
      }
    },
    { $unwind: "$user" },
    {
      $project: {
        userId: 1,
        userName: "$user.name",
        action: 1,
        timestamp: 1
      }
    },
    { $sort: { timestamp: -1 } }
  ]
)
```

### 场景 3：数据汇总视图

```javascript
// 创建产品统计视图
db.createView(
  "productStats",
  "orders",
  [
    { $unwind: "$items" },
    {
      $group: {
        _id: "$items.productId",
        totalSold: { $sum: "$items.quantity" },
        totalRevenue: { $sum: { $multiply: ["$items.quantity", "$items.price"] } },
        orderCount: { $sum: 1 }
      }
    },
    {
      $lookup: {
        from: "products",
        localField: "_id",
        foreignField: "_id",
        as: "product"
      }
    },
    { $unwind: "$product" },
    {
      $project: {
        productName: "$product.name",
        totalSold: 1,
        totalRevenue: 1,
        orderCount: 1
      }
    }
  ]
)
```

## 23.7 性能考虑

### 视图性能

```javascript
// ⚠️ 注意：视图每次查询都会执行聚合管道
// 对于复杂视图，考虑使用物化视图

// ❌ 差：复杂视图频繁查询
db.complexView.find()  // 每次都要执行复杂聚合

// ✅ 好：使用物化视图
db.materializedView.find()  // 直接查询预计算结果
```

### 索引优化

```javascript
// ✅ 好：为源集合创建合适的索引
db.users.createIndex({ status: 1, age: 1 })

// 视图查询可以使用索引
db.activeUsers.find({ age: { $gte: 18 } })
```

## 23.8 最佳实践

### 1. 视图命名

```javascript
// ✅ 好：使用清晰的命名
db.createView("activeUsers", "users", [...])
db.createView("userStats", "users", [...])

// ❌ 差：命名不清晰
db.createView("view1", "users", [...])
```

### 2. 视图文档化

```javascript
// ✅ 好：记录视图用途和逻辑
// 视图：activeUsers
// 用途：显示活跃用户列表
// 逻辑：status = "active" 且 age >= 18
db.createView("activeUsers", "users", [
  { $match: { status: "active", age: { $gte: 18 } } }
])
```

### 3. 性能监控

```javascript
// ✅ 好：监控视图查询性能
db.activeUsers.find().explain("executionStats")
```
