# 前端页面使用说明

## 📁 文件结构

前端页面位于 `public/` 目录：

```
public/
├── index.html    # 主页面
├── style.css     # 样式文件
└── app.js        # JavaScript 逻辑
```

## 🚀 使用方法

### 1. 安装静态文件服务依赖

```bash
npm install @nestjs/serve-static
```

### 2. 启动后端服务

```bash
npm run start:dev
```

### 3. 访问前端页面

在浏览器中打开：
```
http://localhost:3000
```

## ✨ 功能特性

### 1. Todo 列表展示
- 显示所有 Todo 项
- 支持筛选（全部/待完成/已完成）
- 支持按优先级筛选
- 支持搜索功能

### 2. 创建 Todo
- 标题（必填）
- 描述（可选）
- 优先级（低/中/高）
- 到期日期（可选）
- 标签（可选，用逗号分隔）

### 3. 编辑 Todo
- 修改所有字段
- 切换完成状态
- 更新标签

### 4. 删除 Todo
- 软删除（可恢复）
- 确认对话框

### 5. 统计信息
- 总数
- 已完成数量
- 待完成数量
- 完成率

## 🎨 界面特点

- ✅ 现代化设计
- ✅ 响应式布局（支持移动端）
- ✅ 实时更新
- ✅ 友好的用户交互

## 🔧 配置

### 修改 API 地址

如果后端运行在不同的端口，编辑 `public/app.js`：

```javascript
const API_BASE_URL = 'http://localhost:3000/api';
```

### 修改默认用户 ID

编辑 `public/index.html`：

```html
<input type="text" id="userId" value="user001" placeholder="输入用户 ID">
```

## 📱 响应式设计

页面支持：
- 桌面端（> 768px）
- 平板端（768px）
- 移动端（< 768px）

## 🐛 故障排除

### 1. 页面无法加载

- 确认后端服务已启动
- 检查端口是否正确（默认 3000）
- 检查浏览器控制台错误信息

### 2. API 请求失败

- 确认后端 API 正常运行
- 检查 CORS 配置
- 检查网络连接

### 3. 样式显示异常

- 清除浏览器缓存
- 检查 CSS 文件是否正确加载
