# 平台基础概念（速查）

## 角色

| 角色 | 说明 |
|------|------|
| 资源作者 | 创建并发行数字资源，制定授权策略 |
| 节点商 | 将资源签约为展品，面向消费者推广 |
| 资源消费者 | 通过节点获取资源授权并访问 |

## 资源

平台上的数字商品（小说、图片、主题、插件等），由以下信息组成：

- **资源授权标识**（`resourceName`）：创建后不可修改
- **资源类型**：创建时选定，不可修改
- **版本**：同一资源可发布多个版本，便于增量更新
- **授权策略**：上架前必须至少一条启用策略
- **状态**：待发行 / 上架 / 下架

## 发行方式

| 方式 | 控制台 | CLI |
|------|--------|-----|
| 单品 | creator 四步向导 | `create` → `publish` → `policy` → `online` |
| 批量 | creatorBatch | `batch init/create/publish` |
| 合集 | collectionCreator | `collection` + `batch` |

## 与 CLI 配置的对应

| 平台概念 | CLI 配置字段 |
|---------|-------------|
| 资源条目 | `freelog.resource.config` → `resourceId` |
| 资源版本 | `freelog.version.config` → `version` / `versionId` |
| 依赖声明 | `freelog.version.config` → `dependencies` |
| 合集 | `freelog.collection.config` → `items` |

更多 Web 操作细节见 [Freelog 帮助中心](https://www.freelog.cn/help)。
