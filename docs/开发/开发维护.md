## 本地开发

### 环境

- Node.js ≥ 20
- pnpm ≥ 8，在**仓根**执行命令

| 环境变量 | 说明 |
|---------|------|
| `FREELOG_ENV=development` | 等同 `--test`，访问测试网 API |
| `FREELOG_AUTH_PATH_GLOBAL` | 覆盖全局认证文件路径 |
| `FREELOG_AUTH_PATH_WORKSPACE` | 覆盖工作区认证文件路径 |

### 启动

```bash
pnpm install
pnpm --filter @freelog-cli/cli build
pnpm --filter @freelog-cli/cli link --global   # Windows 可能需管理员
freelog-cli --test login
```

开发 watch：

```bash
pnpm --filter @freelog-cli/cli dev
```

### 目录

- `packages/cli/src/commands/` — 命令
- `packages/cli/src/services/` — 业务
- `packages/cli/src/platform/` — `@freelog/tools-lib` 装载与 Request patch
- `packages/templates/*` — 脚手架模板包

### 排障

| 问题 | 处理 |
|------|------|
| 未登录 | 重新 `freelog-cli login` |
| API 报错 | 看返回的 `msg` / JSON `--json` |
| 命令不生效 | 确认 `pnpm --filter @freelog-cli/cli build` 后 `dist/` 最新 |

---

## 发布 npm 包

```bash
pnpm --filter @freelog-cli/cli check:compat
pnpm --filter @freelog-cli/cli build
pnpm --filter @freelog-cli/cli publish
```

模板包：在 `packages/templates/<id>` 执行 `pnpm pub`（或 Changesets 流程，见 [新方案 README](../新方案/README.md)）。
