# S03 · 前端库 / 软件库发布

> **文档角色：** package 类资源的模板、namespace、资源类型和打包发布体验设计。总规则见 [../02-CLI体验拓扑设计.md](../02-CLI体验拓扑设计.md)。

最后更新：2026-08-28

---

## 1. 用户目标

用户要发布一个可复用前端库或软件库，例如 JS 工具包、React/Vue 组件库。它和主题/插件一样是工程型资源，但它不需要 runtimeVersion；它需要 package 模板、namespace、构建产物和目录打包。

---

## 2. 资源类型与模板映射

package 入口不能“随便搜一个类型”。模板选择会影响平台 leaf 类型：

| 用户选择 | 模板 | 期望平台 leaf | 说明 |
|---|---|---|---|
| JS 工具包 | `package-js` | `JS工具包` | 普通 JS library |
| React 组件库 | `package-react` | `组件库` | package 模板声明 React 技术栈 |
| Vue 组件库 | `package-vue` | `组件库` | package 模板声明 Vue 技术栈 |

如果当前环境的类型树没有对应 leaf，CLI 必须停止并提示显式 `--resource-type <code>` 或联系平台配置；不得自动写死旧 code。

---

## 3. Console 对齐点

| Console 业务 | CLI 必须对齐的结果 |
|---|---|
| creator Step1 类型 | 最终必须是有效 leaf 类型 |
| creator Step1 标题/name | 同资源创建约束 |
| creator Step2 本地文件 | 发布 dist zip，受类型能力限制 |
| version payload | description、属性、依赖、authExcluded、batchSign 规则同 createVersion |
| sidebar 维护 | 已发版维护只能改 Console 允许字段 |

namespace 是 CLI 模板/包名能力，不是 Console 字段；它的校验和错误文案必须和资源标题/name 分开。

---

## 4. TTY 连续向导

| checkpoint | 用户看到 | 输入 | 副作用 | 失败处理 |
|---|---|---|---|---|
| P1 选择 package | “发布前端库/软件库” | package | 无 | 返回主菜单 |
| P2 选择模板 | JS/React/Vue | 模板 id | 无 | 不兼容提示换模板 |
| P3 类型定稿 | 模板对应 leaf 类型路径/code | 确认 | 无 | 多候选继续选择 |
| P4 namespace | 包命名空间 | 文本 | 写 manifest/template 文件 | namespace 错误只提示包约束 |
| P5 资源字段 | title/name/version | 文本 | 写 manifest | Console 字段同源校验 |
| P6 构建与发布 | dist zip preflight | confirm | 写平台/state | 版本冲突/依赖授权按通用处理 |

## 5. AI/CI 等价命令

```bash
freelog-cli init package ./my-lib --template package-react --namespace my-scope --env <env>
cd ./my-lib
pnpm install && pnpm build
freelog-cli create --yes --env <env>
freelog-cli publish --bump patch --yes --env <env>
```

---

## 6. 常见情况处理

| 情况 | 处理 |
|---|---|
| package leaf 多个 | 模板优先缩小；仍多个则 TTY 选 leaf，非 TTY 失败 |
| namespace 缺失 | TTY prompt；非 TTY code 4 |
| 用户把组件库当插件 | 文案解释：插件是运行时资源；组件库是 package 资源 |
| dist 未构建 | 停在本地阶段 |
| 环境未签字 | 设计不降级；验证报告记录 ENV 缺口 |

---

## 7. 回归到总设计

package 场景要求：

- 模板到平台 leaf 的映射必须是集中规则；
- package 不需要 runtimeVersion；
- namespace 是 CLI-native 字段；
- public help 不能把 package 藏成 theme/widget 的变体。
