# S07 · 批量本地目录发布

> **文档角色：** 本地目录内多个文件批量创建/发布为多个独立资源的体验设计。总规则见 [../02-CLI体验拓扑设计.md](../02-CLI体验拓扑设计.md)。

最后更新：2026-08-31

---

## 1. 用户目标

用户有一批素材，想批量变成 Freelog 独立资源。CLI 要比 Console 更适合长任务：可预览、可中断、可恢复、可给 AI/CI 消费。

---

## 2. 不是 init

批量目录发布不应该让用户先手动创建 N 个工程。入口是：

```text
resource import-dir <dir>
  → 扫描
  → 预览
  → 分批创建/发布
  → report
```

---

## 3. Console 对齐点

| Console creatorBatch | CLI 对齐 |
|---|---|
| 单批最多 20 文件 | CLI 可自动分批；strict 模式复刻 20 |
| 文件 Task 成功/失败 | 每项独立记录阶段和错误 |
| 标题默认文件名 | prepare 阶段展示最终 title |
| 授权标识生成和查重 | 批内去重 + 平台查重 |
| 无策略确认 | TTY preflight；非 TTY 必须 `--yes` |

---

## 4. TTY 连续向导

| checkpoint | 用户看到 | 输入 | 副作用 | 失败处理 |
|---|---|---|---|---|
| B1 选择目录 | “批量发布目录里的文件” | 目录路径 | 无 | 目录不存在重新选 |
| B2 扫描规则 | `.freelogignore`、强制排除、递归规则 | confirm | 无 | 敏感文件强制排除 |
| B3 类型策略 | 统一类型或逐项配置 | leaf/type config | 无或写 batch config | 混类型未声明则停 |
| B4 预览 | 将处理/跳过/拒绝数量、批次数 | confirm | 无 | 用户可导出配置修改 |
| B5 执行 | 每项 create/publish/online 阶段 | 等待 | 写平台、子工程、report | 部分失败继续记录 |
| B6 完成 | 成功/失败/unknown 汇总 | 选择 retry/resume/退出 | 看选择 | unknown 不自动 retry |

---

## 5. AI/CI 等价命令

```bash
freelog-cli resource import-dir ./assets --resource-type <leaf-code> --yes --env <env> --json-lines
freelog-cli resource import-dir --retry .freelog/reports/<run>.json --yes --env <env> --json-lines
freelog-cli resource import-dir --resume .freelog/reports/<run>.json --yes --env <env> --json
```

---

## 6. 常见情况处理

| 情况 | 处理 |
|---|---|
| 目录为空 | 停止，不生成空 report |
| 文件超过 Console 单批限制 | 自动分批；strict 模式阻止并提示最多 20 |
| 部分文件类型不匹配 | strict 模式阻止；宽松模式 skip 并写 report |
| 同名资源冲突 | prepare 阶段展示新 name 或要求用户处理 |
| 平台写入后网络中断 | 标记 `remote_outcome_unknown`，不自动重试 |
| 用户想把结果做合集 | 成功页引导进入 S08，不在批量流程里伪装成合集 |

### 6.1 恢复状态

| 状态 | 用户解释 | 自动能力 |
|---|---|---|
| `passed` | 该项完成 | 不重复执行 |
| `failed` | 平台明确未完成或本地明确失败 | 可 `--retry` |
| `remote_succeeded_local_pending` | 远端成功，本地还没补齐 | 可 `--resume` |
| `remote_outcome_unknown` | 网络断在危险窗口，无法判断平台是否成功 | 停止，要求人工对账 |
| `skipped` | 按规则跳过 | 不计成功、不重试 |

---

## 7. 回归到总设计

批量场景要求：

- 长任务必须有 NDJSON；
- report 是产品能力，不是调试日志；
- 成功/失败/unknown 不能混成一个“失败列表”。
