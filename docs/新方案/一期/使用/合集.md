# 合集

[返回使用文档目录](./README.md)

合集用于把多个已经发行的资源按目录顺序共同展示。把一个媒体文件夹做成合集时，CLI 会先为每个文件创建独立子资源，再将它们加入合集目录草稿；不会把整个文件夹压缩成一个合集文件。

## 从文件夹创建合集工程

```bash
freelog-cli collection init-from-folder --project-dir photo-album --media-dir ./photos --yes --env <env>
```

交互流程会选择合集类型、创建合集工程和平台合集，并导入媒体文件。命令完成后仍需在合集项目目录中发行合集版本、配置合集策略并上架。

## 分步创建

```bash
freelog-cli init photo-album --scaffold collection --resource-type <collectionTypeCode> --yes --env <env>
cd photo-album
freelog-cli collection create --yes --env <env>
freelog-cli collection item import-dir ../photos --resource-type <imageTypeCode> --title-prefix "照片 " --yes --env <env>
freelog-cli collection version set --description "首版合集" --env <env>
freelog-cli collection publish --yes --env <env>
freelog-cli collection policy template list --env <env>
freelog-cli collection policy template apply <templateId> --yes --env <env>
freelog-cli online --yes --env <env>
```

也可以为媒体目录准备 `freelog.batch.json`：

```bash
freelog-cli collection item import-dir ../photos --config ../photos/freelog.batch.json --yes --env <env>
```

## 子资源要求

加入合集目录前，子资源必须：

1. 已有正式版本。
2. 至少有一条启用策略。
3. 已上架。
4. 其基础上抛资源已在当前合集下完成授权。

`--item-policy-file` 是高级/批量入口，可为本次导入的新子资源统一应用策略文件。普通交互路径优先进入每个子资源目录使用 `policy template list/apply`，或在 Console 中处理后再加入合集。

大量目录项会分批写入目录草稿。中途失败不会删除已创建的子工程；修复问题后重新执行同一导入命令，已经存在于草稿中的条目会跳过。

## 维护目录草稿

```bash
freelog-cli collection item add <resourceId> --title "章节名" --yes --env <env>
freelog-cli collection item add ./child-project --yes --env <env>
freelog-cli collection item update <itemId> --title "新标题" --yes --env <env>
freelog-cli collection item remove <itemId> --yes --env <env>
freelog-cli collection item reorder --order-file order.json --yes --env <env>
freelog-cli collection item reorder --sort-field itemTitle --sort-type 1 --yes --env <env>
```

这些命令修改的是合集目录草稿。只有执行 `collection publish`，目录变化才会进入正式合集版本。

目录项需要授权排除时：

```bash
freelog-cli collection item add <resourceId> --auth-excluded-file auth-excluded.yaml --yes --env <env>
```

`auth-excluded.yaml` 是数组，每项包含 `resourceId`、`excludedType` 和 `excludedValue`。

## 更新合集信息和展示

```bash
freelog-cli collection update --title "新合集标题" --intro "合集简介" --tags "图片,精选" --yes --env <env>
freelog-cli collection update --display-sort asc --display-view card --display-image show --yes --env <env>
```

可用展示值以 `freelog-cli collection update --help` 为准。listing 更新和目录发布是两种独立操作。

## 高级维护

```bash
freelog-cli collection properties sync --yes --env <env>
freelog-cli collection properties sync --dry-run --yes --env <env>
freelog-cli collection logs --skip 0 --limit 20 --env <env>
freelog-cli collection publish --dry-run --env <env>
```

`collection publish --dry-run` 只输出计划请求，不修改平台。RSS 和自动收录见[特殊流程](./特殊流程.md)。
