## 方法

1. **Evidence** — 直接来自代码、脚本、文档的可引用事实  
2. **Inference** — 由多条 Evidence 推出的结论（标注置信度）  
3. **Unknown** — 仓库证据不足以判定  

发现项编号：`F-001`…；严重度：**P0**（Agent/安全）→ **P3**（低影响债务）。

---

## 与验证目录的关系

```text
验证/reports/     → 某日期某 commit 的 PASS/FAIL/SKIP 证据
审计/             → 跨时间的结构性问题与文档/代码落差
对齐/             → 能力矩阵与 Console 契约（审计对照真源之一）
```

**更新节奏建议：** 大版本发版前、DESIGN 合并前、或架构大改后重跑审计；发现项关闭时在登记表注明日期与 commit。
