## P6 Console parity（`verify:p6-parity.mjs`）

| ID | 场景 | 通过标准 |
|---|---|---|
| P6-1 | `dep add` 无 range | 默认 `^latestVersion`；显式 `*` 优先 |
| P6-2 工程 | `publish --reuse-version --bump` | 1.0.1 + 同 fileSha1 |
| P6-2 会话 | `resource publish --session --reuse-version` | 1.0.1 + 同 fileSha1 |
| P6-4 | frozen online | code 4 | `test/.freelog-test-fixtures.local.json` 或 `FREELOG_TEST_FROZEN_RESOURCE_ID`（Console 手动冻结） |

**冻结 fixture：** dev 普通账号 **不能** API 写 `status:2`；复制 `test/.freelog-test-fixtures.local.example.json` 后在 Console 冻结并填 ID；`pnpm provision:frozen-fixture` 仅验证。
