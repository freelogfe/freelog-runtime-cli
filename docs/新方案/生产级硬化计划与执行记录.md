# 生产级硬化计划与执行记录

最后更新：2026-08-05

本文是 CLI 改造进入生产可用前的执行台账，主要给后续开发会话接手使用。它不替代产品说明和使用说明，只记录“还要把哪些风险收口、已经用什么证据证明过、哪些问题必须留到专项验收”。

## 1. 当前目标

把 `packages/cli` 从“核心流程已跑通”推进到“可以进入发布前验收”的状态：

1. 本地门禁可一键执行，覆盖单测、类型检查、模板兼容、构建、npm 包内容预检。
2. 已完成的 dev 环境实测有资源名、资源 ID、结论和限制说明。
3. 尚未自动化的真实素材、复杂授权、大合集、生产权限类问题被显式列为专项验收，不悬空。
4. 每次代码修改前先更新设计/执行记录；每次验证后回写命令和结论。
