> 最佳实践 **目标态 only**。你已有整仓备份 → **工作树不保留旧布局、旧分包、旧 readme、过渡路径名**。

## 0. 定稿

| 项 | 定稿 |
|----|------|
| 形态 | **pnpm monorepo**（根 `pnpm-workspace.yaml`） |
| 包 | `@freelog-cli/cli` + `@freelog-cli/template-*` |
| 文档 | 仓根 `docs/`（不发包；**唯一**设计权威） |
| 版本 | **Changesets**；CLI/模板 `0.5.x`（主推）；需旧运行时再开 `0.4.x` 线 |
| 兼容表 | `packages/cli/compat/template-compat.json` 随 CLI 发 |
| 工作树 | **只有**目标目录；备份在仓外，不进 workspace、不进发布 |

## 1. 仓根布局（唯一合法）

```text
freelog-runtime-cli/
  pnpm-workspace.yaml
  package.json                 # private: true
  .changeset/
  docs/                        # 新方案 + 使用/平台
  packages/
    cli/                       # @freelog-cli/cli @0.5.x
      compat/template-compat.json
      src/
    templates/
      vite-vue-ts/             # @freelog-cli/template-* + template/
      …
  .github/workflows/
```

```yaml
# pnpm-workspace.yaml
packages:
  - 'packages/*'
  - 'packages/templates/*'
```

`packages/templates/*/template/` **不是** workspace 包；外壳 `packages/templates/<id>/package.json` 的 `files` 含 `template` 与 `template.manifest.json`。

---

## 2. 从工作树删除（已备份则直接删）

| 路径 / 事物 | 处理 |
|-------------|------|
| `freelog-cli-ts/` | **删除**；能力在 `packages/cli` **重写**，不迁就旧目录名 |
| `freelog-cli-ts copy/` | 仓外备份即可；工作树删除或永不提交 |
| `backup/`、旧 `packages/init|core|publish` | 删除或移出仓 |
| `freelog-cli-ts/开发readme/` | 删除；Changesets 规则只以本文为准 |
| 旧 `src/api/**` 手写分叉 | 不存在于新 cli；禁止 `@deprecated` 双轨 |
| 用户命令 `batch` / `syncr` / `syncv` / `publish --draft` | 不实现 |
| `tutorial/` | 与产品无关则移出仓或单独仓；**不进** workspace |

## 3. 包边界

| 包 | 发布 | 依赖 |
|----|------|------|
| `@freelog-cli/cli` | 是 | **不** `workspace:*` 链全部 template |
| `@freelog-cli/template-*` | 是 | 互不依赖；按需被 init 用 npm 拉取 |
| `docs` | 否 | — |

开发：`--templates-dir ./packages/templates` 读仓内源，不必先 publish。

## 4. Changesets

```bash
pnpm changeset
pnpm changeset version
pnpm -r build
pnpm changeset publish
git push --follow-tags
```

| 规则 | 定稿 |
|------|------|
| 改 runtime 模板 | bump 模板 `0.5.x` + 改 CLI compat + bump CLI |
| 只改 CLI | 仅 cli changeset |
| 只改 docs | 不发 npm |
| CI | version 必须 `^0\.(4|5)\.\d+`；compat 档与模板前缀一致 |
| 禁止 | 手改 version 绕过 changeset；新发 `1.x`/`3.x` 模板号 |

## 7. 本地开发

```bash
pnpm install
pnpm --filter @freelog-cli/cli dev
pnpm --filter @freelog-cli/cli link --global

freelog-cli init my-app --scaffold runtime --template vite-vue-ts \
  --templates-dir ./packages/templates --resource-type <code> --yes
```

## 8. 明确不做

- 保留 `freelog-cli-ts`「一边用一边迁」  
- 再拆用户向 `core` / `init` / `publish` 多包  
- CLI 安装时拖全量 template  
- 文档权威放在包内 `开发readme`  
- ESM + 长期 CJS 双轨（目标 **仅 ESM**）
