# 开发设计：字段约束

> 来源：Console 资源页、`@freelog/tools-lib2` 契约、资源类型配置。失败统一 exit 4；平台更严时以平台为准并补本文。

## 1. 通用规则

manifest 不绑定环境；`.freelog/state.json` 必须记录当前 CLI env。旧 state 的 `env:null` 只兼容读取，一旦初始化或写入平台事实，就写为当前 `--env`。后续读取到非空 env 且与当前 CLI env 不一致时 exit 2，避免 dev/test/prod 串资源。

| 字段 | 规则 | 命令 |
|---|---|---|
| 短授权名 | 必填；只接收短名；非法字符、空白、`@`、`$`、`#`、emoji 归一为 `_`；长度 <= 60 | `create` / `collection create` |
| 标题 | trim 后必填；<= 100 | `create` / `update` |
| 简介 | <= 200 | `update` |
| 标签 | <= 20 个；单个 <= 20；去重 | `update` |
| 封面 | JPEG/PNG/GIF；<= 5MB；先上传再写 URL | `update` |
| 策略名 | 2-20；同资源内唯一 | `policy apply` |
| 策略文本 | 非空；提交前恰好一次 `encodeURIComponent` | `policy apply` |
| 属性 key | `/^[a-zA-Z]([a-zA-Z0-9_]{1,29})?$/` | `version set` / manifest |
| 属性 name/remark | name 必填 <= 50 且不重复；remark <= 50 | 同上 |
| 自定义属性条数 | <= 30 | `publish` |

## 2. 资源类型校验

所有 publish / import 前必须读取：

```text
FServiceAPI.Resource.getResourceTypeInfoByCode({ code: manifest.resource.typeCode })
```

校验项：

| 类型配置字段 | CLI 行为 |
|---|---|
| `fileCommitMode` | 官方 bit 能力；不包含本地上传位 `1` 则 exit 4 |
| `formats` | 校验文件扩展名 / MIME；zip 后按平台要求校验 |
| `fileMaxSize` + `fileMaxSizeUnit` | 按字节换算后校验 |
| `supportOptionalConfig` | 官方枚举 `2` 表示支持；非 `2` 时拒绝自定义属性 / 可选配置 |
| 运行时类标识 | 若类型需要运行时档位，`runtimeVersion` 必填 |

禁止长期依赖中文类型名判断“图片/视频/主题/插件”。中文名只能作为 TTY 搜索提示。

## 3. create

| manifest/flag | API 字段 | 必填 | 约束 |
|---|---|---:|---|
| `resource.typeCode` / `--type` | `resourceTypeCode` | 是 | 创建后不可变 |
| `resource.title` / `--title` | `resourceTitle` | 是 | 见通用标题 |
| `identity.name` / `--resource-name` / `create --name` | `name` | 是 | 短名；create 前预查重 |

已有 `state.resource.resourceId` 时再次 `create` 直接 exit 4。

## 4. version set / publish

| 字段 | `version set` | `publish` |
|---|---|---|
| `version.version` | semver，可缺省由 `--bump` 写入 | 必填；首版固定 `1.0.0`；续版必须大于平台 latest |
| `version.filePath` | 可写入相对 cwd 路径 | 必填；必须存在 |
| `version.description` | 可选 | 传给 `createVersion` |
| `runtimeVersion` | 运行时类必填 | 运行时类必传；非运行时类不得传 |
| `dependencies` | schema 校验 | 授权不完整 exit 5 |
| `baseUpcastResources` | schema 校验 | 同 Console payload |
| `authExcludedItems` | schema 校验 | 同 Console payload |
| `inputAttrs` / `customPropertyDescriptors` | schema 校验 | 按 typeInfo 决定是否允许 |

冻结资源 `(status & 2) === 2` 拒绝 publish。合集资源走 `collection publish`，单品 publish 对 `subjectType === 4` exit 4。

## 5. version edit

只能修改已发布版本元数据：

| 可改 | 不可改 |
|---|---|
| description、部分属性展示信息 | version、fileSha1、filename、dependencies、runtimeVersion |

平台若拒绝某字段，以平台为准并 exit 4。

## 6. policy

`policy apply --from-file <policy.json>` 支持单对象或数组，用于新增策略：

```json
{
  "policyName": "免费",
  "policyText": "策略正文",
  "status": 1
}
```

| 字段 | 约束 |
|---|---|
| `policyName` | 必填；2-20 |
| `policyText` | 必填；非空；CLI 提交前编码一次 |
| `status` | 可选；默认 1；仅 0/1 |

策略正文/名称修改不走 CLI `policy apply`；Console/tools-lib 当前稳定契约只支持 `addPolicies` 新增和 `updatePolicies(policyId,status)` 启停。
已上架资源不能停用最后一条启用策略。

## 7. online / offline

| 命令 | 前置 |
|---|---|
| `online` | 平台 `latestVersion` 存在；至少一条 `policy.status === 1` |
| `offline` | `--yes` 或 TTY 确认 |

状态码：`0` 未发行 / `1` 上架 / `2` 冻结 / `4` 下架。普通 `update` 不允许接收 `status:1`。

## 8. resource import-dir

用于“目录下每个文件都是独立资源”。

| 约束 | 说明 |
|---|---|
| 类型 | 整批同一 `resourceTypeCode` |
| 数量 | P0 默认最多 20；超过 exit 4 |
| 每项 | create -> version set -> publish，可选 policy/online |
| 失败 | 跑完汇总；任一失败 exit 4；成功项保留 state |
| 文件夹 | 不把目录 zip 成一个资源；每个文件一资源 |

## 9. 合集

| 项 | 约束 |
|---|---|
| `collection create` | 同 create，且 subjectType=4 |
| `collection item add <resourceId>` | 允许他人资源，不校验条目 owner |
| `collection item add <path>` | 路径对应资源必须属于当前账号 |
| `collection item import-dir` | 每个文件先成为独立资源，再写入合集目录草稿 |
| `collection publish` | 调 `updateCollection`；可空目录；条目授权缺口 exit 5 |
| collect-rules | `serializeStatus` 完结1/连载0；`conditionType` every=1/some=2 |
| filter key | 仅 `resourceTitle` / `authIdentity` / `resourceTypeCode` |
| RSS bind | `feedUrl` + 邮箱验证码；无 code exit 4 |
