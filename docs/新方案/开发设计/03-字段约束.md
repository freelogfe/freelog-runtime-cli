# 开发设计：表单字段约束

> 来源：Console 资源页 UI / models / 共用组件。写命令在调 API 前做同等校验；失败 **exit 4**。平台更严则以平台为准。  
> **online** 对齐 `resourceOnline`（严格）：须 latestVersion + 启用策略（不代建策略）。

## 0. 通用

| 主题 | 规则 | 命令 |
|------|------|------|
| 授权标识 | 非法字符/空白/@$#/emoji → `_`；≤60；`username/`+name 查重 | create / --from-dir / collection create |
| 标题 | 必填；trim；≤100 | create / update |
| 简介 | 可选；≤200 | update / collection update |
| 标签 | ≤20 个；单标 ≤20；不重复 | update --tags |
| 封面 | JPEG/PNG/GIF；≤5MB；上传后 URL 数组 | update --cover |
| 策略名 | 2–20；本资源内唯一 | policy add |
| 策略文本 | 本资源内唯一；提交前 `encodeURIComponent` | policy add |
| 属性 key | `/^[a-zA-Z]([a-zA-Z0-9_]{1,29})?$/` | 版本属性 |
| 属性 name/remark | name 必填 ≤50 不重复；remark ≤50 | 同上 |
| 自定义属性条数 | ≤30；value 常见 ≤100 | 同上 |

## 1. create

| 选项 | API | 必填 | 约束 |
|------|-----|------|------|
| `--type` | resourceTypeCode | 是 | 非空；创建后不可变 |
| `--title` | resourceTitle | 是 | 见 §0 |
| `--name` | name | 是 | 见 §0 净化+查重；创建后不可变 |

## 2. updateVersion / publish

| 字段 | 必填 | 约束 |
|------|------|------|
| 文件 | publish 是 | 入口/格式/大小来自 `getResourceTypeInfoByCode`（非全局常量） |
| 版本（首版） | 是 | 固定 `1.0.0`（**资源 semver**） |
| 版本（新版） | 是 | semver.valid；`gt(v, latest\|\|'0.0.0')`；默认 patch+1 |
| `runtimeVersion` | 资源类型为**主题/插件**（运行时类）时 publish **是**；其它类型不传 | 仅 `0.4` \| `0.5`；主题与依赖插件同档；**禁止漏传**（平台默认 0.4） |
| 依赖授权 | 有依赖时 | 不完整 → publish exit 5 |
| 冻结 / 合集 | — | `(status&2)===2` 拒绝；subjectType===4 拒绝单品 publish |
| version edit | — | 不可改 version/fileSha1；可改 description/属性；runtime 是否可改以平台为准 |

## 3. policy

- add：名 2–20、文本唯一、encodeURIComponent  
- 已上架（status===1）时不能关掉最后一条启用策略  

## 4. online / offline

| 命令 | 前置 |
|------|------|
| online | 有 latestVersion；至少一条 policy.status===1 |
| offline | 确认（`--yes` 可跳过） |

状态：`0` 未发行 / `1` 上架 / `2` 冻结 / `4` 下架。

## 5. create --from-dir

| 约束 | 说明 |
|------|------|
| 类型 | 整批同一 resourceTypeCode |
| 数量 | 最多 20 |
| 每项 | 同 create；version=1.0.0 |
| sha1 | 本人/他人占用 → 该项失败 |
| 授权 | 有依赖须完整 |

## 6. 合集

| 项 | 约束 |
|----|------|
| collection create | 同 create + subjectType=4 |
| item add | 写合集只校合集 owner；路径则另校路径资源为本账号；resourceId 允许他人 |
| collection publish | isMergeCatalogueDraft；授权完整；允许 0 条目 |
| collect-rules | serializeStatus 完结1/连载0；status 自动收录 1/0；conditionType every=1/some=2 |
| filter key | 仅 resourceTitle \| authIdentity \| resourceTypeCode |
| 操作符 | 标题/授权标识禁止 EQUAL/NOT_EQUAL；类型仅 EQUAL；另有 INCLUDES 等 |
| rss bind | feedUrl + **验证码**；preview 错误码阻断 |
| RSS 合集 | 除标签外 listing/目录多只读；以 rss sync 为主 |
