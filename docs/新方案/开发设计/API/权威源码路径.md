# 权威源码路径（对照用）

> CLI 实现与文档核对时**优先读源码**，避免只看 npm 打包后缺注释/旧构建。

## tools-lib

| 路径 | 用途 |
|------|------|
| `D:/appinside/freelogfe-web-repos/packages/@freelog/tools-lib/src/service-API/` | `FServiceAPI.*` 全量（含 `resources` / `storages` / `user` / `policies` / `rss` / `contracts` / `payment`…） |
| `.../src/utils/axios.ts` | 浏览器默认 Request；CLI 不直接 patch，改走 `@freelog/tools-lib2/node` 的 Node adapter |
| `.../src/utils/domain.ts` | 公网后缀：`.freelog.cn` / `.testfreelog.com` / `.devfreelog.com` |
| `.../src/utils/tools.ts` | `getSHA1Hash(File)` — CLI 用路径适配 |

CLI 依赖声明：`@freelog/tools-lib2@^0.3.0`。

**注意**：本地源码目录仍是 `packages/@freelog/tools-lib`，但发布包名已经改为 `@freelog/tools-lib2`。CLI 开发期可通过 workspace override / link 指向该源码；正式发 CLI 前必须先确保 npm 上存在匹配版本的 `@freelog/tools-lib2`。

## CLI 适配落点

| 路径 | 用途 |
|------|------|
| `packages/cli/src/platform/tools-lib.ts` | 唯一允许直接 import `@freelog/tools-lib2/node` 的入口 |
