## 1. 双身份测试模型

```text
身份 1 · 各类用户（07）     →  「我能不能把活干完」—  happy path + 用户级偷懒
身份 2 · 测试人员（本文）   →  「系统会不会被用坏」—  负向、边界、并发、parity、安全
```

**原则：**

1. **每个用户身份**至少覆盖：单品 +（若适用）批量 + 合集；各做首版 + 维护。
2. **每个 FAIL** 必须映射到 [04-问题矩阵](./04-问题矩阵.md) 某行，或登记 §5 漏洞台账。
3. **Console 并排**是用户身份验收的终态；测试人员额外做 **CLI↔CLI**、**CLI↔Console**、**自动化↔手工** 三角验证。
