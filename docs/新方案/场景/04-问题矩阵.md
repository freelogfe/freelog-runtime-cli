**第二条及以后策略文件规范语法（dev 实测）：**

```text
FOR PUBLIC

Initial:
	terminate
```

首条策略可能接受旧式小写 `for public` / `initial[active]:`，**追加时平台校验更严** — 统一用 uppercase 写法。
