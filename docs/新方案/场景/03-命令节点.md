## 3.1 L0 基础层

| 节点 | 前置 | 命令 | 状态变化 | 后继 | 典型失败 |
|---|---|---|---|---|---|
| N-login | 无 | `login [--env] [--login-name --password --yes]` | 写用户级 auth | 所有写命令 | 非交互缺 --yes；dev 401 缺 Cookie |
| N-logout | 无 | `logout` | 删 auth | login | 误删 manifest（不应发生） |
| N-status | 无 | `status [--env]` | 只读 | 诊断后任意 | 未登录只读仍可用 |

**全局门禁（所有写命令）：** `--env` 匹配 state.env；auth.environment 匹配；owner 匹配；必要时 ensureSynced。

## 3.12 节点依赖图（写命令最小序）

```text
login → (init|import-dir) → create|bind → version set → publish
       → policy apply → online
       → [维护] update / version set+bump / draft* / policy set / dep* / offline
```

**常见非法跳跃：**

| 跳跃 | 结果 |
|---|---|
| 无 create/bind 就 publish | code 4 |
| 无 publish 就 online（无 latestVersion） | ONLINE_GATE_FAILED |
| 无启用策略就 online | ONLINE_GATE_FAILED |
| 维护期再 create | 已有 resourceId 应走 update/version |
| collection publish 前未 item import | 空目录或阻断 |
