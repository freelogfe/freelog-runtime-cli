# 用户场景（生产级拓扑）

最后更新：2026-08-10

**用户场景是 CLI 面向生产的核心。** 本目录用拓扑方式穷举：主路径、命令节点、可能碰到的**全部问题**、可执行命令实例、Console 对照与测试覆盖。

> 命令参数细节见 [CLI使用说明](../使用/CLI使用说明与Console差异.md)；**分角色简明手册**见 [普通用户](../使用/普通用户简明手册.md) / [产品经理](../使用/产品经理简明手册.md) / [测试人员](../使用/测试人员简明手册.md)；parity 与核对报告见 [Console对齐核对报告](../对齐/Console对齐核对报告.md)。

## 双身份测试（生产必做）

```text
身份 1 · 各类用户   →  07-用户身份测试手册（主题/插件/图片/小说/短视频 × 单品/批量/合集）
身份 2 · 测试人员   →  08-测试人员手册（负向、漏洞猎杀、Console 并排、发版签字）
```

## 读法（三步）

```text
1. 选主路径     →  02-主路径.md（P1–P6）
2. 沿节点链走   →  03-命令节点.md（L0–L9）
3. 查问题应对   →  04-问题矩阵.md（节点 × 问题 × code × 处理）
```

维护期、协作冲突、批量重试等：直接查 **04-问题矩阵** 对应层，或 **05-场景实例** 找完整 bash 链。

## 六条主路径（速查）

| 路径 | 意图 | 入口命令 |
|---|---|---|
| **P1** | 压缩类（主题/插件/软件库） | `init` 五选一前三项 → `create` |
| **P2** | 单文件（图片/视频） | `init none` → `create` |
| **P3** | 批量独立资源 | `resource import-dir`（无父 init） |
| **P4** | 合集 | `init collection` → `collection *` |
| **P5** | 半路接入 | `init` → `bind` |
| **P6** | 维护（sidebar 阶段 B） | `update` / `version *` / `draft *` / `policy *` / `online` |

阶段 A（创建/首版）→ 阶段 B（维护）见 [01 §1](./01-生命周期与拓扑.md#1-console-两阶段与-cli-全生命周期)。

## 维护规则

新增场景或生产踩坑时：

1. 在 [02-主路径](./02-主路径.md) 定位或扩展路径；
2. 在 [03-命令节点](./03-命令节点.md) 补节点行；
3. 在 [04-问题矩阵](./04-问题矩阵.md) **必须**补问题行（含 code、CLI 行为、处理）；
4. 在 [05-场景实例](./05-场景实例.md) 补至少一条可执行命令链；
5. 同步 [CLI字段账本](../开发/CLI字段账本.md) / [verify-scenarios.mjs](../../../packages/cli/scripts/verify-scenarios.mjs)（若可自动化）。

**禁止：** 无拓扑定位的散文；声称 init 内含批量/文件夹合集（方案 A 已禁止）；忽略 sidebar **info / versionInfo** 维护阶段。
