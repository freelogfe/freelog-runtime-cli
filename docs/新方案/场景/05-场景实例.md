## P1 压缩类

### P1a — 新建 React 主题

```bash
freelog-cli login --env dev --yes ...
freelog-cli init my-project --env dev          # 五选一「主题」→ vite-react-ts
cd my-project && pnpm install && pnpm build
freelog-cli create --yes --env dev
freelog-cli version set --version 1.0.0 --file dist --runtime 0.5 --env dev
freelog-cli publish --yes --env dev
freelog-cli policy apply --from-file ./policy.free.json --yes --env dev
freelog-cli online --yes --env dev
```

**CI 脚本（须传 code）：**

```bash
freelog-cli type info RT001 --env dev
freelog-cli init my-project --scaffold runtime --template vite-react-ts \
  --resource-type RT001 --runtime 0.5 --yes --env dev
# …同上 create → online
```

cd my-existing-plugin

## P4 合集

### P4 首版

```bash
freelog-cli init photo-album --scaffold collection --resource-type RT003006 --yes --env dev
cd photo-album
freelog-cli collection create --yes --env dev
freelog-cli collection item import-dir ../photos --config ../photos/freelog.batch.json --yes --env dev
freelog-cli collection version set --description "首版" --env dev
freelog-cli collection publish --yes --env dev
freelog-cli collection policy apply --from-file ./policy.free.json --yes --env dev
freelog-cli online --yes --env dev
```

### P4 合集维护（S15e）

```bash
freelog-cli collection policy list --json --env dev
# 追加第二条策略（规范语法 FOR PUBLIC）
freelog-cli collection policy apply --from-file ./policy.coll-alt.json --yes --env dev
freelog-cli offline --yes --env dev
freelog-cli online --yes --env dev
freelog-cli collection version set --description "draft test" --env dev
freelog-cli draft push --collection --yes --env dev
freelog-cli draft pull --collection --yes --env dev
freelog-cli draft discard --collection --yes --env dev
freelog-cli collection update --title "新合集名" --intro "维护" --env dev
freelog-cli pull --collection --env dev
```

**item CRUD：**

## P6 维护（单品）

### P6a — listing（S15a）

```bash
freelog-cli update --cover ./cover.png --tags "cli,e2e,prod" --yes --json --env dev
freelog-cli update --title "Platform Title" --yes --env dev
# 本地 manifest 与平台冲突时：
freelog-cli pull --apply-listing --force --yes --env dev
```

### P6b — 发新版 + bump（S15c）

```bash
freelog-cli version set --file photo.png --yes --env dev
freelog-cli publish --bump --yes --env dev
freelog-cli version edit --version 1.0.1 --description "maint note" --env dev
freelog-cli version show --version 1.0.1 --json --env dev
freelog-cli version edit --version 1.0.1 --sync-properties --yes --env dev
```

### P6d — 草稿协作

```bash
freelog-cli draft pull --env dev
freelog-cli version set --version 1.2.0 --file dist --env dev
freelog-cli draft push --yes --env dev
freelog-cli draft push --force --yes --env dev    # 冲突时
freelog-cli draft discard --yes --env dev
```

### P6e — 策略门禁（S15b）

```bash
freelog-cli policy list --json --env dev
freelog-cli policy apply --from-file ./policy.alt.json --yes --env dev
freelog-cli policy set <firstId> --status 0 --yes --env dev
# 上架态停用最后一条 → 应失败
freelog-cli policy set <lastEnabledId> --status 0 --yes --env dev
freelog-cli offline --yes --env dev
freelog-cli policy set <id> --status 0 --yes --env dev
freelog-cli online --yes --env dev                  # 无启用策略 → 应失败
freelog-cli policy set <id> --status 1 --yes --env dev
freelog-cli online --yes --env dev
```

**policy.alt.json 示例（第二条策略）：**

```json
{
  "policyName": "备用",
  "policyText": "\nFOR PUBLIC\n\nInitial:\n\tterminate\n",
  "status": 1
}
```

### P6f — dep（S15d）

```bash

freelog-cli dep list --json --env dev
freelog-cli dep update <targetResourceId> --version-range ">=1.0.0" --yes --env dev
freelog-cli dep remove <targetResourceId> --yes --env dev
```
