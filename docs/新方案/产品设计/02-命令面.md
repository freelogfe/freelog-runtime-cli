# 产品设计：目标命令面

> 唯一用户命令面。命令拓扑见开发设计 [15](../开发设计/15-资源生命周期拓扑设计.md)。

## 1. 全局命令

| 命令 | 作用 | 主要选项 |
|---|---|---|
| `login` / `logout` | 登录 / 退出 | `--env`、`--test` |
| `status` | 本地 manifest/state + 平台状态报告 | `--json`、`--cwd` |
| `pull` | 平台事实拉到 state，并可显式采用平台 listing | `--version`、`--collection`、`--apply-listing`、`--force`、`--json` |
| `type list` | 列资源类型 | `--subject resource|collection`、`--json` |
| `type search <keyword>` | 搜索资源类型 | `--subject`、`--json` |
| `type info <code>` | 查看资源类型能力 | `--json` |
| `init [name|.]` | 初始化工程或接入已有目录 | `--scaffold`、`--template`、`--resource-type`、`--runtime`、`--yes` |

通用写命令选项：`--cwd`、`--yes`、`--no-auto-pull`、`--env`、`--json`。
联调排错命令选项：`--debug`。debug 只允许输出脱敏后的错误详情，不打印 token/password/cookie/authorization。

交互规则：TTY 下可选择类型/模板/runtime；非交互或 `--yes` 下缺关键字段必须 exit 4。

## 2. 单品资源

| 命令 | 作用 | 平台能力 | 写入 |
|---|---|---|---|
| `create` | 创建资源壳 | `Resource.info` + `Resource.create` | state.resource |
| `update` | 更新基础信息 | `Resource.update` | manifest.listing + state snapshot |
| `version set` | 更新下一版本地意图 | 无 | manifest.version |
| `publish` | 创建正式版本 | upload + `Resource.createVersion` | state.version |
| `version edit` | 编辑已发布版本说明等元数据 | `updateResourceVersionInfo` | state snapshot |
| `draft push` | 本地发版意图推到平台草稿 | `saveVersionsDraft` | state.version.draftSync |
| `draft pull` | 平台发版草稿拉回 manifest | `lookDraft` | manifest.version + state.version.draftSync |
| `draft discard` | 删除平台发版草稿 | draft delete API | state.version.draftSync cleared |
| `policy apply` | 应用 `--from-file` 策略 | `Resource.update(addPolicies)` | state.resource.policies |
| `policy list` | 查询策略 | `Resource.info` | state.resource.policies |
| `policy set` | 启停策略 | `Resource.update(updatePolicies)` | state.resource.policies |
| `dep add/remove/update/list` | 维护下一版依赖意图 | 可选 `dependencyTree` | manifest.version.dependencies |
| `dep auth` | 声明式免费依赖签约 | `Contract.batchCreateContracts` + `authTree` | 平台合约事实；本地不维护 contract state |
| `online` / `offline` | 上架 / 下架 | `info` 门禁 + `Resource.update(status)` | state.status |

`publish` 可以没有本资源策略。依赖授权失败可以阻断 `publish`，本资源缺策略只能阻断 `online`。

## 3. 多文件单品

| 命令 | 作用 | 说明 |
|---|---|---|
| `resource import-dir <dir>` | 批量把文件夹内文件发布成多个独立单品 | 不创建合集 |

规则：

1. 读取扁平文件夹。
2. 每个文件生成子项目 manifest/state。
3. 每个文件创建资源壳并发布 `1.0.0`。
4. 同类型资源，格式/大小按平台类型配置校验。
5. 部分失败不回滚成功项。

## 4. 合集资源

| 命令 | 作用 | 平台能力 | 写入 |
|---|---|---|---|
| `collection create` | 创建合集壳 | `Resource.create(subjectType=4)` | state.resource |
| `collection update` | 更新合集基础信息和展示设置 | `Resource.update` + `updateCollection` | manifest.listing/collection.display + state |
| `collection item add` | 加入已有资源或本地子项目 | catalogue draft API | state.collection |
| `collection item remove` | 移除目录草稿项 | catalogue draft API | state.collection |
| `collection item update` | 更新目录条目标题等 | catalogue draft API | state.collection |
| `collection item reorder` | 重排目录草稿 | catalogue draft API | state.collection |
| `collection item import-dir` | 从图片/视频文件夹批量创建单品并加入合集 | create/createVersion + catalogue draft API | many states + collection state |
| `collection version set` | 更新合集下一次 publish 的说明意图；合集版本号由平台固定 | 无 | manifest.collection |
| `collection publish` | 合并目录草稿并发布合集版本 | `Resource.updateCollection` | state.resource.latestVersion + state.collection.catalogueDraft |
| `collection collect-rules get/set` | 自动收录规则 | `get/setCollectRules` | state.rules |
| `collection rss send-code/bind/sync` | RSS 验证与同步 | RSS APIs | state.rss |

合集没有策略也能 `collection publish`；合集 `online` 才需要 latestVersion + 启用策略。

## 5. 删除的旧入口

| 旧入口 | 新入口 |
|---|---|
| `updateVersion` | `version set` |
| `create --from-dir` | `resource import-dir`，或 `collection item import-dir` |
| `batch *` | `resource import-dir` / `collection item import-dir` / 循环 `--cwd` |
| `syncr` / `syncv` | `pull` |
| `publish --draft` | `draft push` |
| 手改旧 config | 编辑 `freelog.manifest.json` 或使用命令 |
| `contract list` | 不进入正式命令面；依赖签约用 `dep auth`，复杂合约查询回 Console |

## 6. 版本三态

| 态 | 存哪 | 命令 | Console 续编 |
|---|---|---|---|
| 本地下一版意图 | `freelog.manifest.json` | `version set` / `dep *` / 编辑 manifest | 否 |
| 平台发版草稿 | Freelog draft API | `draft push/pull/discard` | 是 |
| 正式版本 | Freelog versions | `publish` / `version edit` | 已发行 |

```text
version set -> draft push -> Console 可续编 -> draft pull -> publish
version set -> publish
```
