# 产品设计：数据与目录

> 字段边界见开发设计 [14](../开发设计/14-无旧负担脚手架目标设计.md)；生命周期拓扑见开发设计 [15](../开发设计/15-资源生命周期拓扑设计.md)。

## 1. 单品项目

```text
my-theme/
├── freelog.manifest.json
├── .freelog/
│   ├── state.json
│   ├── cache/
│   └── tmp/
├── src/
└── dist/
```

规则：

1. `freelog.manifest.json` 是用户意图，提交 git。
2. `.freelog/state.json` 是 CLI 状态，不提交 git。
3. `.freelog/cache/` 和 `.freelog/tmp/` 不提交 git。
4. 命令默认以当前目录为资源目录；`--cwd` 与进入目录执行等价。

`.gitignore`：

```gitignore
.freelog/state.json
.freelog/cache/
.freelog/tmp/
```

## 2. 接入已有项目

已有 React/Vue/其它工程不需要移动目录：

```bash
cd existing-project
freelog-cli init . --scaffold none --resource-type <code> --runtime 0.5
```

`init .` 只写 manifest/state/gitignore；不复制模板，不覆盖用户源码。

## 3. 合集项目

```text
photo-album/
├── freelog.manifest.json
├── .freelog/
│   └── state.json
└── items/
    ├── a/
    │   ├── freelog.manifest.json
    │   └── .freelog/state.json
    └── b/
        ├── freelog.manifest.json
        └── .freelog/state.json
```

规则：

1. 合集根 manifest 的 `subject` 是 `collection`。
2. 子目录 manifest 的 `subject` 是 `resource`。
3. 合集目录项引用的是子资源 `state.resource.resourceId` 或平台已有 resourceId。
4. 合集根不拥有子资源的发版意图；子资源仍由自己的 manifest 管理。

## 4. 多文件单品导入

输入：

```text
photos/
├── a.jpg
├── b.jpg
└── c.jpg
```

命令：

```bash
freelog-cli resource import-dir ./photos --resource-type <imageCode>
```

输出：

```text
photos/
├── a.jpg
├── b.jpg
├── c.jpg
├── a/
│   ├── freelog.manifest.json
│   └── .freelog/state.json
├── b/
└── c/
```

该命令只创建多个独立单品，不创建合集。

## 5. 文件夹导入合集

输入：

```text
photo-album/
└── ../photos/
    ├── a.jpg
    ├── b.jpg
    └── c.jpg
```

命令：

```bash
freelog-cli collection item import-dir ../photos --resource-type <imageCode> --item-policy-file ./item-policy.json
```

输出：

```text
photo-album/
├── freelog.manifest.json
├── .freelog/state.json
└── items/
    ├── a/
    │   ├── a.jpg
    │   ├── freelog.manifest.json
    │   └── .freelog/state.json
    ├── b/
    └── c/
```

产品语义：文件夹内每个文件成为一个单品资源，合集只保存目录关系。文件夹本身不打包成合集资源。

## 6. Manifest / State 归属

| 数据 | 文件 | 是否提交 git |
|---|---|---:|
| 短授权名、标题、类型 code | `freelog.manifest.json` | 是 |
| listing 意图 | `freelog.manifest.json` | 是 |
| 下一版版本号、描述、filePath、依赖、属性 | `freelog.manifest.json` | 是 |
| 策略文本和目标状态 | `freelog.manifest.json` | 是 |
| 合集展示、目录意图 | `freelog.manifest.json` | 是 |
| resourceId、完整 resourceName、owner | `.freelog/state.json` | 否 |
| latestVersion、status、policyId 映射 | `.freelog/state.json` | 否 |
| fileSha1、filename、versionId | `.freelog/state.json` | 否 |
| draftSync | `.freelog/state.json` | 否 |
