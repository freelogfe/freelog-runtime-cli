## 工程化与发版辅助（2026-08-10）

### 13.1 项目配置

```bash
freelog-cli config init --default-env dev   # 创建 .freelog/config.json + .freelogignore
freelog-cli config set --default-env dev     # 写入 defaultEnv
freelog-cli config show                     # 查看配置与当前生效 env
```

非交互 CI 可在项目根配置 `defaultEnv`，减少漏传 `--env`。命令行参数说明见 `freelog-cli --help` 与各子命令 `--help`（与 [全局参数与登录](./全局参数与登录.md) 全局参数一致）。

### 13.2 批量 import 忽略规则

在项目或 import 目录放置 `.freelogignore`（glob 风格，默认已忽略 `.DS_Store`、`Thumbs.db` 等）：

```gitignore
draft.*
*.tmp
```

### 13.3 策略与依赖模板

```bash
freelog-cli policy init              # 生成 policy.free.json（FOR PUBLIC）
freelog-cli policy init --collection # 合集语法
freelog-cli dep init-auth-map        # 生成 auth-map.yaml
```

### 13.4 monorepo

```bash
freelog-cli workspace list [--cwd 根目录] [--depth 5]
```

### 13.5 release 扩展

```bash
freelog-cli release --changelog-from-git --yes --env dev   # git log -1 → description
freelog-cli release --yes --env dev                        # 合集 cwd 时走 collection publish
freelog-cli release --bump patch --build-cmd "pnpm build" --online --yes --env dev
freelog-cli release --dry-run --yes --env dev              # 仅 publish dry-run
freelog-cli release --skip-validate --yes --env dev        # 跳过 validate（不推荐）
freelog-cli release --no-auto-pull --yes --env dev
```

| flag | 作用 |
|---|---|
| `--bump patch\|minor\|major` | publish 前升版本（manifest） |
| `--build-cmd` | publish 前执行本地构建 |
| `--online` | publish 成功后上架 |
| `--dry-run` | 不实际上传/写平台 |
| `--skip-validate` | 跳过 `validate` |
| `--changelog-from-git` | 用 `git log -1` 正文作版本说明 |
| `--no-auto-pull` | 同全局含义 |

合集 **不支持** `--bump`（平台固定版本）；可用 `collection version set --description`。

## 预检、差异与 create 覆盖

### validate / doctor

```bash
freelog-cli validate --env dev
freelog-cli validate --for publish --env dev    # 深度：版本文件、SHA1、授权等
freelog-cli validate --for online --env dev     # 含上架门禁
freelog-cli doctor --json --env dev             # validate 别名
```

已有 `resourceId` 且未指定 `--for` 时，默认按 **`publish`** 深度检查。失败 exit **4**。

### diff

```bash
freelog-cli diff --env dev
freelog-cli diff --json --env dev   # 漂移时 exit 3，供 CI 门禁
```

### create 覆盖 manifest

非交互 `create` 可用 flag 覆盖 manifest 字段（仍须先 `init`）：

```bash
freelog-cli create --title "覆盖标题" --type <code> --name shortname --type-name "显示名" --yes --env dev
```

### init 预设子命令

```bash
freelog-cli init theme my-theme --resource-type <code> --runtime 0.5 --yes --env dev
freelog-cli init widget my-widget --resource-type <code> --yes --env dev
freelog-cli init package my-lib --resource-type <code> --yes --env dev
```

非交互 `init --scaffold none` **必须**传 `--artifact-mode file|directory-zip`。可选 `--pm pnpm|npm|yarn`、`--skip-install`、`--templates-dir`、`--namespace`。
