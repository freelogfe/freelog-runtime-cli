## 1. CLI 是什么

**Freelog CLI = Console「本地文件发版 + 维护写入」的无界面版。**

- 同一套 API、同一套平台状态
- 差异只在：**没有网页向导**，用命令行 + 本地 manifest/文件代替表单

**不适合用 CLI 的人：** 只想点按钮、依赖云存储选文件、Markdown 微应用写小说、付费收银台签约的用户。

---

## 2. 产品范围（做 / 不做）

### ✅ CLI 覆盖（与 Console 对齐）

| 场景 | CLI 入口 |
|---|---|
| 单资源首发/发新版 | `init` → `create` → `publish` → `policy` → `online` |
| 批量独立资源 | `resource import-dir` |
| 合集（含文件夹导入） | `collection create` / `init-from-folder` → `item *` → `publish` |
| 维护：改标题/封面/标签/简介 | `update` / `collection update` |
| 维护：改已发版描述/属性/视频封面 | `version edit` |
| 策略新增与启停 | `policy apply` / `policy set` |
| 上下架 | `online` / `offline` |
| 依赖声明与免费签约 | `dep *` / `dep auth` |
| 半路接入已有资源 | `bind` |
| 合集 RSS / 自动收录 | `collection rss *` / `collect-rules set`（维护分支，非发版主链路） |

### ❌ 明确不做

| 能力 | 原因 | 产品建议 |
|---|---|---|
| 云存储里点选文件发版 | 无浏览器 Storage UI | 引导用 Console 或下载到本地 |
| Markdown/Cartoon 微应用编辑 | 内嵌编辑器非文件路径 | 小说/富文本走 Console 或选「本地文件类型」 |
| 付费策略收银台 | 须人机支付 | Console 完成签约后再 CLI 维护 |
| 列表运营、收藏、收入、节点 | 消费/运营侧 | 仅 Console |
| 改已有策略正文 | 平台规则 | 新增策略 + 启停 |

---

## 3. 对齐结论（可对外说）

> **在「本地文件发版 + sidebar 维护写入」范围内，CLI 与 Console 业务已对齐。**  
> 已知差异是交互方式（无 Builder、无自动草稿、上架更严格），不是能力缺失。

| 层级 | 状态 |
|---|---|
| 业务/API（81 项） | ✅ 无缺口 |
| 校验/门禁 | ✅ 对齐 |
| 错误文案/i18n | ✅ OSS 同源 |

---

## 4. 需要知道的差异（影响体验）

| 差异 | 用户感受 | 是否阻塞 |
|---|---|:---:|
| CLI 上架须完整门禁（无「软上架」） | 条件不齐会失败，比 Console Step4 更严 | 否，更安全 |
| 新增策略后须手动 `online` | 多一步 | 否 |
| 策略用文件写，无 Builder | 学习成本 | 否 |
| 封面须本地裁好 | 无裁剪弹窗 | 否 |
| Console 创建视频**可能不传封面**（源码 TODO） | Console 首版或无封面；CLI 可 `--video-cover` | ⚠ 跨端不一致 |
| RSS 验证码 | 须人工收邮件填 `--code` | 否，与 Console 相同 |
