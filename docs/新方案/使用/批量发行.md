# 批量发行

[返回使用文档目录](./README.md)

`resource import-dir` 把目录顶层的每个文件创建为一个独立资源，并发行首版。它不会创建合集，也不会在部分失败时回滚已成功的资源。

## 快速批量发行

```bash
freelog-cli resource import-dir ./photos --resource-type <imageTypeCode> --title-prefix "照片 " --yes --env production
```

CLI 只扫描目录顶层文件，并遵循 `.freelogignore`。每个成功项都会生成独立子工程，之后可进入对应目录单独更新、配置策略和上下架。

## 使用批量配置

在媒体目录中创建 `freelog.batch.json`：

```json
{
  "defaults": {
    "resourceTypeCode": "<imageTypeCode>",
    "version": "1.0.0",
    "policyFile": "policy.free.json",
    "tags": ["album"]
  },
  "items": [
    {
      "filePath": "a.png",
      "name": "photo-a",
      "resourceTitle": "图片 A",
      "description": "首版说明",
      "coverImages": ["cover-a.png"]
    },
    {
      "filePath": "b.png",
      "name": "photo-b",
      "resourceTitle": "图片 B"
    }
  ]
}
```

执行：

```bash
freelog-cli resource import-dir ./photos --config freelog.batch.json --yes --env production
```

`--config` 可省略；CLI 会自动发现导入目录中的 `freelog.batch.json` 或 `freelog.batch.yaml`。配置文件中的相对文件和策略路径以配置文件所在目录为基准。

常用字段：

| 字段 | 作用 |
|---|---|
| `defaults` | 所有条目的默认类型、版本、策略、标签和依赖 |
| `items[].filePath` | 必填，本地文件路径 |
| `items[].name` | 资源短授权标识 |
| `items[].resourceTitle` | 资源标题 |
| `items[].description` | 首版说明 |
| `items[].policyFile` / `policies` | 条目策略 |
| `items[].skip` | 为 `true` 时跳过该项 |

没有策略也可以发行版本，但不能直接上架。交互模式会要求确认；非交互模式必须传 `--yes`。需要上架时，进入生成的子工程添加策略并执行 `online`。

## 文件数量

默认情况下，超过 20 个文件时 CLI 会自动拆成多批平台请求并提示。使用 `--strict-batch-limit` 可要求单次最多 20 个文件，超出时在平台写入前失败。

## 依赖和授权

条目声明 `dependencies` 或 `baseUpcastResources` 时，批量配置还必须用 `batchSignContracts` 覆盖所有待授权资源及策略。缺少授权映射时，整个远端写入会在预检阶段停止。

带 `authExcludedItems` 的条目会使用单条创建路径。无论采用哪条路径，仍应在批量执行前完成相同的授权检查。详细字段和签约流程见[依赖与授权](./依赖与授权.md)。

## 报告、继续和重试

每次运行会创建 `.freelog/reports/<runId>.json`，并更新最近报告入口。部分失败时：

```bash
freelog-cli resource import-dir --resume .freelog/reports/<runId>.json --yes --env production
freelog-cli resource import-dir --retry .freelog/reports/<runId>.json --yes --env production
```

- `--resume` 从报告记录的最后一个安全阶段继续，适合进程中断或平台成功但本地尚未写完。
- `--retry` 只重新执行明确失败的条目。
- 两者不能同时使用。
- 恢复会核对环境、配置指纹和输入文件 SHA1，防止用修改后的目录误续跑。
- 报告标记远端结果未知时，CLI 会拒绝自动恢复。应先按账号、授权名和版本到 Console 对账，避免重复创建资源。

CI 可加 `--json-lines`，逐行读取 `start`、`ok`、`fail`、`skip` 和 `done` 事件。
