# 准备与本地文件

[返回使用文档目录](./README.md)

## 查询资源类型

资源类型和上传限制由平台动态提供。创建工程前应查询当前环境中的叶子类型：

```bash
freelog-cli type search 主题 --env <env>
freelog-cli type search 图片 --env <env>
freelog-cli type search 视频 --env <env>
freelog-cli type list --subject collection --env <env>
freelog-cli type info <typeCode> --env <env>
```

脚本中使用查询结果返回的 `typeCode`，不要根据名称自行拼接 code。`type info` 可查看文件格式、大小和运行时等类型能力。

## 查看主题和插件模板

```bash
freelog-cli template list --scaffold runtime --runtime 0.5 --env <env>
```

模板用于创建主题或插件开发工程。模板 ID 以命令当前输出为准；现有项目无需套用模板，可使用 `--scaffold none` 接入。

正式安装版 CLI 会在每次新建主题或插件工程时查询对应模板的 npm `latest`，再把解析出的具体版本下载、校验并缓存。初始化结果会显示实际使用的模板包和版本，便于复现和排查。已经创建的工程不会自动升级模板；需要采用新模板时，应新建工程并迁移业务代码，或由开发者自行升级原工程依赖。

## 选择发行物模式

| 模式 | 适用内容 | 发布处理 |
|---|---|---|
| `file` | 图片、视频、压缩包或其他单文件 | 上传原文件，不压缩 |
| `directory-zip` | 主题、插件等构建目录 | CLI 生成临时 zip 后上传 |
| `collection` | 多个子资源组成的合集 | 发行合集目录，不上传整个文件夹 |

CLI 不做图片裁剪、视频转码或前端项目构建。内容生产和构建完成后，再把最终文件或构建目录交给 CLI。

## 本地工程文件

| 文件 | 内容 | 是否提交到版本库 |
|---|---|---|
| `freelog.manifest.json` | 资源类型、标题、短授权标识、下一版文件、依赖和合集展示等用户意图 | 是 |
| `.freelog/state.json` | `resourceId`、owner、环境、状态、版本和同步信息等平台事实缓存 | 否 |
| `.freelog/config.json` | 项目级 CLI 配置 | 按团队约定 |
| `.freelog-auth` | 加密登录凭据 | 否 |
| `.freelog/reports/` | 批量和 Studio 的恢复报告 | 通常否 |

manifest 不绑定环境，state 绑定环境。同一工程在另一个环境执行时，CLI 会拒绝复用原环境 state，避免把一个本地目录误绑定到不同平台资源。

建议加入 `.gitignore`：

```gitignore
.freelog/
.freelog-auth
```

`login` 会确保当前工作区的 `.freelog-auth` 被忽略，但团队仍应在仓库级 `.gitignore` 中保留明确规则。

## 同步平台数据

```bash
freelog-cli pull --env <env>
freelog-cli pull --apply-listing --env <env>
freelog-cli pull --apply-listing --force --env <env>
freelog-cli pull --version 1.0.0 --env <env>
freelog-cli pull --collection --env <env>
freelog-cli pull --all --env <env>
```

- `pull` 默认只刷新 state，不覆盖 manifest 中的标题、简介、封面和标签。
- `--apply-listing` 明确采用平台 listing；本地也有改动时需要确认，`--force` 才允许覆盖。
- `--collection` 同时拉取合集目录草稿、自动收录和 RSS 状态。
- `--all` 对当前目录下包含 Freelog 工程的子目录逐个同步，不能与 `--collection` 同用。

## 准备策略和授权文件

```bash
freelog-cli policy init
freelog-cli policy init --collection
freelog-cli dep init-auth-map
```

`policy init` 生成可编辑的免费策略模板，`dep init-auth-map` 生成依赖授权映射模板。应用前应检查文件内容，策略语法错误会在平台提交前失败。
