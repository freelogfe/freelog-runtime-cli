## 文件夹作为合集

**快捷入口（方案 A，不经过 init 五选一）：**

```bash
freelog-cli collection init-from-folder --project-dir photo-album --media-dir ./photos --yes --env dev
```

交互时会依次：选合集类型 → 输入项目目录与媒体文件夹 → 创建合集 manifest → `collection create` → 导入子资源到目录草稿。

**分步命令链（与 Console collectionCreator 等价）：**

```bash
freelog-cli init photo-album --scaffold collection --resource-type <collectionCode> --yes --env dev
cd photo-album
freelog-cli collection create --yes --env dev
freelog-cli collection item import-dir ../photos --config ../photos/freelog.batch.json --yes --env dev
freelog-cli collection version set --description "首版合集" --env dev
freelog-cli collection publish --yes --env dev
freelog-cli collection policy apply --from-file ./policy.free.json --yes --env dev
freelog-cli online --yes --env dev
```

没有批量配置时：

```bash
freelog-cli collection item import-dir ../photos --resource-type <imageCode> --title-prefix "照片 " --item-policy-file ./policy.free.json --yes --env dev
```

说明：

1. 合集不是上传整个文件夹。
2. 文件夹合集 = 每个文件先变成独立子资源，再加入合集目录草稿。
3. 子资源策略可来自 `freelog.batch.json` 的 `policies/policyFile`，也可用 `--item-policy-file` 统一追加。
4. 子资源必须有正式版本、启用策略并能上架，才能加入合集。
5. **加入目录前的上抛授权（与 Console `FAddResourcesHandleAuth` 对齐）：** 若子资源声明了 `baseUpcastResources`，合集作为 licensee 须对这些 subject 已有 `contractStatus=0` 的合同；否则 `collection item add` / `item import-dir` 失败，文案为 **「以下单品或其上抛未获得授权，点击对应条目解决相关问题」**。
6. `collection publish` 才把目录草稿合并成正式合集版本。
7. 合集自身也要策略才能 `online`。

### 合集目录项维护

```bash
# 加入已有平台资源（须已 publish + policy + online；有 baseUpcast 须合集侧已签约）
freelog-cli collection item add <resourceId> --title "章节名" --env dev
freelog-cli collection item add ./child-dir --env dev          # 路径形式，读子目录 manifest
freelog-cli collection item add <id> --auth-excluded-file auth-excluded.yaml --env dev

freelog-cli collection item update <itemId> --title "新标题" --env dev
freelog-cli collection item remove <itemId> --env dev
freelog-cli collection item reorder --order-file order.json --env dev
freelog-cli collection item reorder --sort-field itemTitle --sort-type 1 --env dev
```

`auth-excluded.yaml` 为数组，每项 `{ resourceId, excludedType: contractId|policyId, excludedValue }`（与 manifest `authExcludedItems` 同形）。

### 合集高级维护

```bash
freelog-cli collection properties sync --env dev          # 仅同步合集自定义属性（不改目录）
freelog-cli collection properties sync --dry-run --env dev
freelog-cli collection logs --skip 0 --limit 20 --env dev # 合集操作日志
freelog-cli collection update --display-title rtitle --display-no hide --display-image show --env dev
```

`collection update` 的 `--display-*` 与 Console 合集展示表单枚举一致（`display-sort/view/title/no/image/descr`）。
