# 安装与升级

[返回使用文档目录](./README.md)

## 环境要求

- Node.js 20 或更高版本
- npm，随 Node.js 一同安装
- Windows、macOS 或 Linux 终端

确认 Node.js 版本：

```bash
node --version
npm --version
```

## 安装

使用 npm 全局安装：

```bash
npm install --global @freelog-cli/cli
```

确认安装结果：

```bash
freelog-cli --version
freelog-cli --help
```

本文档适用于 `0.5.x`。如果 `freelog-cli --version` 显示其他主次版本，请先安装与本文匹配的版本，再继续操作。

## 升级

升级到 npm 发布的最新稳定版本：

```bash
npm install --global @freelog-cli/cli@latest
freelog-cli --version
```

升级不会主动删除项目中的 manifest、state 或登录凭据。升级后进入已有工程执行：

```bash
freelog-cli status --env production
freelog-cli validate --for publish --env production
```

先处理预检提示，再执行平台写操作。自动化环境应固定经过验证的 CLI 版本，避免依赖浮动的 `latest`。

## 卸载

```bash
npm uninstall --global @freelog-cli/cli
```

卸载 CLI 不会删除以下用户数据：

- 项目中的 `freelog.manifest.json` 和 `.freelog/`
- 工作区或用户主目录中的 `.freelog-auth`
- 用户主目录中的 `.freelog-cli/`

如需删除这些数据，请先确认不再需要对应工程、平台绑定和登录信息，再手动处理。

## 命令不可用

安装后若找不到 `freelog-cli`：

1. 重新打开终端。
2. 执行 `npm prefix --global`，确认 npm 全局可执行目录已加入 `PATH`。
3. 执行 `npm list --global @freelog-cli/cli`，确认安装成功。
4. 检查是否同时存在旧版本，并重新执行全局安装命令。
