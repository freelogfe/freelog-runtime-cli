## 尚未由主文档定稿的专题

- **供给与发现**：公开可见、允许新签约、合同交付和平台强制限制要分别建模；具体状态及查询视图未定。
- **内容范围**：成员与版本分别选择固定或未来新增规则，可轮换成员目录另受准入约束；具体开放顺序、动态范围准入及移出后如何继续交付，仍不得沿用旧稿默认值。
- **异常履约**：支付/退款证据、无法交付、提前撤回、最低补救、争议与人工裁决的方案和权限未定。
- **能力治理**：哪些资源类型可开放哪些策略能力、资格事实与事件源的权限、隐私和失败语义未定。
- **多合同细则**：可售增量的判定、未知重叠的有偿确认、默认扣额和替换结算仍见第 14 篇待决项。

这些是后续需要逐个讨论的新专题，不是恢复 archive 中旧规则的理由。
