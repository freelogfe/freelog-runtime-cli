## E03 - collect-rules 条件复杂逻辑

```bash
当满足以下条件时自动收录:
  Level 1 (AND 关系):
    typeCode = "react-theme" AND
    authorId = "8847953" AND
    downloadCount > 1000
    
  Level 2 (OR 关系):
    tags CONTAINS "tutorial" OR
    intro CONTAINS "free"

✅ 规则摘要:
  收录符合条件的资源并置顶显示
```
