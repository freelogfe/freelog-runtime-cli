# 单资源：资料与上下架管理

前置条件：工程已登录正确账号，目标资源已 create 或 bind。本页在工程根执行，用资源 ID 明确目标与 dev 环境；修改线上资料不会发行新版本，也不改下一版本的工作稿。

## 查看现状

```powershell
freelog-cli status --resource id:<资源ID> --env dev
freelog-cli version show --resource id:<资源ID> --env dev
freelog-cli policy list --resource id:<资源ID> --env dev
```

status 汇总身份、工作稿与线上 latest；version show 读取线上版本，policy list 读取自身策略。指定历史版可给 version show 加 `--version 1.0.0`；只看未提交稿则加 `--local`，两种用途不要混淆。

## 修改展示信息

只发送明确给出的字段。下面同时修改标题、简介和标签；先把示例内容换成自己的：

```powershell
freelog-cli update --title "新标题" --intro "一句话简介" --tags "教程,图片" --resource id:<资源ID> --yes --env dev
```

只改一个字段时删掉其它字段参数，不必全填。要换封面，先准备工程内图片，再执行独立操作：

```powershell
freelog-cli update --cover cover.png --resource id:<资源ID> --yes --env dev
```

封面支持 JPG、PNG、静态 GIF，最大 5MB，CLI 上传后写入 URL，**没有裁剪功能，也不支持清空封面**。标题最多 100 字符，简介最多 200 字符；最多 20 个不重复标签，每个最多 20 字符。标签可写 # 前缀，存储时去掉前缀。

清空简介用 `--intro ""`，清空全部标签用 `--tags ""`，不是保留原值。没有任何修改字段的 --yes 更新会拒绝，不发送空更新。update 当前没有展示资料读回输出；操作后在浏览器核对资料，status 不显示这些字段。

## 同步本地标题

标题可以重复，也可能被网页改过，只作展示，**不用标题定位资源，不默认先同步所有标题**。

要刷新当前环境全部已绑定单资源的本地标题：

```powershell
freelog-cli resource sync --env dev
```

若只想刷新一份，使用下面这条替代批量命令：

```powershell
freelog-cli resource sync --resource id:<资源ID> --env dev
```

同步只读线上并回写匹配身份的本地标题，不修改平台、版本稿或产物路径。部分失败时成功项已更新，失败项保持原值，命令非零退出并报告。CLI update --title 成功后已回写本地标题，无需立即再同步。

## 上架

资源必须有已发行版本和至少一条启用的自身策略；依赖签约不算自身策略。

```powershell
freelog-cli validate --for online --resource id:<资源ID> --env dev
```

这条只检查。读清结果，补齐缺失项后才执行：

```powershell
freelog-cli online --resource id:<资源ID> --yes --env dev
freelog-cli status --resource id:<资源ID> --env dev
```

online 会再次检查后写线上状态，但当前不读回，也没有专门的成功文案。status 只能确认身份、工作稿与 latest，不能确认上下架状态；最后在浏览器资源管理页核对已上架。完整首次流程见[快速上手](./01-快速上手.md)，策略添加见[单资源授权策略](./07-单资源授权策略.md)。

## 下架

确实需要下架时执行，**不是上架后的下一步**：

```powershell
freelog-cli offline --resource id:<资源ID> --yes --env dev
freelog-cli status --resource id:<资源ID> --env dev
```

只改变可用状态，不删除资源、历史版本、策略、本地身份或工作稿。offline 也不读回上下架状态，在浏览器核对已下架；不要从 CLI 下架操作自行推导已有合约的退款或解除规则。

## 其它管理与失败

- 自身策略启停见[策略教程](./07-单资源授权策略.md#启停已有策略)。
- 发新版、绑定已有资源见[日常路径](./04-日常路径.md)。
- 修改已发版本说明见[两种版本说明](./06-版本工作稿.md#5-两种版本说明)，不是资源简介。
- 非 owner、被冻结或环境不符时写操作会拒绝，不因此删除本地稿。中断或结果未知先按[故障恢复](./09-常见情况与报错.md)只读核实；资料和策略更新不套用版本提交恢复器。
