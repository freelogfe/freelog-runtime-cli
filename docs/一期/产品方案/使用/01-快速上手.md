# 01 - 快速上手

目标：从零把一个本地视频发成线上的 `1.0.0`。全链已经过 dev 真网验证。

---

## 0. 安装与前提

- Node >= 20。
- 仓库内开发：`pnpm --filter @freelog-cli/cli2 build` 后用 `node packages/cli/dist/bin/index.js`（下文记作 `freelog-cli`）。
- 一期**只做普通单资源**。合集（subjectType=4）整条失败。
- prod 暂未开放：所有写命令不加 `--env` 会被拦。联调一律 `--env dev`（或 `test`）。

---

## 1. 登录

```bash
# 交互：省略 --login-name 会提示；密码目前必须走 stdin（避免进 shell 历史）
freelog-cli login --login-name <账号名> --password-stdin --yes --env dev
# 提示密码后输入，回车

# 一行版
echo '你的密码' | freelog-cli login --login-name <账号名> --password-stdin --yes --env dev
```

- 密码**必须** `--password-stdin`（连同 `--yes`）；直接把密码当参数的写法不存在。
- 凭据写入当前目录 `.freelog/auth`（加密）。找不到工作区凭据时才看 `~/.freelog-auth`。
- `--global` 写机器默认号 `~/.freelog-auth`。
- 换账号 / 换环境：`logout` 再 `login`。一份凭据只绑一个环境。

## 2. 立项（可选）

`init` 只建本地工程，不碰平台，不登录也行。

```bash
freelog-cli init --scaffold none --resource-type RT006003 --env dev   # 短视频
freelog-cli type list --env dev          # 先查有哪些叶子类型
freelog-cli type search 视频 --env dev   # 按名搜
```

跳过 `init` 直接 `create` 也可以（会自动新建 `.freelog/1.json`）。

## 3. 建壳

```bash
freelog-cli create --title 我的视频 --type RT006003 --name my-video --file ./video.mp4 --env dev
# 输出 resourceId，例如 6a9e40114b5cf5002fa7499d
```

- `--name` 只传短标识（1–60 字符，`\ / : * ? " < > |`、空白、`@$#`、emoji 会换 `_`）。不要带 `username/`。
- `--file` 只记路径，**本步不上传**；路径必须落在当前工程里。
- `--yes` 时 `--type` `--title` `--name` 三个都缺一不可。

壳已存在（本地 `N.json` 有 `resourceId`，或线上同名）会失败并指路，见 [06-常见情况](./06-常见情况与报错.md)。

## 4. 发首版

```bash
freelog-cli create-version --prepare --env dev    # 上传 + 解析，不提交；稿留在本地
freelog-cli version show --local --env dev        # 看工作稿
freelog-cli create-version --yes --env dev        # 正式提交 1.0.0
# 输出：1.0.0；成功后 .freelog/N.version.json 自动删除
```

- 版本号写死 `1.0.0`，描述空串。视频可以一次都不填属性直接交。
- 中断没关系：文件 sha1 已在工作稿，下次接着来。
- 提交前线上若已出现版本（网页上发过）会再拦一次，稿不丢。

## 5. 加策略并上架（可选，上架需要）

```bash
freelog-cli policy apply --from-file /path/to/free.json --yes --env dev
# free.json: {"policyName": "免费策略", "policyText": "FOR PUBLIC Initial[active]:\n  terminate", "status": 1}
freelog-cli policy list --env dev                 # 确认策略是 on
freelog-cli validate --for online --env dev       # 预检：有版本 + 有启用策略
freelog-cli online --env dev                      # 上架
freelog-cli status --env dev                      # 本地 / 工作稿 / 线上 一览
freelog-cli offline --env dev                     # 下架
```

没有版本或没有启用策略，`online` 会失败且**不会**帮你加策略——先 `policy`。

## 6. 完整链一屏版

```bash
echo '你的密码' | freelog-cli login --login-name <账号名> --password-stdin --yes --env dev
freelog-cli init --scaffold none --resource-type RT006003 --yes --env dev
freelog-cli create --title 我的视频 --type RT006003 --name my-video --file ./video.mp4 --yes --env dev
freelog-cli create-version --prepare --env dev
freelog-cli create-version --yes --env dev            # → 1.0.0
freelog-cli policy apply --from-file ../free.json --yes --env dev
freelog-cli validate --for online --env dev
freelog-cli online --env dev
```

之后要发新号：见 [02-日常路径 §发新号](./02-日常路径.md)。
