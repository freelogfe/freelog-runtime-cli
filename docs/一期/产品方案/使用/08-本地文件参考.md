# 08 - 本地文件参考

工程里只有 **`.freelog/`** 这一个产品目录。根上不该出现 `freelog.manifest.json`、`.freelog-auth`（全局凭据例外）、`state.json`。真源在 [ARCHITECTURE/02-本地状态](../脚手架设计/ARCHITECTURE/02-本地状态.md)。

```
my-project/
  .freelog/
    auth          # 凭据（加密）——不提交
    1.json        # 第 1 份身份——宜提交
    2.json        # 第 2 份身份——宜提交
    1.version.json# 第 1 份的工作稿（有稿才有）——宜提交
    index.json    # 路径 → 编号 查询索引——宜提交
    lock          # 进程写锁（瞬时，进程退出即删）——不提交
  video.mp4       # 本地素材
  dist/           # 主题/插件构建产物
```

---

## 1. `N.json` —— 身份

**编号只是文件名，不是排序。** 新资源 `max+1`，用过的号不复用（删掉 `2.json` 再建新资源是 `3.json`，不补 2）。

```json
{
  "subject": "resource",
  "resourceId": "6a9e40114b5cf5002fa7499d",
  "name": "my-video",
  "typeCode": "RT006003",
  "filePath": "video.mp4",
  "env": "dev"
}
```

| 字段 | 谁写入 | 说明 |
|------|--------|------|
| `subject` | `init` / `create` | 恒 `"resource"`（普通单资源） |
| `name` | `init` / `create` / `bind` | 授权标识短段；创建后只读 |
| `typeCode` | `init` / `create` | 叶子类型编号；`create --type` 可改写 |
| `resourceId` | **仅** `create` 成功或 `bind` | 没有它就不能发版 |
| `filePath` | `init`（主题/插件默认 `dist`）/ `create --file` / `bind --file` / `version set --file` / 发版确认后回写 | 本地文件或产物目录的相对路径 |
| `env` | **仅**非 prod 的 `create` / `bind` | `"dev"` / `"test"`；**没写 = prod** |

写不进去的字段（会报 `N.json 不能写入 …`）：`title`、`intro`、`coverImages`、`tags`、`latestVersion`、`artifactMode`、`fileSha1`、任何策略/版本信息。**标题、listing、策略、已发版事实都在平台上，不缓存。**

手工编辑是允许的（人 / AI 都可以直接改），但只许改上面这些字段、JSON 必须合法；改坏会报 `身份文件无效`。

## 2. `N.version.json` —— 版本工作稿

**还没 POST 的下一版。** 每改一项立刻写盘；`create-version` / `update-version` **成功后自动删除**，失败保留。

```json
{
  "fromVersion": "1.0.0",
  "fileSha1": "c27caad95fc5f6c9866b9352fd10313c8105ecc2",
  "filename": "video.mp4",
  "description": "第二版的描述",
  "inputAttrs": [
    { "key": "时长", "value": "120" }
  ],
  "customPropertyDescriptors": [
    {
      "key": "author",
      "name": "作者",
      "defaultValue": "张三",
      "type": "readonlyText"
    }
  ],
  "dependencies": [
    { "resourceId": "res_xxx", "versionRange": "^1.0.0" }
  ],
  "baseUpcastResources": [],
  "authExcludedItems": []
}
```

| 字段 | 说明 |
|------|------|
| `fromVersion` | **仅更新稿**：这份稿从哪一号拉下来的（`draft pull --version` 或 latest）。首版稿没有它；有它却跑 `create-version` 会失败 |
| `fileSha1` / `filename` | 上传成功（或平台已有同 sha1 文件）后立刻写入。中断续传靠它 |
| `description` | 描述。首版恒空串；更新稿用 `version draft description` 改 |
| `inputAttrs` | 附加 value（系统解析出来的那些）。**raw 系统属性不进稿**，每次现解析 |
| `customPropertyDescriptors` | 自定义属性（`readonlyText`）+ 可选配置（`radio`/`checkbox`/`select`/文本），各 30 条上限 |
| `dependencies` | 依赖树（范围 + 已签状态由 `version dep` 维护） |
| `baseUpcastResources` / `authExcludedItems` | **本期恒 `[]`**，不要填 |

看稿：`version show --local`。丢稿：`version draft discard [--yes]`。改稿：`version attr / option / dep / draft description`。

## 3. `index.json` —— 查询索引

```json
{
  "video.mp4": 1,
  "dist": 2
}
```

- 只是「路径 → 编号」的加速查找，**不是主本**；和 `N.json` 打架时听 `N.json`，下一条命令会自动修好 index。
- 手工删掉也没关系：会按各份 `N.json` 的 `filePath` 重建。
- 键是正斜杠相对路径（`\` 会归一化成 `/`）。

## 4. `auth` —— 凭据

形状见 [07 §5](./07-环境与凭据.md)。加密存储；**不提交、不复制、不手改**。从 `--cwd` 往上找最近的一份，找不到才用 `~/.freelog-auth`。

## 5. `lock` —— 写锁

跑写命令时瞬时出现；进程退出即删。看到它残留且确认没有 CLI 进程在跑，可以手动删（报 `工程正在被另一进程写入` 时的处理）。

## 6. 提交到 Git 的口径

| 文件 | Git |
|------|-----|
| `.freelog/N.json`、`N.version.json`、`index.json` | **宜提交**（团队/AI 接着干活的凭据） |
| `.freelog/auth` | **不提交**（凭据） |
| `.freelog/lock` | 不提交（瞬时） |

一夹多资源的工程就是多份 `N.json` + 一个 index；每份身份独立 `create --file` → `create-version --file`。
