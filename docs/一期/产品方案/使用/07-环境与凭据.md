# 环境与账号

## 环境

| 参数 | 用途 | 当前状态 |
|---|---|---|
| `--env dev` | 开发联调环境 | 可用 |
| `--env test` | 测试环境 | 可用 |
| `--env prod` | 正式环境 | 当前 CLI 明确拦截 |

环境优先级为：命令行 `--env` → `FREELOG_ENV` → `prod`。因此联调时建议每条平台命令都显式带 `--env dev` 或 `--env test`。

## 登录

交互终端：

```powershell
freelog-cli login --env dev
```

自动化或非交互终端：

自动化命令必须同时带 `--login-name <账号名>`、`--password-stdin` 和 `--yes`；由 CI 的保密输入将密码写入标准输入。不要用 PowerShell 变量、命令行文本、脚本文件或环境变量保存或传递密码。

登录请求默认 15 秒超时；超时、网络错误、认证失败或系统凭据库不可用时，都不会写入账号选择器。

切换账号或环境必须先退出再登录：

```powershell
freelog-cli logout --cwd <工程目录>
freelog-cli login --cwd <工程目录> --env test
```

默认登录写工作区选择器；`--global` 写机器默认选择器：

```powershell
freelog-cli login --global --env dev
freelog-cli logout --global
```

## 凭据保存位置

| 内容 | 位置 | 是否可提交到 Git |
|---|---|---|
| 工作区账号选择器 | 最近的 `.freelog/auth` | 否 |
| 全局账号选择器 | `~/.freelog/auth-default.json` | 否 |
| token、Cookie 等秘密 | 操作系统凭据库 | 不适用 |

`.freelog/auth` 和全局文件只保存 schema、环境、用户 id、用户名与凭据库 key；不保存密码、token 或 Cookie。运行命令时，CLI 从 `--cwd` 向上寻找最近的工作区选择器；一旦找到，即使它损坏或环境不符也不会回退到全局账号。

旧式、含 `token` / `cookie` / `iv` 等字段的账号文件不会被解密或迁移。显式 `logout` 清除目标选择器后再 `login`。

## 安全边界

- 不要把密码写成 `--password`、命令行文本、环境变量、JSON 或 Git 文件。
- 不要复制 `.freelog/auth` 到另一台机器；它不带秘密，另一台机器仍需重新登录。
- `logout` 只删除账号选择器，不会删除 `.freelog/N.json`、版本工作稿或模板缓存。
- 平台返回认证失败时，CLI 停止当前操作；未提交版本稿仍然保留。
