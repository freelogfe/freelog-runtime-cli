# 按场景选入口

本页只帮你选择教程，不重复列一遍命令。先分清“没有线上资源”“线上只有资源壳”“已有发行版本”，再选路径；主题、插件与普通文件共用单资源发行规则，合集单独操作。

## 单资源：我从哪里开始？

| 当前情况 | 操作目标与入口 |
|---|---|
| 第一次用 CLI，已有一张图片、一段视频或其它普通文件 | [安装 → 创建 → 首版 → 策略 → 上架](./01-快速上手.md) |
| 没有主题源码，想从线上模板开始 | [模板 → 开发构建 → 首版 → 策略 → 上架](./05-主题与插件.md#从线上模板到主题首次上架) |
| 已有本地主题或插件，线上还没有资源 | [接入现有工程并首次发行](./05-主题与插件.md#已有本地主题或插件首次发行) |
| 本地已经 init，但还没有线上资源 ID | [继续创建，不要重复 init](./04-日常路径.md#initcreatebind-各做什么) |
| 自己的线上资源已经发行，本地尚未接入 | [bind → 拉更新稿 → 发新版](./04-日常路径.md#接入已有资源并发布新版本) |
| 已经 bind，且线上已有版本 | [先核对 status 和产物，再建立或编辑更新稿](./04-日常路径.md#接入已有资源并发布新版本)，跳过重复 bind。 |
| 自己的线上资源只有壳，没有发行版本 | [bind 后走首版，不走更新](./04-日常路径.md#接入只有资源壳的线上资源) |
| 同一个目录有多份文件或多个构建产物 | [每份单资源分别操作，显式选目标](./04-日常路径.md#同一目录管理多份资源) |
| 下一版需要填写属性、可选配置、依赖或说明 | [发行前编辑工作稿](./06-版本工作稿.md) |
| 只想改已有版本的说明，不发新版 | [已发版本说明](./06-版本工作稿.md#5-两种版本说明) |
| 文件路径或构建目录变了 | [先选资源，再改产物路径](./05-主题与插件.md#产物路径与压缩规则)及[版本工作稿](./06-版本工作稿.md#换文件复核与放弃工作稿) |
| 当前稿来自旧版本、想保留或丢弃 | [工作稿复核与明确丢弃](./06-版本工作稿.md#换文件复核与放弃工作稿) |
| 想添加自身策略 | [人工选模板](./07-单资源授权策略.md#人工从模板列表完成添加)或[AI 参数提交](./07-单资源授权策略.md#ai-或脚本添加策略) |
| 想修改标题、封面、简介、标签，或上下架 | [资源管理](./08-资源管理.md) |
| 修改了网页标题，本地还显示旧标题 | [显式同步标题](./08-资源管理.md#同步本地标题) |
| 登录、路径、工作稿报错，或写操作中断 | [故障恢复](./09-常见情况与报错.md)，先核实结果再重试 |

普通文件传一个真实文件；主题、插件通常传构建目录，发版时由 CLI 临时压缩。一个工程包含多个文件不等于一份“多文件普通资源”，也不等于自动批量发行。

## 合集：我从哪里开始？

| 当前情况 | 操作目标与入口 |
|---|---|
| 已有自己的线上已上架单资源，要新建合集 | [合集首次发行与上架](./合集/01-首次发行与发布.md) |
| 单品仍只是本地文件或主题源码 | 先按上面的单资源教程逐个发行、添加自身策略并上架，再进入合集教程。 |
| 已有自己的线上合集，要在本地管理 | [合集管理手册](./合集/02-发行后管理与边界.md) |
| 要增删或调整目录、修改表单、发下一次合集版本 | [合集发行后管理](./合集/02-发行后管理与边界.md) |
| 要为合集添加或启停自身策略 | [合集授权策略](./合集/03-合集授权策略.md) |
| 合集发行中断，结果不确定 | [合集管理中的发行恢复](./合集/02-发行后管理与边界.md) |

合集收录线上资源 ID，不扫描本地文件，不自动包装单资源发行，也不读取网页端未发行草稿。批量单资源发行与 RSS 暂不提供。
