# 资源管理

这些命令管理已绑定资源的线上事实。它们不替代版本发行，也不会修改未提交版本工作稿。

## 查看现状

```powershell
freelog-cli status --env dev
freelog-cli version show --env dev
freelog-cli version show --version 1.0.0 --env dev
freelog-cli policy list --env dev
```

`status` 汇总本地身份、是否存在工作稿和线上 latest；`version show` 与 `policy list` 读取平台当前结果。若只想看本地未交内容，用 `version show --local`。

## 修改展示信息

```powershell
freelog-cli update --title "新标题" --yes --env dev
freelog-cli update --intro "一句话简介" --tags "教程,视频" --yes --env dev
freelog-cli update --cover "<封面值>" --yes --env dev
```

`update` 只会发送明确给出的字段：标题、简介、封面和标签。它不会提交新版本、修改资源标识或上下架状态。

- 标题最多 100 个字符，简介最多 200 个字符。
- 标签最多 20 个，每个最多 20 个字符；不能重复或包含 `#`。
- `--yes` 且没有任一修改字段会失败，不发送空更新。

## 管理授权策略

```powershell
freelog-cli policy list --env dev
freelog-cli policy template list --page 1 --page-size 20 --env dev
freelog-cli policy template apply <templateId> --env dev
freelog-cli policy apply --from-file .\free-policy.json --yes --env dev
freelog-cli policy set --id <policyId> --on --env dev
freelog-cli policy set --id <policyId> --off --env dev
```

`policy template list` 按当前资源类型列出全部平台模板（默认每页 20 条），包含带交易事件的模板；应用模板只是创建授权规则，不会触发支付。策略变更与版本工作稿相互独立，添加策略不会自动上架。`policy apply --from-file` 接受策略文本，或包含 `policyName` 与 `policyText` 的 JSON 文件；策略语义最终由平台校验。

## 上架与下架

```powershell
freelog-cli validate --for online --env dev
freelog-cli online --env dev
freelog-cli offline --env dev
```

上架前必须已有至少一个已发版本和一条启用策略。`validate --for online` 只检查并说明缺失项；`online` 会再次检查后才写线上状态。`offline` 只改变可用状态，不删除资源、版本、策略、身份或工作稿。

如果账号不是资源 owner、资源被冻结或环境不匹配，平台写操作会失败。CLI 不会因此删除本地工程或未提交工作稿；修正登录账号或环境后可继续。
