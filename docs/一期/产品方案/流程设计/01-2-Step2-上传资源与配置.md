## ⚠️ **重要提醒**

Console 的 Step2 是**整个 F1 流程中最复杂的一步**,包含:
1. **4 种上传方式**(本地/存储/MC/卡通编辑器)
2. **文件自动解析系统属性**
3. **可选配置系统**(最多 30 个)
4. **依赖声明与授权管理**

**⏱️ 预计完成时间**: 约 5-8 分钟

**数据验证规则**:
```typescript
interface FileValidationRules {
  maxSize: 500 * 1024 * 1024; // 500MB
  allowedFormats: ['.zip', '.tar.gz', '.pkg'];
  minFileSize: 1024; // 1KB
}

async function validateFile(file: File): Promise<ValidatedFile> {
  // 1. 格式验证
  if (!ALLOWED_FORMATS.includes(file.type)) {
    throw new ValidationError('FILE_FORMAT_INVALID');
  }
  
  // 2. 大小验证
  if (file.size > MAX_SIZE || file.size < MIN_SIZE) {
    throw new ValidationError('FILE_SIZE_INVALID');
  }
  
  // 3. SHA1 计算
  const sha1 = await calculateSHA1(file.path);
  
  return { file, sha1 };
}
```

**Checkpoint 保存时机**: 
- `DURING_UPLOAD`: 每上传 10% 保存一次
- `AFTER_FILE_PARSE`: 属性解析完成后立即保存

interface Step2Submission {
  // 文件信息
  fileInfo: {
    fileId: string;

## 🚨 **四、异常分支与错误码**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|-------|---------|---------|---------|
| FILE_PARSE_ERROR | 文件解析失败 | "无法解析文件属性" | 检查文件格式是否正确 |
| FIELD_REQUIRED | 缺少必需属性 | "缺少必填属性：{key}" | 补充属性值 |
| CONFIG_LIMIT_EXCEEDED | 可选配置超限 | "最多 30 个配置项" | 删除不需要的配置 |
| DEPENDENCY_CONFLICT | 依赖冲突 | "检测到版本冲突" | 调整依赖版本范围 |
| AUTH_NOT_COMPLETE | 授权未完成 | "请先完成依赖授权" | 完成授权后再提交 |
| UPLOAD_TIMEOUT | 上传超时 | "上传超时，请检查网络" | 断点续传后重试 |
