### **Phase 1: 目录扫描**

#### **2.1 功能说明**

递归扫描指定目录及其子目录，识别所有包含 `manifest.json` 的资源工程。

#### **2.2 扫描规则**

| 规则 | 说明 | 示例 |
|------|------|------|
| **递归深度** | 无限制 | `./themes/a/b/c/theme/manifest.json` ✓ |
| **文件匹配** | 查找 `manifest.json` | 必须有此文件 |
| **隐藏文件** | 跳过 | `.gitignore`, `.DS_Store`, `node_modules/` |
| **忽略文件夹** | 不处理 | `.git`, `dist/`, `build/`, `vendor/` |

#### **2.4 实现逻辑**

```typescript
class DirectoryScanner {
  constructor(
    private rootDir: string,
    private config: {
      includeHidden: boolean = false;
      ignorePatterns: string[] = ['.git*', 'node_modules', 'dist*'];
      manifestPattern: string = 'manifest.json';
    }
  ) {}

  async scan(): Promise<ScanResult> {
    const validEntries: ValidEntry[] = [];
    const invalidEntries: InvalidEntry[] = [];
    const duplicateGuids: Set<string> = new Set();

    // 递归扫描函数
    const walk = async (dir: string): Promise<void> => {
      try {
        const files = await fs.readdir(dir);

        for (const file of files) {
          const filePath = path.join(dir, file);
          const stat = await fs.stat(filePath);

          // 检查是否为目标文件
          if (file === this.config.manifestPattern) {
            try {
              const manifest = await this.parseManifest(filePath);
              validEntries.push({
                dir: dir,
                manifest: manifest,
                type: 'valid'
              });
            } catch (error) {
              invalidEntries.push({
                path: filePath,
                reason: error.message
              });
            }
          } 
          // 检查是否为目录
          else if (stat.isDirectory() && !this.isIgnored(file)) {
            await walk(filePath);
          }
        }
      } catch (error) {
        console.warn(`⚠️ 无法读取目录 ${dir}: ${error.message}`);
      }
    };

    // 启动扫描
    await walk(this.rootDir);

    // 去重检查 (基于 guid)
    const uniqueEntries = this.removeDuplicates(validEntries);

    return {
      rootDir: this.rootDir,
      totalScannedDirs: this.countDirectories(),
      validEntries: uniqueEntries,
      invalidEntries: invalidEntries,
      duplicatesRemoved: duplicateGuids.size
    };
  }

  private isIgnored(name: string): boolean {
    return this.config.ignorePatterns.some(pattern => {
      const regex = new RegExp(pattern.replace('*', '.*'));
      return regex.test(name);
    });
  }
}
```

#### **2.6 功能说明**


#### **2.8 批次划分算法**

```typescript
class BatchPlanner {
  plan(entries: ValidEntry[], config: BatchConfig): BatchPlan {
    const batches: Batch[] = [];
    
    // 按导入顺序分批次
    for (let i = 0; i < entries.length; i += config.batchSize) {
      const batchEntries = entries.slice(i, i + config.batchSize);
      batches.push({
        index: Math.floor(i / config.batchSize) + 1,
        items: batchEntries,
        status: 'PENDING'
      });
    }
    
    return {
      totalBatches: batches.length,
      batches: batches,
      config: config
    };
  }
}
```

#### **2.9 冻结资源检测**

```typescript
class FrozenResourceChecker {
  async check(resourceId: string): Promise<boolean> {
    const resource = await platform.Resource.getDetail(resourceId);
    return resource.frozen === 1;  // 1=冻结，0=正常
  }

  async checkBatch(items: Item[]): Promise<Map<string, boolean>> {
    const frozenMap = new Map<string, boolean>();
    
    for (const item of items) {
      const isFrozen = await this.check(item.resourceId);
      frozenMap.set(item.resourceId, isFrozen);
    }
    
    return frozenMap;
  }
}

// 使用时
const checker = new FrozenResourceChecker();
const frozenStatus = await checker.checkBatch(batchItems);

batchItems.forEach(item => {
  if (frozenStatus.get(item.resourceId)) {
    console.log(`⏭️  ${item.manifest.name} (资源已冻结)`);
  } else {
    console.log(`✅  ${item.manifest.name} (可发布)`);
  }
});
```

### **Phase 3: 并发发布**

#### **2.11 功能说明**

对每个批次内的项目并行执行 F1 发布流程，支持进度监控和失败重试。

#### **2.12 并发控制实现**

```typescript
class BatchPublisher {
  async publish(batches: Batch[], config: BatchConfig): Promise<BatchReport> {
    const semaphore = new Semaphore(config.maxConcurrency);
    const results: ItemResult[] = [];

    // 并行执行所有批次
    const batchPromises = batches.map(async (batch) => {
      const batchResults = await Promise.allSettled(
        batch.items.map(async (item) => {
          // 获取信号量许可
          const release = await semaphore.acquire();
          
          try {
            // 检查冻结状态
            const isFrozen = await this.checker.check(item.resourceId);
            
            if (isFrozen) {
              return {
                status: 'skipped',
                resourceId: item.resourceId,
                reason: 'frozen',
                message: '资源已冻结，已跳过'
              };
            }
            
            // 执行 F1 发布流程
            const result = await this.publishSingle(item);
            return { ...result, status: 'success' };
            
          } finally {
            release();  // 释放信号量
          }
        })
      );
      
      // 批次间隔
      if (config.delayBetweenBatches > 0) {
        await sleep(config.delayBetweenBatches);
      }
    });
    
    await Promise.all(batchPromises);
    
    return this.generateReport(results);
  }

  private async publishSingle(item: ValidEntry): Promise<ItemResult> {
    let retries = 0;
    
    while (retries < config.maxRetries) {
      try {
        // 调用 F1 发布流程
        const result = await publishFlow.execute(item);
        return result;
        
      } catch (error) {
        retries++;
        
        if (retries >= config.maxRetries) {
          return {
            status: 'failed',
            resourceId: item.resourceId,
            error: error.message
          };
        }
        
        // 指数退避重试 (1s, 2s, 4s...)
        const delay = Math.pow(2, retries - 1) * 1000;
        console.log(`⏱️  等待 ${delay/1000}s 后重试 (${retries}/${config.maxRetries})`);
        await sleep(delay);
      }
    }
  }
}
```

#### **2.14 进度条实现**

```typescript
class ProgressBar {
  private current: number = 0;
  private total: number;
  private width: number = 40;
  private startTime: number;

  constructor(total: number) {
    this.total = total;
    this.startTime = Date.now();
  }

  update(current: number) {
    this.current = current;
    const percent = current / this.total;
    
    // 计算进度条宽度
    const filledWidth = Math.floor(this.width * percent);
    const emptyWidth = this.width - filledWidth;
    
    const bar = `[${'█'.repeat(filledWidth)}${'░'.repeat(emptyWidth)}]`;
    
    // 计算实时速度
    const elapsed = (Date.now() - this.startTime) / 1000;
    const speed = (current / elapsed).toFixed(2);
    
    // 输出进度条
    process.stdout.write(
      `\r${chalk.blue('▶')} 发布中... ${bar} ${(percent * 100).toFixed(0)}%  ` +
      `(${current}/${this.total}) @ ${speed} MB/s`
    );
    
    if (current === this.total) {
      console.log('\n✅ 完成!\n');
    }
  }
}

// 使用示例
const progressBar = new ProgressBar(totalItems);

for (let i = 0; i < totalItems; i++) {
  await publishItem(items[i]);
  progressBar.update(i + 1);
}
```

```typescript
async function generateReport(report: BatchReport): Promise<void> {
  // CSV 格式
  const csvContent = generateCSV(report);
  await fs.writeFile('report.csv', csvContent);
  console.log('✅ CSV 报告已保存：report.csv');
  
  // PDF 格式
  const pdfContent = generatePDF(report);
  await fs.writeFile('report.pdf', pdfContent);
  console.log('✅ PDF 报告已保存：report.pdf');
}

function generateCSV(report: BatchReport): string {
  const headers = ['Status', 'ResourceID', 'ResourceName', 'Version', 'Reason'];
  const rows = [
    ...report.details.successes.map(r => ['SUCCESS', r.resourceId, r.resourceName, r.version, '-']),
    ...report.details.failures.map(r => ['FAILED', r.resourceId, r.resourceName, '-', r.reason]),
    ...report.details.skips.map(r => ['SKIPPED', r.resourceId, r.resourceName, '-', r.reason])
  ];
  
  return [headers.join(','), ...rows.map(r => r.join(','))].join('\n');
}
```

## 🔄 **三、Checkpoint 机制**

### **3.1 批量场景的特殊要求**

| 特性 | 普通发布 | 批量发布 |
|------|---------|---------|
| **粒度** | 单个资源 | 每个条目独立 checkpoint |
| **恢复范围** | 完整流程 | 从失败项继续 |
| **持久化** | .freelog-checkpoint.json | checkpoint-batch-{timestamp}.json |

### **3.2 数据结构**

```typescript
interface BatchCheckpoint {
  version: "2.0";
  runId: string;
  rootDir: string;
  scannedEntries: number;
  completedItems: string[];       // 已完成的 resourceId 列表
  failedItems: FailedItem[];      // 失败的项及原因
  skippedItems: SkippedItem[];    // 跳过的项及原因
  currentBatchIndex: number;      // 当前批次索引
  retryCounts: Map<string, number>;  // 每个资源的重试次数
  status: "IN_PROGRESS" | "PAUSED" | "COMPLETED";
  lastUpdateAt: number;
}

interface FailedItem {
  resourceId: string;
  resourceName: string;
  error: string;
  retryAfter: number;  // 建议的下次尝试时间戳
}

interface SkippedItem {
  resourceId: string;
  resourceName: string;
  reason: string;
}
```
