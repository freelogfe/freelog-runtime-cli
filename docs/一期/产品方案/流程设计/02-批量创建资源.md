## 🔍 **二、Phase 1: 目录扫描**

### **2.1 扫描规则定义**

```typescript
interface ScanRules {
  // 入口目录
  rootDir: string;
  
  // 匹配规则
  manifestPatterns: string[];  // ['manifest.json', 'freelog.json']
  ignorePatterns: string[];    // ['.git/*', '.DS_Store', 'node_modules/**']
  
  // 过滤选项
  skipHiddenFiles: true;
  skipEmptyDirectories: true;
  maxDepth?: number;           // 默认无限深度
}

// DirectoryScanner 核心逻辑
class DirectoryScanner {
  async scan(config: ScanConfig): Promise<ScanResult> {
    const entries: ValidEntry[] = [];
    const invalidEntries: InvalidEntry[] = [];
    
    // 1. 递归扫描所有文件
    const allFiles = await this.readdirRecursive(config.rootDir);
    
    // 2. 应用忽略规则
    const relevantFiles = allFiles.filter(file => 
      !this.matchesIgnorePattern(file, config.ignorePatterns)
    );
    
    // 3. 查找 manifest 文件
    for (const filePath of relevantFiles) {
      if (this.isManifestFile(filePath)) {
        try {
          const entry = await this.parseManifest(filePath);
          entries.push(entry);
        } catch (err) {
          invalidEntries.push({
            path: filePath,
            reason: this.extractErrorCode(err),
            errorMessage: err.message
          });
        }
      }
    }
    
    return {
      validEntries: entries,
      invalidEntries,
      statistics: this.computeStatistics(entries, invalidEntries)
    };
  }
}
```

### **2.3 Manifest 解析逻辑**

```typescript
async function parseManifest(filePath: string): Promise<ValidEntry> {
  const content = fs.readFileSync(filePath, 'utf-8');
  const ext = path.extname(filePath);
  
  let manifest: ManifestData;
  
  switch (ext) {
    case '.json':
      manifest = JSON.parse(content);
      break;
      
    case '.yaml':
    case '.yml':
      manifest = jsyaml.load(content) as ManifestData;
      break;
      
    default:
      throw new ValidationError('UNSUPPORTED_FORMAT', '不支持的 manifest 格式');
  }
  
  // 验证必填字段
  const validated = ManifestSchema.parse(manifest);
  
  return {
    path: filePath,
    directory: path.dirname(filePath),
    manifestType: detectManifestType(validated),
    resources: validated.resources || [{ type: 'theme' }],
    metadata: {
      title: validated.title,
      version: validated.version,
      author: validated.author
    },
    isValid: true
  };
}

// 自动识别 manifest 类型
function detectManifestType(data: any): ManifestType {
  if (data.type === 'collection') return 'collection';
  if (Array.isArray(data.resources)) return 'batch';
  return 'single';
}
```

### **2.4 异常分支处理**

| 异常场景 | 错误码 | 用户提示 | 处理方式 |
|---------|--------|---------|---------|
| 文件不是有效 JSON | MANIFEST_PARSE_ERROR | "manifest.json 格式错误" | 加入 invalidEntries 跳过 |
| 缺少必填字段 | FIELD_REQUIRED | "缺少字段：title" | 加入 invalidEntries 跳过 |
| 检测到循环引用 | CIRCULAR_REFERENCE | "目录结构包含循环" | 终止整个扫描 |
| 磁盘 I/O 错误 | DISK_IO_ERROR | "读取文件失败" | 尝试 3 次后标记为 invalid |
| 权限不足 | PERMISSION_DENIED | "无法访问：{path}" | 记录警告但继续扫描 |

### **3.2 批次划分算法**

```typescript
class BatchPartitioner {
  partition(entries: ValidEntry[], config: BatchConfig): Batch[] {
    // 1. 按导入顺序分组
    const batches: Batch[] = [];
    
    for (let i = 0; i < entries.length; i += config.batchSize) {
      const batchEntries = entries.slice(i, i + config.batchSize);
      
      batches.push({
        id: `batch-${batches.length + 1}`,
        entries: batchEntries,
        startIndex: i,
        endIndex: Math.min(i + config.batchSize - 1, entries.length - 1),
        estimatedDuration: this.estimateDuration(batchEntries)
      });
    }
    
    // 2. 冻结资源检测
    const frozenResources = await this.detectFrozenResources(entries);
    
    // 3. 过滤掉冻结的资源
    const activeBatches = batches.map(batch => ({
      ...batch,
      entries: batch.entries.filter(entry => 
        !frozenResources.has(entry.id)
      ),
      skippedCount: batch.entries.length - batch.entries.filter(
        entry => !frozenResources.has(entry.id)
      ).length
    })).filter(batch => batch.entries.length > 0);
    
    return activeBatches;
  }
  
  private estimateDuration(entries: ValidEntry[]): number {
    // 基于历史数据估算时间
    const avgTimePerEntry = 5000; // 平均 5 秒/条
    return entries.length * avgTimePerEntry;
  }
}
```

### **3.3 冻结状态检测**

```typescript
async function detectFrozenResources(entries: ValidEntry[]): Promise<Set<string>> {
  const frozenIds = new Set<string>();
  const client = createFreelogClient();
  
  // 并行查询所有资源的冻结状态
  const checks = entries.map(async (entry) => {
    try {
      const resourceInfo = await client.resource.get(entry.id);
      if (resourceInfo.status === 'frozen') {
        return entry.id;
      }
      return null;
    } catch (err) {
      // API 调用失败视为非冻结（继续尝试）
      return null;
    }
  });
  
  const results = await Promise.all(checks);
  results.forEach(id => {
    if (id) frozenIds.add(id);
  });
  
  return frozenIds;
}
```

## ⚡ **四、Phase 3: 并发发布**

### **4.1 并发控制实现**

```typescript
class BatchPublisher {
  async publish(batches: Batch[], config: BatchConfig): Promise<BatchResult[]> {
    const results: BatchResult[] = [];
    const semaphore = new Semaphore(config.maxConcurrency);
    
    // 使用 Promise.allSettled 保证所有批次都执行
    const promiseResults = await Promise.allSettled(
      batches.map(async (batch, index) => {
        return semaphore.acquire(() => 
          this.publishSingleBatch(batch, index + 1, config)
        );
      })
    );
    
    promiseResults.forEach((result, idx) => {
      if (result.status === 'fulfilled') {
        results.push(result.value);
      } else {
        results.push({
          batchId: batches[idx].id,
          status: 'failed',
          error: result.reason,
          successCount: 0,
          failureCount: batches[idx].entries.length
        });
      }
    });
    
    return results;
  }
  
  private async publishSingleBatch(
    batch: Batch,
    batchNumber: number,
    config: BatchConfig
  ): Promise<BatchResult> {
    
    const progressBar = new ProgressBar();
    const startTime = Date.now();
    
    let successCount = 0;
    let failureCount = 0;
    const failures: FailureDetail[] = [];
    
    // 逐个处理批次中的条目
    for (let i = 0; i < batch.entries.length; i++) {
      const entry = batch.entries[i];
      
      try {
        // 显示当前进度
        this.renderCurrentTask(entry, i + 1, batch.entries.length);
        
        // 执行单资源发布
        const result = await this.publishSingleResource(entry, config);
        
        if (result.success) {
          successCount++;
          this.renderSuccess(entry, result.duration);
        } else {
          throw new Error(result.error);
        }
        
      } catch (err) {
        // 重试逻辑
        const finalResult = await this.retryWithExponentialBackoff(
          () => this.publishSingleResource(entry, config),
          config.retryCount,
          config.retryDelay
        );
        
        if (finalResult.success) {
          successCount++;
        } else {
          failureCount++;
          failures.push({
            entryPath: entry.path,
            errorCode: finalResult.errorCode,
            errorMessage: finalResult.errorMessage,
            retries: finalResult.retriesUsed
          });
        }
      }
      
      // 更新进度条
      const progress = Math.round(((i + 1) / batch.entries.length) * 100);
      progressBar.render(progress);
    }
    
    const duration = Date.now() - startTime;
    
    return {
      batchId: batch.id,
      batchNumber,
      status: failureCount === 0 ? 'success' : 'partial_failure',
      total: batch.entries.length,
      successCount,
      failureCount,
      skippedCount: batch.skippedCount || 0,
      duration,
      averageSpeed: (batch.entries.length * 1024 * 1024) / (duration / 1000),
      failures
    };
  }
}
```

### **4.2 信号量实现**

```typescript
class Semaphore {
  private limit: number;
  private available: number;
  private queue: Array<() => void> = [];
  
  constructor(limit: number) {
    this.limit = limit;
    this.available = limit;
  }
  
  async acquire<T>(fn: () => Promise<T>): Promise<T> {
    // 如果有可用许可，立即执行
    if (this.available > 0) {
      this.available--;
      try {
        return await fn();
      } finally {
        this.release();
      }
    }
    
    // 否则排队等待
    return new Promise((resolve, reject) => {
      this.queue.push(async () => {
        try {
          const result = await fn();
          resolve(result);
        } catch (err) {
          reject(err);
        } finally {
          this.release();
        }
      });
      
      this.processQueue();
    });
  }
  
  private release() {
    this.available++;
    this.processQueue();
  }
  
  private processQueue() {
    while (this.available > 0 && this.queue.length > 0) {
      this.available--;
      const fn = this.queue.shift();
      if (fn) fn();
    }
  }
}
```

### **4.3 重试策略**

```typescript
async function retryWithExponentialBackoff<T>(
  operation: () => Promise<T>,
  maxRetries: number,
  initialDelay: number
): Promise<{ success: boolean; data?: T; errorCode?: string; errorMessage?: string; retriesUsed: number }> {
  let lastError: unknown;
  let retriesUsed = 0;
  
  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      if (attempt > 0) {
        const delay = initialDelay * Math.pow(2, attempt - 1);
        console.log(`重试 ${attempt}/${maxRetries} (等待${delay}ms)...`);
        await sleep(delay);
      }
      
      const data = await operation();
      return { success: true, data, retriesUsed };
      
    } catch (err) {
      lastError = err;
      retriesUsed = attempt;
      
      // 检查是否是可重试错误
      const errorCode = extractErrorCode(err);
      if (!IS_RETRYABLE_ERRORS.includes(errorCode)) {
        return { 
          success: false, 
          errorCode,
          errorMessage: extractErrorMessage(err),
          retriesUsed 
        };
      }
    }
  }
  
  // 超过最大重试次数
  return {
    success: false,
    errorCode: extractErrorCode(lastError),
    errorMessage: extractErrorMessage(lastError),
    retriesUsed
  };
}
```

### **5.1 统计数据聚合**

```typescript
interface AggregateReport {
  // 基本信息
  summary: {
    startTime: string;
    endTime: string;
    totalDuration: number;
    totalEntries: number;
  };
  
  // 统计数字
  statistics: {
    successCount: number;
    failureCount: number;
    skippedCount: number;
    partialSuccessCount: number; // 有成功也有失败的批次
  };
  
  // 失败详情
  failures: FailureDetail[];
  
  // 性能指标
  performance: {
    averageSpeed: number;       // 平均速度 MB/s
    totalTimeSpent: number;     // 总耗时 s
    totalDataTransferred: number; // 总传输数据 GB
  };
}

function computeAggregateReport(
  batchResults: BatchResult[],
  startTime: Date,
  endTime: Date
): AggregateReport {
  
  let successCount = 0;
  let failureCount = 0;
  let skippedCount = 0;
  let partialSuccessCount = 0;
  const failures: FailureDetail[] = [];
  let totalDataTransferred = 0;
  
  batchResults.forEach(result => {
    successCount += result.successCount;
    failureCount += result.failureCount;
    skippedCount += result.skippedCount;
    
    if (result.successCount > 0 && result.failureCount > 0) {
      partialSuccessCount++;
    }
    
    result.failures.forEach(f => failures.push(f));
    
    // 估算传输数据 (假设每个条目平均 10MB)
    totalDataTransferred += result.successCount * 10;
  });
  
  return {
    summary: {
      startTime: startTime.toISOString(),
      endTime: endTime.toISOString(),
      totalDuration: (endTime.getTime() - startTime.getTime()) / 1000,
      totalEntries: successCount + failureCount + skippedCount
    },
    statistics: {
      successCount,
      failureCount,
      skippedCount,
      partialSuccessCount
    },
    failures,
    performance: {
      averageSpeed: totalDataTransferred / ((endTime.getTime() - startTime.getTime()) / 1000),
      totalTimeSpent: (endTime.getTime() - startTime.getTime()) / 1000,
      totalDataTransferred: totalDataTransferred / 1024 / 1024 // MB
    }
  };
}
```

## ⚡ **六、Checkpoint 断点续传**

### **6.1 批量场景 Checkpoint 设计**

```typescript
interface BatchCheckpoint {
  version: '1.0';
  runId: string;
  
  // 扫描阶段
  scanComplete: boolean;
  scanResult?: ScanResult;
  
  // 批次状态
  batches: BatchCheckpointItem[];
  
  // 元数据
  startTime: string;
  lastUpdatedAt: string;
  expiresAt: string;
  
  // 环境信息
  cliVersion: string;
  platform: string;
}

interface BatchCheckpointItem {
  batchId: string;
  batchNumber: number;
  status: 'pending' | 'in_progress' | 'completed' | 'failed';
  
  // 已成功发布的条目索引
  successIndices: number[];
  
  // 失败的条目索引及原因
  failures: {
    entryIndex: number;
    errorCode: string;
    errorMessage: string;
    retriesUsed: number;
  }[];
  
  // 跳过的条目索引 (如冻结资源)
  skippedIndices: number[];
  
  // 性能数据
  duration: number;
  averageSpeed: number;
}
```

### **6.2 Checkpoint 保存时机**

| 时机 | 触发条件 | 保存内容 |
|------|---------|---------|
| **SCAN_COMPLETE** | 目录扫描完成 | scanResult, validEntries, invalidEntries |
| **BATCH_COMPLETED** | 每批次完成后 | batchStatus, success/failure indices |
| **USER_PAUSE** | 用户按 SPACE 暂停 | 当前批次进度 + 当前条目状态 |
| **SIGNAL_HANDLER** | Ctrl+C 中断 | 所有已完成批次 + 当前进行中的条目 |

### **6.3 恢复逻辑**

```typescript
async function resumeBatchCheckpoint(
  runId: string
): Promise<ResumeState | null> {
  
  const checkpointPath = getBatchCheckpointPath(runId);
  if (!fs.existsSync(checkpointPath)) {
    return null;
  }
  
  const checkpoint = readCheckpoint(checkpointPath);
  
  // TTL 检查
  if (Date.now() > new Date(checkpoint.expiresAt).getTime()) {
    deleteCheckpoint(checkpointPath);
    return null;
  }
  
  // 计算可以继续的批次
  let continueFromBatch = 0;
  let continueFromEntry = 0;
  
  checkpoint.batches.forEach((batch, batchIdx) => {
    if (batch.status === 'in_progress') {
      continueFromBatch = batchIdx;
      continueFromEntry = batch.successIndices.length;
    } else if (batch.status === 'completed') {
      continueFromBatch = batchIdx + 1;
    }
  });
  
  return {
    runId,
    continueFromBatch,
    continueFromEntry,
    existingScanResult: checkpoint.scanResult,
    completedBatches: checkpoint.batches.filter(b => b.status === 'completed')
  };
}
```

## 🚨 **七、异常分支与错误码**

### **7.1 批量特有错误码**

| 错误码 | 触发条件 | 用户提示 | 修复建议 | 重试策略 |
|-------|---------|---------|---------|---------|
| **BATCH_SCAN_FAILED** | 扫描过程中断 | "目录扫描失败" | 检查磁盘空间 | 允许重新扫描 |
| **FROZEN_RESOURCE** | 检测到冻结资源 | "资源已被冻结，已跳过" | 联系平台解锁 | 不重试 |
| **CONCURRENCY_EXCEEDED** | 并发超出限制 | "API 速率限制 exceeded" | 降低并发数 | 指数退避 |
| **BATCH_PARTIAL_SUCCESS** | 批次部分成功 | "X/Y 个条目发布成功" | 查看详细报告 | 可选重试失败项 |
| **GLOBAL_TIMEOUT** | 整个批次超时 | "批次发布超时" | 增加超时时间 | 允许 Resume |
| **DISK_SPACE_LOW** | 磁盘空间不足 | "磁盘空间不足" | 清理磁盘 | 不允许重试 |

### **7.2 错误处理策略**

```typescript
class BatchErrorHandler {
  handle(error: unknown, context: BatchContext): HandleResult {
    const errorCode = extractErrorCode(error);
    
    switch (errorCode) {
      case 'FROZEN_RESOURCE':
        return this.handleFrozenResource(context);
        
      case 'RATE_LIMIT_EXCEEDED':
        return this.handleRateLimit(context);
        
      case 'GLOBAL_TIMEOUT':
        return this.handleGlobalTimeout(context);
        
      case 'NETWORK_DISCONNECTED':
        return this.handleNetworkDisconnect(context);
        
      default:
        return this.handleUnknownError(error, context);
    }
  }
  
  private handleFrozenResource(context: BatchContext): HandleResult {
    log.warn(`跳过冻结资源：${context.entryPath}`);
    
    return {
      action: 'skip_and_continue',
      updateCheckpoint: {
        status: 'skipped',
        reason: 'frozen_resource'
      }
    };
  }
  
  private handleRateLimit(context: BatchContext): HandleResult {
    // 降低全局并发数
    adjustMaxConcurrency(-1);
    
    return {
      action: 'retry_with_delay',
      strategy: 'exponential_backoff',
      initialDelay: 60000, // 首次等待 60s
      maxDelay: 300000
    };
  }
}
```
