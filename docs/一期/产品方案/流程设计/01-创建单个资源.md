## 🔍 **二、详细步骤说明**

### **Step 1: 创建资源壳**

#### **2.1 功能说明**

创建资源的「空壳」，即创建一个只包含基本信息 (资源 ID、授权标识) 但不包含文件的资源记录。

#### **2.2 输入参数**

| 参数 | 来源 | 必填 | 说明 |
|------|------|------|------|
| 资源类型 | 用户交互式选择 | 是 | 从平台拉取类型树，用户选择叶子节点 |
| 资源标题 | 用户输入 | 是 | 最长 100 字符，支持拼音 |
| 授权标识 | 自动生成/用户修改 | 是 | `{owner}/{authid}`格式，自动优化 |

#### **2.3 UI 组件**

```typescript
// Step1 关键逻辑 (从 Console 源码提取)
function Step1({ dispatch, resourceCreatorPage }) {
  // 1. 监听标题输入，实时优化授权标识
  AHooks.useDebounceEffect(
    () => {
      if (title !== resourceName) {
        const optimized = title.substring(0, 60)
          .replace(/[^\w\u4e00-\u9fa5]+/g, '_');
        dispatch(onChange_resourceName({ value: optimized }));
      }
    },
    [title, resourceName],
    { wait: 10 }
  );

  // 2. 防抖验证授权标识唯一性 (300ms)
  const { run } = AHooks.useDebounceFn(() => {
    dispatch(onVerify_resourceName());
  }, { wait: 300 });

  // 3. 按钮禁用条件
  const isCreateDisabled = 
    resourceType === null ||              // 未选择资源类型
    resourceName === '' ||                // 授权标识为空
    resourceName_errorText !== '' ||      // 验证失败
    resourceName_isVerify ||              // 正在验证中
    resourceTitle === '' ||               // 标题为空
    resourceTitle_errorText !== '';       // 标题验证失败

  return (
    <>
      {/* 资源类型选择 */}
      <FResourceTypeInput4 value={resourceType} onChange={...} />
      
      {/* 标题输入 */}
      <FInput_PinyinSafeTextCounter 
        value={resourceTitle} 
        onChangeValue={...} 
      />
      
      {/* 授权标识输入 (带实时优化提示) */}
      <div className={styles.resourceName}>
        <span>{userName} /</span>
        <FInput_PinyinSafeTextCounter 
          value={resourceName} 
          onChangeValue={...}
        />
        
        {/* 优化提示 */}
        {resourceName !== resourceName_optimized && (
          <div style={{ color: '#44C28C' }}>
            您的资源授权标识将自动转换为 {resourceName_optimized}
          </div>
        )}
        
        {/* 加载状态 */}
        {resourceName_isVerify && <FIcons.FLoading />}
        
        {/* 验证通过 */}
        {!resourceName_isVerify && resourceName_errorText === '' && (
          <FIcons.FCheck />
        )}
      </div>
      
      {/* 立即创建按钮 */}
      <FRectBtn
        disabled={isCreateDisabled}
        onClick={() => dispatch(onClick_createBtn())}
      >
        立即创建
      </FRectBtn>
    </>
  );
}
```

### **Step 2: 上传资源文件**

#### **2.7 功能说明**

上传压缩后的产物文件，支持断点续传、进度监控、SHA1 hash 计算。

#### **2.8 支持的格式**

| 格式 | 说明 | 最大大小 |
|------|------|---------|
| ZIP | 最常见，保留目录结构 | 50MB |
| TAR.GZ | Linux 风格压缩 | 50MB |
| RAR | 不支持 | - |

#### **2.10 实现逻辑**

```typescript
class FileUploadService {
  async uploadFile(filePath: string, onProgress: (percent: number) => void): Promise<{ fileId: string; sha1: string }> {
    const fileBuffer = await fs.readFile(filePath);
    const sha1 = crypto.createHash('sha1').update(fileBuffer).digest('hex');
    
    // 读取 checkpoint 中的已上传字节数
    const checkpoint = await this.readCheckpoint();
    const startByte = checkpoint.upload_start_byte || 0;
    
    // 断点续传
    const rangeHeader = startByte > 0 ? `bytes=${startByte}-` : undefined;
    
    const response = await fetch(`${UPLOAD_URL}?fileSha1=${sha1}`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/zip',
        ...(rangeHeader ? { 'Range': rangeHeader } : {})
      },
      body: startByte > 0 ? fileBuffer.slice(startByte) : fileBuffer
    });
    
    // 实时更新进度条
    const totalSize = parseInt(response.headers.get('content-length') || '0');
    const uploadedBytes = startByte + (fileBuffer.length - startByte);
    const percent = (uploadedBytes / totalSize) * 100;
    onProgress(percent);
    
    if (!response.ok) {
      throw new Error(`UPLOAD_FAILED: ${response.statusText}`);
    }
    
    return {
      fileId: response.headers.get('x-file-id'),
      sha1: sha1
    };
  }
  
  async readCheckpoint(): Promise<UploadCheckpoint> {
    const content = await fs.readFile('.freelog-checkpoint.json', 'utf8');
    return JSON.parse(content);
  }
}
```

#### **2.11 异常分支处理**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|--------|---------|---------|---------|
| `INVALID_FILE_FORMAT` | 非 ZIP/TAR.GZ 格式 | "不支持的文件格式，请压缩为 ZIP 或 TAR.GZ" | 重新压缩或使用正确格式 |
| `FILE_SIZE_EXCEEDS_LIMIT` | 超过 50MB | "文件大小超过限制 (50MB)" | 精简文件内容或分批上传 |
| `UPLOAD_FAILED` | 上传失败 (网络中断等) | "上传失败，已保存断点" | 下次运行会自动续传 |
| `SHA1_MISMATCH` | 本地计算与服务器不一致 | "文件校验失败，可能已损坏" | 重新压缩后再次上传 |

#### **2.15 策略编译流程**

```typescript
async function compilePolicy(policyTemplateId: string, customRules?: object): Promise<PolyCompileResult> {
  // 1. 获取模板定义
  const template = await platform.getPolicyTemplate(policyTemplateId);
  
  // 2. 合并自定义规则 (如果有)
  const finalRules = customRules 
    ? mergeRules(template.rules, customRules)
    : template.rules;
  
  // 3. 调用编译 API
  const compiled = await platform.compilePolicy(finalRules);
  
  // 4. 返回编译结果
  return {
    policyId: compiled.id,
    version: compiled.version,
    executionPlan: compiled.bytecode,  // 可执行的策略字节码
    preview: generatePreview(compiled)  // 自然语言描述
  };
}
```

#### **2.18 字段约束**

```typescript
const LISTING_CONSTRAINTS = {
  coverImage: {
    maxSize: 5 * 1024 * 1024,  // 5MB
    formats: ['JPEG', 'PNG', 'GIF'],
    recommendedRatio: '16:9',  // 1280×720 或 720×1280
    validate: async (file: File) => {
      const img = new Image();
      const url = URL.createObjectURL(file);
      img.src = url;
      await img.decode();
      URL.revokeObjectURL(url);
      
      const ratio = img.width / img.height;
      if (ratio < 1.5 || ratio > 1.7) {
        return { valid: false, message: "推荐比例 16:9" };
      }
      return { valid: true };
    }
  },
  
  tags: {
    maxCount: 20,
    maxLengthPerTag: 20,
    autoLowercase: true,
    autoDeduplicate: true,
    parse: (input: string): string[] => {
      return input.split(/[,,\n]/)
        .map(t => t.trim().toLowerCase())
        .filter(t => t.length > 0)
        .filter((v, i, a) => a.indexOf(v) === i);  // 去重
    }
  },
  
  description: {
    minLength: 10,
    maxLength: 500,
    allowMarkdown: true
  }
};
```

```typescript
async function submitResource(resourceId: string): Promise<ResourcePublishedEvent> {
  // 1. 保存策略
  await platform.Resource.setPolicy({
    resourceId,
    policyId: currentPolicyId
  });
  
  // 2. 更新 listing 信息
  await platform.Resource.updateListing({
    resourceId,
    coverUrl: coverImageUrl,
    tags: parsedTags,
    description: userDescription
  });
  
  // 3. 删除 checkpoint (正常完成)
  await checkpointService.delete(resourceId);
  
  // 4. 返回成功事件
  return {
    event: 'RESOURCE_PUBLISHED',
    resourceId,
    timestamp: Date.now(),
    consoleUrl: `https://console.freelog.cn/resource/${resourceId}`
  };
}
```

## 🔄 **三、Checkpoint 机制**

### **3.1 保存时机**

| 场景 | Checkpoint 状态 | 目的 |
|------|----------------|------|
| **BEFORE_REMOTE_WRITE** | Step1 完成后保存 | 资源壳创建成功后可恢复 |
| **DURING_UPLOAD** | Step2 进行中实时保存 | 支持断点续传 |
| **SIGNAL_HANDLER** | SIGINT/SIGTERM信号处理 | 优雅退出时保存进度 |
| **显式 save** | 每个关键步骤后 | 手动保存 |

### **3.2 数据结构**

```typescript
interface PublishCheckpoint {
  version: "1.0";
  runId: string;                    // UUID，唯一标识本次发布
```

### **3.3 恢复逻辑**

```typescript
async function recoverFromCheckpoint(resourceId: string): Promise<boolean> {
  const checkpoint = await checkpointService.load(resourceId);
  
  // 1. 验证 accountId 严格匹配
  if (checkpoint.accountId !== currentAccountId) {
    console.log("⚠️ Checkpoint 属于另一个账号，忽略");
    return false;
  }
  
  // 2. TTL 检查 (>7 天删除)
  if (Date.now() - checkpoint.lastUpdateAt > 7 * 24 * 3600 * 1000) {
    console.log("⚠️ Checkpoint 已过期，清理");
    await checkpointService.delete(resourceId);
    return false;
  }
  
  // 3. 显示恢复提示
  console.log(chalk`\n${chalk.yellow('💾')} 检测到未完成的发布会话:`);
  console.log(`   资源 ID: ${checkpoint.collectedData.resourceId}`);
  console.log(`   已完成步骤：${checkpoint.completedSteps}/4`);
  console.log(`   上次更新：${formatTime(checkpoint.lastUpdateAt)}`);
  
  const shouldResume = await promptConfirm("是否从中断处继续？[Y/n]");
  
  if (shouldResume) {
    restoreState(checkpoint);
    return true;
  } else {
    await checkpointService.delete(resourceId);
    return false;
  }
}
```
