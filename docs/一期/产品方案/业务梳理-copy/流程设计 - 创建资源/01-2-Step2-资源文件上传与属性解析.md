> **对齐 Source**: Console `creator/Step2/index.tsx` L1-1016  
> **核心职责**: 上传资源文件、解析系统属性、配置自定义属性和依赖关系

## 1. 流程总览

```bash
$ freelog create ./file.zip --authid my-theme --type theme

[Step2] 文件上传 → SHA1 计算 → 属性解析 → 提交下一步
  ├─ 本地上传：选择文件或 ZIP 压缩包
  ├─ 存储导入：从对象存储空间选择
  ├─ Markdown 编辑：在线编辑文本内容
  └─ 漫画编辑器：在线编辑漫画内容
```

### 2.4 基础属性解析与展示 (L468-682)

**Console 位置**: L468-682

**业务流程**:
```typescript
// 1. 文件解析状态显示
{systemPropertiesState === 'parsing' && (
  <FIcons.FLoading />
  <span>{正在解析属性}</span>
)}

// 2. 系统属性 + 自定义属性展示
<FAttrsAndConfigs
  dateSource={[
    // 系统属性 (只读 key/value, 可编辑值)
    ...systemProperties.map(sp => ({
      key: sp.key,
      value: sp.value,
      name: sp.name,
      description: sp.description,
      configs: {
        item_Deletable: false,
        key_Editable: false,
        name_Editable: false,
        description_Editable: false,
        value_Editable: sp.type === 'additional' && sp.valueConfig,
      },
    })),
    
    // 自定义属性 (全部可编辑)
    ...customProperties.map(cp => ({
      key: cp.key,
      value: cp.value,
      name: cp.name,
      description: cp.description,
      configs: {
        item_Deletable: true,
        key_Editable: true,
        name_Editable: true,
        description_Editable: true,
        value_Editable: {
          text: {
            nullable: true,
            minLength: 0,
            maxLength: 100,  // Console 限制！
          },
        },
      },
    })),
  ]}
  onChangeItem={(oldData, newData, index) => {
    if (index < systemProperties.length) {
      // 更新系统属性
      const newSystemProperties = [...systemProperties];
      newSystemProperties[index] = {...};
      dispatch(onChange_step2_systemProperties(newSystemProperties));
    } else {
      // 更新自定义属性
      const newCustomProperties = [...customProperties];
      newCustomProperties[index - systemProperties.length] = {...};
      dispatch(onChange_step2_customProperties(newCustomProperties));
    }
  }}
  onDeleteItem={(value) => {
    const newCustomProperties = customProperties.filter(cp => 
      cp.key !== value.key && cp.name !== value.name
    );
    dispatch(onChange_step2_customProperties(newCustomProperties));
  }}
  disabledKeys={所有属性 key 列表}  // 防止重名
  disabledNames={所有属性 name 列表}  // 防止重名
/>
```

**字段约束**:
- ✅ **自定义属性值**: maxLength=100 (L611)
- ✅ **最多 30 个自定义属性** (L484, L736)
- ✅ **属性 key/name 不可重复** (disabledKeys/disabledNames)

## 6. CLI 特殊说明

### 6.1 简化的文件上传
- 无需显示进度动画，仅输出文本日志
- 支持批量上传多个文件
- 自动检测文件类型并调用相应解析器

### 6.2 无草稿机制
- Console 有 300ms debounce 自动保存草稿 (L66-78)
- CLI 不提供断点续传，需一次性完成

### 6.3 微前端依赖排除
- CLI 不调用 FMicroAPP_Authorization 微前端组件
- 如需处理依赖，使用独立的依赖管理命令

### 6.4 属性解析方式
- CLI 不依赖后端解析服务
- 可自行实现属性提取逻辑或跳过此步

### 6.5 自定义属性交互
- 使用命令行参数传递属性：`--property key=value`
- 或使用交互式问答逐个输入

## 7. 异常分支处理

### 错误场景

| 错误场景 | Console 处理 | CLI 处理 |
|---------|-------------|---------|
| 文件过大 | L171 limitFileSize 校验 | 提前检查文件大小，超限报错 |
| SHA1 校验失败 | 内部捕获并重试 | 重新计算 SHA1，失败退出 |
| 属性解析超时 | console.error + 重试 | 设置超时时间，超时则退出 |
| 上传中断 | L146 cancelHandler() | Ctrl+C 触发 signal.abort |
| 属性重名 | L501 disabledKeys | 实时检测冲突，提示修改 |
| 超过 30 个限制 | L484 禁止添加按钮 | 达到 30 个时报错退出 |
