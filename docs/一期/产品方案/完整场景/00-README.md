# Freelog Runtime CLI 场景演练手册

> **目标**: 通过实际使用场景覆盖验证产品设计的完整性
> 
> **原则**: 
> - 按业务域拆分，每个文档专注一个子场景集
> - 每个场景包含完整的 happy path + 异常分支
> - 最后汇总为《Z-设计修订总结》指导产品方案修订

## 🎯 使用方法

1. **按顺序阅读场景文档** → 理解完整业务流程
2. **对照现有产品方案 (00-06 号文件)** → 检查是否有遗漏
3. **记录发现的问题** → 在对应文档中标注
4. **最终查阅 Z 文档** → 获取完整的设计修订清单
