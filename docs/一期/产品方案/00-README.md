## 📋 **一、产品概述**

### 1.1 项目定位

Freelog Runtime CLI 是面向本地资源工程的命令行工作台，对齐 Console 业务语义并补充 CLI 原生能力。

**核心价值**:
- **模板初始化工程**: 支持主题/插件/前端库/软件库的脚手架创建
- **类型驱动打包**: 根据资源类型自动配置发布参数
- **批量文件处理**: 支持目录扫描和批量发行
- **结构化输出**: TTY 交互与 AI-CI 非交互模式双支持
- **声明式 manifest**: 表达发版意图的结构化配置

**三种发行模式**:
1. **单资源**: init → create → publish
2. **批量独立资源**: resource import-dir
3. **合集**: init collection → collection *

### 1.2 业务范围

#### **A. 创建类功能 (F 编号)**
- **F1**: 创建单个资源 (主题/插件/前端库/软件库)
- **F2**: 批量创建资源 (从目录扫描)
- **F3**: 创建合集 (从目录或手动添加条目)

#### **B. 管理单个资源类功能 (M 编号)**
- **M1**: 版本更新 (已有资源的新版本发布)
- **M2**: listing 属性更新 (封面/标签/描述维护)
- **M3**: 授权策略管理 (策略模板切换)

#### **C. 管理合集类功能 (C 编号)**
- **C1**: 单品管理 (合集内条目增删改序)
- **C2**: 合集信息更新 (标题/描述/封面维护)
- **C3**: 合集授权策略管理 (合集级别的策略)

> **注意**: RSS 自动化收录暂时忽略，留待二期实现

- 重点关注每个流程的决策点、输入输出、异常分支

  - `G2-TTY 交互规范.md` (UI 组件)
  - `I1-Checkpoint 机制.md` (会话恢复)
  - `I2-API 调用层.md` (接口封装)
