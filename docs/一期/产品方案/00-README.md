# 产品方案

一期只做**普通单资源**。合集、批量扫盘、`import-dir`、RSS 不做。

本文只指路。不要当流程总纲，也不要按旧的 F1–F3 / `publish` 去实现。

| 目录 | 答什么 | 是不是真源 |
|------|--------|------------|
| [脚手架设计](./脚手架设计/README.md) | CLI 做什么、怎么敲、本地记什么 | **产品真源**。先读「已敲定」 |
| [业务梳理](./业务梳理/README.md) | Console 实际怎么走、对哪些 API | 对照。和 CLI 冲突时听脚手架设计 |
| [开发](./开发/README.md) | 代码放哪、按哪片写、实现门禁 | 不是产品。不许临场改命令 |
| [交接文档](./交接文档.md) | 新会话从哪接着干 | 不替代真源 |

旧稿、合集备份、**旧 CLI 源码**在 [archive](../archive/)。现行 `packages/cli` 可按 [开发](./开发/README.md) 清空重写。

## 本期主路径

```
login
  创建       init? → create → create-version（无上一版，1.0.0）→ policy? → update? → online
  更新版本   version draft pull? → 改缓存 → update-version
  接入       bind <id|username/name> [--file]
```

不用 `publish`。不用顶层 `release`。上架只用 `online`。
