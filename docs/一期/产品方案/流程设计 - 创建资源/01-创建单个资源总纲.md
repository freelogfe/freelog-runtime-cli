## ⚡ **三、Checkpoint 机制总览**

整个 F1 流程涉及多个 Checkpoint 保存点:

| 步骤 | 保存时机 | 数据结构 |
|------|---------|---------|
| Step1 | BEFORE_REMOTE_WRITE | resourceId, authId, type |
| Step2 | DURING_UPLOAD | fileId, uploadedBytes |
| Step2 | AFTER_FILE_PARSE | systemProperties, customProperties |
| Step2 | AUTH_COMPLETE | directDependencies, upcastResources |
| Step3 | AFTER_POLICY_COMPILE | policyId, compiledPolicy |
| Step4 | PRE_SUBMIT | 全部 completedData |

详细实现请参考各步骤文档。

## 🚨 **四、核心异常分支**

| 错误码 | 触发条件 | 处理策略 |
|-------|---------|---------|
| RESOURCE_TYPE_NOT_FOUND | 类型不存在 | 重新查询类型树 |
| AUTH_ID_EXISTS | 授权标识重复 | 修改标题或 authId |
| UPLOAD_TIMEOUT | 上传超时 | 断点续传 + 重试 |
| POLICY_COMPILE_ERROR | 策略编译失败 | 参数修正后重试 |
| COVER_FORMAT_INVALID | 封面格式错误 | 转换格式后重传 |

完整错误码体系请参考 [全局错误码映射表](../../通用规范/03-错误码体系.md)。
