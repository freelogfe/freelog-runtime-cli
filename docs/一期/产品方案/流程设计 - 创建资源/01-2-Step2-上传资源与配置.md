## ⚠️ **重要提醒**

Console 的 Step2 是**整个 F1 流程中最复杂的一步**,包含:
1. **4 种上传方式**(本地/存储/MC/卡通编辑器)
2. **文件自动解析系统属性**
3. **可选配置系统**(最多 30 个)
4. **依赖声明与授权管理**

**⏱️ 预计完成时间**: 约 5-8 分钟

## 📦 **三、最终提交数据结构**

``typescript
interface Step2Submission {
  // 文件信息
  fileInfo: {
    fileId: string;
    fileName: string;
    fileSize: number;
    sha1: string;
  };
  
  // 系统解析的属性
  systemProperties: Array<{
    key: string;
    value: string;
    type: string;  // 'raw' | 'additional'
    description?: string;
  }>;
  
  // 自定义补充属性
  customProperties: Array<{
    key: string;
    name: string;
    value: string;
    description?: string;
  }>;
  
  // 可选配置
  customConfigurations: Array<{
    key: string;
    name: string;
    type: 'input' | 'select';
    input?: string;      // type='input'时使用
    select?: string[];   // type='select'时使用
    description?: string;
  }>;
  
  // 依赖关系
  directDependencies: string[];
  baseUpcastResources: string[];
  
  // 授权状态
  isCompleteAuthorization: boolean;
}
```

## 🚨 **四、异常分支与错误码**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|-------|---------|---------|---------|
| FILE_PARSE_ERROR | 文件解析失败 | "无法解析文件属性" | 检查文件格式是否正确 |
| FIELD_REQUIRED | 缺少必需属性 | "缺少必填属性：{key}" | 补充属性值 |
| CONFIG_LIMIT_EXCEEDED | 可选配置超限 | "最多 30 个配置项" | 删除不需要的配置 |
| DEPENDENCY_CONFLICT | 依赖冲突 | "检测到版本冲突" | 调整依赖版本范围 |
| AUTH_NOT_COMPLETE | 授权未完成 | "请先完成依赖授权" | 完成授权后再提交 |
| UPLOAD_TIMEOUT | 上传超时 | "上传超时，请检查网络" | 断点续传后重试 |

## ✅ **五、验收标准**

| 测试项 | 预期行为 | 验证方法 |
|-------|---------|---------|
| 4 种上传方式 | 根据类型正确显示 | Mock 不同类型 |
| 文件验证 | 格式/大小检查生效 | 上传违规文件测试 |
| 属性解析 | 自动识别 MIME/版本 | 不同文件测试 |
| 自定义属性 | 可新增/编辑/删除 | UI 交互验证 |
| 可选配置 | 最多 30 个限制 | 尝试添加第 31 个 |
| 依赖授权 | 未完成时禁用下一步 | 不授权点击下一步 |
| Checkpoint 恢复 | 中断后可继续 | Ctrl+C 后 restart |
