### **2.3 策略编译逻辑**

**编译为可执行字节码**:

```typescript
// PolicyCompiler 核心实现
async function compilePolicy(
  templateId: string,
  formData: Record<string, any>
): Promise<PolicyJSON> {
  const template = await getTemplate(templateId);
  
  // 1. 数据验证
  const validated = template.formSchema.parse(formData);
  
  // 2. 编译为可执行策略
  const compiled = PolicyEngine.compile({
    type: template.type,
    parameters: validated
  });
  
  // 3. 返回策略 JSON
  return {
    version: '1.0',
    type: template.type,
    bytecode: compiled.bytecode,
    checksum: computeChecksum(compiled)
  };
}
```

### **2.4 TTY 交互式选择器**

**完整选择流程**:
```typescript
async function selectPolicyTTY(): Promise<PolicyConfig> {
  // 1. 获取模板列表
  const templates = await fetchTemplates();
  
  // 2. 展示模板列表并选择
  const selection = await promptSelect({
    message: '选择策略模板',
    choices: templates.map(t => ({
      value: t.id,
      label: t.name,
      hint: t.description
    }))
  });
  
  // 3. 渲染动态表单收集参数
  const formData = await promptDynamicForm(selection);
  
  // 4. 编译策略
  return compilePolicy(selection, formData);
}
```

**Checkpoint 保存时机**: `AFTER_POLICY_COMPILE` (策略编译成功后立即保存)

## 🚨 **三、异常分支与错误码**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|-------|---------|---------|---------|
| POLICY_COMPILE_ERROR | 策略编译失败 | "策略编译失败：{reason}" | 检查参数是否合法 |
| POLICY_VALIDATION_FAILED | 参数验证失败 | "策略参数不符合要求" | 修正参数值 |
| TEMPLATE_NOT_FOUND | 模板不存在 | "所选策略模板不存在" | 刷新重试 |
| BYTECODE_SIZE_EXCEEDED | 字节码过大 | "策略过于复杂，超过限制" | 简化策略逻辑 |
