```typescript
└───────────────────────────────────────────┘
```

**业务规则**:

#### **1. 标题输入约束**
- 最大长度：**200 字符**
- 禁止字符：`<>&"'`
- 必填字段
- 实时显示字符计数 `(75/200)`

#### **2. 授权标识生成规则**
```typescript
// 基于拼音转换的逻辑
function generateAuthId(title: string): string {
  const pinyin = convertToPinyin(title); // "xingkong-zhimei"
  return normalizePinyin(pinyin);        // "starry-sky"
}

// 格式：{owner}/{authid}
interface AuthIdParts {
  owner: string;    // 当前登录账号的用户名
  authid: string;   // 基于标题生成的拼音标识
}
```

**Console 源码证据**:
```tsx
// packages/console/src/pages/resource/creator/Step1/index.tsx
const checkAuthIdUnique = debounce(async (authId: string) => {
  if (!authId) return;
  
  try {
    await api.resource.checkAuthIdAvailability({ authId });
    setAuthIdAvailable(true);
    setError(null);
  } catch (err: any) {
    setAuthIdAvailable(false);
    if (err.errorCode === 'AUTH_ID_EXISTS') {
      setError('该授权标识已被使用，请更换标题或修改授权标识');
    }
  }
}, 300);
```

#### **3. 实时唯一性验证**
- **300ms 防抖**: 避免频繁调用 API
- **验证 API**: `POST /api/resource/check-auth-id`
- **响应处理**:
  - 可用 → 显示绿色对勾 ✓
  - 不可用 → 显示红色错误提示 + 修改建议

**API 调用**:
```typescript
// POST /api/resource/auth-shell/create
const createPayload = {
  type: 'resourceType.id',        // "theme"
  typeName: 'Theme-Aurora',       // "Theme-Aurora"
  title: '星空之美',              // "星空之美"
  authId: 'liu-kai-github/starry-sky'  // "owner/authid"

const response = await api.resource.createAuthShell(createPayload);
// 返回：{ resourceId, resourceName, authId, version: 1 }
```

**返回值结构**:

## 🚨 **三、异常分支处理**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|-------|---------|---------|---------|
| **RESOURCE_TYPE_NOT_FOUND** | 类型不存在 | "所选资源类型不可用" | 刷新重试 |
| **TITLE_TOO_LONG** | 标题超长 | "标题长度为{actual}/200，请缩短" | 精简标题 |
| **AUTH_ID_EXISTS** | 授权标识重复 | "该授权标识已被使用" | 修改标题或 authId |
| **NETWORK_ERROR** | 网络中断 | "网络连接失败" | 检查网络后重试 |
| **API_RATE_LIMIT** | 请求过快 | "操作过于频繁" | 等待后重试 |

**错误处理实现**:
```typescript
class Step1ErrorHandler {
  async handle(error: unknown): Promise<HandleResult> {
    const errorCode = extractErrorCode(error);
    
    switch (errorCode) {
      case 'AUTH_ID_EXISTS':
        console.log(ui.warning('该授权标识已被使用'));
        console.log('建议：修改标题或手动修改授权标识');
        return {
          action: 'prompt_user',
          preserveData: true // 保留已填写的数据
        };
      
      case 'RESOURCE_TYPE_NOT_FOUND':
        console.log(ui.error('所选资源类型不可用'));
        console.log('正在重新查询类型树...');
        return {
          action: 'retry_api',
          strategy: 'exponential_backoff'
        };
        
      default:
        console.log(ui.error('操作失败：' + error.message));
        return {
          action: 'show_error_detail',
          allowRetry: true
        };
    }
  }
}
```
