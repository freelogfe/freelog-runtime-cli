## 4. 不许违反（写代码也一样）

**产品**

- 合集、F1、`import-dir`、RSS、支付、上抛、平台草稿、顶层 `dep`、`publish`、`release`、`session` / `studio`：不做、不注册
- `N.json` 只记不可变身份 + `filePath`。prod 不要写 `env`
- `N.version.json` 是未提交的下一版。成功 POST **必须删**；失败留下
- 没有上一版 → 只能 `create-version`，号写死 `1.0.0`，禁止 inherit
- 有 latest → 只能 `update-version`。拉缓存用 `version draft pull`，**没有** `update-version --prepare`
- 依赖：只看 `Resource.batchAuth` 的 `isAuth`；false 才免费签，签完再打一遍。不看合约。对方有 `baseUpcastResources`：不加
- 提交体 `baseUpcastResources` / `authExcludedItems` 恒 `[]`
- 主题 `RT001` / 插件 `RT002`：发版仅这两类 **且路径是目录** 才把**目录内容**打成临时 zip。其余类型给目录 → 失败。这两类给 `.zip` 文件 → 失败
- `filePath` 只是记录。发版必须确认本地路径或 `--file`。本地不在 **不准**续用稿里的 sha1
- CLI 不跑构建。`version set --file` 只改记录，不打 zip、不发版
- 上传中断整文件再传。解析走 `filesListInfo`（最长 120s），不用 `fileProperty`

**开发**

- 不改 `packages/tools-lib`。P0-D §7 待加接口（`getVersionAuthContract`、排除项、支付、`resolveResources` query）本期不调
- 不把 archive/cli 整份搬回 `packages/cli`
- 不把 `create-version` / `update-version` 写进同一个编排文件
- `commands/` 不打平台、不写盘规则；只解析参数、TTY、调一个 domain、打印
- 算定是 prod（省略 `--env`、`--env prod`/`production`、`FREELOG_ENV=prod`）：打平台失败，「prod 暂未开放，请用 `--env test` 或 `--env dev`」。**不要把默认改成 test**
- 交给 tools-lib 的 `getEnv()` 必须是 `prod` \| `test` \| `dev`（不要 `production`）。必须 `configurePlatform` 覆盖，空的 `FREELOG_ENV` 会落到 test
- POST 版本只许出现在切片 9 和 11 的 `submit.ts`
