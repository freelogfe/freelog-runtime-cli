# P0-M3: 授权策略（侧栏）

## 概述

与 [F0 Step3](../创建流程%20-%20发行单个资源/P0-F0-Step3-添加授权策略.md) 同构的加策略路径，但本页**可上下线**。资源已上架（`status===1`）时列表 `atLeastOneUsing=true`：至少一条启用。新加策略后，若未上架且已有 `latestVersion`，会弹「立即上架」。

Tab：`edit_resource_tab_authplans` → 「授权策略」。

### 主流程 (ASCII)

```
onMount_PolicyPage → GET info(isLoadPolicyInfo=1)
  → 空：说明 +「添加授权策略」/ 点模板
  → fPolicyBuilder3 → PUT addPolicies（text 先 encodeURIComponent）
  → 成功后 online_afterSuccessCreatePolicy（可能再 PUT status:1）
  → 列表开关 → PUT updatePolicies[{policyId,status 0|1}]
```

---

## 与 F0 Step3 的差异

| 项 | F0 Step3 | 侧栏 M3 |
|----|----------|---------|
| 列表开关 | `activeBtnShow=false` | `FPolicyList` 可改 `status` |
| 上架资源 | 本步不上架 | 至少一条启用 |
| 加完策略 | 只回拉 | 可能追问上架（硬编码「资源待上架」） |
| `trigger` | 无 | `'resource'`（刷新 sider） |

空列表正文在本页是硬编码两行（未用 `authplanmgnt_list_empty_msg` 的 JSX）。有列表时入口硬编码「添加策略」。

| 文案 | i18n key (zh_CN) |
|------|------------------|
| 区标题 | `authplanmgnt_title`: 「授权策略」 |
| 空按钮 | `authplanmgnt_list_empty_btn`: 「添加授权策略」 |
| 模板 | `authplanmgnt_title_templates` / `authplanmgnt_title_templates_help` |
