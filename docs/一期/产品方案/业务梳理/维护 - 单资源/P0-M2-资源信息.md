# P0-M2: 资源信息（listing）

## 概述

侧栏「资源信息」。只改 listing，**不上架**。标识只读。封面保存即写。RSS 相关资源禁改标题/封面/简介。

Tab：`edit_resource_tab_articleinfo` → 「资源信息」。

### 主流程 (ASCII)

```
挂载 sider + resourceInfoPage
  → GET info
  → 标识只读（可复制）
  → 标题编辑保存：PUT resourceTitle
  → 封面 onChange：PUT coverImages
  → 简介确认：PUT intro
  → 标签抽屉确认：PUT tags
```

---

## 字段

| 字段 | i18n | 约束 | 保存 |
|------|------|------|------|
| 标识 | `edit_resource_listing_authid`「授权标识」；`edit_resource_listing_authid_info`「资源在整个授权系统中的唯一标识符，一旦创建则不能更改。」 | 只读；锁图标 | 无 |
| 标题 | `edit_resource_listing_title`「标题」；`edit_resource_listing_title_info` | ≤100；空 → `naming_convention_resource_title_required`「请输入资源标题」；超长硬编码「不超过100个字符」 | `PUT resourceTitle` |
| 封面 | `rqr_input_resouce_image` / `rqr_input_resouce_image_help` | 可选；选完即存 | `PUT coverImages:[url]` |
| 简介 | `resource_short_description`「简介」；`listing_description_info`「为您的作品添加明确实用的描述，以便于其他用户找到您的作品」；按钮 `listing_description_btn`「添加简介」 | 与 F0 Step4 同组件，≤200 | `PUT intro` |
| 标签 | `resource_tag`「标签」；空说明 `rqr_input_resouce_tag_empty_msg`；空按钮 `rqr_input_resouce_tag_empty_btn`「添加标签」 | 抽屉 / CLI：最多 20 条、每条 ≤20 | `PUT tags` |

复制：`edit_resource_listing_btn_copy`「复制」。编辑：`edit_resource_listing_btn_edit`「编辑」。保存/取消：`btn_save` / `btn_cancel`。

## API

| 操作 | FServiceAPI | HTTP | 体 |
|------|-------------|------|-----|
| 挂载 | `Resource.info` `isLoadPolicyInfo=1` `isTranslate=1` | `GET /v2/resources/{id}` | — |
| 标题 | `Resource.update` | `PUT /v2/resources/{id}` | `resourceTitle` |
| 封面 | 同上 | 同上 | `coverImages` |
| 简介 | 同上 | 同上 | `intro` |
| 标签 | 同上 | 同上 | `tags` |

**不传 `status`。**
