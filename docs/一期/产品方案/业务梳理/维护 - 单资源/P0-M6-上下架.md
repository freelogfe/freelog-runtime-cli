# P0-M6: 上下架开关

## 概述

左栏开关。文案：`switch_set_resource_avaliable` → 「上架」。`checked` = `resourceState==='online'`（`info.status` 非 0、非 4）。

上架必须先有 `latestVersion`，且至少一条启用策略。CLI `validate --for online` / `online` 按同一门禁对齐。

### 主流程 (ASCII)

```
开开关 → resourceOnline(id)
  → GET info(isLoadPolicyInfo=1, isLoadLatestVersionInfo=1)
  → 无 latestVersion → toast msg_release_version_first，失败
  → policies.length===0 → 确认后 builder → PUT status:1 + addPolicies
  → 全是 status===0 → 策略选择器 → PUT status:1 + updatePolicies
  → 否则 PUT status:1
关开关 → 确认「下架资源」→ PUT status:4
```

---

## 上架门禁

| 条件 | 行为 | i18n / 硬编码 |
|------|------|----------------|
| 无 `latestVersion` | 失败 toast | `msg_release_version_first`: 「资源上架之前，需要先发行一个版本」 |
| 0 条策略 | 弹窗后可当场加一条并上架 | `set_resource_available_for_auth_*` |
| 有策略但全下线 | `fPolicyOperator` 勾选启用 | 同上系列 |
| 已有启用策略 | 只 `status:1` | 成功 `set_resource_available_for_auth_msg_done`「上架成功」 |

下架确认：`remove_resource_from_auth_confirmation_title`「下架资源」；按钮 `remove_resource_from_auth_btn_remve`「下架」；完成 `remove_resource_from_auth_msg_done`「已下架」。

`resourceSider` 把 `status===0` 映射 `unreleased`，`4` → `offline`，其余 → `online`（含已上架）。

## API

| 操作 | FServiceAPI | HTTP | 体 |
|------|-------------|------|-----|
| 探门禁 | `Resource.info` | `GET /v2/resources/{id}` | — |
| 上架 | `Resource.update` | `PUT /v2/resources/{id}` | `status:1`，可选 `addPolicies` / `updatePolicies` |
| 下架 | `Resource.update` | 同上 | **`status:4`** |
