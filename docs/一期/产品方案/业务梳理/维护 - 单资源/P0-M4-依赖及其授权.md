# P0-M4: 依赖及其授权

## 概述

已发版依赖的**补签**页。微前端 `mainAppType='resourceDepAuth'`。本页**不增删依赖**（增删在 M0 / F0 Step2 发新版时做）。

Tab：`edit_resource_tab_relynauth` → 「依赖及其授权」。侧栏有授权问题时黄感叹号，tooltip `alert_resource_no_auth`。

### 主流程 (ASCII)

```
GET info（baseUpcast + resourceVersions）
  → 版本筛：全部 / 某一版
  → GET versions 列表拼直接依赖（去重）
  → 微前端 resourceDepAuth（licenseeId=本资源）
  → 签约成功后 sider onUpdate_Data（刷新黄标）
```

筛选项：`edit_resource_relynauth_filter_version`「版本」；全部 = `edit_resource_relynauth_filter_version_all`「全部」（value `#all`）。

## API

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 壳 + 上抛 | `Resource.info` | `GET /v2/resources/{id}` |
| 各版依赖 | `Resource.getVersionListByResourceID` | `GET /v2/resources/{id}/versions` |
| 补签 | 微前端内部（平台合约 API） | 本页不直接调 `batchSetContracts` |

`resourceAuthPage` 里仍有 `fetchAuthorized` / `batchSetContracts`（`PUT .../versions/batchSetContracts`），**当前依赖页未走这条**，以微前端为准。
