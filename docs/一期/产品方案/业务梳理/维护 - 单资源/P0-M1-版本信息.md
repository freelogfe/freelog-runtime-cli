# P0-M1: 版本信息（已发版）

## 概述

侧栏「资源及其属性」。看已发行版本的文件、属性、描述、依赖图；**不能换文件**。新版本开 [M0](../创建流程%20-%20发行新版本/P0-M0-发行新版本.md)。无版本时空态可进 M0 或丢弃草稿。

Tab：`edit_resource_tab_versions` → 「资源及其属性」。更新按钮：`edit_resource_vmgnt_btn_update` → 「更新」（界面拼「更新版本」图标 + 该文案）。

### 主流程 (ASCII)

```
挂载 sider + resourceVersionEditorPage
  → GET info + lookDraft + getResourceTypeInfoByCode
  → 无 latestVersion：
       无草稿 →「上传资源」开 M0
       有草稿 → 继续编辑 / 丢弃草稿
  → 有版本：默认 latest；下拉切换
  → GET versions/{version}
  → 已发版只改描述（PUT versions/{version} 只带 description）
  → 改属性 / 配置 / 依赖 / 文件 →「更新版本」开 M0 发新号
  →「更新」→ versionCreator（M0）
```

## 一、空态

### 操作流程

1. `latestVersion===''` 时不拉版本详情，`pageState=loaded`，`version=''`。
2. 无草稿：硬编码「上传资源，开启授权之旅」+ 按钮「上传资源」→ `resourceVersionCreator`。
3. 有草稿：`versionmngt_empty_msg2`「您有一个未完成的发行」；继续编辑开 M0；丢弃 `DELETE /v2/resources/{id}/versions/drafts`。
4. RSS 相关资源不读草稿。

| 文案 | i18n key (zh_CN) |
|------|------------------|
| 未完成发行 | `versionmngt_empty_msg2`: 「您有一个未完成的发行」 |
| 继续 | `versionmngt_empty_btn_continueediting`: 「继续编辑」 |
| 丢弃 | `versionmngt_empty_btn_discard`: 「丢弃」 |

硬编码：「上传资源，开启授权之旅」「上传资源」「草稿」徽章。

### API

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 资源壳 | `Resource.info` | `GET /v2/resources/{id}` |
| 草稿 | `Resource.lookDraft` | `GET /v2/resources/{id}/versions/drafts` |
| 丢弃草稿 | `Resource.deleteResourceDraft` | `DELETE /v2/resources/{id}/versions/drafts` |

## 二、已发版：数据隔离，只改描述

每个版本的文件 / 属性 / 可选配置 / 依赖是**这一号自己的快照**，发出去之后冻住。要改那些 = [M0](../创建流程%20-%20发行新版本/P0-M0-发行新版本.md) 发新号（界面「更新版本」）。

**产品裁定（CLI 跟这条，不跟 Console 页上改 value）**：已发版只允许改描述。Console `versionInfo` 里属性 / 可选配置 `value_Editable` 能点，那是 Console 页行为，**不是**「更新版本」，CLI 不要学。

### 操作流程

1. 版本下拉：`versions` 倒序；`onChange_Version` 重拉该版。
2. 文件区只预览，**无换文件入口**。
3. 属性 / 可选配置 / 依赖：本页 **只读**。CLI 禁止 PUT `inputAttrs` / `customPropertyDescriptors`。
4. 描述：`version_description`；空则 `version_description_empty_msg` / `version_description_empty_btn`「添加描述」。`PUT` **只带** `description`。
5. 依赖图只读。本页不增删依赖。

| 字段 | 约束 |
|------|------|
| 文件 / 属性 / 可选配置 / 依赖 | 不可改；要改发新版 |
| 描述 | 可改；空串当无描述 |

### API

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 版本详情 | `Resource.resourceVersionInfo1` | `GET /v2/resources/{id}/versions/{version}` |
| 改描述 | `Resource.updateResourceVersionInfo` | `PUT /v2/resources/{id}/versions/{version}` 只带 `description` |
| 类型配置 | `Resource.getResourceTypeInfoByCode` | `GET /v2/resources/types/getInfoByCode` |

### Console 源码位置

- 页面：`versionInfo/$id/index.tsx` L250–325 下拉与更新；L537–871 属性与描述
- effects：`resourceVersionEditorPage.ts` L363–518 拉版；L531–605 写回

## 三、CLI 对照

| Console | CLI | 决策 |
|---------|-----|------|
| 新版本（改属性/配置/依赖/文件） | `update-version` | ✅ 对照 M0「更新版本」 |
| 已发版改描述 | `version description` / `version show` | ✅ PUT **只带** description |
| 已发版改属性 value | — | ❌ 发新版，不跟 Console 页上改 value |
| 丢弃草稿 | — | ❌ 本期不做平台草稿 |
| 换已发版文件 | — | ❌ 必须新版本 |

```text
freelog-cli version show --version 1.0.0
freelog-cli version description --version 1.0.0 --description "..."
freelog-cli update-version --version 1.1.0
```
