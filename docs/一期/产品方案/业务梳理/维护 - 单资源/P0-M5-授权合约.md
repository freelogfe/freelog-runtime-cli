# P0-M5: 授权合约（只读）

## 概述

本资源作为**授权方**签出去的合约列表。只读。空态硬编码「暂无合约」。

Tab：`edit_resource_tab_licenceecontracts` → 「授权合约」（区标题也用该 key）。

### 主流程 (ASCII)

```
onMount_ContractPage
  → GET /v2/contracts identityType=1 licensorId={id} limit=pageSize(100)
  → 表：被授权方 / 策略名+状态 / 查看合约抽屉
  → 点被授权方：资源开详情；节点开节点域名
```

---

## 操作流程

1. `Contract.contracts`：`identityType: 1`（授权方视角），`licensorId` = 本资源，`limit` = `FUtil.Predefined.pageSize`（**100**）。
2. 列：`contract_licensee`；`contract_list_contracts`；操作 `contract_list_btn_viewcontract`「查看合约」。
3. 附加：`contract_signed_time` + 时间；`contract_id` + ID。
4. 无分页控件（`pagination={false}`）；超过 100 条本页不加载下一页。
5. 抽屉 `FContractDetailsDrawer2` 只看详情。
