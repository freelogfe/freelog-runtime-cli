# P0-C0: 合集创建流程

## 概述

Console「发行合集」四步向导。入口：`creatorEntry` → `FUtil.LinkTo.collectionCreator()`。

总标题：`cqr_title` → 「发行合集」。**不是五步，没有扫本地目录。**

### 主流程 (ASCII)

```
creatorEntry「发行合集」
  → Step1 创建合集        POST /v2/resources subjectType=4
  → Step2 添加单品        从我的资源勾选（每批≤100）或绑 RSS
  → Step3 添加授权策略    可跳过（同构 F0 Step3）
  → Step4 完善合集信息    listing + 收录规则 + status:1
```

RSS 绑定成功后，从 Step3 起布局会 60s 轮询 `Rss.getSyncProgress`。
