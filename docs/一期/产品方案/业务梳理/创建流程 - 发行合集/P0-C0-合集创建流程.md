## Step 1: 扫描本地目录

### 操作流程
1. 点击"扫描目录"按钮
2. 选择包含资源的文件夹
3. 解析每个资源的 manifest.json/package.json
4. 自动识别资源类型和基础信息
5. 生成待收录资源列表

### API 调用

| 操作 | tools-lib 函数 | HTTP 接口 | i18n key (zh_CN) |
|------|---------------|----------|------------------|
| 选择目录 | fsService.chooseDirectory() | - | cqr_scan_local_directory: "扫描本地目录" |
| 读取配置文件 | resourceService.scanLocalResources(dirPath) | POST /collection/scan-dir | - |
| 解析资源信息 | manifestParser.parse(manifest) | - | hint_parse_resource_info: "解析资源信息" |

### 请求参数

```typescript
POST /collection/scan-dir
Body: {
  dirPath: string  // 用户选择的本地路径
}
```

### 响应数据结构

```typescript
{
  resources: [
    {
      resourceId: string,          // 平台资源 ID (若已存在)
      resourceName: string,        // 资源名称
      resourceTypeCode: string,    // 资源类型代码
      title: string,               // 资源标题
      version: string,             // 版本号
      manifestPath: string         // manifest.json 路径
    },
    // ... N 个资源
  ],
  summary: {
    total: number,
    valid: number,     // 解析成功
    invalid: number    // 解析失败（格式错误）
  }
}
```

### 字段约束

| 字段名 | 来源 | 必填 | maxLength | 备注 |
|--------|------|------|-----------|------|
| `dirPath` | 用户选择 | ✅ | ∞ | 需为有效目录 |
| `resourceId` | 平台返回 | ⚠️ 可选 | ∞ | 已存在的资源才有 |
| `title` | manifest | ✅ | 100 | 资源标题 |

### i18n Keys

| i18n key | 用途 |
|---------|------|
| `cqr_scan_local_directory` | "扫描本地目录" |
| `hint_select_directory` | "选择要收录的资源目录" |
| `error_invalid_directory` | "无效的目录路径" |
| `info_parse_success` | "成功解析 {count} 个资源" |

5. 自动从第一个资源的 package.json 填充部分字段

| 更新合集信息 | collectionService.update(data) | POST /collection/update | btn_save_changes: "保存修改" |

### 封面上传验证

根据 Handover 文档提示的重点关注项：

**验证规则**:
- 文件格式：PNG/JPG/WebP
- 文件大小：< 5MB
- 建议尺寸：1920×1080 或更高

### 字段约束

| 字段名 | maxLength | 默认值 | 变化规则 | i18n key (zh_CN) |

| `author` | 60 | package.json author | 自动填充 OR 手动修改 | rqr_input_author: "作者信息" |

## Step 4: 配置收录规则

### 操作流程
1. 选择收录的资源范围 (全部 vs 筛选)
2. 配置版本过滤规则
3. 配置类型过滤规则
4. 预览最终收录列表

### API 调用

| 操作 | tools-lib 函数 | HTTP 接口 | i18n key (zh_CN) |
|------|---------------|----------|------------------|
| 保存收录规则 | collectionService.saveRules(rules) | POST /collection/save-rules | btn_save_rules: "保存收录规则" |
| 预览收录列表 | collectionService.previewList(rules) | POST /collection/preview-list | - |

### 收录规则结构

```typescript
{
  // 资源类型过滤
  typeFilter?: {
    include: string[],    // 包含的类型代码
    exclude: string[]     // 排除的类型代码
  },
  
  // 版本过滤
  versionFilter?: {
    minVersion: string,   // 最小版本号 (semver)
    maxVersion: string,   // 最大版本号 (semver)
    tagPattern: string    // 标签正则匹配
  },
  
  // 状态过滤
  statusFilter?: {
    publishedOnly: boolean,  // 只收录已发布的版本
    includeDrafts: boolean   // 是否包含草稿
  }
}
```

### 字段约束

| 字段名 | 约束 | 来源 |
|--------|------|------|
| `typeFilter` | 可选 | Platform 资源类型定义 |
| `versionFilter` | 可选 | semver 规范 |
| `statusFilter` | 可选 | Collection 业务规则 |

### i18n Keys

| i18n key | 用途 |
|---------|------|
| `step4_config_rules` | "配置收录规则" |
| `hint_include_types` | "包含类型" |
| `hint_exclude_versions` | "排除版本" |
| `btn_preview_list` | "预览收录列表" |

## Step 5: 完善 Listing

### 操作流程
1. 检查必填字段完整性
2. 确认收录资源数量
3. 预览最终合集页面
4. 确认并发布合集

### API 调用

| 操作 | tools-lib 函数 | HTTP 接口 | i18n key (zh_CN) |
|------|---------------|----------|------------------|
| 创建合集 | collectionService.create(data) | POST /collection/create | btn_create_collection: "创建合集" |
| 获取验证状态 | collectionService.getValidationStatus() | GET /collection/validation-status | - |
| 发布合集 | collectionService.publish(id) | POST /collection/publish/{id} | btn_publish: "发布合集" |

### 请求体结构

```typescript
{
  // 基本信息
  title: string,
  description: string,
  coverUrl: string,
  author?: string,
  homepage?: string,
  
  // 收录资源
  resources: {
    ids: string[],
    order: number[]
  },
  
  // 收录规则
  rules: {
    typeFilter?: object,
    versionFilter?: object,
    statusFilter?: object
  }
}
```

### 响应数据

```typescript
{
  collectionId: string,       // 新建合集的 ID
  resourceName: string,       // 合集的授权标识
  status: 'draft' | 'published',
  resourceCount: number,      // 收录的资源数量
  previewUrl: string          // 合集详情页 URL
}
```

### Next Button 禁用条件

以下任一满足则禁用"创建/发布"按钮：
- `collectionTitle === ''`
- `collectionDescription === ''`
- `coverFile === null`
- `resources.length === 0`
- 存在验证警告（如缺少描述、封面不合规）

## 五、总结：CLI 实现要点

### 推荐 CLI 设计

#### 交互式模式
```
freelog collection create
  → prompts for directory (Step1)
  → auto-scan resources
  → prompts for collection info (Step2)
  → interactive sort (Step3)
  → configure filters (Step4)
  → confirm and publish (Step5)
```

#### 非交互模式
```bash
freelog collection create \
  --dir ./my-resources \
  --title "My Awesome Series" \
  --description "A curated collection of..." \
  --cover ./cover.png \
  --rules collection-rules.yaml \
  --publish
```

#### collection-rules.yaml 示例
```yaml
sortMode: manual
order:
  - res-theme-winter
  - res-theme-spring
  - res-plugin-icon-pack
  
filters:
  types:
    include: ["theme.desktop", "theme.mobile"]
    exclude: []
  versions:
    min: "1.0.0"
    max: "*"
  status:
    publishedOnly: true
```
