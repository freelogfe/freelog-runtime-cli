# P0-L1: 我的资源 / 我的合集列表

## 概述

「我的」列表。都是 `Resource.list` + `isSelf:1`，用 `subjectType` 分开。编辑入口在**卡片**，不在详情页。

### 主流程 (ASCII)

```
我的资源：GET /v2/resources isSelf=1 subjectType=1
  → 筛类型 / 状态（含未发行0） / 关键词 300ms
  → 空：resourceCreatorEntry
  → 卡片：详情 / 侧栏版本(M1) / 新版本(M0)

我的合集：subjectType=4
  → 状态筛无「未发行」（源码注释掉）
  → 顶栏「新建合集」→ collectionCreator
  → 空态按钮却走 resourceCreatorEntry（源码现状）
  → 卡片：合集详情 / 合集侧栏 C1；新版本已注释
```

---

## 一、我的资源

### 操作流程

1. `resourceListPage/onMount` → `buildResourceListApiParams({ subjectType: 1, isSelf: 1, ... })`。
2. 类型：`FResourceTypeFilter3` `subjectTypeArr=['resource']`；文案 `resource_type`「资源类型」。
3. 状态：`resource_state`「资源状态」。

| value | i18n (zh_CN) |
|-------|----------------|
| `#` | `filter_resource_status_all`: 「所有」 |
| `1` | `filter_resource_status_availableforauth`: 「已上架」 |
| `4` | `filter_resource_status_pendingauth`: 「未上架」 |
| `0` | `filter_resource_status_prepareforrelease`: 「未发行」 |
| `2` | `filter_resource_status_removedbyfreelog`: 「已封禁」 |

4. 空：`my_resource_empty`「您创建的资源将会出现在这里」；按钮 `my_resource_empty_btn`「创建资源」→ `resourceCreatorEntry`。
5. 卡片：`onClickDetails` → `resourceDetails`；`onClickEditing` → `resourceVersionInfo`（M1）；`onClickRevision` → `resourceVersionCreator`（M0）。

另有批量管理（策略、加入合集、签到节点等）。批量策略 / 签节点属 Console；CLI 不对照整页批量。

### API

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 列表 | `Resource.list` | `GET /v2/resources` `isSelf=1` `subjectType=1` |

### Console 源码位置

- 页面：`list/Resources/index.tsx` L48–75 状态；L133–144 空态；L655–676 卡片跳转
- model：`resourceListPage.ts` L197–203
- 公共参数：`models/shared/resourceListHelpers.ts` L106–107 `isSelf:1`

## 二、我的合集

### 操作流程

1. `collectionListPage` 同 helper，`subjectType: 4`。
2. 状态选项**没有** value `0`（未发行两行已注释）。有所有 / 已上架 / 未上架 / 已封禁。
3. 顶栏：`my_collections_btn_createcollection`「新建合集」→ `collectionCreator`；`my_collections_btn_bulkaction`「批量管理」。
4. 空：`my_collections_empty`「您创建的合集将会出现在这里」；按钮 `my_collections_empty_btn`「创建合集」→ **`resourceCreatorEntry`**（不是 `collectionCreator`）。
5. 卡片：`my_collections_card_btn_viewdetails`「查看合集」→ `collectionDetails`；编辑 → `collectionVersionInfo`（C1）。`type:'update'`（新版本）整段注释。

### API

`GET /v2/resources` `isSelf=1` `subjectType=4`。

### Console 源码位置

- 页面：`list/Collections/index.tsx` L48–68 状态；L125–136 空态；L145–152 新建；L622–653 卡片
- model：`collectionListPage.ts` L219–226

## CLI

无「我的列表」命令。对照：

| 卡片动作 | CLI |
|----------|-----|
| 创建资源 / 合集 | `create` / `collection create` / `resource import-dir` |
| 编辑资源 | 进项目后 `update` / `version` / `policy` |
| 新版本 | `version set` + `publish` |
| 编辑合集 | `collection item` / `collection update` / `collection publish` |

`resource` 子命令有搜索/会话维护，不是 Console 这页的分页复制。
