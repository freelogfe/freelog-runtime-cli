# P0-L2: 资源 / 合集详情（只读）

## 概述

市场向只读页。展示封面、标题、标识、策略名、简介、版本属性、依赖/授权图。**没有**跳侧栏或新版本的按钮。编辑入口在 [L1 列表卡片](./P0-L1-我的资源与合集列表.md)。收藏按钮存在，本轮文档不展开收藏产品。

详情页「获取授权」是签到节点（`status!==1` 硬编码「该资源未上架，无法获取授权。」），属交易/节点，CLI 发行路径不对照。

### 主流程 (ASCII)

```
资源 /resource/details/:id
  → GET info
  → 冻结(status&2) → 冻结页
  → latestVersion==='' → 不可访问
  → subjectType===4 → 改走合集详情
  → GET 该版 versions/{selected}（默认 latest）
  → 只读渲染

合集 /resource/collectionDetails/:id
  → GET info（冻结同样拦截）
  → 版本写死 GET versions/1.0.0
  → GET catalogue/{id}/items（已发布目录，不是 drafts）
  → 只读单品列表
```

---

## 一、资源详情

### 操作流程

1. `resourceDetailPage/onMountPage`，URL 可带 `?version=`。
2. 无 `latestVersion`：`exceptionUnableToAccess`。合集壳被重定向到合集详情。
3. 展示：封面、标题（或 name 第二段）、`resourcedetails_authid`「授权标识」、类型、标签、启用策略名、简介、版本下拉、属性/可选配置、依赖树与授权树。
4. 版本切换只改只读数据，不写平台。
5. 侧栏标题可链到本页（新开），**本页不链回侧栏**。

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 壳 | `Resource.info` | `GET /v2/resources/{id}` |
| 批量作者/授权 | `User.batchUserList` / `Resource.batchAuth` | 只读拼状态 |
| 版本 | `Resource.resourceVersionInfo1` | `GET /v2/resources/{id}/versions/{version}` |

### Console 源码位置

- 页面：`details/$id/index.tsx` L62–76 挂载（只读 UI，无编辑 Link）
- effects：`resourceDetailPage.ts` L176–243 门禁；L544 起拉版本

## 二、合集详情

### 操作流程

1. `collectionDetailPage/onMount_Page`。冻结同样进冻结页。**未见** `latestVersion===''` 拦截（与资源详情不同，照记）。
2. `fetchVersionInfo` 的 `version` **写死 `'1.0.0'`**。
3. 单品：`Resource.getCollectionItems` → `GET /v2/resources/catalogue/{id}/items`（已发布），再 `getCollectionItemsAuth`。不是 `catalogues/drafts`。
4. 签约微前端版本也写死 `'1.0.0'`。
5. 完结态来自 `serializeStatus`。

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 壳 | `Resource.info` | `GET /v2/resources/{id}` |
| 固定首版 | `Resource.resourceVersionInfo1` | `GET .../versions/1.0.0` |
| 已发布单品 | `Resource.getCollectionItems` | `GET /v2/resources/catalogue/{id}/items` |
| 单品授权态 | `Resource.getCollectionItemsAuth` | 已发布目录 batchAuth |

### Console 源码位置

- 页面：`collectionDetails/$id/index.tsx` L60–74、L80–104（`1.0.0`）
- effects：`collectionDetailPage.ts` L313–368 壳；L442–452 版本写死；L594–761 已发布 items

## CLI

详情是读模型。对照：

```text
freelog-cli pull --env <env>
freelog-cli version show --env <env>
freelog-cli collection collect-rules get --env <env>
```

不要把详情页当成第二套 `update` / `item` 编辑器。改单品必须走目录草稿 + `collection publish`，详情只显示已 merge 的目录。
