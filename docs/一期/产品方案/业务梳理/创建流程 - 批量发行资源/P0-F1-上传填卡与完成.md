# P0-F1: 上传填卡与完成

## 概述

`showPage=uploadFile` 的 `Handle`：空态选文件，有文件后填卡，一次最多 20 个，`POST /v2/resources/createBatch` 后进 Finish。

空态标题：`brr_submitresource_title` → 「上传资源文件」。有卡标题：`brr_resourcelisting_title` → 「完善资源信息」。完成：`brr_completed_msg` → 「资源发行成功」。

### 主流程 (ASCII)

```
uploadFile
  → 本地多选 或 存储空间导入
  → SHA1：fileIsExist → getResourceBySha1（他人/自己已挂则 ErrorCard）
  → 未占用则上传 + 解析属性；可自动封面（autoGenerateCover=2）
  → 每卡：标题≤100、标识规范化后查重、封面/标签/策略/属性
  → 超 20 截断并 toast
  →「现在发行」→ createBatch（version=1.0.0）
  → finish：结果列表 + 我的资源 / 继续发行 / 签约节点 / 加入合集
```

## 一、导入文件

### 操作流程

1. 进 Handle 后 `getResourceTypeInfoByCode`：`autoGenerateCover===2` 决定自动封面。`fileMaxSize` **读了但前端不用**。
2. 本地：再用该接口的 `formats` 作 accept，`fReadLocalFiles({ multiple: true })`。每文件先 `localUpload`，`Task` 算 SHA1。
3. 存储：`fObjectsSelectorDrawer` → `Storage.batchObjectList`，同样按 sha1 占检查。
4. 占用：`Resource.getResourceBySha1`。他人已挂 / 自己已挂 → ErrorCard（对应 `submitresource_err_resourceexist_*`）。
5. 未在存储则 `Storage.uploadFile`，再解析属性。
6. `dataSource.length > 20`：toast `brr_submitresource_alert_limitation`「一次最多上传20个文件」，`slice(0, 20)`。「继续添加」仅 `< 20` 时出现。

### 大小（写死，不读类型配置）

| 条件 | 上限 | 硬编码文案 |
|------|------|------------|
| 类型名第一段是「视频」 | 1GB | 文件大小不能超过1GB |
| 其他 | 200MB | 文件大小不能超过200MB |

### API 调用

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 类型配置 / accept | `Resource.getResourceTypeInfoByCode` | `GET /v2/resources/types/getInfoByCode` |
| SHA1 是否已在存储 | `Storage.fileIsExist` | `GET /v2/storages/files/fileIsExist` |
| SHA1 是否已被资源占用 | `Resource.getResourceBySha1` | `GET /v2/resources/files/{fileSha1}` |
| 上传 | `Storage.uploadFile` | `POST /v2/storages/files/upload` |
| 存储对象列表 | `Storage.batchObjectList` | `GET /v2/storages/objects/list` |
| 自动封面 | `CoverGenerator` SSE | `POST {api}/v2/storages/files/generateCoverImageSSE` body `{ sha1Array }` |

### Console 源码位置

- `Handle/index.tsx` L215–239：类型配置；L469–514：本地；L516–767：存储；L505–512 / L708–715：20 上限
- `Handle/Task/index.tsx` L66–84：大小；L86–206：SHA1 / 占用 / 上传

## 二、卡片字段

列表在 Handle 本地 state。初始标题：去扩展名后截 100。初始短标识：去扩展名 → 规范化 → **截 50** → `generateResourceNames`。

| 字段 | maxLength / 上限 | 必填 | 规则 |
|------|------------------|------|------|
| 标题 | 100 | ✅ | 空 → `naming_convention_resource_title_required`；与 name 未分叉时同步 name（name 取前 60 再规范化） |
| 授权标识 | 输入 60；初始推导截 50 | ✅ | `FRegExpMgr.resourceNameOptimized`；提交用 `resourceName_optimized` |
| 远端查重 | — | — | `Resource.info(encodeURIComponent(username/name))` |
| 批内重名 | — | — | 前端 Map，无 HTTP |
| 封面 | JPG/PNG/GIF ≤5MB | 否 | 空则 `coverImages: []` |
| 标签 | 批量应用截 20 | 否 | — |
| 策略 | builder | 否 | 无策略提交前确认 |
| 自定义属性 | 30 | 否 | 提交 `readonlyText` |
| 可选配置 | 30；仅类型名含「插件」或「主题」 | 否 | `editableText` / `select` |
| 依赖授权 | 须完成 | 提交门槛 | `mainAppType='resourceInBatchPublish'` |

规范化与 F0 相同（非法字符 / emoji → `_`）。

### API

| 操作 | FServiceAPI | HTTP | i18n |
|------|-------------|------|------|
| 批量生成可用名 | `Resource.generateResourceNames` | `POST /v2/resources/generateResourceNames` | — |
| 单卡查重 | `Resource.info` | `GET /v2/resources/{idOrName}` | `resource_name_exist` |

### 提交禁用

没有 `list` 卡、存在非 list、title/name 有错、授权未完成、或正在提交。

### Console 源码位置

- `Handle/Card/index.tsx` L252–282：标题；L956–1018：标识；L168–171：查重；L219–232：封面；L552 / L721：属性/配置上限
- `Handle/index.tsx` L362–365：name 截 50；L416–428：generateResourceNames；L244–260：禁用提交

## 三、createBatch

无策略先确认 `brr_resourcelisting_complete_confirm_msg`。按钮：`brr_resourcelisting_btn_completerelease`「现在发行」。

`Resource.createBatch` → `POST /v2/resources/createBatch`：

| 字段 | Console 实际值 |
|------|----------------|
| `resourceTypeCode` | 所选类型；**不传** `resourceTypeName` |
| `createResourceObjects[].name` | 规范化短标识 |
| `resourceTitle` | 标题 |
| `policies` | `{ policyName, policyText, status: 1 }` |
| `coverImages` | `[]` 或 `[url]` |
| `intro` / `description` | 恒 `''` |
| `tags` | 标签 |
| `version` | **写死 `1.0.0`** |
| `fileSha1` / `filename` | 文件 |
| `customPropertyDescriptors` | 属性 + 可选配置 |
| `baseUpcastResources` / `dependencies` / `batchSignContracts` | 授权微前端 |
| `inputAttrs` | 系统属性 `type==='additional'` |

回包按 key 映射 `data/message/status`；无 data 当失败。status：`2=freeze`，`1=online`，`0=unreleased`，其它 offline。然后 `showPage=finish` + `resultList`。

### Console 源码位置

- `Handle/index.tsx` L786–1014
- `tools-lib/.../resources.ts` L63–123：类型还可带 `resourceTypeName` 等，Console 不传

## 四、Finish

不再调 createBatch。

| 动作 | 行为 |
|------|------|
| 管理我的资源 | 打开 `myResources` |
| 继续发行 | 回 `resourceCreatorEntry` |
| 签约到节点 | 仅 `status==='online'`；否则「不存在上线资源不能签约到节点」 |
| 添加至合集 | 须有 online；选资源 → 合集选择 → `FAddResourcesHandleAuth` |

`addResourceItems_Draft` 在 Finish 内整段注释，写入走授权组件。

### Console 源码位置

- `Finish/index.tsx` L70–280

## 五、CLI 对照

| Console | `resource import-dir` | 决策 |
|---------|----------------------|------|
| 单次最多 20，超出截断 | 默认按 20 **拆多批**；`--strict-batch-limit` 才报错 | CLI 更宽，要严格对齐加 flag |
| name 初始截 50 + generateResourceNames | 同 | ✅ |
| title 截 100 | 可加 `--title-prefix` | ✅ |
| version 1.0.0 | 默认 1.0.0，config 可改 | ✅ |
| 不传 resourceTypeName | 可 `--resource-type-name` | 可选 |
| 大小写死 1GB/200MB | CLI 用类型 `fileMaxSize` | 不一致，以类型配置为准更合理 |
| 存储空间入口 | 只扫目录顶层，不递归 | ❌ 存储入口 |
| 卡上改封面/标签/策略 | config / 默认 | ⚠️ 简化 |
| Finish 签约/合集 | — | ❌ |
| 无 authExcludedItems | 有则降级 create+createVersion | CLI 更完整 |
| — | `--resume` / `--retry` | CLI 特有 |

freelog-cli resource import-dir ./photos --resource-type <imageCode> --title-prefix "照片" --yes --env <env>
