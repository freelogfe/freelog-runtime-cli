# P0-F1: 选择资源类型

## 概述

批量向导第一页：必须选一个**支持批量创建**的叶子类型，再进上传页。不能「添加新类型」，不拉最近使用建议。

标题：`brr_selectresourcetype_title` → 「选择资源类型」。

### 主流程 (ASCII)

```
进入 showPage=resourceType
  → FResourceTypeInput4(subjectType=batchResources, showAddNewType=false)
  → 树：resourceTypes(category=1, status=1, subjectType=1, supportCreateBatch=2)
  → 搜索：ListSimpleByParentCode(..., isTerminate=true, supportCreateBatch=2)
  → 未选则禁用下一步
  → 下一步 → showPage=uploadFile
```

---

## 操作流程

1. `FResourceTypeInput4`：`subjectType='batchResources'`，`showAddNewType=false`。
2. 级联：有子节点只展开，无 children 才选中。搜索只要叶子。
3. 空选择错误：`naming_convention_resource_type_required`。
4. 「下一步」`disabled={!selectedResourceType}`，不另做叶子校验（选择器已限制）。
5. 点下一步只改 `showPage`，此时还不拉类型配置。

## API 调用

| 操作 | FServiceAPI | HTTP | 参数 | i18n key (zh_CN) |
|------|-------------|------|------|------------------|
| 拉树 | `Resource.resourceTypes` | `GET /v2/resources/types/listSimpleByGroup` | `category=1`，`status=1`，`subjectType=1`，`supportCreateBatch=2` | `brr_selectresourcetype_input_resourcetype`: 「资源类型」 |
| 搜索叶子 | `Resource.ListSimpleByParentCode` | `GET /v2/resources/types/listSimpleByParentCode` | `nameChain`，`subjectType=1`，`supportCreateBatch=2`，`isTerminate=true`，`status=1` | — |
| 下一步 | 无 | — | — | `brr_selectresourcetype_btn_next`: 「提交」 |

与 F0 Step1 差异：F0 用 `subjectType=resource`、允许新建类型、拉最近 6 条；本页强制 `supportCreateBatch=2`、禁新建、无最近建议。
