# P0-F1: 批量发布流程

## 概述

Console「批量发行资源」三页向导。入口：`creatorEntry` → `FUtil.LinkTo.resourceCreatorBatch()` → `pages/resource/creatorBatch`。

页面总标题：`brr_title_bulkreleaseresource` → 「批量发行资源」。

`showPage` 三态：`resourceType` → `uploadFile` → `finish`。Model 另有 `'resourceList'`，UI 未渲染。卸载页整表回初始态。提交逻辑在 `Handle` 本地 state，**没有**独立 dva effects 管 `createBatch`。

### 主流程 (ASCII)

```
creatorEntry「批量发行资源」
  → 选类型（仅 supportCreateBatch=2 的叶子，禁止新建类型）
  → 本地/存储导入文件（最多 20）
  → 每卡填标题/授权标识/封面/标签/策略/属性
  → POST createBatch（版本写死 1.0.0）
  → 完成页：看结果、去我的资源、签约节点、加入合集
```

```

```
