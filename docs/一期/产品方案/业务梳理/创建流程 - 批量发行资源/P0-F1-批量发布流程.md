## 📋 概述

Console 批量发布的完整业务流程，基于 CreatorBatch 组件分析。

### 主流程 (ASCII)

```
开始 → 进入批量管理页面 → 添加 N 个资源 → 逐个填写基础信息 → 
批量验证 (类型/名称唯一性) → 点击批量发布 → 
N 个资源顺序/并行创建 → 生成发布报告
```

## 一、添加资源 (循环 N 次)

### 操作流程
1. 点击"添加资源"按钮
2. 选择资源类型（可快速搜索）
3. 输入资源标题
4. 自动同步/手动修改授权标识
5. 唯一性检查通过 → 添加到批次列表

### API 调用

| 操作 | tools-lib 函数 | HTTP 接口 | i18n key (zh_CN) |
|------|---------------|----------|------------------|
| 添加单个资源到批次 | batchService.addResource(item) | POST /batch/add-item | cqr_add_resource_to_batch: "添加到批次" |
| 获取资源类型树 | typeService.getResourceTypeTree() | GET /resource/type/tree | rqr_input_resourcetype: "请选择资源类型" |
| 唯一性检查 | resourceService.checkResourceName(name) | GET /resource/info?resourceName={name} | resource_name_exist: "资源标识已存在" |
| 从批次移除 | batchService.removeResource(index) | POST /batch/remove-item | - |

### 字段约束

| 字段名 | maxLength | 默认值 | 变化规则 | i18n key (zh_CN) |
|--------|-----------|--------|---------|------------------|
| `resourceTypeCode` | ∞ | 必填 | 用户选择或搜索 | naming_convention_resource_type_required: "请选择资源类型" |
| `resourceTitle` | 100 | 必填 | 用户直接输入 | rqr_input_resouce_title: "请输入资源标题" |
| `resourceName` | 60 | title.substring(0,60) | 自动同步 OR 手动修改 | rqr_input_resourceauthid: "资源授权标识" |

### 特殊逻辑

**批量场景下的唯一性检查**:
- 同批次内多个资源的 resourceName 不能重复
- 跨批次也不应重复（由平台保证）

```bash

  --config batch-list.yaml \
  --parallelism 5
```

## 二、批量验证

### 验证规则

- [ ] 所有资源类型已选择
- [ ] 所有资源标题不为空
- [ ] 所有资源名称不重复（批次内 + 全局）
- [ ] 资源名称格式合法（禁止字符规范化）

### Next Button 禁用条件

以下任一满足则禁用"批量发布"按钮：
- 任意资源的 `resourceType === null`
- 任意资源的 `resourceTitle === ''`
- 任意资源的 `resourceName === ''`
- 存在 resourceName 冲突
- 存在 resourceName 已存在错误

### i18n Keys

| i18n key | 用途 |
|---------|------|
| `validation_batch_check_failed` | "批量验证失败，请检查以下问题：" |
| `error_duplicate_resource_name` | "第 {index} 个资源的名称与其他资源重复" |
| `error_empty_resource_field` | "第 {index} 个资源缺少必填字段" |

## 五、总结：CLI 实现要点

### 推荐 CLI 设计

#### 非交互模式

```bash
freelog publish batch \
  --config batch-list.yaml \
  --parallelism 5 \
  --resume \
  --output report.md
```

#### batch-list.yaml 示例

```yaml
resources:
  - typeCode: audio.music
    title: "My Album 2026"
    authId: "my-album-2026"
    
  - typeCode: theme.desktop
    title: "Winter Theme"
    # name 自动生成

options:
  parallelism: 5           # 并发度
  retry: true              # 失败自动重试
  checkpoint: true         # 保存断点
```

### 调用的 tools-lib 函数顺序

```
1. batchService.addResource(item)    // 循环 N 次，添加到批次
2. resourceService.checkResourceName(name)  // 批次内唯一性检查
3. resourceService.batchCreate(list)  // 批量创建
4. batchService.generateReport()     // 生成详细报告
```
