# F1-1 · 批量发布总纲

> **对齐 Source**: Console `creatorBatch/Handle/index.tsx (L807-947) + Finish/index.tsx`  
> **核心职责**: 一次性批量创建多个资源，支持本地上传/存储导入两种方式  
> **CLI 限制**: 仅免费策略、最多 20 个文件、串行处理

---

## 1. 流程总览

```bash
$ freelog batch-create ./resources/ --type theme

[1] 选择资源类型 → theme
[2] 上传文件 → local_upload || object_storage_import
[3] 计算 SHA1 → check_occupancy
[4] 生成资源名 → generate_resource_names (≤50 字符)
[5] 填充属性 → systemProperties/customProperties
[6] 提交批量创建 → create_batch_API
[7] 展示结果 → success_count/fail_list
```

### 2.3 完整提交流程 (L786-960)

**Console 位置**: L786-960

**简化版业务逻辑**(已删除虚构字段):
```typescript
async function onClickRelease() {
  // 检查是否至少有一个策略
  const qty = dataSource.filter(d => d.listInfo.resourcePolicies.length === 0).length;
  if (qty > 0) {
    const confirm = await fPromiseModalConfirm({...});
    if (!confirm) return;
  }

  // 构造请求数据 (仅包含有 UI 输入的字段)
  const createResourceObjects = [];
  for (const data of dataSource) {
    if (data.state === 'list' && data.listInfo) {
      const item = data.listInfo;
      
      createResourceObjects.push({
        // ✅ 真实有 UI 输入的字段
        name: item.resourceName_optimized,                    // Step2 自动生成 (≤50)
        resourceTitle: item.resourceTitle,                    // Step2 自动生成 (≤100)
        policies: item.resourcePolicies.map(p => ({           // Step3 FPolicyList
          policyName: p.title,
          policyText: p.text,
          status: 1,                                          // 固定值
        })),
        coverImages: item.cover === '' ? [] : [item.cover],   // Step4 FUploadCover
        tags: item.resourceLabels,                            // Step4 fEditLabelsDrawer
        
        // ❌ 以下字段 Console 都填空/固定值，无需 CLI 实现
        intro: '',                                            // 无 UI 输入
        version: '1.0.0',                                     // 硬编码
        description: '',                                      // 无 UI 输入
        
        // ✅ 自定义属性转换逻辑 (L881-914)
        customPropertyDescriptors: [
          ...item.customProperties.map(i => ({
            type: 'readonlyText',
            key: i.key,
            name: i.name,
            remark: i.description,
            defaultValue: i.value,                          // ≤100 约束
          })),
          ...item.customConfigurations.map(i => ({
            type: i.type === 'input' ? 'editableText' : 'select',
            key: i.key,
            name: i.name,
            remark: i.description,
            defaultValue: i.type === 'input' ? i.input : i.select[0],
            candidateItems: i.type === 'input' ? undefined : i.select,
          })),
        ],
        
        // ❌ 微前端功能 - CLI 跳过
        // baseUpcastResources, dependencies 不处理
        
        // ✅ 仅 type='additional'的系统属性
        inputAttrs: item.systemProperties
          .filter(sp => sp.type === 'additional')
          .map(ap => ({ key: ap.key, value: ap.value })),
          
        // ✅ 签约信息
        batchSignContracts: item.batchSignContracts.map(b => ({
          resourceId: b.resourceID,
          policyIds: b.policyIDs,
          subjectType: b.subjectType,
        })),
      });
    }
  }

  // 调用 API
  const { data } = await FServiceAPI.Resource.createBatch({
    resourceTypeCode: selectedResourceType.value,
    createResourceObjects,
  });
  
  // 解析结果供 Finish 页面展示
  const resultList = Object.entries(data).map(([k, d]) => {...});
  
  history.push('/resource/creatorBatch/finish');
}
```

## 4. CLI 特殊说明

### 4.1 仅免费策略原则
- 检测逻辑：policyText 包含 TransactionEvent 即判定为付费策略
- 付费策略处理：提示用户跳转 Console 完成支付
- 免费策略处理：CLI 自动调用 batchCreateContracts 完成签约
- 禁止行为：CLI 不执行任何支付操作

### 4.2 无草稿机制
- Console 有自动保存草稿功能 (300ms debounce)
- CLI 不提供断点续传，需一次性完成
- 错误后需重新发起命令

### 4.3 串行处理
- Console 可能并行处理 20 个文件
- CLI 建议串行处理，避免并发限制
- 单个失败不影响其他文件

### 4.4 TTY 交互
- 无法显示验证码图片 → 需提前准备 Code
- 无法显示复杂表单 → 用命令行参数/交互式问答
- 批量进度条显示 (简单文本)

### 4.5 资源名生成
- Console: `getARightName(FRegExpMgr.removeExtension(f.name)).substring(0, 50)`
- CLI 需自行实现相同的命名规则:
  1. 去掉扩展名
  2. 去除禁止字符 (`|/:*?"<>|\@#$`)
  3. 替换为下划线 `_`
  4. 限制 50 字符

## 5. API 契约 (精简版)

### FServiceAPI.Resource.createBatch

**Request** (仅列出真实有 UI 输入的字段):
```typescript
{
  resourceTypeCode: string;  // 资源类型代码，如 "theme"
  createResourceObjects: Array<{
    name: string;            // 资源授权标识 (≤50 字符)
    resourceTitle?: string;  // 资源标题 (≤100 字符)
    policies?: Array<{       // 策略数组 (必填≥1)
      policyName: string;
      policyText: string;
      status: 1;             // 固定 1
    }>;
    coverImages?: string[];  // 封面图片 URL 数组
    tags?: string[];         // 标签数组 (≤10)
    
    // ❌ 以下字段 Console 填空/固定值，CLI 不需要实现
    intro: '';               // 始终为空
    version: '1.0.0';        // 固定版本
    description: '';         // 始终为空
    
    customPropertyDescriptors?: Array<{  // 自定义属性
      type: 'readonlyText' | 'editableText' | 'select';
      key: string;
      name: string;
      defaultValue: string;              // value≤100 约束
      candidateItems?: string[];         // select 类型时有
      remark?: string;
    }>;
    
    inputAttrs?: Array<{     // 系统输入属性
      key: string;
      value: string;
    }>;
    
    batchSignContracts: Array<{  // 签约信息
      resourceId: string;
      policyIds: string[];
      subjectType: string;
    }>;
    
    // ❌ 以下字段为微前端功能，CLI 不实现
    // baseUpcastResources, dependencies
  }>;
}
```

**Response**:
```typescript
{
  "[sha1]": {
    data?: {
      status: 0 | 1 | 2;     // 0:unreleased 1:online 2:freeze
      resourceId: string;
      resourceName: string;
      resourceTitle: string;
      coverImages: string[];
      policies: Array<{policyName: string}>;
    },
    message?: string,         // 失败原因
    status: number            // HTTP 状态码
  }
}
```

**错误码映射**:
- `message` 非空 → 创建失败
- `data` 为 null → 创建失败
- `status` 其他值 → 未知错误
