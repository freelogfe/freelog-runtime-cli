```
│   ✓ theme-b-artifact.zip               │

│                                        │
│ [确认发布] ENTER | 取消:ESC             │
└────────────────────────────────────────┘
```

**业务规则**:
1. **扫描规则**:递归扫描 package.json 和 artifact.zip/RAR/zip
2. **批量验证**:自动检测缺失文件或格式错误
3. **逐项处理**:按顺序处理每个资源，记录成功/失败数量
4. **错误容忍**:单个失败不影响其他资源继续发布

## 🔍 **二、Console 源码证据**

### **2.1 批量扫描核心逻辑**

```typescript
// packages/console/src/pages/batch-publish/index.tsx
class BatchScanner {
  async scan(rootDir: string): Promise<BatchScanResult> {
    const resources: ResourceCandidate[] = [];
    const invalidResources: InvalidResource[] = [];
    
    // 1. 递归扫描所有可能的资源目录
    const allDirs = await readdirRecursive(rootDir);
    
    for (const dir of allDirs) {
      try {
        // 查找 package.json
        const packageJsonPath = path.join(dir, 'package.json');
        if (!fs.existsSync(packageJsonPath)) {
          invalidResources.push({
            path: dir,
            reason: 'MISSING_PACKAGE_JSON',
            errorMessage: '缺少 package.json'
          });
          continue;
        }
        
        // 解析 package.json
        const pkg = JSON.parse(fs.readFileSync(packageJsonPath, 'utf-8'));
        
        // 查找 artifact
        const artifactFile = this.findArtifact(dir);
        if (!artifactFile) {
          invalidResources.push({
            path: dir,
            reason: 'MISSING_ARTIFACT',
            errorMessage: '缺少 artifact 文件'
          });
          continue;
        }
        
        resources.push({
          path: dir,
          metadata: pkg,
          artifact: artifactFile,
          isValid: true
        });
        
      } catch (err) {
        invalidResources.push({
          path: dir,
          reason: 'PARSE_ERROR',
          errorMessage: err.message
        });
      }
    }
    
    return { 
      validResources: resources, 
      invalidResources,
      statistics: this.computeStatistics(resources, invalidResources)
    };
  }
}
```

### **2.2 TTY UI 精简版**

```typescript
class BatchResultUI {
  render(result: BatchScanResult) {
    console.log('\n┌─ 批量扫描结果 ─────────────────────┐');
    console.log(`│ 有效资源：${result.validResources.length}`);
    console.log(`│ 无效资源：${result.invalidResources.length}`);
    console.log('│                                    │');
    
    result.validResources.slice(0, 5).forEach(res => {
      console.log(`│ ✓ ${res.metadata.name.padEnd(30)} ${res.artifact.fileName}`);
    });
    
    result.invalidResources.forEach(e => {
      console.log(`│ ✗ ${e.reason.padEnd(30)} ${path.basename(e.path)}`);
    });
    
    console.log('└────────────────────────────────────┘\n');
  }
}
```

**CLI 说明**:暂不支持详细的批量扫描 UI，仅实现基础扫描和发布功能。

## 🚨 **三、异常分支**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|--------|---------|---------|----------|
| MISSING_PACKAGE_JSON | package.json 不存在 | "缺少 package.json" | 补充元数据后重试 |
| MISSING_ARTIFACT | 缺少 artifact 文件 | "缺少 artifact 文件" | 上传 artifact 后重试 |
| INVALID_PACKAGE_JSON | package.json 格式错误 | "无法解析 package.json" | 修正 JSON 格式 |
| ARTIFACT_FORMAT_INVALID | artifact 格式不支持 | "仅支持 zip/rar格式" | 转换为 supported 格式 |

## ✅ **四、验收标准**

| 测试项 | 预期行为 | 验证方法 |
