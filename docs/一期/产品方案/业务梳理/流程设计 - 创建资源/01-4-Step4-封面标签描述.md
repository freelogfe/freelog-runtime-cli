## 5. CLI 特殊说明

### 5.1 封面上传策略
1. **本地文件**: 调用 UploadFile API 上传到对象存储
2. **URL**: 直接使用用户提供的外链
3. **无封面**: 不调用该字段 (post body 中省略)

### 5.2 短描述处理
- CLI 可直接接受命令行参数 `--desc` 或交互式输入
- 长度超过 200 时提示用户并拒绝提交
- 无需复杂 TTY UI，纯文本即可

### 5.3 标签管理
- CLI 接受空格/逗号分隔的标签列表：`--tags "主题 创意 2024"`
- 自动 trim 空白字符
- 去重处理 (可选)
- 不限制数量 (Console 可能有 maxTags，但未在前端体现)
