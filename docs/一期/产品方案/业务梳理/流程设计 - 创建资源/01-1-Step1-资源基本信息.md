## 3. 字段约束汇总

| 字段 | UI 组件 | 长度限制 | 必填 | 验证规则 | Console 证据 |
|------|--------|---------|------|---------|-------------|
| resourceType | FResourceTypeInput4 | - | 是 | 拼音安全 + 唯一性 | Step1 L91-111 |
| resourceTitle | FInput_PinyinSafeTextCounter | ≤100 | 是 | 拼音安全 | Step1 L126-155 |
| authId (resourceName) | FInput_PinyinSafeTextCounter | ≤60 | 是 | 拼音安全 + 唯一性 + 自动转换 | Step1 L186-271 |

**特殊行为**:
- resourceTitle 与 authId 关联：如果用户先输入 title 且 authId 未被手动修改，则 authId = title.substring(0, 60)
- authId 自动转换：console 会自动将非法字符转换为安全格式 (resourceName_optimized)
- 300ms debounce: authId 输入后等待 300ms 才触发验证

## 5. CLI 特殊说明

### 5.1 authId 生成规则
1. 从文件名自动提取：去掉扩展名
2. 替换非法字符：`|/:*?"<>|\@#$` → `_`
3. 限制 60 字符：substring(0, 60)
4. 检查唯一性：需调用验证 API

### 5.2 无草稿机制
- Console 自动保存状态到 Redux
- CLI 需一次性完成，不支持中途暂停恢复

### 5.3 自动化优势
- CLI 可直接利用文件名作为 authId 基础
- 无需处理复杂的拼音安全转换 (由后端 API 保证)
