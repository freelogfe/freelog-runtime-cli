## 🚀 **二、Console 源码证据**

### **2.1 策略模板体系**

```typescript
// packages/console/src/pages/resource/creator/Step3/PoliciesSelector.tsx
interface PolicyTemplate {
  id: string;
  name: string;
  type: 'free' | 'commercial' | 'custom';
  formSchema: ZodSchema;
  defaultValues: Record<string, any>;
}

const BUILT_IN_TEMPLATES = [
  {
    id: 'free',
    name: '免费使用',
    type: 'free',
    formSchema: z.object({}),
    defaultValues: {}
  },
  {
    id: 'commercial',
    name: '商业使用',
    type: 'commercial',
    formSchema: z.object({
      licenseUrl: z.string().url(),
      termsOfUse: z.string().min(10).max(500)
    }),
    defaultValues: {
      licenseUrl: 'https://freelog.com/licenses/commercial'
    }
  }
];
```

**业务规则**:
- 首次选中默认第一个 (`免费使用`)
- 根据选择的模板动态显示参数输入框

### **2.2 动态表单渲染器**

```typescript
function DynamicFormRenderer({ schema, initialValues }) {
  const fields = schema.toFields();
  return <Form>{fields.map(field => <FieldRenderer field={field} />)}</Form>;
}
```

### **2.3 策略编译逻辑**

```typescript
async function compilePolicy(templateId: string, formData) {
  // 1. Schema 验证
  const validated = template.formSchema.parse(formData);
  
  // 2. 编译为字节码
  const compiled = PolicyEngine.compile({ type, parameters: validated });
  
  // 3. 上传获取 policyId
  return { version: '1.0', bytecode: compiled.bytecode, policyId };
}
```

### **2.5 错误处理**

```typescript
try {
  const result = await compilePolicy(selectedTemplate.id, formData);
  dispatch({ type: 'setPolicyResult', payload: result });
} catch (error) {
  if (error instanceof ZodError) {
    showWarning('表单验证失败:' + error.message);
  } else {
    showError('编译失败:' + error.message);
  }
}
```
