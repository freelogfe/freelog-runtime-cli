# P0-M0: 发行新版本

## 概述

已有普通资源建下一版。路由 `/resource/versionCreator/:id`，`useParams().id`。页面结构接近 [F0 Step2](../创建流程%20-%20发行单个资源/P0-F0-Step2-提交资源文件.md)，本文只写差异。

标题：`create_new_version_newversion` → 「新建版本」。提交：`release_to_market` → 「发行」。草稿：`save_as_draft` → 「暂存为草稿」。

合集 `subjectType===4` 禁止进本页（异常 + `create_new_version_error_unknowsubject`）。非本人 403；冻结 `(status&2)===2` 进冻结页。

### 主流程 (ASCII)

```
侧栏 / 列表「更新版本」→ /resource/versionCreator/:id
  → Resource.info + getResourceTypeInfoByCode（重算四入口）
  → 有草稿：恢复草稿，不 inherit
  → 无草稿且有 latestVersion：inherit 上一版文件（from=上个版本）
  → 可删文件再走四入口
  → FVersionInput：默认 patch+1，须 semver.valid 且 > latest
  → createVersion(version=versionInput, description=descriptionText)
  → 成功页（带真实 version），不进策略 Step
```

---

## 与 F0 Step2 相同

四入口、SHA1 解析、属性/可选配置/依赖微前端（`resourceInVersionUpdate`）、视频封面 UI 但不传 createVersion、dirty 300ms `saveVersionsDraft`、未授权硬编码拦截。依赖加树 / 签约 / inherit 上抛来自壳 `info.baseUpcastResources`：见 [P0-D](../依赖与签约/P0-D-依赖管理与签约.md)。

## 差异

| 项 | F0 Step2 | M0 |
|----|----------|-----|
| resourceId | Step1 内存 | 路由 `:id` |
| 版本号 | 写死 1.0.0，无 UI | `FVersionInput`；空 → `naming_convention_version_required`；非法或不大于 latest → `freelog_versioning` |
| 继承上一版 | 无 | 无草稿时 inherit 文件/部分属性/依赖/描述 |
| 草稿冲突 | 无上一版 | **有草稿则跳过 inherit**，无确认框 |
| `createVersion.version` | `'1.0.0'` | `versionInput` |
| `description` | `''` | `descriptionText` |
| 成功去向 | step=3 策略 | `resourceVersionCreateRelease` |
| 按钮 | 稍后处理 / 提交 | 暂存草稿 / 发行 |
| 自定义属性 value | max 100 | **140** |
| 微前端 | 无 licenseeVersion | 传 `licenseeVersion=versionInput` |

Inherit 细节（`resourceVersionCreatorPage.ts` L544–677）：`resourceVersionInfo1`；`from='上个版本'`；additional 仅 `insertMode===2`；readonlyText → customProperties；`supportOptionalConfig===2` 才带可选配置。

## CLI

```
freelog-cli update-version --version <semver>
freelog-cli update-version --reuse-version <已发版> --version <semver>
freelog-cli update-version --file <path> --version <semver>
```

须已 `create`/`bind`。命令是 **`update-version`**，不要用 `create-version`（那是首版）。回显源用 `--reuse-version`（默认 latest），换文件用 `--file`，两套可以一起用。不要写在 `version set` 上。CLI 上传只走本地 `--file`。
