# P0-C1: 单品管理

## 概述

合集侧栏最重的一页。在**目录草稿**上增删改、排序、授权，底栏「暂存为草稿 / 发布」。**没有**跳 [M0](../创建流程%20-%20发行新版本/P0-M0-发行新版本.md) 的「更新版本」。RSS 合集锁编辑，只允许同步。

标题：`edit_collection_tab_itemmgnt`「单品管理」。件数：`edit_collection_itemmgnt_itemcount`「{itemCount}个单品」。发布成功：`edit_collection_itemmgnt_msg_released_successfully`「发布成功」。

### 主流程 (ASCII)

```
version_onMount
  → GET info + 类型配置 + 已发版 1.0.0 属性
  → GET catalogues/drafts/{id}/items + collectRules
  → 未定来源：库 / RSS 二选一（仅一种则跳过）
资源库：勾选我的资源（每批≤100）→ POST drafts/items
  → 改标题 / 删 / 排序 / 授权排除 → 草稿 API
  → 300ms saveVersionsDraft（RSS 跳过）
底栏有脏：
  →「暂存为草稿」POST versions/drafts
  →「发布」PUT catalogue isMergeCatalogueDraft=1|0
RSS：bindFeed 或 PUT rss/bindings/{id}/sync；单品只读
```

## 一、添加与草稿 CRUD

与 [C0 Step2](../创建流程%20-%20发行合集/P0-C0-Step2-添加单品.md) 同库：`fSelectResourcesAsCollectionItems` + `FAddResourcesHandleAuth`，每批 **100**。

| 操作 | FServiceAPI | HTTP |
|------|-------------|------|
| 拉草稿单品 | `Resource.getCollectionItems_Draft` | `GET /v2/resources/catalogues/drafts/{id}/items` |
| 改标题/排除 | `Resource.updateCollectionItemsInfo_Draft` | `PUT /v2/resources/catalogues/drafts/{id}/items` |
| 删 | `Resource.deleteCollectionItems_Draft` | `DELETE /v2/resources/catalogues/drafts/{id}/items?removeCollectionItemIds=` |
| 排序 | `Resource.reorderCollectionItems_Draft` / `setCollectionItemsSortID_Draft` | `PUT .../drafts/{id}/reorder` / `manualSort` |
| 草稿授权态 | `Resource.getCollectionItemsAuth_Draft` | `GET .../drafts/{id}/items/batchAuth` |
| 表单草稿 | `Resource.saveVersionsDraft` | `POST /v2/resources/{id}/versions/drafts` |

搜索关键词 300ms 再拉列表。完结/连载徽章用 `cqr_itemmgmt_updatedstates_completed` / `cqr_itemmgmt_updatestates_ongoing`。

## 二、发布（不是 createVersion）

`version_SaveDate`：`PUT /v2/resources/catalogue/{id}`，带属性、描述、`catalogueProperty`、依赖、`authExcludedItems`。`isMergeCatalogueDraft` = 单品脏则 **1**，否则 **0**。

底栏仅 `rssSource==='no'` 且（单品脏或其它脏）时出现。RSS 禁用两按钮。

| 按钮 | i18n (zh_CN) |
|------|----------------|
| 提示 | `edit_collection_itemmgnt_submit_info`: 「变更未发布，您可以随时发布 →」 |
| 暂存 | `save_as_draft`: 「暂存为草稿」 |
| 发布 | `edit_collection_itemmgnt_submit_btn`: 「发布」 |

更新日志抽屉：`Resource.getCollectionUpdateLogs` → `GET /v2/resources/catalogue/{id}/updateLogs`。
