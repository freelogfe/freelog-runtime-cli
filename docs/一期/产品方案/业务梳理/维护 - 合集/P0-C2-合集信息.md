# P0-C2: 合集信息 + 收录规则

## 概述

listing 与 [M2](../维护%20-%20单资源/P0-M2-资源信息.md) 同构，文案换成合集 key。另有更新状态 / 自动收录；保存即 `POST collectRules`。RSS 可改订阅地址，成功后跳回 C1。

Tab：`edit_collection_tab_info` → 「合集信息」。

### 主流程 (ASCII)

```
info_onMount
  → GET info + GET collectRules
  → 标识只读
  → 标题≤100 / 封面即存 / 简介 / 标签
       各 PUT update（只 listing，无 status）
  → 完结|连载 + 自动收录条件 → POST collectRules
  → RSS：封面/简介/规则只读；标签仍可改
  →「更改 RSS」→ bindFeed → 跳 collectionVersionInfo
```

---

## 与 M2 的差异

| 项 | M2 | C2 |
|----|----|----|
| 标识/标题 i18n | `edit_resource_listing_*` | `edit_collection_listing_authid`「授权标识」；`edit_collection_listing_title`「标题」 |
| 标识说明 | 资源…不能更改 | `edit_collection_listing_authid_info`「合集在整个授权系统中的唯一标识符，一旦创建则不能更改。」 |
| 收录规则 | 无 | `setCollectRules` 即时保存 |
| RSS | 禁标题/封面/简介 | 另可改 feed；标签**不**锁 |

标题空 / 超 100 与 M2 相同（`naming_convention_resource_title_required`；硬编码「不超过100个字符」）。简介、封面、标签约束同 M2 / F0 Step4。

## 收录规则

挂载读 `getCollectionCollectRules`。保存体：

| 字段 | 含义 |
|------|------|
| `serializeStatus` | 完结 1 / 连载 0（`isFinish`） |
| `status` | 自动收录开 1 / 关 0 |
| `conditionType` | `every`→1，`some`→2 |
| `filterConditions[]` | `key` + `limitOperatorType` + `value` |

`key`：`resourceTitle` / `resourceTypeCode` / `authIdentity`。算子：`INCLUDES` `NOT_INCLUDES` `STARTS_WITH` `ENDS_WITH` `EQUAL` `NOT_EQUAL`。含 `/` 的 value 回显时只取后半段。

创建向导 Step4 是「listing + 规则 + status:1」三连；**本页规则单独 POST，不上架**。

|------|-------------|------|
| 挂载 | `Resource.info` | `GET /v2/resources/{id}` |
