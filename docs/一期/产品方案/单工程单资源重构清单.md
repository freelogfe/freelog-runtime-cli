## 协作规则

每个未完成项固定经过以下状态，不跨级：

```text
[ ] 待讲解 → [~] 已讲解，等待复核 → [>] 方案已确认，待实现
→ [#] 已实现，待验证 → [x] 已验证完成
```

每次讲解必须写明：用户场景、命令输入与输出、本地状态变化、平台调用边界、错误与恢复、测试方案、与普通资源/主题/插件的差异。复核发现问题时回到“待讲解”或“方案已确认”，不得直接修改代码。

### B. 命令逐条收敛

- [ ] `init`：普通资源与主题/插件的初始默认路径、非空目录、login 后 init 的例外。
- [ ] `create`：`--artifact` 只是默认路径记录，是否应要求路径存在、普通文件与主题/插件的形态校验。
- [ ] `bind`：已有线上资源接入时 `--artifact` 的必填规则、换绑、工作稿清理。
- [ ] `create-version`：未传 artifact 的默认路径、显式 artifact 的回写时机、首版 prepare 与提交。
- [ ] `update-version`：换文件/换构建目录、工作稿底版本、重新上传与路径回写。
- [ ] `version set`：只改默认路径的输入校验与错误恢复。
- [ ] `status`、`version`、属性、配置、依赖、策略、上下架：确认它们不再接受或依赖身份路径选择器。
