## 📋 **一、核心类型定义**

### **1. 资源类型 (Resource Types)**

```typescript
/**
 * Freelog 支持的资源类型树
 * 来源：Console resources/resource-type-tree.tsx
 */
interface ResourceTypeTree {
  id: string;                    // 类型 ID
  name: string;                  // 显示名称
  type: 'theme' | 'plugin' | 'library' | 'software';
  children?: ResourceTypeTree[]; // 子类型 (嵌套结构)
}

// 一级分类
export const RESOURCE_TYPES = {
  THEME: 'theme',                // 主题
  PLUGIN: 'plugin',              // 插件
  LIBRARY: 'library',            // 前端库
  SOFTWARE: 'software',          // 软件
} as const;

// 二级分类 (Theme-Aurora, Theme-Nature 等)
interface SubResourceType {
  parentId: string;
  id: string;                    // "theme-aurora", "plugin-shortcut"
  name: string;
  schema: ResourceSchema;        // 对应的 Schema 定义
}
```

### **2. 认证凭据 (Credentials)**

```typescript
/**
 * CLI 登录凭据
 * 来源：packages/tools-lib/src/auth.ts
 */
interface CLICredentials {
  accessToken: string;           // Access Token (有效期 2h)
  refreshToken: string;          // Refresh Token (长期有效)
  expiresIn: number;             // 过期时间 (秒)
  scope: string[];               // 权限范围
  accountId: string;             // 用户账号 ID
}

interface AuthState {
  current: CLICredentials | null;
  isEphemeral: boolean;          // Session 模式 (临时)
  isStudio: boolean;             // Studio 模式 (工作室)
}
```

### **3. API 响应类型**

```typescript
/**
 * Freelog API 通用响应
 * 来源：packages/tools-lib/src/api-types.ts
 */
interface APISuccess<T> {
  success: true;
  data: T;
}

interface APIError {
  success: false;
  error: {
    code: string;                // 错误码 (见 05-错误码体系.md)
    message: string;             // 错误消息
    details?: any;               // 额外详情
  };
}

type APIResponse<T> = APISuccess<T> | APIError;
```

## 💡 **三、关键说明**

### **1. tools-lib 复用原则**
- ✅ **所有类型定义**都来自 `tools-lib/src/types.ts`
- ✅ **不允许重复定义**,CLI 必须导入使用
- ✅ 如需扩展 → 先修改 `tools-lib`,再同步 CLI

### **2. TypeScript 严格模式**
```typescript
// ✅ 正确：从 tools-lib 导入
import { CLICredentials, APIResponse } from '@freelog/tools-lib';

// ❌ 错误：本地重新定义
interface CLICredentials { ... }  // 会造成功能不一致!
```
