# 01 - 账号

账号 = **登录谁、凭据放哪、何时登出**。  
`session` / `studio` / `--session` **不是账号**，见文末。

`init` 不负责登录。

```
login  →  init / create / create-version / update-version / online
logout →  只清本地凭据，工程还在
```

---

## 1. 登录 / 登出

平台登录：`POST /v2/passport/login`（用户名 + 密码）。不保存密码。不要浏览器授权。

登出只删凭据，**不调**平台注销。不删 `.freelog/` 里的 manifest / index。

```
$ freelog-cli login --env dev
  → 写入当前目录 .freelog/auth（工作区）；.gitignore 忽略它

$ freelog-cli login --global --env dev
  → 写入 ~/.freelog-auth（这台机器的默认号）

$ freelog-cli login --login-name <name> --password-stdin --yes --env <env>
  → CI：密码只进 stdin

$ freelog-cli logout            # 先工作区，没有才是全局
$ freelog-cli logout --global   # 只删机器默认号
```

换人：`logout` 再 `login`。换环境：`logout` 再 `login --env <新环境>`（一份文件只绑一个环境）。

没登录：还能改代码、构建、`version set`（无 resourceId 时）。  
必须先登录：交互选类型的 `init`，以及 `create` / `create-version` / `update-version` / `online` / `update` / `bind`。合集命令本期不做。

---

## 2. 凭据放哪

从 `--cwd`（否则当前目录）往上找：

| 层 | 文件 | 谁用 |
|----|------|------|
| 工作区 | 最近一份 `.freelog/auth` | **默认**。子目录有就盖过父目录 |
| 全局 | `~/.freelog-auth` | 整条路径都没有工作区凭据时 |

规则：可以先 `login` 再 `init`。命中的文件坏了：**报错**，不准改用另一份。文件里的环境必须等于 `--env`。省略 `--env` = **prod**。token 加密存放。

---

## 3. 和发行怎么接

写平台前：当前登录必须是资源 owner。

| 路径 | 账号 |
|------|------|
| [init](./03-init.md) | 不登录。选类型或 `create` 之前再 `login` |
| [Step1](../PHASE/单资源/创建/01-Step1-创建授权条目.md) / [发行版本](../PHASE/单资源/创建/02-Step2-发行版本.md) / [更新版本](../PHASE/单资源/更新版本/01-更新版本.md) | 先 `login` |
| [管理](../PHASE/单资源/管理/00-总览.md) | 同一个号；或 `bind` 后仍用当前号 |

PHASE 主路径**不要**写 `session` / `studio`。

---

## 4. 干活方式（不是账号）

| 名字 | 入口 | 凭据 | 工程 |
|------|------|------|------|
| 工程（默认） | `login` + 普通命令 | `.freelog/auth` | `.freelog/` 编号 manifest |
| 一刀 | `xxx --session --resource-id` | 可读已有工作区凭据 | 这刀不写工程 |
| 交互会话 | `freelog-cli session` | 进壳重登，不写盘 | 不写盘 |
| 多账号壳 | `freelog-cli studio` | 进壳重登，不写盘 | 子工程可以落盘 |

没有 [本地状态](./02-本地状态.md) 的身份，只能在一个进程里做完。`--session` 是旗标，不是 `session` 命令。壳里门禁与 PHASE 相同。

---

## 5. 禁止

- 浏览器 OAuth；把 `session`/`studio` 当成 `login` 的两种模式
- `init` 里顺带登录
- 坏掉的工作区凭据回退全局
- 一份凭据跨环境用
- 密码进 JSON / `--debug` 打出 token
