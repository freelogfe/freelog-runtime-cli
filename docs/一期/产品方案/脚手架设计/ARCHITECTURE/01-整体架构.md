## 📋 **一、四层模型**

```
┌─────────────────────────────────────┐
│   Layer 4: UI/UX (TTY Interface)    │
│   └── TTY 交互组件 + 进度渲染器      │
├─────────────────────────────────────┤
│   Layer 3: Step Orchestrator        │
│   └── PHASE 专项设计 (P0-P4)         │
├─────────────────────────────────────┤
│   Layer 2: Business Logic           │
│   └── 业务梳理中的 Step 实现          │
├─────────────────────────────────────┤
│   Layer 1: API Client               │
│   └── tools-lib 复用                 │
└─────────────────────────────────────┘
```

---

## 🔗 **二、与其他层级关系**

| 层级 | 职责 | 位置 |
|------|------|------|
| **业务梳理/** | Console 对齐业务流程 | `业务梳理/` |
| **PHASE/** | Step 编排器 | `脚手架设计/PHASE/` |
| **ARCHITECTURE/** | 技术约束 + API 契约 | `脚手架设计/ARCHITECTURE/` |
