## S26 发新号：表单跟上一号，文件换成新的

**判定**：能走通

```
# 分步：先拉底，再交时换文件
freelog-cli version draft pull --version 1.0.0
freelog-cli update-version --artifact b.mp4 --version 1.1.0 --yes

# 也可在同一条提交命令中同时指定来源、文件与新号
freelog-cli update-version --reuse-version 1.0.0 --artifact b.mp4 --version 1.1.0 --yes

# 多份资源：a.mp4 是已登记身份，b.mp4 是这次新产物
freelog-cli update-version --resource artifact:a.mp4 --artifact b.mp4 --version 1.1.0 --yes
```

`--reuse-version` 与 `--resource` 不是互斥。未传 `--artifact` 时，只会采用确实存在的已记录路径；路径缺失则停止，不能复用稿里的 SHA1。


## S28 一夹多份，只指「哪一份」并不是换文件

**判定**：能走通

```
freelog-cli update-version --resource artifact:a.mp4 --bump patch --yes
# 只选该份。本地记录的产物存在则按磁盘；不在走 S27
```

多份未 `--resource`：TTY 选择；非交互失败并列出可用选择器。

## S29 改系统附加 / 自定义 / 可选配置，分多次

**判定**：自定义属性和类型允许的配置可以编辑；系统附加属性尚缺完整的字段发现与编辑前格式复验，不能将整条场景宣称为闭环。

```
# 已有更新稿（先 draft pull）或首版稿（先 create-version --prepare）
freelog-cli version attr add "名称=作者 键=author 值=张三"
freelog-cli version attr set "键=author 值=李四"
freelog-cli version attr set "键=<平台确认的系统附加属性key> 值=<填写值>"
freelog-cli version option add "名称=主题 键=theme 方式=文本 默认=dark"
```

各表单命令使用同一套字段校验。已发号只读：`version show`。类型不允许时 `version option add` 与 `set` 均失败；`rm` 仍可删历史稿中的遗留项，提交前仍有最后一道类型门禁。满 30 不能再加。

当前 `version attr list` 只列自定义属性，`version show --local` 只输出工作稿，不列完整解析格式或所有未填写的附加属性。`attr set` 的系统分支检查分析 SHA，却没有重新取得字段格式并校验 key 属于可编辑附加属性。暂时只能使用已经确认的 key，不能依靠这两个读取入口自动发现所有字段；正式属性设计要求的展示/编辑闭环仍是待实现项。

## S30 加一条依赖：已有授权直接声明；未授权才选策略签约

**判定**：能走通

```
freelog-cli version dep add someone/lib --range ^1.0.0
```

先验证对方为可引用的单资源、存在 latest、版本列表可解析且范围命中；随后 `GET /v2/auths/resources/batchAuth/results`（`resourceIds`=对方，`versionRanges`=范围）。只看 `isAuth`。true：不签，直接写稿。false：列出对方全部可签策略，由用户选择一条后签约（不分免费/付费，付费为待执行态）；签约成功即直接写稿，不复查。未授权的非交互调用必须显式给 `--policy-id`，不按列表顺序自动选择。不查合约。`dep range` 与 `dep add` 使用同一验证链。对方有基础上抛 / 未发行 / 冻结 / 下架 / 无 latest / 无可信版本列表：不写稿；未授权且一条启用策略都没有时也不写稿。循环：不加。没有顶层 `dep add`。

## S32 回显来的依赖，对方后来有了基础上抛或冻了

**判定**：能走通

回显不自动从稿里删。提交再核，点名失败。人自己 `version dep rm` 或换一条。不替对方签上抛链。

## S33 资源已冻结 / 不是本人

**判定**：远端发行和绑定门禁已实现；纯本地属性改稿没有远端 owner/冻结复核，不完全覆盖真实场景的所有写入口。

`create-version` / `update-version` / `bind` 核验 owner 与冻结后拒绝不允许的操作；`version show` 保持只读。不能由此推断 `version attr add/set/rm` 的纯本地改稿也做了相同核验：这些入口目前只走本地身份与稿校验。若要求所有本地改稿也拒绝冻结或非本人目标，仍需补充实现与测试；本轮只记录，不修改业务代码。

## S35 解析属性超过两分钟还在转

**判定**：能走通

`filesListInfoSse` 从建立连接起最长 120 秒。连接异常、流无效或未收到终态即失败，不提交。不要用会空转的 `getFilesSha1Info` / `fileProperty`。
