# 04 - 文件、属性、依赖与其它（实现）

真实场景：[04](../真实场景/04-文件属性依赖与其它.md)

---

## S26 发新号：表单跟上一号，文件换成新的

**判定**：能走通

```
# 分步：先拉底，再交时换文件
freelog-cli version draft pull --version 1.0.0
freelog-cli update-version --file b.mp4 --version 1.1.0

# 一次会话也可以一起说
freelog-cli update-version --reuse-version 1.0.0 --file b.mp4 --version 1.1.0
```

`--reuse-version` 与 `--file` 不是互斥。未传 `--file` 不重读磁盘。

---

## S27 续用文件：本地文件已经不在了

**判定**：能走通

未传 `--file`，或 `--file` 已是该份路径且本地不在：复用稿 / 回显的 sha1。先 `fileIsExist`。存储没有：失败，要求 `--file` 重传。

---

## S28 一夹多份，只指「哪一份」并不是换文件

**判定**：能走通

```
freelog-cli update-version --file a.mp4 --bump patch
# a.mp4 已是某份 filePath：只选份。本地不在则仍续用 sha1
```

多份未 `--file`：失败，列出各份。

---

## S29 改系统附加 / 自定义 / 可选配置，分多次

**判定**：能走通

```
# 已有更新稿（先 draft pull）或首版稿（先 create-version --prepare）
freelog-cli version attr add "名称=作者 键=author 值=张三"
freelog-cli version attr set          # 键不改；系统附加改 value
freelog-cli version option add "名称=主题 键=theme 方式=文本 默认=dark"
```

会话菜单同一套问法。已发号只读：`version show`。类型不允许可选配置：`version option` 失败。满 30 不能再加。

---

## S30 加一条依赖：签完就能授权

**判定**：能走通

```
freelog-cli version dep add someone/lib --range ^1.0.0
```

先 `GET /v2/auths/resources/batchAuth/results`（`resourceIds`=对方，`versionRanges`=范围）。只看 `isAuth`。true：不签，直接写稿。false 才当场免费签，签完再看一次 `isAuth`。不查合约。对方有基础上抛 / 未发行 / 冻结 / 下架 / 只有付费：不加。循环：不加。没有顶层 `dep add`。

---

## S31 依赖只在「准备下一版」时管

**判定**：能走通

```
freelog-cli version show                # 只读已发号依赖
# 没有顶层 dep / dep auth
# 要改树：
freelog-cli version draft pull
freelog-cli version dep add|rm|range
freelog-cli update-version --yes --bump patch
```

---

## S32 回显来的依赖，对方后来有了基础上抛或冻了

**判定**：能走通

回显不自动从稿里删。提交再核，点名失败。人自己 `version dep rm` 或换一条。不替对方签上抛链。

---

## S33 资源已冻结 / 不是本人

**判定**：能走通

写操作（`create-version` / `update-version` / 改稿 / `bind` 等）失败。`version show` 只读线上可以。

---

## S34 合集

**判定**：能走通

`subjectType===4`：本期整条失败。不要当普通资源 `createVersion`。

## S35 解析属性超过两分钟还在转

**判定**：能走通

`filesListInfo` 从第一次请求起最长 120 秒。超时：「属性解析超时」，不进会话。不要用会空转的 `getFilesSha1Info` / `fileProperty`。
