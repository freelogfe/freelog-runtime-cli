# 09 - 参数化策略与异常（实现）

对应[真实场景](../真实场景/09-参数化策略与异常.md)。规则真源是[参数化策略模板](../../ARCHITECTURE/09-参数化策略模板.md)；本文只映射当前命令，不表示所有 dev 分支均已验收。

下面使用单资源前缀；合集替换成 `freelog-cli collection policy` 并使用合集选择器。所有示例明确环境，单资源的选择器必须对应本地身份；合集支持直接线上 ID。

## S71 浏览与选择

```text
freelog-cli policy template list --resource id:<资源ID> --env dev
```

TTY 每页 20 条，上一页、下一页和退出均在同一内存快照上操作。选中后直接进入创建流程；普通非 TTY 只展示首页，需要完整目录用 `--json`。平台请求固定为 `{}`，响应后按主体的 `compileType` 筛选；没有页码参数。

## S72 编辑参数与预览

```text
freelog-cli policy template apply <模板ID> --resource id:<资源ID> --env dev
```

TTY 展示完整标记说明、参数表和名称，用户按编号反复编辑。数字、选项、日期时间依本次模板描述校验；无安全默认值必须补填。预览调用平台编译和翻译，展示名称、译文和值，最终确认后才创建并启用。

## S73 查看或取消

```text
freelog-cli policy template info <模板ID> --resource id:<资源ID> --env dev
```

`info` 只读；TTY `list` 的退出、编辑菜单取消及最终预览取消均零写入。不为参数建立任何自动本地 JSON。人工需最终确认时不要传 `--yes`。

## S74 脚本或 AI 精确提交

```text
freelog-cli policy template list --json --resource id:<资源ID> --env dev
freelog-cli policy template apply <模板ID> --template-fingerprint <指纹> --name "策略名称" --param "1=<值>" --param "2=<值>" --yes --resource id:<资源ID> --env dev
```

按所选项的真实参数数量调整 `--param`，每个编号恰好一项；无参数模板省略全部 `--param`。`list --json` 返回完整可读目录，`info <ID> --json` 只刷新单项；两者不输出可编辑 DSL。脚本必须给 ID、指纹、名称、所有参数和 `--yes`。

## S75 模板变化

编辑预览前或脚本 apply 时重读模板并校验指纹。变化即停止，不写平台；先重新执行 `template info <ID> --json` 或全量 `list --json`，重新确认参数后再提交。指纹不是 DSL 语义校验，编译结果仍由平台决定。

## S76 空目录与编译失败

空目录正常显示无可用模板，JSON 的 `templates` 为空数组；未知 ID、畸形字段、无效参数明确失败。编译或翻译失败均不调用创建接口，保留平台原错误；本期不存在本地文本策略备用入口。

## S77 重复名称或内容

默认标题重名时先要求填写有效名称，准备创建时再核对最新线上策略。TTY 可回到名称或参数编辑，脚本失败；不自动改名，不替换已有策略。

## S78 创建结果未知

```text
freelog-cli policy list --resource id:<资源ID> --env dev
```

`POLICY_CREATE_RESULT_UNKNOWN` 后先查询目标策略列表；本次 TTY 写入循环立即结束，不能自动重发。请求抛错不能靠同名读回猜成功；HTTP 成功但读回不一致也属未知结果。版本提交的 `resource recover` 不适用于策略创建。

## S79 启停与上架门禁

```text
freelog-cli policy set --id <策略ID> --off --resource id:<资源ID> --env dev
freelog-cli policy set --id <策略ID> --on --resource id:<资源ID> --env dev
```

目标已满足时幂等返回；已上架主体最后一条启用策略禁止停用。先下架或建立另一条启用策略，再调整。`policy list` 一次展示全部现有策略，不分页；它与模板目录分页不是同一功能。

## S80 目标身份与冻结

模板目录、详情和策略列表均读线上主体以确认 owner、类型和主体身份；冻结仅阻止写操作。写前重新确认当前目标，使用稳定 policyId 启停并读回；不修改 `N.json` 的策略字段或版本工作稿。

## 验收边界

命令和本地回归不能代替真实样本。真实跨页需要超过 20 条适用模板；datetime、平台编译错误及未知写入结果各按证据单独验收，缺样本标 `BLOCKED`。后端类型收窄、支付和手写策略语言仍不在本期公开流程中。
