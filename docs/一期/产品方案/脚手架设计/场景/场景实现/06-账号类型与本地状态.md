## S43 第一次在一台机器和一个工程里开始

**判定**：能走通

```text
freelog-cli login
# 或 freelog-cli login --global
```

交互登录只把机密凭据放进操作系统安全凭据库。项目 `.freelog/auth` 仅保存账号 / 环境选择器；`--global` 只设置全局默认选择。不得提供密码、token 或授权码参数，也不得在日志、JSON 或状态文件输出机密。

CI 以 `--login-name`、一次性 `--password-stdin` 与 `--yes` 登录；不使用环境变量、仓库文件或命令参数保存秘密。

---

## S44 换账号、换环境，或凭据过期

**判定**：能走通

```text
freelog-cli logout
freelog-cli login --env <env>
```

项目选择器优先于全局选择器。认证过期、环境不匹配或无权限时，任一线上命令必须停止并指向重新登录；不得删除版本工作稿，也不得静默换用其他账号。

---

## S45 普通资源立项：逐层找到正确类型

**判定**：能走通

```text
freelog-cli init <dir>
```

交互式 `init` 读取类型树，按一级到叶子的层级选择；可返回上级重选。仅 `status=1`、`subjectType` 值中包含 `1`、`isTerminate=true` 的可用叶子能继续。树接口缺少 `isTerminate` 时，仅将无子节点显示为候选，确认前必须用详情接口复验。`theme`、`widget` 不走选择器，类型固定。

---

## S46 知道关键词或 code，想快速选类型

**判定**：能走通

```text
freelog-cli init <dir> --type <leaf-code>
```

交互选择器内支持搜索和直接输入；搜索展示完整路径，直接输入与 `--type` 共用精确叶子校验。名称模糊命中、父节点、停用节点或未知 code 一律不能写入项目身份。

---

## S47 安全立项：取消、非空目录与模板下载失败

**判定**：能走通

```text
freelog-cli init <dir> [--type <leaf-code>] [--yes]
```

先校验目标目录和远端模板包，在临时目录下载、校验、安装；所有步骤成功后才原子落盘身份状态。非空目录默认拒绝；取消、下载失败、校验失败或并发冲突不得留下半个工程或 `.freelog`。本期只创建主题 / 插件的工程骨架，不渲染占位内容。

---

## S48 版本工作中断、换文件或系统属性变化

**判定**：能走通

```text
freelog-cli version show --local
freelog-cli create-version --artifact <path>
freelog-cli update-version --artifact <path>
```

本地查看应显示草稿种类、文件摘要、分析状态、待处理输入属性和依赖。换文件后重分析：兼容值保留，不再适用的值进入待处理项。多份资源时另以 `--file <已记录路径>` 选择身份。存在待处理项、文件变更未分析时禁止提交；`--yes` 不能静默删除值。

---

## S49 另一台机器、损坏旧稿或重绑后的恢复

**判定**：能走通

```text
freelog-cli bind <resourceId> --force --yes
```

不迁移旧状态：无 `schemaVersion=1`、身份不一致或无法辨明草稿种类时，保留原文件并停止，用户只能明确丢稿或从线上重新拉取。另一台机器缺少本机安全凭据时只要求重新登录，不碰工作稿。强制改绑在同一事务清掉旧资源版本工作稿和模板缓存。
