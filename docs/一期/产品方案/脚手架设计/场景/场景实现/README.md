# 场景实现

用**现行** CLI 把 [真实场景](../真实场景/README.md) 同一编号走完。只许提已设计的命令，不要发明。

| 判定 | 意思 |
|------|------|
| 能走通 | 按右边命令能做到场景里的成功，避开失败 |
| 别扭 | 能做到，但入口不好找或默认行为容易踩 |
| 缺口 | 现行命令盖不住，或默认行为和场景相反 |

改命令只改 `ARCHITECTURE` / `PHASE` / `COMMANDS`。**不要改真实场景来迁就。**  
问法、门禁真源仍在 PHASE，本文只写这条场景敲什么。

实现时仍要写死的文案（不是设计缺口）：

1. **S5 / S18 / S20**：提示带上「线上 latest 是多少、你要发的是多少」。
2. **S13 / S19**：`--yes` 对不上必须打印来自 {x}、底是 {y}，指向 `version draft pull` 或 `--reuse-version`。
3. **S10 / S11**：`update-version --prepare` **不存在**。实现若还留这个旗，当未知参数失败。
4. **S12**：`draft pull` 盖之前打将丢掉的摘要（来源 / 文件 / 条数），TTY 与 `--yes` 都打。
5. **提交拦**：失败点名字段（文件 / 依赖 {id} / 可选配置 {key} / 版本号），不要只回「校验失败」。
