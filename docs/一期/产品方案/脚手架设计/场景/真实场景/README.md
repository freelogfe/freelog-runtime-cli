# 真实场景

写**人要干什么**。不写该敲哪条命令、不写旗标。

命令怎么走见 [场景实现](../场景实现/README.md)。

## 怎么读

每条都是「现状 / 人要 / 成功 / 失败」。成功、失败指**人能感知的结果**，不是某条 CLI 的退出码名字。

## 覆盖边界

本册覆盖一个**单资源**从登录、立项、建壳、首版、更新版本，到接入、信息维护、策略与上下架的完整旅程；也覆盖中断恢复、冲突、文件变化、权限和失败恢复。普通资源、CLI 模板创建的主题/插件，以及已有本地主题/插件工程均在范围内。

合集、前端库 / package 模板、资源自身的付费策略编辑、支付与网页端操作及多资源批量编排不属于本期单资源 CLI。依赖方可以选择对方的免费或付费启用策略并签约，但支付始终留给平台；其余超出范围的动作应明确停止或引导到平台，而不是伪造本地成功。

## 用户旅程覆盖表

这张表按人的起点而不是按命令分组；每一种起点都必须有且只有一个正常入口。

| 人的起点 | 正常结果 | 真实场景 | 命令路径见 |
|---|---|---|---|
| 空目录中的普通资源，尚未上线 | 选最终叶子、建壳、发 `1.0.0` | S1、S2、S7 | 01、06 |
| 已有普通文件工程，尚未上线 | 不覆盖工程，直接建壳、发首版 | S59 | 01 |
| 自己的普通资源壳未发行 | bind 后发首版 | S4、S60 | 01、07 |
| 已发行普通资源换机器或工程 | bind 后拉稿、发新号 | S9–S17、S50 | 02、07 |
| 空目录中从官方模板开始主题/插件 | 固定类型、模板缓存、构建目录 | S36、S41 | 05 |
| 已有主题/插件工程，尚未上线 | 不 init、不覆盖，记录目录后建壳 | S56 | 05 |
| 自己的主题/插件壳未发行 | bind 目录后发首版 | S57 | 05 |
| 已发行主题/插件换机器或工程 | bind 目录、拉稿、重新构建后发新号 | S42、S58 | 05 |
| 文件/目录、工作稿或线上版本发生变化 | 明确选择、恢复或停止，不猜测 | S12–S25、S26–S35、S38–S40、S48–S49 | 02–06 |
| 展示、策略、上下架 | 不混入版本流程 | S51–S55 | 07 |

新场景只往本夹加，不要为了现有命令去删。面向实际操作的命令示例同时维护在 [使用/按场景操作](../../../使用/09-按场景操作.md)。
