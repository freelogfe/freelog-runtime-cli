# 真实场景

写**人要干什么**。不写该敲哪条命令、不写旗标。

命令怎么走见 [场景实现](../场景实现/README.md)。

## 怎么读

每条都是「现状 / 人要 / 成功 / 失败」。成功、失败指**人能感知的结果**，不是某条 CLI 的退出码名字。
