# 06 - 账号、资源类型与本地状态

不提命令。这里描述人在开始、切换环境、立项和中断恢复时真正要保障的事。

对应实现：[场景实现/06](../场景实现/06-账号类型与本地状态.md)

---

## S43 第一次在一台机器和一个工程里开始

**现状**：人第一次使用 CLI，本机和工程都没有登录选择。  
**人要**：安全地登录当前账号，并在这个工程中继续使用；密码和 token 不应出现在工程、Git、终端历史或诊断输出。  
**成功**：后续需要账号的动作认出正确的人；工程只保留非秘密选择，秘密由操作系统保护。  
**失败**：密码被要求写进参数或文件；凭据库不可用时悄悄退回明文；登录失败却留下一个看似可用的账号。  

---

## S44 换账号、换环境，或凭据过期

**现状**：工程已经选择了账号 / 环境；人想换到另一账号或 dev、test、prod 的另一套平台，或者原凭据已失效。  
**人要**：明确知道正在用谁、为何不能继续，并安全切换；不能误把另一环境或父目录账号拿来写平台。  
**成功**：当前选择与本次环境一致；失效时保留未交工作稿并告诉人重新登录。  
**失败**：静默覆盖原选择、坏工作区选择器自动回退全局账号、认证失败后自动换号或重试写操作。  

---

## S45 普通资源立项：逐层找到正确类型

**现状**：人有一个空工程，知道资源大类但不一定知道最终资源类型 code。  
**人要**：从一级类别逐级往下选，直到最终叶子；能看见已经选过的路径并返回重选。  
**成功**：本地身份记下一个启用的最终叶子类型，尚未创建线上资源；父级永远不能被误当成最终类型。  
**失败**：必须预先背 code；选了父级也能继续；为了类型选择顺带创建线上壳。  

---

## S46 知道关键词或 code，想快速选类型

**现状**：人知道类型名称的一部分、或从别处拿到一个 code。  
**人要**：按名称 / code 搜索后从清晰结果中选择；也能直接输入精确 code。  
**成功**：搜索只返回可用叶子并展示完整路径；直接输入的 code 经在线验证后才写入工程。  
**失败**：名称模糊命中就自动定稿；停用、不存在、非叶子或非普通资源类型被接受。  

---

## S47 安全立项：取消、非空目录与模板下载失败

**现状**：人选择了目录和类型 / 模板，随后取消，或者目录已有内容、模板网络下载失败。  
**人要**：原来的目录不受损；失败后不会出现半个工程、半份身份或假成功。  
**成功**：只保留人原本存在的空目录；重新执行时可从头得到完整工程。  
**失败**：`--yes` 覆盖已有文件；目录检查与复制之间被并发写入；模板失败但留下可被误用的身份。  

---

## S48 版本工作中断、换文件或系统属性变化

**现状**：人已经留下一份未交稿；隔天继续，或换了文件，导致系统解析出的附加属性发生变化。  
**人要**：已填的兼容值继续保留；不再适用的值显式列出，让人决定后再提交。  
**成功**：工作稿能恢复；新文件重新解析；失效值不会静默丢失或进入提交体；脚本遇到待处理值会停止。  
**失败**：旧文件的属性值直接随新文件发出；本地稿损坏后被 CLI 猜测修复或覆盖。  

---

## S49 另一台机器、损坏旧稿或重绑后的恢复

**现状**：人从另一台机器继续、遇到旧版本工作稿，或把本地文件绑定到不同线上资源。  
**人要**：旧稿不被猜测改写；身份不一致、孤儿稿或重绑时不复用错误数据。  
**成功**：当前 v1 稿可在另一台机器继续（重新登录不改稿）；旧或损坏稿保留原文件并提示丢稿或从线上重新拉取；换绑清掉旧资源的工作稿与模板缓存。  
**失败**：自动迁移覆盖未交属性 / 依赖；只删身份却留下孤儿版本稿；不同资源之间沿用同一份稿。
