# 场景

单资源分为真实场景与场景实现两套，使用相同的 S 编号；合集是独立的 C-S 编号场景册，也按需求与实现分开。用户实际要敲的完整路径另见 [使用/按场景操作](../../使用/03-按场景操作.md)。

| 子夹 | 写什么 | 不写什么 |
|------|--------|----------|
| [真实场景/](./真实场景/README.md) | 人要用 CLI 干什么：现状 / 人要 / 成功 / 失败 | 命令名、旗标、实现细节 |
| [场景实现/](./场景实现/README.md) | 用**现行**设计命令把同一条场景走完 | 不要改真实场景来迁就命令 |
| [合集/](./合集/README.md) | 合集首次发行和发行后管理的独立场景 | 不和单资源版本发行混写 |

改 `ARCHITECTURE` / `PHASE` / `COMMANDS` 之前：先看真实场景还成不成立，再看场景实现还能不能走通。覆盖不了 = 设计缺口，改命令，不改真实场景。

当前独立单资源场景必须至少覆盖以下分流，缺任一项都不是完整体验。每个资源操作还必须覆盖零/一/多状态路由；`create` / `bind` 另覆盖新增状态与接续未绑定状态，不能只验证已有资源的选择：

| 资源形态 | 尚未上线 | 线上有壳、未发行 | 已发行后继续维护 |
|---|---|---|---|
| 普通单文件 | 已有真实文件后立项或直接建壳 | bind 文件后发首版 | bind / 拉稿 / 发新号 |
| 主题 / 插件模板工程 | `init theme/widget` 后建壳 | bind 构建目录后发首版 | bind / 拉稿 / 重新构建目录 / 发新号 |
| 已有主题 / 插件工程 | 显式固定类型 + 构建目录建壳 | bind 构建目录后发首版 | bind / 拉稿 / 重新构建目录 / 发新号 |

主题/插件与普通文件共享版本表单、依赖、属性、策略和管理场景；差异仅是固定类型、模板来源（如有）、目录记录和提交前临时压缩。本期不保存模板缓存。

参数化策略模板的取消、缺参、模板漂移和未知写入结果另见 [真实场景/09](./真实场景/09-参数化策略与异常.md) 与 [场景实现/09](./场景实现/09-参数化策略与异常.md)。

场景册记录应支持的体验，不是所有分支已经通过的声明。已知实现缺口在对应场景中标注；本轮未执行 dev 真实测试，不把文档对齐当作业务验收。
