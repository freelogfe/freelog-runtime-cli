---

## 已发版属性（M1）

看 / 改**已经发行的版本**，不能换文件。字段含义见 [06](./06-属性配置与依赖.md)。

```
freelog-cli version show --version <已发版>
freelog-cli version edit --version <已发版> --description "..." --yes
freelog-cli version edit --version <已发版> --sync-properties --yes
```

`--sync-properties`：GET 该已发版，按当次参数 / TTY 改 **value**，再 `PUT versions/{version}`。不读 `N.json`。本页不新建属性 key、不改可选配置结构。要换文件或改依赖树 → [M0](./02-M0-发行新版本.md)。

---

## 依赖补签（M4）

已发版**不增删**依赖。看树、补免费签：

```
freelog-cli dep list --tree
freelog-cli dep init-auth-map
freelog-cli dep auth --policy-map ./auth-map.yaml --yes
```

付费策略拒绝。授权合约列表不做。

## 只多这些

| 做什么 | 命令 | 不要做成 |
|--------|------|----------|
| 已发版改说明/属性 value | `version show` / `version edit` | `version set --file` |
| 无版本或要换文件 / 改依赖树 | [M0](./02-M0-发行新版本.md) | 再 `create`；已发版上改树 |
| 已发版补签（仅免费） | `dep auth --policy-map` | 付费 / 微前端 |
| 授权合约列表 | 不做 | 不要做签约管理 |

```
freelog-cli status
freelog-cli version show
freelog-cli version edit --version <已发版> --description "..." --yes
```
