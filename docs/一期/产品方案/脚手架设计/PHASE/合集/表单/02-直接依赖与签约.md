# 合集直接依赖：声明与网页授权分离

状态：2026-10-13 dev 无合约试验后定稿；本期 CLI 暂停签约，直接依赖无需合约即可编辑并发布。签约、支付由网页完成，不将声明成功等同消费授权。

## 1. 三种关系

| 关系 | 操作与存储 | 本期授权边界 |
|---|---|---|
| 合集直接依赖 | `collection dep` 写本地表单 dependencies，publish 提交完整快照 | 无合约可声明/发布，不查询或签约 |
| 单品上游授权 | `collection item add` 管理目录与独立授权排除映射 | 不自动签约；没有可验证的合同映射时提示先到网页处理 |
| 合集自身授权策略 | `collection policy` | 作者配置对外条款，不是与依赖签约，保持现有能力 |

单资源的依赖规则另见单资源版本表单。直接依赖不会自动加入目录，也不等于单品的上游授权。

## 2. 平台事实与命令

本次 4 个新主体 × 6 个目标及组合，共 28 次平台写入都成功。每项读回依赖准确、合同为 0，补充状态 0/1/2 扫描仍为 0。其中合集用 `updateCollection` 更新快照，未创建单资源版本。

```text
collection form pull --out collection-form.json
collection dep list
collection dep add <id:…|name:…> [--range <semver-range>]
collection dep range <id:…|name:…> --range <semver-range>
collection dep rm <resource-id>
collection publish [--include-items auto|yes|no] [--yes]
```

删除直接依赖的 `--policy`，不保留隐藏或失效签约参数；成功输出不再包含 `signed`。所有命令仍支持各自共享目标/环境参数。

## 3. 添加和改范围

1. 经 tools-lib 重读当前账号可维护的合集，核对环境、subjectType=4，拒冻结/RSS。
2. 目标必须是其他 subjectType=1、status=1、有可信已发布版本的单资源；当前合集壳自身下架仍可维护。无目标、未发布、冻结或下架目标拒写。
3. 范围须可由 semver 解析，并命中已发布版本；默认 `^latest`。
4. 本地必须有合集表单稿；完整候选依赖交给 `Resource.cycleDependencyCheck`，校验失败不写。
5. 原子更新同一目标的 `{resourceId,versionRange}`，不修改目录草稿、不查合同或策略、不签约、不付款。

本人/他人、免费/付费/等待免费、已有/无合约都使用同一声明校验，不增加授权状态 gate。提示“仅声明依赖，CLI 未签约或支付；需要授权到网页以当前合集身份处理”。

## 4. 发布

`publish` 提交最终完整表单 dependencies；本地稿、手改 JSON、pull 稿、以及仅合并目录沿用的线上表单均不要求合约存在，不请求合同或 batchAuth，不隐式签约。

保留完整快照与属性/配置验证、目录全量比较、类型/冻结/RSS、基线冲突、自动收录并发、精确授权排除映射、intent 与读回恢复门禁。没有直接依赖合约和无法恢复既有排除映射是两个问题，不能因此用空数组覆盖已有 `authExcludedItems`。

`updateCollection` 不含 `batchSignContracts`；未知写入仍只读诊断，不自动重发。本命令不隐式上架，也不保证依赖可消费。

## 5. 网页与单品边界

需要签约时乙方为当前合集 ID、身份类型 4，标的单资源主体类型 1；不是登录用户个人。CLI 不查询依赖授权状态，网页实际状态和运行时授权结果才是依据。

单品上游的 `authExcludedItems` 需要真实 contractId 映射，不能拿策略 ID 冒充，也不能基于本次直接依赖实验猜测空映射合法。关闭单品自动签约后：已有有效合集合同可以只读恢复映射；缺失时停止目录写入并提示网页处理，不生成空映射强行继续。

删除直接依赖不解约、不退款。不读取、导入或保存 Console 草稿；网页对已发布事实的修改仍受原有 pull/发布基线保护。

## 6. 验收

- add/range/直接依赖 publish 不调用合约查询、签约或 batchAuth；无合同、无启用策略仍可声明。
- 请求保留完整 ID/范围，版本/快照读回一致，前后双方合同为 0；不传签约字段。
- 单资源/合集身份、类型、版本范围、循环及其它原有门禁不删除。
- 单品上游只读合同采用当前合集身份 4，缺合同给网页提示，绝不签约或猜造 contractId。
- 删除旧签约选项，帮助与使用教程明确声明不等于授权；作者配置合集自身策略继续正常使用。
