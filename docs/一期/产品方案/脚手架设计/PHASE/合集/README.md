# 合集（部分实现，首次发行与管理继续推进）

合集是 `subjectType=4` 的独立授权主体。它引用线上、当前账号、已上架的单资源作为单品；不上传本地文件，不创建单资源版本，也不把单品当作合集依赖。

## 先这样审阅

不要把本目录当成 Console 四步页面的逐项翻写。先确认下列产品判断是否合理；若其中任一项不同意，再进入对应页面修改细节。

1. **主体与入口**：合集先创建一个不可变身份壳；所有后续能力都能独立从已有线上合集进入，不要求本地 bind。
2. **草稿隔离**：目录草稿是合集的服务端事实；表单操作草稿只保存在 CLI 本地。CLI 不读取、导入或保存 Console 的服务端版本草稿；listing/收录规则/策略/上下架也各有独立写入。
3. **发布边界**：`collection publish` 是唯一合并表单与（可选）目录草稿的提交；它不隐式上架。
4. **授权边界**：单品上游授权、合集直接依赖和合集自身策略是三件不同的事，不能因为都涉及“策略”而共用字段。
5. **安全恢复**：任何未知远端写入都只能读回核验，不能按标题、缓存或 HTTP 成功码猜测后重发。

建议审阅顺序：先读[创建总览](./创建/00-总览.md)理解用户旅程，再读“添加单品 → 表单/依赖 → 发布 → 策略与上架”；自动收录和单品编辑是目录管理的专项规则。

本目录按首次发行和后续管理逐步定稿。已确认的文档可以作为后续实现依据；没有文档的步骤仍在讨论，不能从 archive、旧 CLI 示例或 Console 注释推断。

在新增合集代码、自动化测试或 dev 写入前，必须按[功能拓扑与证据驱动测试门禁](./测试/00-功能拓扑与证据驱动测试门禁.md)逐项关闭契约缺口；未关闭项只能标记 `BLOCKED`，不能通过猜测实现绕过。

## 当前进度

### 所有已有合集命令的共同定位规则

2026-10-19用户确认：显式 `--resource id:<id>`、`name:<username/name>` 或 `file:N.json` 优先；裸ID/完整授权标识也是稳定选择器，不接受标题、短名称或产物路径。

省略时，恰一份本地合集身份自动使用；零份或多份时，交互终端从当前账号的线上合集分页选择（每页100条，可前后翻页或取消，包括未bind的合集），非交互必须明确 `--resource`。`--yes` 不代替身份选择。选择本身不自动bind、不创建身份或表单稿。列表空时明确提示；列表请求失败或结构不完整时停止，不将错误当空列表。

本地身份缺省env视为prod；选中的本地身份必须属于当前环境，否则在资源请求前拒绝。重复ID或完整标识的本地合集身份必须报冲突，不能选第一份。每次最终选定后重新读取详情，要求数值 `ret:0/errCode:0` 的对象响应、精确ID（name选择要求精确完整标识）、数值userId属于当前账号、subjectType为4或包含数值4的数组、明确的resourceTypeCode及合法状态0/1/2/4。详情不能用ownerId/creatorId猜所有者，不能用展示路径resourceType补机器码。已有本地身份的ID、完整标识和类型不得与详情冲突；标题允许不同。

一次命令只选择一次；后续读取、子步骤、提交和故障读回都锁定首次resourceId，不能重新选择或因本地文件变化改目标。冻结及RSS的各写门禁仍独立执行，`--yes`不能绕过。分页列表仅作选择候选，不替代最终详情核验，也不构成版本管理缓存。

选择交互输出到stderr，不能污染`--json`的stdout；这不改变各命令既有成功输出协议。

Console 的四步是首次发行的**教程建议顺序**，不是 CLI 的强制事务或单一命令。创建壳之后，每项能力均可独立、重复执行；CLI 可以在命令成功后展示下一步建议，但不能自动替用户执行。

```text
collection create
  ├─ collection item add：添加线上本人已上架单资源
  ├─ collection update / collection collect-rules：合集信息与更新状态
  ├─ collection form / collection dep：编辑待发布表单
  ├─ collection policy：管理合集自身策略
  ├─ collection publish：合并目录与表单变更
  └─ collection online / offline：独立上下架
```

`collection create` 只创建合集壳，不隐式添加单品、策略、属性、依赖、发布目录或上架。策略模板主链已实现并有 dev 非交互读回证据；后端未来的主体/类型筛选契约、真实 TTY 与 datetime 样本仍要单独补证，不能将这些剩余项说成“策略命令尚未实现”。

合集身份已和单资源身份共存于同一个 `.freelog/`：`subject:'collection'` 不含 `filePath`，单资源解析器仍只接收 `subject:'resource'`。合集命令使用独立的目标解析器，不把单资源产物选择器当合集身份。
