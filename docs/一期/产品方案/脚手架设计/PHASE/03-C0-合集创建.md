# 03 - C0 合集创建

合集是**已上架普通资源的目录**，不上传视频。  
主路径：建壳 → `item add`（只写目录草稿）→ `collection publish`。  
策略 / listing / 上架见 [共用管理](../ARCHITECTURE/05-共用管理.md)。再改目录见 [合集维护](./05-合集维护.md)。本地与接续见 [02](../ARCHITECTURE/02-本地状态.md)。

---

## 1. 单品先发成资源

加进合集之前必须是**自己的、已上架**普通资源。发行走 F0，不是 `item add` 代做。

```
create --file 09-01.mp4 → publish → policy → online
# create / status 给出 resourceId、username/name
collection item add <resourceId|username/name>
```

`item add` 只认 id 或标识，**不认**本地路径。主路径不签约（无上抛则直接写入草稿）。

---

## 2. 命令串

```
freelog-cli login
freelog-cli collection create --type <code> --title "..." --name <short> --yes
freelog-cli collection item add <resourceId|username/name>
freelog-cli collection publish --yes
```

`init --scaffold collection` 可省。`collection create` 先查同名；自己的壳且目录从未提交则接续，不要再 create。

| Console | CLI |
|---------|-----|
| Step1 `subjectType=4` | `collection create` |
| Step2 勾选已上架资源 | `item add <resourceId\|username/name>` |
| 提交目录 | `collection publish`（`PUT catalogue`，不是 `createVersion`） |
| Step3 / Step4 | 共用管理，不接续 |

---

## 3. `item add`

`POST .../catalogues/drafts/{合集id}/items`，`isPublish=0`。须：本人、`subjectType=1`、有版本、有启用策略、已上架、不在草稿里。每批 ≤100。

合集身份：本夹唯一 `subject=collection`（index `.`）。`status` 无 `--file` 时列草稿 `itemId`。

---

## 4. `collection publish`

允许空目录。有改动则 `isMergeCatalogueDraft=1`。  
有壳、从未提交过目录 → 接续；已有 `latestVersion` → 结束创建。合集没有 M0。
