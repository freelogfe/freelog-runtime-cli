# 创建总览

CLI **一条命令做一件事**，不串成一条 `publish`。对照只用来对业务（Console 发行四步叫什么）。  
真源是各命令正文。本文只串**创建**（还没有版本）。已有版本要发新号：走 [更新版本](../更新版本/01-更新版本.md) 的 `update-version`，不要读本文的 Step2。

| 命令 | 做什么 | 文档 |
|------|--------|------|
| `create` | 建**新**壳。本地/线上已有壳（含还没发行）不要再 POST，见 [01 §0](./01-Step1-创建授权条目.md) | [01](./01-Step1-创建授权条目.md) |
| `create-version`（无 `latestVersion`） | 上传、空表改属性/配置/依赖、POST `1.0.0` | [02 发行版本](./02-Step2-发行版本.md)；菜单问法 [版本表单](../版本表单/README.md) |
| `policy template apply` | 加一条免费策略，可跳过 | [03](./03-Step3-添加授权策略.md) |
| `update` | 改标题/封面/简介/标签，可跳过；不上架 | [04](./04-Step4-完善资源信息.md) |
| `online` | 上架 | [管理/05](../管理/05-上下架.md) |

```
freelog-cli login
freelog-cli init <dir> --scaffold runtime|package|none ...   # 可省
freelog-cli create
freelog-cli create-version
freelog-cli policy template apply <templateId>              # 可跳过
freelog-cli update --cover --intro --tags                   # 可跳过
freelog-cli online
```

只有「有壳、无 `latestVersion`」接续 `create-version`（本文 Step2）。不用 `publish`。禁止 `update --status`。不做 F1 / RSS。合集暂缓。
