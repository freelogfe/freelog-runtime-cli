# 依赖及其授权

对照业务：Console 侧栏「依赖及其授权」（P0-M4）。全量事实见 [P0-D](../../../../业务梳理/依赖与签约/P0-D-依赖管理与签约.md)。

**CLI 不做独立的依赖授权管理命令。** 依赖声明只通过 `version dep` 编辑工作稿，随首版 / 更新版发行，见 [05](../../../ARCHITECTURE/05-版本工作稿与独立命令.md)、[版本表单/依赖](../版本表单/03-依赖.md)。签约与支付到网页按当前源资源身份处理，不是用户个人。

| 要做什么 | CLI |
|----------|-----|
| 看线上已发号的依赖 | `version show`（[版本信息](./01-版本信息.md)） |
| 看工作稿依赖 | `version show --local` / `version dep list` |
| 加 / 改范围 / 删声明（不分免费付费） | 首版：`create-version --prepare`。已有版本：先 `version draft pull`，再 `version dep *`，最后 `update-version`；不查询合同、不签约或支付 |
| 已发版改树 | 必须走 [更新版本](../更新版本/01-更新版本.md)，不能对着已发号改 |
| 已发版只补签、不发新号 | 到网页当前资源的「依赖及其授权」处理；不需要为签约而创建 CLI 更新稿或发行新号 |
| 授权合约列表 | **不做** |

没有 `dep`、`dep list`、`dep auth`、`dep init-auth-map`、顶层 `dep add`。
