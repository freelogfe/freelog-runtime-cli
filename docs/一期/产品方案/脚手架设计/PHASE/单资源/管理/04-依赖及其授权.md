# 依赖及其授权

对照业务：Console 侧栏「依赖及其授权」（P0-M4）。全量事实见 [P0-D](../../../../业务梳理/依赖与签约/P0-D-依赖管理与签约.md)。

**CLI 不做这组独立命令。** 依赖只在发行版本 / 更新版本时管理（会话菜单或 `version dep`），见 [05](../../../ARCHITECTURE/05-版本工作稿与独立命令.md)、[版本表单/依赖](../版本表单/03-依赖.md)。

| 要做什么 | CLI |
|----------|-----|
| 看线上已发号的依赖 | `version show`（[版本信息](./01-版本信息.md)） |
| 看工作稿依赖 | `version show --local` / `version dep list` |
| 加 / 改范围 / 删 / 当场免费签 | 首版：`create-version --prepare` 或会话。已有版本：先 `version draft pull`，再会话或 `version dep *`，最后 `update-version` |
| 已发版改树 | 必须走 [更新版本](../更新版本/01-更新版本.md)，不能对着已发号改 |
| 已发版只补签、不发新号 | **本期不做**。Console 侧栏可以。CLI 要签就进更新版本工作稿（先 §1.5 查，没有再 §1.6 签），合约挂在本资源上 |
| 授权合约列表 | **不做** |

没有 `dep`、`dep list`、`dep auth`、`dep init-auth-map`、顶层 `dep add`。
