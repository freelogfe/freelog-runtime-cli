# 资源信息

对照业务：Console「资源信息」（P0-M2）。终端里是一条 `update`。只改 listing，**不上架**。不传 `status`。标识只读。

本命令功能：

| # | 功能 | 何时 |
|---|------|------|
| 1 | 打印当前 listing（含只读标识） | `update` 启动后先打 |
| 2 | 改标题 | `update --title` 或 TTY |
| 3 | 改封面 | `update --cover` 或 TTY |
| 4 | 改简介 | `update --intro` 或 TTY |
| 5 | 改标签 | `update --tags` 或 TTY |
| 6 | 确认写入 | 有变更才 PUT |

```
freelog-cli update
freelog-cli update --title --intro --cover --tags
```

须已 `login`，已有 `resourceId`。本人、未冻结。  
已传的 flag 不问。一个 flag 都没传且是 TTY：按 2–5 逐项问，每项都可以回车跳过。  
`--yes` 且什么 flag 都没有：失败，不要空 PUT。`--yes` 只改传入的字段。

与创建 Step4 同一条 `update`。本文按维护写全，不要只写「同 Step4」。

---

## 0. 门禁

`Resource.info`（`GET /v2/resources/{id}`）。非本人 / 冻结失败。RSS 本期不做；若 `info` 表明禁改 listing，失败并说明。

---

## 1. 看当前 listing

先打印，再决定问不问：

- 标识：`username/name`。打一行「一旦创建不能改」。TTY 能复制到剪贴板就复制，做不到只打印。不要做成 `create --name`。
- 标题
- 是否已有封面（有则「已有封面」，不要打 URL 当可改字段）
- 简介字数（空：「无简介」）
- 标签列表（空：「无标签」）

帮助：

> 完善资源的相关信息，可以提升资源曝光度；您也可以稍后完善。

本项只读。无独立 API。

---

## 2. 改标题

帮助：标题直接影响搜索曝光，不超过 100 个字符。

已传 `--title`：只校验，不问。未传且 TTY：问「标题」，默认 = 线上当前标题。直接回车 = 不改。

| 输入 | 行为 |
|------|------|
| 回车且未传 `--title` | 本字段不进请求 |
| 空串且用户显式要清空 | 不让过：「请输入资源标题」 |
| 超过 100 | 「不超过100个字符」，TTY 重新问；`--yes` 失败 |
| 1–100 | 请求带 `resourceTitle` |

本项无独立 API。

---

## 3. 改封面

帮助：

> 封面  
> 图片是作品对外展示的窗口。只支持 JPG/PNG/GIF，GIF 不能动画，大小不超过 5M，建议宽高不小于 800px。

已有封面时先说：「回车保留现有；给新路径则替换」。

| 进入 | 行为 |
|------|------|
| `--cover <本地路径>` | 校验格式与大小后上传 |
| TTY 未传 | 问「封面图片路径（可空）」；空 = 不改 |
| 用户要去掉封面 | 本期不做「清空封面」（平台 `coverImages: []` 未证实用，不要猜） |

本地文件：

| 检查 | 失败 |
|------|------|
| 不是 JPG/PNG/静态 GIF | 失败 |
| 动画 GIF | 失败 |
| > 5MB | 失败 |

通过后：`Storage.uploadImage`（`POST /v2/storages/files/uploadImage`）。用返回 URL。请求里 `coverImages: [url]`。不改则不传该字段。

---

## 4. 改简介

帮助：为作品添加明确实用的描述，方便其他用户找到。最多 200 字。

问「简介」，可空。默认展示当前简介。回车 = 不改。

| 输入 | 行为 |
|------|------|
| 回车 / 不传 `--intro` | 不改 |
| `--intro` 或问完有内容 | `trim` 后 ≤200 才带 `intro` |
| >200 | 「简介不超过 200 个字符」，TTY 重新问；`--yes` 失败 |

本项无独立 API。

---

## 5. 改标签

问「标签（逗号分隔，可空）」。已有标签时默认展示当前列表；回车不改；要改就输入**完整新列表**（本期不做「单个增删」命令）。

| 约束 | |
|------|--|
| 最多 20 个 | 超过失败 |
| 每个 ≤20 字 | 超过失败 |
| 单个空（`a,,b`） | 失败 |

`--tags ""` 且用户显式要清空：`tags: []`。回车不改。

可选：`Resource.availableTags`（`GET /v2/resources/tags/availableTags`，`resourceTypeCode`）打几条推荐，只作提示，不自动写入。失败则跳过推荐，不要挡主流程。

---

## 6. 确认写入

TTY 摘要将要改的字段。什么都没改：打印「没有变更」退出，不 PUT。  
有变更：确认后 `Resource.update`（`PUT /v2/resources/{resourceId}`），**只带改了的字段**：`resourceTitle` / `intro` / `tags` / `coverImages`。

**不带 `status`。** 不要在这里上架。

失败：平台 `msg`。成功：再 `info` 打一行当前 listing。提示上架用 `online`。

| 门禁 / 回拉 | `Resource.info` | `GET /v2/resources/{id}` |

## 禁止

`update --status`。`pull` 回写 listing。把版本属性写进本命令。未改也空 PUT。封面传非图片。
