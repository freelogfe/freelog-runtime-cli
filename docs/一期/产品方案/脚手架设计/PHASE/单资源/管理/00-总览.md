# 管理总览

须已有本地身份（`N.json.resourceId` 或先 [bind](../../../ARCHITECTURE/04-bind.md)）。非本人、冻结不写。  
这些命令创建之后随时能跑，**不接续**。真源是各命令正文。

对照只用来对业务（Console 侧栏叫什么）；终端里没有页、没有侧栏。

换文件 / 改属性 / 改可选配置 / 改依赖树：先 `version draft pull` 再改稿，最后 `update-version` 提交。不要做成管理命令里的一项菜单，也不要去读创建 Step2。

| 命令 | 做什么 | 文档 |
|------|--------|------|
| `version show` / `version show --local` / `version description` | 看线上已发号 / 看本地工作稿 / 只改线上描述 | [01 版本信息](./01-版本信息.md) |
| `version draft pull` / `discard` | 拉 / 盖 / 丢掉工作稿，不 POST | [05](../../../ARCHITECTURE/05-版本工作稿与独立命令.md) |
| `update-version` | 定新号 + 提交 | [更新版本](../更新版本/01-更新版本.md) |
| `update` | 看/改标题、封面、简介、标签；标识只读 | [02 资源信息](./02-资源信息.md) |
| `policy list` / `template apply` / `set` | 看列表、加免费策略、启用、停用 | [03 授权策略](./03-授权策略.md) |
| （无 `dep` 命令） | 已发版依赖只看：`version show`。改 / 签走更新版本 | [04 依赖及其授权](./04-依赖及其授权.md) |
| `validate --for online` / `online` / `offline` | 预检、上架、下架 | [05 上下架](./05-上下架.md) |
| 授权合约 | **不做** | — |
