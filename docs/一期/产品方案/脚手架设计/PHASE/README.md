## 💡 **四、文档写作规范**

### **4.1 每个文档必须是完整的产品设计规格**

包含以下内容，无需参考其他文档:

1. **ASCII Diagram 流程图**: 清楚表达步骤流转
2. **字段约束表**: 约束规则 + 提示文案 + 错误码 + 处理方式
3. **数据结构 Interface**: TypeScript 类型定义 (Request/Response)
4. **算法逻辑步骤**: if-then-else 样式的伪代码描述 (**不是真代码!**)
5. **异常分支矩阵**: 所有可能的错误及处理策略

### **4.2 禁止出现伪代码黑盒调用**

❌ **错误的写法**:
```typescript
executeStep('uploadFiles');
importBusinessStep();
callPolicyModule();
// 开发者不知道这些函数的具体实现！
```

✅ **正确的写法** (纯产品设计):
```typescript
uploadWithChunkStrategy(file):
  IF file.size <= 10MB THEN
    response = POST /v2/storages/uploadSingle({ filePath })
  ELSE IF file.size > 10MB THEN
    chunks = splitFileIntoChunks(file, chunkSize=5*1024*1024)
    FOR EACH chunk in chunks DO
      uploadResponse = POST /v2/storages/uploadChunk({ chunkData })
    END FOR
    mergeResponse = POST /v2/storages/mergeChunks({ chunkIds[] })
  END IF
  RETURN response.fileId
```
