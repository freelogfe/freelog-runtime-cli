# REUSE - 通用模块库设计层

> **版本**: v1.0 | **最后更新**: 2026-09-03  
> **用途**: 定义 PHASE 可复用的通用能力模块，提供统一的接口契约

---

## 🎯 **模块分层架构**

```
┌──────────────────────────────────────┐
│   PHASE (业务编排层)                  │
│   ─────────────────                  │
│   F0: 单资源发布                      │
│   M0: 版本更新                        │
│   C0: 合集创建                        │
│   H0: 批量发布                        │
└──────────────────────────────────────┘
           ↓ 依赖
┌──────────────────────────────────────┐
│   REUSE LIBS (通用模块层)             │
│   ──────────────                      │
│   G2-UPLOAD   : 文件上传服务           │
│   G3-CHECKPOINT : 断点续传基础         │
│   POLICY      : 策略模板编译系统       │
│   ... (其他通用能力)                   │
└──────────────────────────────────────┘
```

## 📋 **通用模块清单**

### **G2 - File Upload Service（文件上传服务）**

| 属性 | 说明 |
|------|------|
| **定位** | 为 PHASE 提供统一的文件上传抽象，屏蔽单片/分片模式差异 |
| **职责** | 压缩检测 → 模式选择 → 上传执行 → 进度汇报 |
| **复用方** | F0-Step2, M0-Step3, C0-Step4 等 |
| **输出形式** | `{fileId, fileUrl, sha1, size}` |

**核心能力**:
- 自动检测文件大小并选择单片/分片模式
- 断点续传机制（基于 G3-CHECKPOINT）
- TTY 进度条展示 / NDJSON 事件流
- 网络异常自动重试

---

### **G3 - Checkpoint Service（断点续传基础）**

| 属性 | 说明 |
|------|------|
| **定位** | 提供通用的断点保存/恢复能力，不绑定具体业务场景 |
| **职责** | 持久化上传位置、校验和、时间戳 |
| **复用方** | G2-UPLOAD, H0-BatchPublish |
| **存储形式** | 内存（会话模式）或 `.freelog/checkpoints/`（工程模式） |

**核心能力**:
- `saveCheckpoint(step, data)` - 保存当前状态
- `restoreCheckpoint(step)` - 恢复到上次断点
- `clearCheckpoint(step)` - 清理已完成阶段的断点

---

### **POLICY - Strategy Template System（策略模板编译系统）**

| 属性 | 说明 |
|------|------|
| **定位** | 将用户友好的策略参数编译为平台可用的 policyText |
| **职责** | 模板查询 → 参数填充 → URL 编码 → 重复检测 |
| **复用方** | F0-Step3, M0-Step4 等 |
| **输出形式** | `{policyId, policyName, policyText}` |

**核心能力**:
- 按资源类型查询免费/付费策略模板列表
- 交互式引导用户填写参数（如授权范围、期限）
- 自动生成符合 RFC 3986 的 URL 编码正文
- 检查是否已存在相同正文的策略（避免重复创建）

## 📝 **通用模块设计原则**

### **1. 禁止跨层依赖**
- ❌ G2 不能直接调用 PHASE 的逻辑
- ❌ POLICY 不能假设调用方是 F0 还是 M0
- ✅ 所有输入输出必须通过明确的接口契约

### **2. 错误码标准化**
每个模块的错误码独立命名空间：
- **G2-20x**: 文件上传相关错误
- **G3-30x**: 断点续传相关错误  
- **POLICY-40x**: 策略模板相关错误

### **3. TTY 与 Non-TTY 分离**
- TTY 模式：显示进度条、ASCII Diagram、彩色输出
- Non-TTY 模式：只输出 NDJSON 事件流 + 最终结果
