# 05 · 场景、异常与验收方案

> **文档角色：** 场景、异常和验收方案。本文用真实使用场景反推产品是否完整，每个场景都必须能从需求走到字段、接口、异常和验收。

最后更新：2026-09-02

## 1. 主场景矩阵

| 场景 | 入口 | 必走流程 | 必验收 |
|---|---|---|---|
| L01 独立模板创建 | `create theme/plugin` | 模板分类 → 技术模板 → 目标目录 → 冲突检查 → 写本地工程 → 下一步提示 | 不写平台；工程可运行；模板来源和版本可追溯 |
| L02 独立压缩打包 | `pack dir` | 扫描 → ignore/强制排除 → 文件摘要 → 确认输出 → 生成 artifact → 输出 sha1 | 不上传、不写平台；压缩包可复用；文件清单可审查 |
| S01 普通单文件首次发布 | `publish file` | 登录 → 类型 → 资源壳 → 上传 → 版本 → 策略 → listing → 上架选择 | 资源存在，版本为 `1.0.0`，字段符合 Console 约束 |
| S02 工程首次发布 | `publish dir` | 类型选择 → 内容来源选择 → 识别模板/manifest → 构建 → 压缩 → 产物确认 → 单资源发布 | 产物可追溯，上传失败可重试 |
| S03 主题资源发布 | `publish --kind theme` | 类型树选择主题类型 → 选择模板/现有工程/构建目录/artifact → 构建压缩 → 资源发布 → Console 激活接力 | 资源发行完成，输出节点激活信息 |
| S04 插件资源发布 | `publish --kind plugin` | 类型树选择插件类型 → 选择模板/现有工程/构建目录/artifact → 构建压缩 → 资源发布 → 依赖/签约提示 | 插件资源可在平台查到 |
| S05 已有资源新版本 | `update --new-version` | 读远端 → 继承 → 上传新产物 → semver 校验 → 创建版本 | 新版本大于最新版本，不覆盖旧版本 |
| S06 listing 维护 | `update --listing` | 读现值 → 编辑封面/简介/标签 → diff → 保存 | 只提交改动字段，RSS 锁定字段不可写 |
| S07 策略维护 | `update --policy` | 拉模板 → 选模板 → 填参 → 编译 → 翻译 → 保存 | 不默认手写策略，重复可识别 |
| S08 合集创建 | `collection create` | 类型 → 资源壳 → 条目 → 排序 → 策略 → listing | 条目顺序确定，条目标题不改资源标题 |
| S09 RSS 绑定 | `rss bind` | feed 预览 → 验证码 → 数量限制 → 绑定 | 超 1000 必筛选，验证码错误可继续 |
| S10 RSS 地址更新 | `rss update` | 新 feed 预览 → GUID 比较 → 确认 → 绑定 | 大面积 GUID 不匹配必须阻断确认 |
| S11 collect-rules | `rules edit` | 启用状态 → 条件关系 → 条件构造 → 摘要 → 保存 | 字段/操作符/值联动正确 |
| S12 批量发布 | `batch publish` | 扫描 → 规则 → 预览 → 分批 → 逐项报告 → resume | 单项失败不影响成功项 |
| S13 只管理线上状态 | `update --online/offline` | 读资源 → 展示状态 → 二次确认 → 写入 | 上下架有明确线上影响提示 |
| S14 AI/CI 自动发布 | manifest/stdin | validate → plan → dry-run → write → JSON/NDJSON | 无 TTY 不提问，错误可解析 |

## 2. 字段异常

| 字段 | 异常 | 处理 |
|---|---|---|
| 资源标题 | 空、超过 100 字符 | 停在标题；显示当前长度和上限 |
| 授权标识 | 空、超过 60、非法字符、重复 | 展示规范化结果；重复时要求改名或选择更新 |
| 资源类型 | 搜索无结果、选到非叶子、类型不支持批量 | 返回类型树；展示实际支持能力 |
| 模板 | 模板不存在、模板版本不可用、目标目录非空且冲突 | 停在模板/目录选择；展示可选模板和冲突文件；默认不覆盖 |
| 压缩 | 目录为空、全部被忽略、包含不可读文件、输出路径冲突 | 停在压缩阶段；展示包含/忽略/拒绝摘要；不上传 |
| 文件 | 不存在、不可读、超类型大小、上传失败 | 不进入版本发布；保留本地路径和错误 |
| 版本号 | 非 semver、小于等于最新版本 | 返回版本号；给出推荐 patch/minor/major |
| 版本范围 | 非 semver range、未命中依赖版本 | 返回该依赖；列出可用版本 |
| 策略参数 | 缺必填、类型错误、编译失败 | 返回参数字段；不保存策略 |
| 封面 | 非 JPEG/PNG/GIF、超过 5MB、上传失败 | 返回封面字段；可改 URL 或换文件 |
| 简介 | 超过 200 字符 | 返回简介字段；给摘要建议但不自动覆盖 |
| 标签 | 超 20 个、单个超 20、重复 | 去 `#`，重复提示，超限停止 |
| RSS feed | 不可访问、无邮箱、已绑定、格式错误 | 停在 feed；展示平台返回原因 |
| RSS 验证码 | 错误或过期 | 只清验证码，保留 feed 和预览 |
| collect-rules 条件值 | 空、类型 code 过期、owner 不一致 | 返回该条件 |

## 3. 流程异常

| 异常 | 发生位置 | 恢复规则 |
|---|---|---|
| 用户取消 | 任意确认页 | 保存本地 checkpoint，标记 `cancelled_by_user` |
| 模板写入中断 | 独立模板或发布内模板创建 | 已写文件保留；报告写明哪些文件已创建；重跑前展示冲突，不自动覆盖 |
| 压缩完成但发布取消 | 发布流程内压缩后 | 保留 artifact 路径和 sha1；用户可复用 artifact 或清理 |
| 网络失败 | 上传、预览、写入 | 保留当前步骤，允许 retry；写入未知则先查远端 |
| 远端写入成功但本地进程中断 | 任意 L3/L4 写入后 | resume 时先根据远端 ID/name/version/sha1 查状态 |
| 远端返回字段错误 | 创建/更新接口 | 映射到字段 ID，展示原平台消息 |
| 账号过期 | 任意平台接口 | 暂停流程，重新登录后继续，不丢草稿 |
| owner 不一致 | 加载已有资源后 | 停止写入，除非用户显式切换账号或选择有权限账号 |
| 批量部分失败 | 批量写入 | 成功项不回滚；失败项可修复后 resume |
| Console 接力 | 支付、签约、节点激活 | 输出接力链接和携带信息；CLI 状态为 `handoff_required` |

## 4. 手测验收清单

手测前必须能完成以下检查：

1. 未登录时，所有写命令都有明确登录提示。
2. 多账号时，不会默认猜账号写入。
3. 资源类型可以逐级浏览，也可以搜索。
4. 策略流程默认从模板开始。
5. 独立创建 React 主题模板工程时，只写本地文件，不写平台。
6. 独立压缩目录时，输出 artifact 路径、大小、sha1 和文件清单，不上传。
7. 选择主题/插件资源类型后，可以选择模板创建、现有工程、构建目录或已有 artifact。
8. 单资源首次发布可以一次会话完成。
9. 已有资源新版本不会覆盖旧版本。
10. listing 维护显示 diff，RSS 锁定字段不可写。
11. 合集条目标题明确是合集内标题。
12. RSS 超过 1000 单集必须进入日期筛选。
13. collect-rules 保存前有人类可读摘要。
14. 批量发布有逐项结果和 resume。
15. 主题/插件资源类型可进入发行流程。
16. 需要支付/签约/节点激活时输出 Console 接力信息。
17. 非交互模式不问问题，缺字段输出结构化错误。

## 5. 开发验收清单

| 验收项 | 标准 |
|---|---|
| 字段覆盖 | 02 中每个字段 ID 都有校验、提示、错误 code 和测试 |
| 流程覆盖 | 04 中每个流程都有状态机或步骤实现 |
| 本地准备覆盖 | 模板创建、构建、独立压缩、发布内压缩都有独立状态、输出和测试 |
| 接口覆盖 | 02 中每个写接口都有 adapter 和失败映射 |
| 输出覆盖 | 人类输出、JSON、NDJSON、report 都覆盖 |
| 恢复覆盖 | 至少覆盖上传成功发布失败、写入未知、批量部分失败 |
| 安全覆盖 | 文档、测试、日志不出现账号密码、token、cookie、authorization 值 |
| Console 对齐 | Console 修改字段约束时，先更新 02，再改实现和测试 |

## 6. 方案完整性回归

每次改方案或代码，必须回答：

- 是否新增了产品方案没有定义的字段？
- 是否新增了产品方案没有定义的写入步骤？
- 是否有 CLI 错误只能看代码才知道？
- 是否有 Console 已确认规则没有写到 02？
- 是否有 CLI 特有体验只在实现里体现、文档没有说明？

任一答案为“是”，方案不能算完成。
