**业务规则**:
1. **Feed URL 验证**:检查格式有效性
2. **验证码处理**:如需验证码则显示并让用户输入
3. **GUID 差异检测**:提示新旧 GUID 变化
4. **数量限制**:单次同步不超过 50 集
5. **锁定字段**:guid/pubDate/enclosure.url等不可修改

## 🔍 **二、Console 源码证据**

### **2.1 RSS 绑定核心逻辑**

```typescript
// packages/console/src/pages/collection/creator/Step4/index.tsx
class RSSBindingFlow {
  async bind(feedUrl: string): Promise<RSSBindingResult> {
    // 1. Feed URL 验证
    const urlValidation = await validateFeedUrl(feedUrl);
    if (!urlValidation.valid) {
      throw new Error(`无效的 Feed URL:${urlValidation.reason}`);
    }
    
    // 2. 检测是否需要验证码
    const captchaRequired = await checkCaptchaRequired(feedUrl);
    if (captchaRequired) {
      const captchaResponse = await promptCaptcha();
      if (!await verifyCaptcha(feedUrl, captchaResponse)) {
        throw new Error('验证码错误');
      }
    }
    
    // 3. 获取 feed 元数据
    const feedMetadata = await fetchFeedMetadata(feedUrl);
    
    // 4. GUID 差异检查
    const existingGuids = await getExistingCollectionGuids();
    const newGuidsInFeed = await extractNewGuidsFromFeed(feedUrl);
    const diff = computeGuidDiff(existingGuids, newGuidsInFeed);
    
    if (diff.mismatchCount > 0) {
      warn(`检测到 ${diff.mismatchCount} 个 GUID 不匹配`);
    }
    
    // 5. 锁定字段定义
    const lockedFields: LockableField[] = ['guid', 'pubDate', 'enclosure.url'];
    
    return {
      feedUrl,
      feedTitle: feedMetadata.title,
      episodeCount: newGuidsInFeed.length,
      lockedFields,
      warnings: diff.mismatchCount > 0 ? ['GUID_MISMATCH_DETECTED'] : []
    };
  }
}
```

**CLI 说明**:暂不支持复杂的 RSS 绑定和验证码处理，仅实现基础收录规则配置。

## 🚨 **三、异常分支**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|--------|---------|---------|----------|
| INVALID_FEED_URL | RSS URL 无效 | "无效的 Feed URL" | 检查 URL 格式 |
| CAPTCHA_REQUIRED | feed 需要验证码 | "Feed 需要验证码验证" | 输入验证码 |
| GUID_MISMATCH_DETECTED | GUID 不一致 | "检测到 GUID 差异" | 确认使用 GUID 作为唯一标识 |
| RSS_SYNC_LIMIT_EXCEEDED | 同步数量超限 | "一次性同步过多，限制 50 集" | 增加天数范围 |
