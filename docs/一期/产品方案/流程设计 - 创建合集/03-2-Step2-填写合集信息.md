**业务规则**:
1. **自动填充**:优先从 package.json 读取 title/description/author
2. **标题约束**:1-200 字符，必填
3. **描述约束**:50-1000 字符，必填
4. **封面验证**:格式/JPG-PNG-WebP，大小<5MB，尺寸≥800×600

## 🔍 **二、Console 源码证据**

### **2.1 元数据表单核心逻辑**

```typescript
// packages/console/src/pages/collection/creator/Step2/index.tsx
class CollectionMetaForm {
  render(currentMetadata: Partial<CollectionSchema>) {
    // 自动填充逻辑
    const autoFilled = this.autoFillFromPackageJson();
    
    return (
      <div>
        {/* 标题输入 */}
        <Input
          label="合集标题 *"
          value={currentMetadata.title || autoFilled.title}
          maxLength={200}
          validate={(val) => val.trim().length > 0 ? null : '标题不能为空'}
        />
        
        {/* 描述文本域 */}
        <TextArea
          label="描述 *"
          value={currentMetadata.description || autoFilled.description}
          maxLength={1000}
          minLength={50}
        />
        
        {/* 封面图片上传 */}
        <CoverUpload
          currentCover={currentMetadata.coverImage}
          onUploadSuccess={(cover) => setMetadata({ ...metadata, coverImage: cover })}
          rules={{
            acceptedFormats: ['image/jpeg', 'image/png', 'image/webp'],
            maxSize: 5 * 1024 * 1024,
            minDimensions: { width: 800, height: 600 }
          }}
        />
      </div>
    );
  }
  
  private autoFillFromPackageJson(): AutoFillResult {
    // 尝试读取 package.json
    const pkg = readPackageJson(this.props.rootDir);
    
    return {
      title: pkg?.name || path.basename(this.props.rootDir),
      description: pkg?.description || '',
      author: pkg?.author || null
    };
  }
}
```

**CLI 说明**:暂不支持 package.json 自动填充的详细 UI，仅实现基础表单功能。

## 🚨 **三、异常分支**

| 错误码 | 触发条件 | 用户提示 | 修复建议 |
|--------|---------|---------|----------|
| TITLE_TOO_LONG | 标题超过 200 字符 | "标题长度不能超过 200" | 精简标题 |
| DESCRIPTION_TOO_SHORT | 描述少于 50 字符 | "描述至少需要 50 个字符" | 补充详细说明 |
| COVER_FORMAT_INVALID | 封面格式不支持 | "仅支持 JPG/PNG/WebP" | 转换格式后重试 |
| COVER_SIZE_EXCEEDED | 封面超过 5MB | "封面图片太大，不超过 5MB" | 压缩图片 |
