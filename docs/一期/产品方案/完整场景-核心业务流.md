# Freelog Runtime CLI - 核心业务场景手册

> **目标**: 按真实业务分类，编写核心大场景，每个大场景覆盖完整的流程链 + 所有异常分支
> 
> **方法**: 不是零散的 86 个小场景，而是按资源类型分为 3 个大场景，每个大场景再按业务流程细分

---

## 📚 第一部分：普通资源完整发行流程

**涵盖范围**:
- 普通单文件资源 (图片/视频/音频/文档)
- 前端库/组件库
- 静态网站
- Markdown 文档资源
- 任意文件格式的资源

**核心流程链**:
```
环境确认 → 选择资源类型 → 创建资源壳 → 上传版本 → 配置策略 → Listing 设置 → 上架
       ↓              ↓               ↓           ↓          ↓            ↓           ↓
    A01-A08      选择类型树       Step1      Step2     Step3      Step4      最终确认
```
