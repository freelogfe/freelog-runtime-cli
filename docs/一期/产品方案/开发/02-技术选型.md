# 02 - 技术选型

按**当前最佳**选，不被旧 `packages/cli` / archive 绑住。那边只供对照业务怎么调接口。

分层（`commands` → `domain` → `local`）仍听 [00](./00-文件分类.md)，那是职责，不是框架。

## 1. 定什么

| 层 | 选定 | 不选（含旧 CLI） | 为什么 |
|----|------|------------------|--------|
| 语言 | TypeScript ESM，Node >= 20 | — | tools-lib、仓库已锁 |
| 命令 | **commander** | citty、yargs、cac、clipanion | 子命令深、未知旗默认失败（`--prepare` 不能被吞）、文档和审查都熟、`.parseAsync` 好测 |
| 交互 | **@inquirer/prompts** | @clack/prompts、旧 inquirer | 官方分模块；`--yes` 就是不调用，没有 `isCancel` 仪式 |
| 校验 | **zod** | 手写、io-ts | 工作稿 / 一行式 / `--json` |
| 版本号 | **semver** | 手写比较 | `update-version` 新号必须 `>` latest |
| 压缩 | **archiver** | adm-zip | 流式打大目录；zip 根不套一层文件夹 |
| 测试 | **vitest** | node:test、jest | 切片单测 + 架构测试 |
| 构建 | **tsup** | tsdown、tsx 直接当 bin | 发布要 dist；和 tools-lib 同一套打包器（运维理由，不是抄旧 CLI） |
| 模板 | **先 `node:fs` 拷文件** | 先上 ejs | `init` 一期主要落身份；占位符真需要再加 |
| HTTP | 只 `FServiceAPI` | ofetch、自建 axios | 07 |
| 日志 / 磁盘 | `console` + `node:fs` | consola、fs-extra | 少依赖 |
| 文案 | **源码里写中文** | 运行时查 i18n 表 | 见 §2 |
| 包名 | 仍 `@freelog-cli/cli2`，bin `freelog-cli` | 现在改正式名 | 少动 workspace；对外名以后再定 |

不要带进新包：`citty`、`@clack/prompts`、`adm-zip`、`consola`、`fs-extra`、`ofetch`、`yaml`、`ejs`、CLI 自己的 i18next / `bundled-data.json`、旧 `verify:*` 联调脚本。

## 2. 文案：中文硬编码 + 注释 key

审查时要一眼看见说了什么。**不要** `t('cli.xxx')` 再跳到 JSON。

```
// i18n: cli.production_env_disabled
throw new CliError('prod 暂未开放，请用 --env test 或 --env dev');

// i18n: naming_convention_resource_name
throw new CliError('资源授权标识长度必须在 1–60 字符之间，…');
```

| | |
|--|--|
| 用户看见的 | 字符串本身（中文） |
| 注释 | `// i18n: <key>`，写在该字符串上一行 |
| 和 Console 同一句 | 用 Console / 业务梳理里的原 key（如 `naming_convention_resource_name`） |
| 只有 CLI 有的 | `cli.` 前缀，点分路径（`cli.production_env_disabled`） |
| 插值 | 普通模板字符串；key 仍写注释里 |
| `--json` | 机器字段用稳定英文 code；给人看的 `message` 仍是上面那句中文 |

一期**不**建 `i18n/` 运行时、不加载 `bundled-data.json`。以后要英文化：按注释 key 收表，再换调用点。

规格里已经写死的句子，按原文抄，key 跟场景实现 / PHASE 能对上就对上。

## 3. commander 怎么用（和 00 对齐）

- 根程序挂共用旗：`--env` `--yes` `--cwd` `--json` `--file`
- 每个 COMMANDS 命令一个 `commands/*.ts`，只解析参数、调一个 domain、打印
- 默认拒绝未知选项（不要 `allowUnknownOption`）
- 未实现的命令可以先 `command(...).action(() => { throw 未实现 })`，**不要**注册禁止名单里的旧命令
