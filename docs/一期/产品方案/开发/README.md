# 开发入口

先读[交接文档](../交接文档.md)和[研发交付规范](../../../研发交付规范/README.md)。产品真源是[脚手架设计](../脚手架设计/README.md)，字段按[对照表](../业务梳理/字段级校验对照表.md)核对。

当前已实现单资源与合集，不再执行“清空 CLI 重铺”或“不做合集”的旧阶段指令。允许有依据地重构，不为旧版本保留无意义兼容；先锁定正确行为和回归。

## 实现约束

- 命令层负责参数、交互和输出；业务在 domain、本地状态在 local、平台适配在 platform，见[源码架构](../../../../packages/cli/src/ARCHITECTURE.md)。
- 请求经 tools-lib；读写 DTO 分别核对。确有接口变化可修改适配并验证，不受旧稿“一律不许改”约束。
- 本地身份不是版本数据库，工作稿与 pending 要可恢复；只改选中资源，未知结果先核验、不重发。
- 公共模块变更分析单资源和合集两边影响，提取共享代码不改变业务语义。
- `--yes` 不绕过业务门禁，prod 保护不能撤，必要的边界/规则注释不能省。
- 设计、命令契约、场景和随包交付的使用文档一起维护。

按[变更模板](../../../研发交付规范/变更记录模板.md)说明目标、影响和用例，设计先行、缺陷回归先行，再实现和验证。依据[DEV 计划](../../../../test/DEV-全流程测试计划.md)扩大测试，独立复核后验固定候选包。

本目录其它编号文档仅作历史切片/目录参考，不能覆盖当前范围和新质量契约，历史测试数字不是新证据。
