## 📋 **一、错误码分类体系**

### **1.1 分类维度**

| 类别前缀 | 范围 | 描述 | 示例 |
|---------|------|------|------|
| `FIELD_` | FIELD_REQUIRED ~ FIELD_MAX | 字段验证错误 | TITLE_EXCEEDS_LIMIT |
| `API_` | API_NETWORK ~ API_MAX | API 调用错误 | RESOURCE_FROZEN |
| `CHECKPOINT_` | CHECKPOINT_START ~ END | Checkpoint 机制错误 | ACCOUNT_MISMATCH |
| `RSS_` | RSS_BIND ~ RSS_SYNC | RSS 相关错误 | GUID_CONFLICT |
| `POLICY_` | POLICY_COMPILE ~ POLICY_MAX | 策略模板相关错误 | POLICY_SCHEMA_INVALID |
| `COLLECTION_` | COL_CREATE ~ COL_MAX | 合集管理错误 | ITEM_NOT_FOUND |
| `AUTH_` | AUTH_LOGIN ~ AUTH_MAX | 认证授权错误 | TOKEN_EXPIRED |
| `BUILD_` | BUILD_PACKAGE ~ BUILD_MAX | 构建打包错误 | ENTRY_NOT_FOUND |
| `BATCH_` | BATCH_START ~ END | 批量操作错误 | FROZEN_RESOURCE_SKIPPED |
| `SYSTEM_` | SYS_DISK ~ SYS_MAX | 系统级错误 | DISK_SPACE_LOW |

## 📊 **三、错误码使用规范**

### **3.1 TTY 模式错误显示格式**

```typescript
interface ErrorDisplay {
  title: string;              // 错误标题 (中文)
  code: string;               // 错误码 (英文大写下划线)
  description: string;        // 详细描述
  suggestion: string;         // 修复建议
  helpLink?: string;          // 帮助文档链接
  relatedField?: string;      // 关联字段 ID
}

function displayErrorTTY(error: ErrorDisplay): void {
  console.log(chalk`\n${chalk.red('❌')} {bold ${error.title}}\n`);
  
  if (error.code) {
    console.log(chalk`{gray Code: ${error.code}}`);
  }
  
  if (error.description) {
    console.log(`${error.description}\n`);
  }
  
  if (error.relatedField) {
    console.log(chalk`{dim Field: ${error.relatedField}}\n`);
  }
  
  console.log(chalk`${chalk.yellow('💡')} ${error.suggestion}\n`);
  
  if (error.helpLink) {
    console.log(chalk`📖 {cyan ${error.helpLink}}\n`);
  }
}
```

### **3.3 错误码一致性保证**

| 要求 | 说明 |
|-----|------|
| **全局唯一性** | 每个错误码只能定义一次，不得重复 |
| **命名规范** | 全大写 + 下划线分隔 (如 VERSION_NOT_INCREMENTAL) |
| **语义清晰** | 错误码本身应表达核心问题 |
| **版本控制** | 新增错误码时记录在 CHANGELOG.md |
| **文档同步** | 每次添加新错误码必须更新此表 |
