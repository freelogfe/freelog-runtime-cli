# CLI 与 Console 的差异

[返回使用文档目录](./README.md)

Freelog CLI 的目标是在没有网页 UI 的环境中完成本地文件型资源的创建、发行和维护。CLI 与 Console 使用相同的平台业务规则和 API 结果，但不会机械复制网页步骤。

## 结果一致，交互不同

| 业务 | Console | CLI |
|---|---|---|
| 选择资源类型 | 树形选择器 | `type search|info|pick` |
| 填写资源信息 | 网页表单 | `init`、命令参数和 manifest |
| 上传封面 | 上传与裁剪 UI | `--cover <本地路径或 URL>`，本地先裁剪 |
| 上传版本文件 | 云存储或本地上传 | `--file <本地文件或构建目录>` |
| 保存发版草稿 | 网页自动或手动保存 | 显式 `draft push`，`draft pull` 合并 |
| 管理依赖 | 可视化依赖页 | manifest、`dep` 和授权映射文件 |
| 管理策略 | 可视化编辑器 | 策略文件、`policy apply|set` |
| 上下架 | 页面按钮和弹窗 | `online`、`offline` 和 `--yes` |
| 合集目录 | 列表拖拽和选择器 | `collection item` 命令和顺序文件 |

同一业务操作成功后，平台上的资源标题、类型、版本、文件 SHA1、策略状态、合集目录和上下架状态应与 Console 操作结果一致。

## CLI 更明确的地方

- 环境通过 `--env`、项目配置或环境变量表达，适合脚本和 CI。
- 本地意图保存在 manifest，平台事实保存在 state，便于审查和复现。
- 草稿不会隐式保存，跨端冲突不会静默覆盖。
- 写操作可以使用 `validate`、`diff`、`--dry-run`、`--json` 和退出码建立自动门禁。
- 主题和插件可在发行前运行构建，并由 CLI 压缩最终构建目录。
- 批量发行有逐项报告、继续和重试，不会把部分成功描述成整体回滚。

## CLI 更严格的地方

- `online` 会先确认正式版本、启用策略、owner 和冻结状态，不允许先上架再补条件。
- 非交互写操作必须明确环境和确认参数。
- listing 或草稿发生双向变化时会停止，要求用户选择保留哪一侧。
- 合集目录项必须满足版本、策略、上架和授权条件后才能加入。
- 本地封面必须已经裁剪完成，CLI 不模拟浏览器裁剪器。

这些差异不会改变最终平台规则，只是把 Console 通过按钮禁用、弹窗和页面顺序表达的约束，转换成预检、参数和明确错误。

## 必须使用浏览器的能力

以下能力依赖网页交互，CLI 会提供 Console 接力信息而不是模拟 UI：

- 从 Freelog 云存储中浏览并选择已有文件
- 使用 Markdown、Cartoon 等可视化内容编辑器
- 完成付费策略支付和复杂人工授权
- 解冻资源
- 浏览资源详情和播放预览
- 查看收入、收藏、消费和其他运营页面

浏览器处理完成后，回到原工程执行 `pull`、`status` 或错误信息给出的重试命令。

## 无法逐步复制、但已有明确处理的差异

| 差异 | 为什么不能逐步相同 | CLI 的正式处理 |
|---|---|---|
| 付费策略、支付、复杂人工签约 | 依赖浏览器收银台、用户确认和合约页面 | 输出当前环境的 Console 链接和可重复执行的下一条命令；完成后重新检查授权，不伪造支付成功 |
| 云存储选文件、可视化编辑器和封面裁剪 | 依赖 Console 微应用和浏览器组件 | CLI 只接收本地文件、已存在的平台引用或已裁剪封面；不提供功能较弱的伪编辑器 |
| Console 自动保存版本草稿 | 网页会话可以持续防抖保存，单次 CLI 命令没有同样生命周期 | 工程模式使用显式 `draft push|pull|discard`；会话模式在单次命令内直接提交，不跨进程保留隐式草稿 |
| Console SSE 文件属性进度 | CLI 需要稳定的终端与 CI 协议 | CLI 使用 REST 轮询并保持相同的最终属性结果、超时和失败语义；传输方式不同不算业务缺口 |
| 页面拖拽和即时保存 | 依赖鼠标、页面局部状态和组件事件 | 使用 `collection item reorder`、显式 `update` 等命令；比较最终顺序和平台字段，不比较点击次数 |
| RSS 验证码和解冻资源 | 需要受控邮箱或 Console 权限，不能由 CLI 猜测或绕过 | CLI 提供 RSS inspect/send-code/bind/status/sync；验证码由用户安全输入。冻结状态只能检测并拒绝写入，解冻仍在 Console 完成 |
| CLI 新版本视频封面 | 当前 Console 创建新版时保存草稿字段但未把它提交给 createVersion | CLI 将其作为明确的 CLI 增强；它不计入严格 Console parity，也不提供 Console 当前不存在的已发版封面编辑命令 |

上述差异必须同时记录在内部能力矩阵和验证场景中。只有最终平台语义等价的项目才能标记 `PARITY` 或 `EQUIVALENT`；需要浏览器接力、CLI 独有增强或尚缺目标环境证据的项目必须单独标识。

## CLI 独有能力

以下能力服务于本地开发和自动化，Console 没有完全相同的入口：

- 从主题或插件模板创建工程
- 将构建目录确定性压缩为发行物
- 把文件夹批量发行成多个独立资源
- 从文件夹创建子资源并组织为合集
- 使用 `release` 串联预检、构建、升版、发行和上架
- JSON/NDJSON 输出、退出码、批量恢复和 CI 门禁
- `session` 和 `studio` 临时、多账号工作方式

遇到差异时，应比较最终平台对象和状态，而不是要求命令数量、菜单顺序或提示形式与 Console 完全相同。
