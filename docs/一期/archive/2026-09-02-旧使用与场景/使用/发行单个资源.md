# 发行单个资源

[返回使用文档目录](./README.md)

单资源流程适用于一个主题项目、一个插件项目、一个 package/前端库项目、一张图片、一个视频或一个普通文件。所有写命令示例都显式使用当前授权的 `<env>` 环境。

## 从模板创建主题、插件或 package

先查看当前可用模板。主题和插件使用 runtime 模板；package/前端库使用 package 模板：

```bash
freelog-cli template list --scaffold runtime --runtime 0.5 --env <env>
freelog-cli template list --scaffold package --env <env>
```

创建主题：

```bash
freelog-cli init theme my-theme --template vite-react-ts --runtime 0.5 --yes --env <env>
cd my-theme
pnpm build
freelog-cli create --yes --env <env>
freelog-cli version set --version 1.0.0 --file dist --artifact-mode directory-zip --runtime 0.5 --env <env>
freelog-cli validate --for publish --env <env>
freelog-cli publish --yes --env <env>
freelog-cli policy template list --env <env>
freelog-cli policy template apply <templateId> --yes --env <env>
freelog-cli online --yes --env <env>
```

创建插件时使用 `init widget`，模板 ID 和构建命令以所选模板为准：

```bash
freelog-cli init widget my-widget --template vite-vue-ts --runtime 0.5 --yes --env <env>
```

创建 package/前端库时使用 `init package`，并填写 namespace：

```bash
freelog-cli init package my-package --template package-js --namespace <namespace> --yes --env <env>
```

`init` 默认可以安装模板依赖；使用 `--skip-install` 后，需要在构建前自行安装。

## 接入已有主题或插件项目

在现有项目根目录执行：

```bash
pnpm build
freelog-cli init . --scaffold none --resource-type <runtimeTypeCode> --artifact-mode directory-zip --runtime 0.5 --yes --env <env>
freelog-cli create --yes --env <env>
freelog-cli version set --version 1.0.0 --file dist --artifact-mode directory-zip --runtime 0.5 --env <env>
freelog-cli publish --yes --env <env>
```

注意：

1. `publish` 不运行项目构建命令。
2. `--file` 应指向可部署的最终构建目录，而不是源码目录。
3. CLI 对目录生成确定性的临时 zip，不修改原构建目录。
4. 资源类型要求自定义类型名时，可在 `init` 使用 `--resource-type-name`，或在 `create` 使用 `--type-name`。

## 发行图片、视频或普通文件

```bash
mkdir media-resource
cd media-resource
freelog-cli init . --scaffold none --resource-type <typeCode> --artifact-mode file --yes --env <env>
freelog-cli create --yes --env <env>
freelog-cli version set --version 1.0.0 --file <path-to-file> --env <env>
freelog-cli validate --for publish --env <env>
freelog-cli publish --yes --env <env>
```

图片、视频和普通文件使用 `file` 模式，上传原文件。CLI 不压缩图片、不转码视频，也不提供终端内播放预览。

为下一版视频设置版本封面：

```bash
freelog-cli version set --video-cover ./video-cover.png --env <env>
```

listing 封面和视频版本封面是不同字段：

```bash
freelog-cli update --cover ./listing-cover.png --yes --env <env>
freelog-cli version set --video-cover ./video-cover.png --env <env>
```

本地封面文件支持 JPG、PNG 和静态 GIF，最大 5 MB。Console 提供裁剪界面，CLI 不裁剪，因此应在上传前准备好最终尺寸和画面。

## 使用 release 串联发版

首次创建平台资源后，后续版本可以用 `release` 串联预检、构建、升版、发行和上架：

```bash
freelog-cli release --bump patch --build-cmd "pnpm build" --online --yes --env <env>
```

`release` 不替代首次 `init` 和 `create`。使用前先阅读[工程化与预检](./工程化与预检.md)。
