# 快速上手：发行一张图片并上架

[返回使用文档目录](./README.md)

本教程使用你已获得权限的 `<env>` 环境。完成后会真实创建、发行并上架一个图片资源。请准备一个可公开发行的本地图片文件。

如果只是第一次体验，优先用交互入口；如果要给 AI、CI 或团队复盘，使用后面的显式命令路径。

## 最快方式：进入 start 向导

```bash
freelog-cli --version
freelog-cli login --env <env>
freelog-cli start --env <env>
```

在空目录中运行 `start` 时，CLI 会优先推荐“发布一个新资源”。你可以选择：

| 选择 | 适合 |
|---|---|
| 进入 session 连续首发/发版 | 马上完成一次发行，不想先写 manifest/state |
| 查看本地工程命令 | 希望留下 `freelog.manifest.json`，方便后续维护、提交到仓库或交给 AI/CI |

交互流程里遇到资源类型、策略模板、上下架等选择时，按提示先查看候选项再确认。策略新增默认走 Console 同源模板，不需要手写策略文件。

## 可复盘路径：显式命令发行图片

下面这条路径适合长期维护，也适合你把步骤交给 AI 或 CI 执行。

### 1. 创建目录并登录

```bash
mkdir freelog-photo-demo
cd freelog-photo-demo
freelog-cli login --env <env>
freelog-cli status --env <env>
```

默认登录会把加密凭据写入当前工作区的 `.freelog-auth`，子目录可以继承该账号。

### 2. 查询图片资源类型

资源类型由平台动态提供，不要在脚本中猜测类型 code：

```bash
freelog-cli type search 图片 --env <env>
freelog-cli type info <imageTypeCode> --env <env>
```

从结果中选择符合文件格式和用途的叶子类型，并记下 `typeCode`。下文用 `<imageTypeCode>` 表示该值。

### 3. 初始化本地工程

```bash
freelog-cli init . --scaffold none --resource-type <imageTypeCode> --artifact-mode file --yes --env <env>
```

命令会生成 `freelog.manifest.json`。检查资源标题、短授权标识和资源类型，确认无误后继续。

### 4. 创建平台资源

```bash
freelog-cli create --yes --env <env>
freelog-cli status --env <env>
```

`create` 会在平台创建资源，并把 `resourceId`、owner 和环境写入 `.freelog/state.json`。此操作不会创建正式版本。

### 5. 发行首版

将 `<path-to-image>` 替换为本地图片路径：

```bash
freelog-cli version set --version 1.0.0 --file <path-to-image> --env <env>
freelog-cli validate --for publish --env <env>
freelog-cli publish --yes --env <env>
```

`publish` 会计算文件 SHA1、上传文件并创建正式版本。版本创建成功后，不会因为后续策略或上架失败而自动撤销。

### 6. 选择策略模板并应用

```bash
freelog-cli policy template list --env <env>
freelog-cli policy template apply <templateId> --yes --env <env>
freelog-cli policy list --env <env>
```

确认列表中至少有一条状态为启用的策略。只有专家手写、迁移或 AI/CI 批量生成策略时，才使用 `policy init` 与 `policy apply --from-file` 的高级路径。

### 7. 上架

```bash
freelog-cli validate --for online --env <env>
freelog-cli online --yes --env <env>
freelog-cli status --env <env>
```

上架成功后，可在当前环境对应的 Freelog Console 查看资源详情。CLI 不在终端内播放视频或渲染资源详情页。

## 本地产生的文件

| 文件 | 用途 | 是否建议提交 |
|---|---|---|
| `freelog.manifest.json` | 资源和下一版发行意图 | 是 |
| `.freelog/state.json` | 当前环境的平台事实缓存 | 否 |
| `.freelog-auth` | 当前工作区的加密登录凭据 | 否 |

显式命令链路如下：

```text
login -> type search -> init -> create -> version set -> validate
      -> publish -> policy template apply -> online
```
