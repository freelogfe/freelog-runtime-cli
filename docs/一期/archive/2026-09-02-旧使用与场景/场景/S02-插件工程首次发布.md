# S02 · 插件工程首次发布

> **文档角色：** 插件资源从本地工程到首次发布的历史场景材料。当前主线方案见 [../产品方案/README.md](../产品方案/README.md)；交互拓扑补充见 [../02-CLI体验拓扑设计.md](../02-CLI体验拓扑设计.md)。

最后更新：2026-08-28

---

## 1. 用户目标

用户是插件/组件运行时开发者。他要发布的是平台“插件”资源，不是主题，也不是普通前端库。插件可以复用 runtime 模板，但入口、文案、最终资源类型都必须是插件。

---

## 2. Console 对齐点

| Console 业务 | CLI 必须对齐的结果 |
|---|---|
| creator Step1 类型必选 | 最终 resourceTypeCode 必须是平台插件 leaf |
| creator Step1 标题/name | 同资源创建约束 |
| creator Step2 文件 | 发布 build 后的 dist zip |
| runtimeVersion | 插件和主题一样，发版前必须显式存在 |
| 策略/online | 策略新增先走 Console 同源模板 Builder；online 同 sidebar 严格门禁 |

---

## 3. 资源类型设计

插件是独立大类入口，不得藏在搜索框里。

| 步骤 | 规则 |
|---|---|
| 大类入口 | 第一屏显示「插件」 |
| 类型来源 | 当前环境平台类型树 |
| 定稿规则 | 优先匹配展示名「插件」；若是父节点则继续逐级选择 leaf |
| 多候选 | 展示完整路径/code/能力摘要，用户确认 |
| 无候选 | 停止并提示平台未提供插件类型 |
| 禁止 | 不得用主题 leaf 替代插件；不得靠 `widget` 字符串猜平台 code |

## 4. TTY 连续向导

| checkpoint | 用户看到 | 输入 | 副作用 | 失败处理 |
|---|---|---|---|---|
| W1 选择任务 | “发布插件工程” | 插件 | 无 | 返回主菜单 |
| W2 类型确认 | 插件 leaf 路径/code | 确认 | 无 | 多候选必须人工选 |
| W3 模板选择 | runtime 模板列表 | Vue/React/TS | 未确认前无写 | 不兼容则换模板 |
| W4 工程字段 | title/name/version/runtime | 文本 | 写 manifest | 即时字段校验 |
| W5 构建 | 说明 dist 产物 | build 或退出 | 无 | dist 不存在给命令 |
| W6 发布预检 | zip、SHA、版本、owner/env | confirm | 无 | 依赖/版本/大小失败先修 |
| W7 发布和续接 | createVersion 后策略模板/上架 | 继续或退出 | 写平台/state | 策略进入 [S14](./S14-策略模板选择与应用.md)；partial/unknown 按 recovery |

## 5. AI/CI 目标等价命令

```bash
freelog-cli init widget ./my-widget --template vite-react-ts --runtime 0.5 --env <env>
cd ./my-widget
pnpm install && pnpm build
freelog-cli create --yes --env <env>
freelog-cli publish --bump patch --yes --env <env>
freelog-cli policy apply --template <templateId-for-永久免费> --name "永久免费" --yes --env <env>
freelog-cli online --yes --env <env>
```

## 6. 常见情况处理

| 情况 | 处理 |
|---|---|
| 用户以为插件就是主题模板 | 文案说明“技术模板可复用，平台资源类型不同” |
| 平台插件类型拆成多个 leaf | TTY 展示候选；非 TTY 要 `--resource-type` |
| 模板生成成功但 build 失败 | 不进入平台写；给 build 日志和重新运行命令 |
| 用户已有线上插件 | 走 S06 绑定维护，不重新 init 覆盖 |

---

## 7. 回归到总设计

插件场景要求：

- root/start 与 init 第一层必须有「插件」；
- 成功/错误文案不能复用“主题工程”；
- 类型定稿逻辑支持大类固定入口，而非只靠搜索；
- runtime 模板文案必须写“主题/插件共用技术模板”。
