## 目录（C1）

`item *` 改的是平台目录草稿，`collection publish` 才提交。

| 做什么 | 命令 |
|--------|------|
| 加 | `item add <resourceId\|username/name>`（门禁同 C0：已上架自己的普通资源） |
| 删 / 改标题 / 排序 | `remove` / `update` / `reorder`，id 用 `status` 打出的 `itemId` |
| 提交 | `collection publish`（merge 草稿） |

```
freelog-cli status
freelog-cli collection item add <resourceId|username/name>
freelog-cli collection item remove <itemId>
freelog-cli collection publish --yes
```

## 属性与依赖

与单资源同一套字段，见 [版本表单](../../产品方案/脚手架设计/PHASE/单资源/版本表单/README.md)。合集没有 `createVersion`：跟当次 `collection publish` 走，不写 `N.json`。

只改属性、不 merge 目录：当次 `collection properties sync`（读平台或当次参数）。  
改合集自己的依赖：在当次 `collection publish` 里按 `resourceId` 或 `username/name` 查资源并签约。没有 `dep add`。加单品不是依赖（`item add`，不签约）。

收录规则：`collect-rules get` / `set`，不进创建主路径。
