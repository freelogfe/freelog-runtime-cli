## 📋 **一、Session/Studio 模式切换**

### **1. 两种运行模式**

```typescript
interface CLIMode {
  // Session: 临时登录模式
  ephemeral: {
    login(): Promise<Credentials>;
    logout(): void;
    expiresIn: number; // Token 剩余有效期
  };
  
  // Studio: 工作室模式 (长期登录)
  studio: {
    switchAccount(accountId: string): Workspace;
    listWorkspaces(): Workspace[];
    deleteWorkspace(id: string): void;
  };
}
```

### **2. 默认模式选择**

- **无参数启动**: Session 模式 (安全优先)
- **`--studio` 参数**: Studio 模式 (多账号场景)
- **`--global` 参数**: 全局凭据存储

## 💾 **三、凭据存储策略**

| 存储类型 | 路径 | 用途 | 加密 |
|----------|------|------|------|
| **Ephemeral** | `~/.freelog/temp.json` | Session 临时登录 | 否 |
| **Workspace** | `~/.freelog/workspace.json` | Studio 工作区 | AES-256 |
| **Global** | `/etc/freelog/global.json` | 多机器共享 | AES-256 |
