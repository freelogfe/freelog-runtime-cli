## 方案裁决规则

1. 业务规则以 [02-Console业务流程字段接口.md](./02-Console业务流程字段接口.md) 为准。
2. CLI 交互和本地体验以 [04-CLI流程与命令设计.md](./04-CLI流程与命令设计.md) 为准。
3. 异常、恢复和验收以 [05-场景异常与验收方案.md](./05-场景异常与验收方案.md) 为准。
4. 实现分层以 [06-实现解决方案.md](./06-实现解决方案.md) 为准。
5. 接续上下文以 [项目上下文与接续记录.md](./项目上下文与接续记录.md) 为准，但它不裁决产品规则。
6. 归档目录只保留历史材料，不参与新实现裁决。

## 禁止状态

- 禁止代码里存在产品方案没有定义的业务流程。
- 禁止用“按 Console 处理”“以接口为准”替代具体字段规则。
- 禁止只写接口名，不写调用时机、输入来源、成功状态和失败恢复。
- 禁止把旧实现中的交互当成新设计依据。
- 禁止因为 CLI 是终端就牺牲用户体验；CLI 必须提供可探索、可恢复、可脚本化、适合 AI 使用的流程。
