## 1. 能力 ID 前缀

| 前缀 | 域 | 状态 | 示例 |
|---|---|---|---|
| R | 资源身份与 listing | 一期 ✅ | R-01 create |
| V | 版本与文件 | 一期 ✅ | V-01 publish |
| D | 依赖 | 一期 ✅ | D-05 dep auth |
| P | 策略与资源上下架 | 一期 ✅ | P-03 online |
| C | 合集 | 一期 ✅ | C-01 collection create |
| N | CLI 原生（非 Console 等价） | 一期 ✅ | N-04 import-dir |

**勿混淆：** `N-01~N-06`（CLI 原生）与 `NM-01~NM-23`（节点域）是不同命名空间。

## 2. 平台对象

| 术语 | 英文/字段 | 一句话 | CLI 命令 touchpoint |
|---|---|---|---|
| **资源** | Resource / `resourceId` | 可发行的内容单元（图/音视频/主题等） | `create`, `publish`, `online` |
| **版本** | Version / `version`, `versionId` | 某次发版快照；fileSha1 不可变 | `publish`, `version edit` |
| **策略** | Policy / `policyId` | 授权与定价规则；资源/展品上架门禁 | `policy apply`, `policy set` |
| **市场条目** | Market listing | **不是**独立表；= `status=1` 的资源列表项 | `market search`, `market show` |
| **节点** | Node / `nodeId` | 店铺壳：域名、标题、主题 runtime | `node list`, `node show`（只读） |
| **节点壳** | node shell | 域名、Logo、可见性、删除等 **Console 配置** | **无写命令**（P11） |
| **展品** | Presentable / `presentableId` | 某资源在某节点上的挂载实例 | `node exhibit *` |
| **合约** | Contract / `contractId` | 签约后的授权关系记录 | `dep auth`；`node exhibit sign` 间接 |

## 3. 易混动词

| 用户说法 | 实际含义 | 命令 | 阶段 |
|---|---|---|---|
| **资源上架** | `Resource.status → 1`，进市场 | `online`（资源侧） | 一期 |
| **展品上架** | `presentable.onlineStatus → 1`，访客可见 | `node exhibit online` | 二期 |
| **依赖签约** | 作者签依赖，为了能 publish | `dep auth` | 一期 |
| **展品签约 / 挂到节点** | 节点主签市场资源，创建 presentable | `node exhibit sign` | 二期 |
| **sign**（无上下文） | ⚠️ 歧义 — 须区分 dep auth vs exhibit sign | — | — |
| **online**（无上下文） | ⚠️ 歧义 — 资源 online vs 展品 online | 看对象 | — |

## 4. 状态字段速查

### 4.1 Resource.status

| 值 | 含义 |
|:---:|---|
| 0 | 未发行 |
| 1 | 已上架（可出现在市场） |
| 2 | 冻结 |
| 4 | 下架 |

### 4.2 Node.status（位标志）

| 检查 | 含义 | CLI |
|---|---|---|
| `-1` | 已删除 | code 2 |
| `& 4` | 冻结 | code 2 |
| `1` / `2` / `8` | 公开 / 私密 / 暂停 | `node show` 可读 |

### 4.3 Presentable.onlineStatus

| 值 | 含义 |
|:---:|---|
| 0 | 展品下架 |
| 1 | 展品在线（访客可见，还须节点/主题等 Console 侧配置） |

### 4.4 Presentable 生命周期（展品层）

| 状态 | 含义 | 进入方式 | CLI |
|---|---|---|---|
| **NoPresentable** | node+resource 无挂载 | 初始 | `exhibit list` 无项 |
| **SignedOffline** | presentable 存在，`onlineStatus=0` | `exhibit sign` | 可 `online` |
| **Online** | `onlineStatus=1` | `exhibit online` | 可 `offline` |
| **Offline** | 曾 online 后下架 | `exhibit offline` | 可再 `online`（幂等） |

完整转移、重试与停损：[17-展品状态机与恢复模型](./17-展品状态机与恢复模型.md)。

## 5. CLI 退出码（Agent 必读）

| code | 含义 | 典型场景 |
|:---:|---|---|
| 0 | 成功 | — |
| 1 | 平台/未知错误 | 5xx、未分类 |
| 2 | 权限 / owner / 节点冻结 | 非 node owner |
| 3 | 冲突 | 本地/平台漂移 |
| 4 | 预检失败 | 未上架、重复 sign、无 policy、`--strict` |
| 5 | Console 接力 | 付费签约、dep auth 未完成 |

用户动作表：[12 §3.5](./12-多视角设计说明.md#35-失败时用户该做什么)。

### 5.1 error.reason 速查（Top 10）

完整索引见 **[06 §12](./06-JSON协议与Schema草案.md#12-errorreason-与-signblockers-索引)**。

| reason | code | 一句话 |
|---|---|:---:|---|
| `not_owner` / `node_frozen` | 2 | 账号或节点状态不对 |
| `resource_not_online` | 4 | 先资源 `online` |
| `duplicate` | 4 | 已签约，查 `exhibit list` |
| `no_enabled_policy` | 4 | 先配置 policy |
| `auth_exception` / `owner_frozen` | warn→4 | 默认可 sign；`--strict` 更严 |
| `payment_required` | 5 | 打开 Console，跑 `nextCommand` |

## 6. 对齐类型（验收用语）

| 类型 | 含义 |
|---|---|
| **PARITY** | 同 API、同门禁、结果等价 Console |
| **EQUIVALENT** | 同 API；CLI 用参数/拆步替代 UI |
| **CLI_ONLY** | 无 Console 等价（如 `--dry-run`） |
| **OUT** | 不做；handoff 或 Console |
