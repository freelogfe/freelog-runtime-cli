# Console 与 CLI 对齐入口

> **文档角色：** Console 资源域事实证据入口。本文不定义产品目标，不写实现方案；产品主线见 [../产品方案/README.md](../产品方案/README.md)。

最后更新：2026-09-02

## 本目录放什么

| 内容 | 应放这里吗 | 说明 |
|---|---|---|
| Console 业务流程 | 是 | 页面背后的业务顺序、状态门禁和写入结果 |
| Console 字段约束 | 是 | 必填、长度、格式、提示、禁用条件 |
| Console 接口调用 | 是 | API 名称、关键 payload、调用顺序 |
| Console 源码路径 | 是 | 可追溯到页面、组件、service 或 model |
| CLI 产品取舍 | 否 | 应写入 `产品方案/` |
| CLI 实现模块 | 否 | 应写入 `开发/` |
| 环境测试结果 | 否 | 应写入 `验证/` |

## 和产品方案的关系

```text
对齐/ 提供 Console 事实
  → 产品方案/ 根据事实和 CLI 环境做产品推导
  → 开发/ 把产品方案落成实现规格
  → 验证/ 记录测试结果
```

发现 Console 新变化时，先更新本目录的事实总账；如果影响用户流程，再同步 `产品方案/`、`使用/`、`场景/` 和代码。
