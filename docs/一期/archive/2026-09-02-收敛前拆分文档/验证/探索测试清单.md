## L3-G TTY 字段约束（输入前提示）

对照 [CLI交互与字段约束](../开发/CLI交互与字段约束.md) §4.1–4.6。除 **FORM-RES-NAME 规范化**（prompt 放行 → info 自动转换）外，其它 HARD 非法值须在 **prompt validate 内失败**，不得等到 API 调用（preflight / RSS 预检除外）。

**前置：** 已 `freelog-cli login --env dev`；使用**真实 TTY**（勿加 `--yes` / `--json`）；自动化预检先跑：

```bash
pnpm --filter @freelog-cli/cli2 exec vitest run tests/fieldConstraints.test.ts tests/preflightSummary.test.ts tests/onlineGates.test.ts tests/onlineService.test.ts
pnpm --filter @freelog-cli/cli2 verify:console-forms
```
