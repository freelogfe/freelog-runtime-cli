# 14 · 策略模板选择与应用

## 用户目标

用户要给资源或合集新增策略。普通流程应先看可用策略模板，再选择模板、填写参数、预览并应用。

## 前置条件

- 资源或合集已创建。
- 已知资源类型。
- 当前账号是 owner。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 列模板 | 展示当前类型可用模板 | policy template list |
| 选模板 | 用户选择 templateId | 显式传 templateId |
| 填参数 | 对模板 inputs 逐项填写 | `--param key=value` |
| 预览 | 展示编译和翻译结果 | policy template render |
| 应用 | 用户确认后写平台 | policy template apply |
| 后续 | 启用策略并上架 | policy set / online |

## 分支与异常

| 情况 | 处理 |
|---|---|
| 当前类型无模板 | 提示换类型或使用高级文件路径 |
| 参数缺失 | 停在参数填写，不写平台 |
| 编译失败 | 展示模板错误，不应用 |
| 翻译不可读 | 允许返回修改参数 |
| 高级用户已有策略文件 | 可用 from-file 兜底，但不是普通主路径 |

## 验收点

- 所有首发、合集、只维护策略场景都引用本场景规则。
- 普通用户不会被要求手写 policyText。
- AI/CI 可以用 render 先审阅再 apply。
