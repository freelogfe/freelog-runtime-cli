# 08 · 合集从本地目录创建

## 用户目标

用户想把一组本地文件做成相册、专辑或系列展示。每个文件是子资源，合集负责目录组织。

## 前置条件

- 已登录目标环境。
- 已确认子资源类型和合集类型。
- 本地目录中文件可发行。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 消歧 | 确认这是合集，不是目录 zip 或批量独立资源 | 显式 collection 流程 |
| 创建合集壳 | 输入合集标题、类型、短名 | collection create |
| 创建子资源 | 扫描媒体文件并发行子资源 | import 子资源 |
| 目录草稿 | 将子资源加入合集目录 | collection item add/import |
| 发布合集 | 合并目录草稿并发布 | collection publish |
| 上架 | 合集策略模板后 online | collection policy template apply / online |

## 分支与异常

| 情况 | 处理 |
|---|---|
| 子资源部分失败 | 保留成功项和报告 |
| 用户想手动排序 | 目录草稿中 reorder |
| 已绑定 RSS | 不允许手动改目录，转 RSS 场景 |
| 只想多个独立资源 | 转批量场景 |

## 验收点

- 平台存在子资源和合集资源。
- 合集目录项指向已发布子资源。
- 合集发布使用目录草稿合并语义。
