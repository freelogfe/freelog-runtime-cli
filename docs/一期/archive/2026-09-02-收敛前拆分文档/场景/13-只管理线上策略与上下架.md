# 13 · 只管理线上策略与上下架

## 用户目标

用户只想给已有资源配置策略、启停策略或上下架，不想发布新文件。

## 前置条件

- 资源已存在。
- 当前账号是 owner。
- 如果要上架，资源必须已有正式版本。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 定位资源 | 搜索或绑定 | resource search / bind |
| 看策略 | 列出现有策略 | policy list |
| 新增策略 | 选模板、预览、应用 | policy template list/render/apply |
| 启停 | 选择策略状态 | policy set |
| 上下架 | 展示门禁后确认 | online/offline |

## 分支与异常

| 情况 | 处理 |
|---|---|
| 没有正式版本 | 不能上架，先发布版本 |
| 没有启用策略 | 先启用或新增策略 |
| 策略需要签约 | Console 接力 |
| 资源被冻结 | 停止，提示解冻接力 |

## 验收点

- 不触发 version create。
- 策略新增优先走模板。
- online 门禁解释清楚。
