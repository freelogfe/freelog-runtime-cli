# 12 · 已有本地工程更新版本

## 用户目标

用户已有本地工程和线上资源，现在修改了文件，希望发布下一版。

## 前置条件

- 本地工程已绑定 resourceId。
- 当前账号是 owner。
- 本地文件或构建目录已准备好。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 检查 | status + diff | status/diff JSON |
| 升版本 | 选择 patch/minor/major | version bump |
| 写产物 | 选择文件或目录 | version set |
| 发布 | 预检后确认 | publish --yes |
| 后续 | 必要时更新策略/上架 | policy / online |

## 分支与异常

| 情况 | 处理 |
|---|---|
| 平台已有更新 | 先 pull 或处理 diff |
| 文件未变化 | 可提示 reuse 或停止 |
| 发布响应未知 | 对账版本和 fileSha1 |
| 只改版本说明 | 使用 version edit |

## 验收点

- latestVersion 更新。
- 本地 state 记录新版本事实。
- 不把失败后的旧文件误标为已发布。
