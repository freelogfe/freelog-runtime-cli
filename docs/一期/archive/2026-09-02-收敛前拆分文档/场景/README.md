# 场景卡目录

场景卡不是主产品方案，也不是用户手册。它只回答一个问题：真实用户拿着某类本地资源或线上资源时，CLI 是否能清楚地完成目标。

## 阅读方式

1. 先读产品方案，明确业务主流程。
2. 再读对应场景卡，看实际入口、分支和异常。
3. 发现全局规则缺失时，回写产品方案；不要在场景里重复堆规则。

## 每张场景卡必须包含

| 小节 | 作用 |
|---|---|
| 用户目标 | 用户想完成什么，不写内部愿望 |
| 前置条件 | 文件、账号、环境、线上状态 |
| 主流程 | TTY 和 AI/CI 如何完成 |
| 分支与异常 | 用户实际会遇到的歧义、错误、恢复 |
| 验收点 | 测试人员如何判断场景完成 |
