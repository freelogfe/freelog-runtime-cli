# 04 · 普通单文件资源发布

## 用户目标

普通作者想把一个本地文件发行成一个 Freelog 资源，例如图片、视频、音频或文档。

## 前置条件

- 已登录目标环境。
- 本地文件存在且可公开发行。
- 资源类型必须选到叶子类型。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 选择类型 | 搜索或逐级选择 | `type search` / `type info` |
| 初始化 | 填标题、短名、标签 | `init --scaffold none --artifact-mode file` |
| 设文件 | 选择本地文件 | `version set --file <file>` |
| 发行 | create / publish | create / publish |
| 上架 | 策略模板后 online | policy template apply / online |

## 分支与异常

| 情况 | 处理 |
|---|---|
| 文件格式不符合类型 | 预检失败，提示换文件或类型 |
| 文件过大 | 发布前提示平台限制 |
| 用户想发布目录 | 转到普通目录、批量或合集场景 |
| resourceName 冲突 | 要求换短授权标识或绑定已有资源 |

## 验收点

- 用户可以逐级选择类型，也可以搜索类型。
- 非交互模式必须明确 `artifactMode=file`。
- 发布失败时能判断是否已创建资源或版本。
