# 07 · 批量本地目录发布

## 用户目标

用户有一个素材目录，希望每个文件成为一个独立资源，并保留逐项报告和恢复能力。

## 前置条件

- 已登录目标环境。
- 已确认统一资源类型，或准备逐项配置。
- 素材目录不包含凭据和不应发布的文件。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 扫描 | 展示候选、跳过、拒绝项 | import-dir scan |
| 预检 | 文件数、类型、标题、短名 | config + validate |
| 平台写入 | 分批创建和发布 | import-dir |
| 报告 | 输出成功项、失败项、reportFile | JSON/NDJSON |
| 后续 | 每个子工程可独立维护 | 进入子目录维护 |

## 分支与异常

| 情况 | 处理 |
|---|---|
| 部分失败 | 成功项保留，失败项写报告 |
| 连接中断 | 用 reportFile resume |
| 单项参数错误 | 修配置后 retry |
| 用户想生成合集 | 批量完成后转合集流程 |

## 验收点

- 批量发行结果是多个独立资源。
- 不把部分失败描述成整体回滚。
- reportFile 可用于 resume/retry。
