# 06 · 已有线上资源维护

## 用户目标

用户已经在 Console 或其他目录创建过资源，现在想接入 CLI 继续维护。

## 前置条件

- 已登录资源 owner 账号。
- 已知道 resourceId、授权名或能用关键词搜索。
- 当前目录没有绑定到另一个资源，或用户明确覆盖。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 找资源 | 搜索当前账号资源 | `resource search <keyword>` |
| 绑定 | 确认 resourceId 和 listing | `bind <resourceId> --apply-listing` |
| 拉取 | 对齐平台状态 | `pull` |
| 维护 | update / version / policy / online | 显式命令 |

## 分支与异常

| 情况 | 处理 |
|---|---|
| 当前目录已有 resourceId | 要求确认 force 或换目录 |
| 平台 listing 与本地不同 | 显示 diff，用户选择 pull 或保留本地 |
| 不是 owner | 拒绝写操作 |
| RSS 相关资源 | 只允许维护标签和 RSS 允许的操作 |

## 验收点

- 不重复创建资源。
- 绑定后本地 state 保存平台事实。
- 后续发版继承正确的资源归属。
