# 03 · 前端库 / 软件库发布

## 用户目标

开发者想把前端库或软件库作为 Freelog 资源发行，并保留可重复构建和发版的本地工程。

## 前置条件

- 已登录目标环境。
- 已确定 package 类叶子类型。
- 已准备 namespace。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 建工程 | 选择 package / 前端库 | `init package <dir> --namespace <name>` |
| 选模板 | 展示 package 模板 | `template list --scaffold package` |
| 写信息 | 标题、短授权标识、标签 | 显式参数或 manifest |
| 发行 | 构建后发布版本 | version set / create / publish |
| 后续 | 策略和上架 | policy template apply / online |

## 分支与异常

| 情况 | 处理 |
|---|---|
| namespace 缺失 | 建工程前要求补齐 |
| 用户已有 package 项目 | 可使用 scaffold 接入，而不是强制模板 |
| 产物目录和源码目录混淆 | 明确 `version set --file` 指向构建产物 |

## 验收点

- package 入口不要求用户手选主题/插件类型。
- namespace 写入本地意图。
- 发布请求包含正确的版本产物。
