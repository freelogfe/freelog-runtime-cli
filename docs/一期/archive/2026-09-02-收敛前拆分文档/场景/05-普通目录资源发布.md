# 05 · 普通目录资源发布

## 用户目标

用户想把一个目录整体作为一个资源发行，例如静态站点产物、文档包或构建目录。

## 前置条件

- 目录存在。
- 用户明确选择“目录整体是一个资源”。
- 资源类型允许目录压缩产物。

## 主流程

| 阶段 | TTY | AI/CI |
|---|---|---|
| 消歧 | 询问目录整体、批量、合集三选一 | 显式传 `--artifact-mode directory-zip` |
| 初始化 | 创建单资源工程 | init scaffold none |
| 预检 | 展示将被打包的文件 | validate / diff |
| 发行 | 压缩并发布版本 | publish |
| 上架 | 策略模板后 online | policy template apply / online |

## 分支与异常

| 用户真实意图 | 应转向 |
|---|---|
| 每个文件都是独立作品 | 批量发行 |
| 文件要共同展示成相册/专辑 | 合集 |
| 目录是构建产物 | 当前场景 |

## 验收点

- CLI 不猜目录语义。
- 压缩排除凭据、state、版本库元数据。
- 成功后只有一个平台资源。
