# 开发文档入口

> **文档角色：** 实现规格和代码维护材料。本文不定义产品目标，不裁决 Console 业务；产品方案见 [../产品方案/README.md](../产品方案/README.md)，Console 事实见 [../对齐/README.md](../对齐/README.md)。

最后更新：2026-09-02

## 本目录放什么

| 内容 | 应放这里吗 | 说明 |
|---|---|---|
| 命令拓扑到模块职责 | 是 | 说明实现如何承接产品流程 |
| manifest/state/session/report 字段契约 | 是 | 说明本地数据怎样表达意图和事实 |
| TTY prompt 和字段约束实现 | 是 | 说明如何落地 Console 字段账本 |
| 当前代码结构、边界、注释要求 | 是 | 方便维护者读代码 |
| 产品目标、用户价值、流程裁决 | 否 | 应回到 `产品方案/` |
| Console 源码事实 | 否 | 应回到 `对齐/` |
| 某次测试结果 | 否 | 应回到 `验证/` |

## 修改规则

1. 发现产品流程不清，先改 `产品方案/`。
2. 发现 Console 事实不清，先改 `对齐/`。
3. 只有当产品和事实已经清楚，才在本目录写实现规格。
4. 不要在本目录记录“已完成/未完成”的口头结论；完成度进入能力矩阵或验证报告。
