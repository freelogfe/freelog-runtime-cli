# 01 · 安装、登录与环境

[返回目录](./README.md)

## 安装

需要 Node.js 20 或更高版本。

```bash
node --version
npm --version
npm install -g @freelog-cli/cli2
freelog-cli --version
```

安装后版本应为 `0.5.x`。

## 登录

```bash
freelog-cli login --env <env>
freelog-cli status --env <env>
```

如果要把登录信息写到全局位置，用：

```bash
freelog-cli login -g --env <env>
```

## 环境选择规则

环境优先级从高到低：

1. 命令行 `--env <env>`。
2. 环境变量 `FREELOG_ENV`。
3. 当前工程配置。
4. 全局配置。

写命令没有明确环境时会停止，不会自动落到生产环境。

## 凭据存储

| 模式 | 凭据位置 | 适合 |
|---|---|---|
| 工作区登录 | 当前目录向上查找 `.freelog-auth` | 项目专用账号 |
| 全局登录 | 用户目录下的 `.freelog-auth` | 个人日常使用 |
| session / studio | 当前进程内存 | 临时操作、多账号隔离 |

凭据本地加密写入，读取时解密。不要把 `.freelog-auth`、`.freelog/` 或密钥文件提交到版本库。

## 常用全局参数

| 参数 | 含义 |
|---|---|
| `--env <env>` | 指定运行环境 |
| `--cwd <dir>` | 指定工程目录 |
| `--yes` | 非交互确认写操作 |
| `--json` | 输出结构化结果 |
| `--debug` | 输出脱敏调试信息 |
| `--no-auto-pull` | 写命令前不自动拉取平台状态 |

`--no-auto-pull` 只建议在你明确知道本地和平台没有漂移时使用。
