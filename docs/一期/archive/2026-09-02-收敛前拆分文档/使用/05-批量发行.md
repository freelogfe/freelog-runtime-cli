# 05 · 批量发行

[返回目录](./README.md)

批量发行用于“目录里每个文件都是一个独立资源”。它不会创建合集，也不会把整个目录压成一个资源。

## 快速批量

```bash
freelog-cli resource import-dir ./photos --resource-type <typeCode> --title-prefix "照片 " --yes --env <env>
```

CLI 会扫描目录顶层文件，按资源类型限制预检，逐项创建资源并发布首版。成功项会生成子工程，失败项写入报告。

## 批量配置文件

```bash
freelog-cli resource import-dir ./photos --config ./freelog.batch.json --yes --env <env>
```

配置文件适合表达逐项标题、短授权标识、标签、版本号、策略或授权排除项。

## 进度输出

```bash
freelog-cli resource import-dir ./photos --resource-type <typeCode> --json-lines --yes --env <env>
```

`--json-lines` 适合 AI/CI 逐行读取进度。每一行都是一个事件，不要按普通终端文案解析。

## 中断恢复

命令失败时先保存报告路径。恢复时二选一：

```bash
freelog-cli resource import-dir --resume <reportFile> --yes --env <env>
freelog-cli resource import-dir --retry <reportFile> --yes --env <env>
```

| 模式 | 含义 |
|---|---|
| `--resume` | 从最后一个安全阶段继续，适合中断或本地状态没写完 |
| `--retry` | 只重试失败项，适合个别文件或权限问题修好后 |

不要手工删除成功项再重跑整个目录；那样容易制造重复资源。
