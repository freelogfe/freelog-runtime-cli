# 02 · 选择资源类型与本地文件

[返回目录](./README.md)

发行前必须先确定两件事：平台资源类型，以及本地文件如何作为版本产物上传。

## 资源类型怎么选

```bash
freelog-cli type search 主题 --env <env>
freelog-cli type search 插件 --env <env>
freelog-cli type search 图片 --env <env>
freelog-cli type pick --env <env>
freelog-cli type info <typeCode> --env <env>
```

`type pick` 适合人工逐级选择；`type search` 适合 AI、脚本或已知道关键词的用户。最终必须选到叶子类型。

## 常见类型入口

| 内容 | 推荐入口 | 本地产物 |
|---|---|---|
| 主题工程 | `init theme` | 构建目录压缩包 |
| 插件工程 | `init widget` | 构建目录压缩包 |
| package / 前端库 | `init package` | package 模板产物 |
| 图片、视频、文档等单文件 | `init --scaffold none` | 原文件 |
| 一个目录整体作为一个资源 | `init --scaffold none` | 目录压缩包 |
| 目录里每个文件都是资源 | `resource import-dir` | 多个独立文件 |
| 多个资源共同展示 | `collection` | 子资源 + 合集目录 |

## 模板怎么选

```bash
freelog-cli template list --scaffold runtime --runtime 0.5 --env <env>
freelog-cli template list --scaffold package --env <env>
```

主题和插件使用 runtime 模板；package 使用 package 模板。模板负责创建工程结构，不替代你自己的构建命令。

## 本地文件模式

| 模式 | 参数 | 说明 |
|---|---|---|
| 单文件 | `--artifact-mode file` | 上传原文件，不压缩 |
| 目录压缩包 | `--artifact-mode directory-zip` | 将目录打包后上传 |

非交互模式下必须显式传 `--artifact-mode`，CLI 不会猜测一个目录是“整体资源”“批量资源”还是“合集素材”。

## 发行前自检

```bash
freelog-cli validate --for publish --env <env>
freelog-cli diff --env <env>
```

如果 `type info` 显示文件格式、大小或运行时不满足要求，先修本地文件或换资源类型。
