# 07 · 字段约束与提示总账

> **文档角色：** 汇总一期 CLI 必须内置或动态获取的字段约束、提示、默认值、规范化规则和状态门禁。实现时不能再去旧文档里猜字段。

最后更新：2026-09-01

## 1. 约束强度

| 强度 | 含义 | CLI 处理 |
|---|---|---|
| HARD | 必填、长度、格式、状态不满足时 Console 会阻止或平台会拒绝 | 写平台前必须失败 |
| CONDITIONAL | 由资源类型、状态、账号或 RSS 状态决定 | 查询平台事实后校验 |
| SUGGESTION | Console 只提示，不阻止 | CLI 可提示，但不得当作硬门禁 |
| UI_ONLY | 裁剪、拖拽、弹窗、页面草稿等 UI 行为 | CLI 用命令/确认/report/handoff 等价处理 |

## 2. 全局字段

| 字段 | 规则 | 提示 |
|---|---|---|
| env | 写平台必须明确；当前发布线不默认 production | “请选择获授权环境” |
| account | 写平台前必须显示 username | “当前账号：...” |
| resource target | 维护动作必须明确 resourceId 或 authId | “将操作资源：...” |
| yes | 非 TTY 写操作必须显式确认 | “非交互写操作需要 --yes” |
| json | stdout 只能输出 JSON envelope | 人类提示放 stderr |

## 3. 登录和凭据字段

| 字段 | 规则 | 失败处理 |
|---|---|---|
| username/password | 只用于登录请求，不写入本地文件 | 登录失败提示账号或密码错误 |
| token | 落盘前加密 | 解密失败报凭据损坏 |
| authorization | 落盘前加密，可选 | 解密失败报凭据损坏 |
| cookie | dev 等环境可能必需，落盘前加密 | 缺失导致 API 不可用时提示重新登录 |
| auth environment | 必须与命令 env 一致 | code 2 |
| scope | workspace/global/ephemeral | workspace 损坏不得回退 global |

## 4. 资源基础字段

| 字段 | 规则 | 规范化 / 提示 |
|---|---|---|
| resourceTypeCode | 必填；必须来自平台类型树；必须是 leaf | 父类型提示继续下钻 |
| resourceTypeName | 自定义类型名，独立资源特定场景才允许 | 1–40；中文/英文/数字/`- & . ,` |
| title / resourceTitle | 必填；trim；最多 100 | “标题最多 100 字” |
| name | 必填；1–60；同账号唯一 | 规范化空白、emoji、禁用字符为 `_`；提交前查重 |
| subjectType | 普通资源默认；合集固定 4 | 不让用户手输 |
| owner | 维护时必须是当前账号 | owner 不符停止 |

## 5. Listing 字段

| 字段 | 规则 | CLI 提示 |
|---|---|---|
| intro | 最多 200 字 | “简介最多 200 字” |
| cover | jpg/jpeg/jpe/png/gif；最大 5MB | “CLI 不提供裁剪；如需裁剪请去 Console” |
| tags | 最多 20 个；单项最多 20；不能为空；不重复；输入去 `#` | 展示规范化后的标签 |
| RSS listing lock | RSS 相关资源锁定 title/cover/intro；tags 仍允许手动维护 | “该字段由 RSS feed 托管，不能手动修改” |

## 6. 文件与 artifact 字段

| 字段 | 规则 | CLI 提示 |
|---|---|---|
| filePath | file 模式必须是文件；directory-zip 模式必须是目录 | 路径不存在返回 code 4 |
| artifactMode | file 或 directory-zip | 目录必须明确选择含义 |
| filename | 上传文件名或 zip 文件名 | directory-zip 可自动生成 |
| file size | 单资源按类型配置；批量视频 1GB、非视频 200MB，再叠加类型限制 | 显示当前大小和上限 |
| file format | 来自资源类型配置 | 显示允许格式 |
| sha1 | 上传前计算；他人已发行阻断 | 同用户已发行单资源可确认继续 |
| ignore | 目录 zip 和批量扫描使用 | `.git`、`.freelog`、`.freelog-auth`、密钥强排 |

## 7. 版本字段

| 字段 | 规则 | CLI 提示 |
|---|---|---|
| version | 首版固定 1.0.0；后续 semver 且大于 latestVersion | 推荐 patch +1 |
| description | 可空 | 可从 changelog 或输入生成 |
| runtimeVersion | 主题/插件等 runtime 类型需要 | 缺失时发版前提示 |
| reuseVersion | 只能引用已有版本 | 复用旧 sha1 创建新版本 |
| inputAttrs | 来自类型和文件解析 | 只读项不可编辑，可填项按类型校验 |
| customPropertyDescriptors | 仅类型支持时可提交 | 不支持时报错 |
| videoCover | 仅视频相关场景；CLI 可作为增强 | 不计作严格 Console parity |

## 8. 系统属性字段

| 类型 | 规则 |
|---|---|
| 文本 | 按 nullable、minLength、maxLength |
| 整数 | 必须整数；约 ±99999999999 安全范围；再叠加 min/max |
| 小数 | 必须数字；按 precision 截断；再叠加 min/max |
| 日期 | `YYYY-MM-DD`；受 startDate/limitDate |
| 日期时间 | `YYYY-MM-DD HH:mm:ss`；受 startDateTime/limitDateTime |
| 枚举 | 只能选配置项 |
| 只读属性 | 来自文件解析，不允许用户改 |

## 9. 自定义属性与资源选项

| 字段 | 规则 |
|---|---|
| 自定义属性名 | 必填；最多 50；不能重名 |
| 自定义属性 key | 必填；最多 30；英文字母开头；字母/数字/下划线；不能重复；至少 2 位 |
| 自定义属性描述 | 可空；最多 50 |
| 资源选项 key | 保存时有 `options_` 前缀；整体最多 30；同 key 规则 |
| 资源选项名 | 必填；最多 50；不能重名 |
| 资源选项描述 | 可空；最多 50 |
| 输入型资源选项默认值 | 最多 140；可空 |
| 选择型资源选项 | 至少 1 项，最多 30 项；每项必填、最多 140、不能重复；默认第一项 |

主题和插件的资源选项是一等能力；不能因为 CLI 入口是模板就跳过。

## 10. 策略字段

| 字段 | 规则 | 提示 |
|---|---|---|
| template | 新增策略普通路径必须先选模板 | “请选择授权策略模板” |
| policyName | 必填；2–20；同资源不重复 | 默认可用模板名，允许改 |
| policyText | 模板编译生成；同资源不重复 | 普通用户不手写 DSL |
| number param | 默认 min 0.01、precision 2；相对时间事件 min 1、precision 0 | 显示单位和精度 |
| select param | 从模板候选项选择 | 列表选择 |
| time param | 按模板要求输入 | 显示格式 |
| paid / transaction event | 需要结算或支付能力 | handoff 到 Console |
| last enabled policy | 已上架资源不能停用最后一条启用策略 | 阻断并解释 |

## 11. 上下架字段和门禁

| 动作 | 门禁 |
|---|---|
| online | resource 存在；owner 正确；非 frozen；latestVersion 存在；至少一条启用策略 |
| offline | resource 存在；owner 正确；非 frozen；用户确认 |
| policy set off | 如果资源已上架且这是最后启用策略，则禁止 |

## 12. 依赖授权字段

| 字段 | 规则 |
|---|---|
| dependencies | 直接依赖资源列表 |
| baseUpcastResources | 上抛依赖列表 |
| versionRange | 显式优先；未传可推荐 latest range |
| authExcludedItems | 必须来自授权树解释 |
| batchSignContracts | 批量配置里显式声明，用于预检 |
| paid contract | CLI 不支付，返回 Console 接力 |

发布前依赖授权不完整时，publish/collection publish 必须阻断。

## 13. 批量字段

| 字段 | 规则 |
|---|---|
| item count | 每个平台 createBatch 请求最多 20 |
| directory | 必须存在；扫描前应用 ignore |
| item title | 默认文件名去扩展名；最多 100 |
| item name | 规范化；1–60；批内不重复；平台不冲突 |
| item resourceTypeCode | 必须是支持批量的 leaf |
| item file size | 视频 1GB，非视频 200MB，再叠加类型限制 |
| item sha1 | 同用户或他人已发行都作为错误项 |
| policy | 非交互必须显式配置或显式允许无策略 |
| report | 长任务必须写，作为恢复依据 |

## 14. 合集字段

| 字段 | 规则 |
|---|---|
| collection type | 必须是合集类型 leaf |
| subjectType | 固定 4 |
| item resourceId | 必须存在，且可加入合集 |
| itemTitle | 最多 100 |
| item count add | 一次最多按 Console 行为处理 100 个 |
| display view | card / list |
| page size | card 默认 6；list 默认 10 |
| title source | 资源标题 / 序号 / 自定义 / 隐藏 |
| image/intro/sn | show / hide |
| order | 手动、标题、创建时间、资源更新时间 |
| isMergeCatalogueDraft | 目录项变化为 1；仅属性/展示变化为 0 |

## 15. RSS 字段

| 字段 | 规则 |
|---|---|
| feedUrl | 必填；更新时不能与原 URL 相同 |
| preview | 绑定前必须执行 |
| ownerEmail | 缺失阻断 |
| bound by self | 可继续，但提示 |
| bound by other | 阻断 |
| verifyCode | 提示发送到 ownerEmail 的 6 位验证码；`VerificationCodeInvalid` 或 `wrong_verified_code` 作为字段级验证码错误 |
| date range | `matchedItemCount` 超过 1000 时必填；不能未来；提交为日开始/日结束的 `YYYY-MM-DD HH:mm:ss` |
| sync status | 空、pending、running、sync 请求已发出但 progress 未刷新，都视为导入中或待确认 |
| failed items | 必须展示失败原因 |
| rss lock | 锁定手动 title/cover/intro/display/items/draft/update-status；不锁 tags |

## 16. collect-rules 字段

| 字段 | 用户语言 | 规则 |
|---|---|---|
| status | 是否启用自动收录 | 0/1 |
| serializeStatus | 持续收录或收录到此为止 | 0/1 |
| conditionType | 全部条件 / 任一条件 | 1/2 |
| field=resourceTitle | 资源标题 | 操作符：包含、不包含、开头、结尾 |
| field=authIdentity | 授权身份 | 操作符：包含、不包含、开头、结尾 |
| field=resourceTypeCode | 资源类型 | 操作符只能 EQUAL，值来自 leaf |
| title value | 标题条件值 | 必填，最多 100 |
| auth value | 授权身份条件值 | 必填，最多 60 |
| type value | 资源类型 code | 必须来自类型选择 |

启用自动收录但无条件时，CLI 必须提示用户补条件或明确确认 Console 等价空条件。

## 17. 错误提示规范

错误提示必须包含：

- 哪个字段错；
- 当前值是什么；
- 允许值或限制是什么；
- 是否写了本地；
- 是否写了平台；
- 下一步命令或操作。

示例：

```text
资源标题超长：当前 128 字，最多 100 字。
没有写入平台。请缩短标题后重试。
```
