# 08 · 异常场景与恢复策略

> **文档角色：** 汇总用户真实使用 CLI 时会遇到的错误、取消、冲突、外部依赖和未知结果，并定义产品层恢复策略。实现时不得只抛 raw error。

最后更新：2026-09-01

## 1. 错误处理原则

CLI 的失败提示必须回答：

1. 失败发生在哪一步？
2. 本地是否已写？
3. 平台是否已写？
4. 用户输入错、状态不满足、权限不足，还是平台未知？
5. 下一步怎么继续？

错误不能只有“失败了”。

## 2. 错误码语义

| code | 含义 | 是否可自动恢复 |
|---|---|---:|
| 1 | 未分类错误或平台异常 | 视具体 details |
| 2 | 未登录、凭据过期、凭据损坏、环境不一致 | 否，需要登录/清理 |
| 3 | 本地与远端冲突 | 否，需要用户选择方向 |
| 4 | 用户输入、字段、参数、状态门禁不满足 | 修正后可 |
| 5 | 授权、支付、签约、浏览器动作未完成 | 需 Console 或授权后继续 |

AI/CI 只依赖 code、JSON details、report 和 nextCommand，不读人类长文。

## 3. 本地写入异常

| 场景 | 本地状态 | 平台状态 | 处理 |
|---|---|---|---|
| init 写一半 | 可能有部分模板文件 | 未写平台 | 使用临时文件/原子写；提示可删除目录或重跑 |
| manifest 格式损坏 | 本地不可读 | 未必相关 | 停止，提示备份和修复 |
| state 丢失 | manifest 存在 | 平台资源可能存在 | 不猜，要求 bind/pull |
| state 环境不匹配 | state 属其它 env | 平台不可写 | 停止，要求切环境或重新 bind |
| report 写入失败 | 长任务恢复受损 | 可能已写平台 | 停止并输出已知 resourceId/versionId |

## 4. 凭据异常

| 场景 | 处理 |
|---|---|
| 未登录 | 提示 login 或 session/studio no-save 登录 |
| auth 文件损坏 | 明确报损坏，不回退 global |
| auth.key 丢失 | 提示无法解密，需重新 login |
| token 过期 | 提示重新 login |
| auth env 与命令 env 不一致 | code 2，禁止写平台 |
| session/studio 退出 | 清除内存凭据，不落盘 |

## 5. 环境和 owner 异常

| 场景 | 处理 |
|---|---|
| 写操作未指定 env 且没有安全默认 | 停止 |
| production 当前未开放 | 在请求前失败 |
| 当前账号不是 owner | 停止，显示当前账号和资源 owner |
| 资源不存在 | 提示检查 env/resourceId/authId |
| 资源 frozen | 禁止发版、策略、上下架；只允许查看 |

## 6. 类型选择异常

| 场景 | 处理 |
|---|---|
| 资源类型接口失败 | 不创建工程；允许重试 |
| 选中父类型 | 继续下钻，不允许确认 |
| 搜索无结果 | 回到逐级选择 |
| 类型不支持本地上传 | 阻断 publish |
| 主题/插件类型不可达 | 显示类型树问题，停止，不猜 code |
| package 模板多候选 leaf | 要求用户显式选择 |

## 7. 文件和版本异常

| 场景 | 处理 |
|---|---|
| 文件不存在 | code 4，提示路径 |
| 目录含义不明确 | 回到“目录 zip / 批量 / 合集”选择 |
| 构建失败 | 停在本地，不上传 |
| 文件格式不支持 | 显示类型允许格式 |
| 文件超大小 | 显示当前大小和上限 |
| sha1 被他人发行 | 阻断 |
| sha1 被自己发行 | 单资源可确认；批量作为错误项 |
| 属性解析失败 | 显示可重试/手填/停止选项 |
| version 不合法 | 显示 semver 示例 |
| version 不大于 latest | 推荐下一个版本 |
| createVersion 未知 | 记录 unknown，禁止盲重试 |

## 8. 策略异常

| 场景 | 处理 |
|---|---|
| 无可用模板 | 提示资源类型可能不支持，给 Console 链接 |
| 模板变量缺失 | 停在参数编辑 |
| 模板编译失败 | 不写平台，显示可编辑变量 |
| 翻译失败 | 不应用策略，允许重试 |
| policyName 重复 | 要求改名 |
| policyText 重复 | 阻断 |
| 交易事件需结算 | code 5 + Console 结算链接 |
| 已上架资源停用最后策略 | 阻断 |

## 9. 上下架异常

| 场景 | nextCommand |
|---|---|
| 无 latestVersion | publish |
| 无启用策略 | policy template apply |
| 策略全禁用 | policy set |
| owner 不符 | 切换账号或停止 |
| frozen | 无自动恢复 |
| offline 未确认 | 加 `--yes` 或 TTY 确认 |

## 10. 依赖授权异常

| 场景 | 处理 |
|---|---|
| 依赖资源不存在 | 阻断 publish |
| versionRange 不合法 | 提示格式 |
| 授权树不完整 | code 5，列出缺失路径 |
| 免费签约失败 | 列出失败项，可重试 |
| 付费签约 | Console handoff |
| 合集条目授权不完整 | 阻断 add/publish |
| 授权接口不可达 | 不继续写平台 |

## 11. 批量异常

| 场景 | 处理 |
|---|---|
| 目录空 | 停止 |
| 文件超限 | 单项 rejected |
| name 批内重复 | 自动去重并展示 |
| createBatch 部分失败 | report 标记 failed |
| 平台成功本地失败 | remote_succeeded_local_pending，恢复本地 |
| 远端结果未知 | remote_outcome_unknown，人工对账 |
| resume 输入变化 | 停止，提示重新扫描 |
| retry 包含 success 项 | 忽略 success，只处理失败项 |

## 12. 合集异常

| 场景 | 处理 |
|---|---|
| 合集类型不是 leaf | 返回类型选择 |
| 手动编辑 RSS 锁字段 | 阻断；但 tags 不属于当前 Console 锁字段 |
| 条目重复 | 跳过或更新已有条目 |
| 条目授权不完整 | 进入授权处理或阻断 |
| 子资源导入部分失败 | 成功项加入，失败项 report |
| 目录草稿和发布版本不一致 | 提示 collection publish |
| publish 时 RSS 导入中或 sync 请求刚发出 | 阻断或提示等待 |

## 13. RSS 异常

| 场景 | 处理 |
|---|---|
| URL 为空或不可访问 | 停止 |
| ownerEmail 缺失 | 阻断，说明无法验证 |
| feed 已被他人绑定 | 阻断 |
| feed 已被自己绑定 | 提示可继续 |
| 验证码错误 | 停在验证码字段；AI/CI 返回字段级错误，不当作普通平台异常 |
| matchedItemCount 超过 1000 | 要求日期范围并重新 preview；日期不能未来 |
| 日期范围包含未来 | 阻断 |
| 更新 URL 与原 URL 相同 | 阻断 |
| 更新 URL GUID 风险大 | 按 Console 公式二次确认 |
| 同步中或等待 progress 刷新 | 禁止冲突编辑和重复 sync |
| failed-items 存在 | 展示失败原因和修复建议 |

## 14. collect-rules 异常

| 场景 | 处理 |
|---|---|
| 启用但无条件 | 提示补条件或确认空条件 |
| 条件字段不支持 | 只能选三种字段 |
| 操作符不支持 | 按字段过滤 |
| 值为空 | 停在当前条件 |
| 标题值超 100 | 阻断 |
| 授权身份值超 60 | 阻断 |
| 类型值不是 leaf | 回到类型选择 |
| STARTS_WITH 前缀歧义 | 标记待实测，不用旧实现猜 |

## 15. Console 接力

CLI 遇到浏览器专属动作时输出：

```json
{
  "ok": false,
  "code": 5,
  "reason": "需要在 Console 完成签约或支付",
  "actionUrl": "<console-url>",
  "nextCommand": "freelog-cli publish --resume <report> --env <env>"
}
```

适用：

- 支付；
- 结算信息；
- 复杂签约；
- 浏览器验证码页面；
- 图片裁剪；
- 节点/展品/主题激活边界。

接力不是失败的尽头，而是流程 checkpoint。

## 16. 成功、取消和未知

| 结果 | 定义 |
|---|---|
| success | 平台结果和本地记录都确认 |
| cancelled | 用户确认前取消，没有平台写入 |
| local_only | 只写本地工程 |
| remote_succeeded_local_pending | 平台成功，本地待恢复 |
| remote_outcome_unknown | 不能确认平台是否执行 |
| handoff_required | 需要 Console 完成 |

所有长任务必须能把这些状态写入 report。
