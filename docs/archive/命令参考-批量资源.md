# 批量资源（batch）— 已归档

> **不采用**（无旧命令兼容）。目标态见 [新方案 · 命令面](../新方案/产品设计/02-命令面.md)。本文仅溯源。

操作 `freelog.batch-resources.config.js/ts`，批量管理多个单品资源。

通用选项：`-c, --config <path>` 指定配置文件（默认 `freelog.batch-resources.config.js`）。

## 典型流程

```bash
freelog-cli batch init ./chapters   # 扫描目录生成配置
freelog-cli batch list
freelog-cli batch create            # 交互选择，或 -f 全部创建
freelog-cli batch publish
freelog-cli batch add-to-collection # 写入合集 items
```

## 命令一览

### 配置与列表

| 命令 | 说明 |
|------|------|
| `batch init [directory]` | 初始化配置；可扫描目录 |
| `batch add [filePath]` | 添加资源项 |
| `batch list` | 列出资源项 |
| `batch edit <name>` | 编辑单个资源项 |
| `batch remove [names...]` | 从配置移除（不删服务器资源） |

### 创建与发布

| 命令 | 说明 |
|------|------|
| `batch create [names...]` | 在平台创建资源，回填 `resourceId` |
| `batch update [names...]` | 更新资源元信息 |
| `batch update-version [names...]` | 更新版本配置 |
| `batch publish` | 批量发布版本 |
| `batch publish-one <name>` | 发布单个资源 |
| `batch update-and-publish [names...]` | 更新版本并发布 |

### 依赖（batch dep）

| 命令 | 说明 |
|------|------|
| `batch dep add <name> <depId>` | 添加依赖 |
| `batch dep list [name]` | 查看依赖 |
| `batch dep remove <name> <depId>` | 移除依赖 |
| `batch dep update <name> <depId> [range]` | 更新版本范围 |
| `batch dep change <name> <depId> [range]` | 修改依赖配置 |
| `batch dep sync <name> [target]` | 同步依赖版本 |

### 策略（batch policy）

| 命令 | 说明 |
|------|------|
| `batch policy add <name>` | 添加授权策略 |
| `batch policy list [name]` | 查看策略 |

### 状态与同步

| 命令 | 说明 |
|------|------|
| `batch online [names...]` | 上架 |
| `batch offline [names...]` | 下架 |
| `batch sync [names...]` | 从平台同步资源信息 |
| `batch sync-version [names...]` | 同步版本信息 |
| `batch load-from-collection [config]` | 从合集配置加载到批量配置 |
| `batch add-to-collection [config]` | 将已发布资源写入合集 `items` |

## 配置文件

```javascript
module.exports = {
  defaults: {
    resourceType: [],
    resourceTypeCode: '',
    version: '1.0.0',
    filePath: './dist',
    // intro, coverImages, tags, description ...
  },
  resources: [
    {
      name: 'chapter-01',       // 命令中使用的唯一标识
      resourceName: 'chapter-01',
      resourceTitle: '第一章',
      filePath: './chapters/01/dist',
      resourceId: '',           // create 后回填
      versionId: '',            // publish 后回填
      skip: false,              // true 则跳过批量操作
    },
  ],
};
```

字段由命令自动回填：`resourceId`（create）、`versionId` / `fileSha1`（publish）。
