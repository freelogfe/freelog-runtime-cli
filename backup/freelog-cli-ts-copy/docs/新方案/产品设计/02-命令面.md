# 产品设计：目标命令面

> 实现步骤 → [开发设计/02-命令规格.md](../开发设计/02-命令规格.md) · 退出码 → [01-结论与原则](./01-结论与原则.md)  
> **唯一用户命令面** · 无旧命令兼容

「实施」：`现有` / `增强` / `新增` = 相对今日代码库。

## 1. 全局

| 命令 | 作用 | 主要选项 | 实施 |
|------|------|----------|------|
| `login` / `logout` | 登录 / 退出 | `-g`；`--test` | 现有 |
| `status` | owner + 同步 + 平台发版草稿 + 登录态 | `--json`；资源/版本/合集维度 | 增强 |
| `pull` | 平台 → 本地缓存 | `--version`；`--collection`；`--all` | 新增 |
| `init [name]` | 脚手架 + 空配置壳 | 主题 / 插件 / 合集等 | 现有 |

写命令通用选项：`--cwd` · `--yes` · `--no-auto-pull` ·（列表类）`--json`。

## 2. 单品（一目录 = 一资源）

| 命令 | 作用 | 平台能力 | 主要选项 | 实施 |
|------|------|----------|----------|------|
| `create` | 创建资源壳 | `Resource.create` | `--title` `--type` `--name`；`--from-dir` | 增强 |
| `updateVersion` | 写**本地**版本意图 | — | `--version` `--description` `--filePath` | 现有 |
| `publish` | 正式 `createVersion` | createVersion | `--bump`；未授权 exit 5 | 增强 |
| `draft push` | 本地 → 平台发版草稿 | saveVersionsDraft | `--force`；`--upload` | 新增 |
| `draft pull` | 平台草稿 → 本地 | lookDraft | 保留 `filePath` | 新增 |
| `draft discard` | 删平台发版草稿 | deleteResourceDraft | — | 新增 |
| `policy add` | 加策略 | update addPolicies | **`--from-file` 主路径**；JSON schema → [开发命令规格 §6](../开发设计/02-命令规格.md) | 增强 |
| `policy list` | 查 / 启停策略 | updatePolicies | `--json` | 现有 |
| `update` | 改 listing | update | `--title` `--intro` `--cover` `--tags` | 增强 |
| `online` / `offline` | 上 / 下架 | **严格** resourceOnline / status4 | `--yes`；online 须 latestVersion+≥1 启用策略；**非**软 `status:1` | 现有 |
| `dep add\|remove\|list\|update` | 依赖（随下版 publish） | dependencies | `-v`；`list --json` | 现有 |
| `version edit` | 改已发行版元数据 | updateResourceVersionInfo | `--description` 等 | 新增 |
| `dep auth` | 声明式补签 | batchSignContracts 等 | `--policy-map`；schema → [开发命令规格 §6](../开发设计/02-命令规格.md) | Phase 5 |
| `contract list` | 授权方合约只读 | Contract.contracts | `--json` | P2 |

### 版本三态

| 态 | 存哪 | 命令 | Console 续编 |
|----|------|------|--------------|
| 本地意图 | `freelog.version.config` | `updateVersion` / `dep *` | 否 |
| 平台草稿 | `…/versions/drafts` | `draft push\|pull\|discard` | 是 |
| 正式版本 | `…/versions/{ver}` | `publish` / `version edit` | 已发行 |

```text
updateVersion →（可选）draft push →（浏览器可改）→ draft pull → publish
```

合集**目录**草稿走 `collection item *`（`catalogues/drafts`）。合集发版表单草稿见 [开发设计/04-草稿转换层](../开发设计/04-草稿转换层.md) 二期。

## 3. 合集

| 命令 | 作用 | 平台能力 | 主要选项 | 实施 |
|------|------|----------|----------|------|
| `collection create` | 合集壳 | create subjectType=4 | `--title` `--type` | 现有 |
| `collection item add` | 单品入 draft | addResourceItems_Draft | `<resourceId\|路径>` | 增强 |
| `collection item remove` | 移除 | deleteCollectionItems_Draft | `<id>` | 现有 |
| `collection item update` | 改条目标题等 | updateCollectionItemsInfo_Draft | `--title` | 新增 |
| `collection item reorder` | 排序 | reorder | `--order-file` 或 id 列表 | 新增 |
| `collection update` | listing + 展示 | update + catalogueProperty | `--display-*` | 增强 |
| `collection policy add\|list` | 策略 | addPolicies | `--from-file`（同 policy.json schema） | 现有 |
| `collection publish` | 合并 draft 并发布 | updateCollection isMergeCatalogueDraft | 依赖未授权同构 exit 5（见命令规格） | 增强 |
| `online` / `collection unpublish` | 上 / 下架（合集目录同单品） | **严格** resourceOnline / status=4 | `--yes`；**非**软 status:1 | 现有 |
| `collection collect-rules set\|get` | 自动收录 | setCollectRules | flags / `--from-file` | 新增 |
| `collection rss send-code` | 发验证码到邮箱 | Rss.sendVerificationCode | `<feedUrl>`；**人机混合** | 新增 |
| `collection rss bind\|sync` | 绑定 / 同步 | bindRssFeed / syncBinding | `bind --code` 必填（码来自邮箱；CI 人工注入） | 新增 |
| `collection logs` | 变更日志 | getCollectionUpdateLogs | `--json` | P2 |

## 4. 明确删除

| 旧入口 | 处理 |
|--------|------|
| `batch *` | 删除 → `--from-dir` / 循环 `--cwd` |
| `syncr` / `syncv` | 删除 → `pull` |
| `publish --draft` | 删除 → `draft push` |
| 手改 config | 禁止 |
