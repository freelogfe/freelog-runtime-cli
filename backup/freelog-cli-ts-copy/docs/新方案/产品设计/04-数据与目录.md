# 产品设计：数据与目录

> Config 字段明细 → [开发设计/06-Config字段.md](../开发设计/06-Config字段.md) · Owner 实现 → [开发设计/01-Owner与同步.md](../开发设计/01-Owner与同步.md)

## 1. 单品项目

```text
my-theme/
├── src/ ...
├── dist/                          # publish 的 filePath
├── freelog.resource.config.js
└── freelog.version.config.js
```

工作目录即资源目录；命令默认读当前目录。

## 2. 合集项目（推荐）

合集壳在根；每个单品为独立子目录（各自走单品命令）。

```text
my-novel/
├── freelog.collection.config.js
└── chapters/
    ├── 01-intro/
    │   ├── dist/ 或内容文件
    │   ├── freelog.resource.config.js
    │   └── freelog.version.config.js
    └── 02-chapter/
        └── …
```

```bash
freelog-cli create --cwd ./chapters/01-intro
freelog-cli publish --cwd ./chapters/01-intro
```

## 3. 多文件一次发行（图集等）

输入可为扁平目录：

```text
photos/
├── a.jpg
├── b.jpg
└── c.jpg
```

`create --from-dir` 成功后，为每个文件生成子目录并写入带 owner 的 config：

```text
photos/
├── a.jpg / b.jpg / c.jpg
├── a/   → freelog.resource.config.js + freelog.version.config.js
├── b/
└── c/
```

文件名无法作安全目录名时用 `.freelog/<safeName>/`。后续对该资源用 `--cwd` 或进入子目录执行单品命令。

约束（数量、类型、版本）见 [开发设计/03-字段约束](../开发设计/03-字段约束.md)「多文件」。
