# resource-policy-lang 项目解析

## 项目概述

`@freelog/resource-policy-lang` 是 Freelog 平台的**资源策略语言编译器**，用于将人类可读的策略文本编译成状态机 JSON，实现资源授权管理。

### 项目定位

```
策略文本（DSL）  ──编译──>  状态机 JSON  ──执行──>  资源授权控制
```

这是一个典型的**领域特定语言（DSL）编译器**，使用 ANTLR4 实现。

## 核心功能

| 功能 | API | 说明 |
|------|-----|------|
| 编译 | `compile()` | 将策略文本编译为状态机 JSON |
| 反编译 | `decompile()` | 将状态机 JSON 还原为策略文本 |
| 格式化 | `reformat()` | 格式化策略文本 |
| 报告 | `report()` | 生成合约报告（中文描述） |
| 状态转换 | `transfer()` | 处理状态机状态转换 |
| 路由解析 | `parseRoutes()` | 解析状态机路径 |

## 业务场景

### 数字资源授权

Freelog 是一个数字资源交易平台，资源策略语言用于定义：
- 谁可以访问资源（受众）
- 访问资源的条件（事件）
- 授权的生命周期（状态机）

### 典型用例

1. **订阅服务**：用户支付后获得一段时间的访问权限
2. **免费试用**：用户可以免费试用一段时间
3. **一次性购买**：用户支付后获得永久访问权限
4. **按量计费**：根据访问次数收费

## 目录结构

```
resource-policy-lang/
├── index.js                 # 主入口，导出所有 API
├── interface.ts             # TypeScript 接口定义
├── gen/                     # ANTLR4 生成的代码
│   ├── LexToken.js          # 词法分析器
│   ├── resourcePolicy.js    # 语法分析器
│   ├── resourcePolicyVisitor.js  # Visitor 接口
│   └── resourcePolicyListener.js # Listener 接口
├── src/translate/           # 翻译模块
│   ├── index.ts             # 翻译入口
│   ├── strategy/            # 事件翻译策略
│   └── tools/               # 工具类
├── resources/               # 资源文件
│   ├── event_definition.json    # 事件定义
│   └── translate_templates.json # 翻译模板
├── UserPolicyCustomVisitor.js   # 自定义 Visitor
├── UserPolicyDecompiler.js      # 反编译器
└── UserPolicyReformatVisitor.js # 格式化 Visitor
```
