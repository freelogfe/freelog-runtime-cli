## 🛠️ 环境准备

### 1. 安装 MongoDB

**Windows:**
```bash
# 下载并安装 MongoDB Community Server
# https://www.mongodb.com/try/download/community

# 启动服务
net start MongoDB
```

**Docker（推荐）:**
```bash
docker run -d \
  --name mongodb \
  -p 27017:27017 \
  -v mongodb_data:/data/db \
  mongo:latest
```

**Mac (Homebrew):**
```bash
brew tap mongodb/brew
brew install mongodb-community
brew services start mongodb-community
```

### 2. 安装 Node.js 依赖

```bash
# 安装 MongoDB 驱动（如果运行 JavaScript 示例）
npm install mongodb

# 项目已包含 Typegoose 和 Mongoose
# 无需额外安装
```

### 3. 验证安装

```bash
# 连接 MongoDB
mongosh

# 或使用旧版
mongo
```

### 2. 在项目中使用

参考您的现有代码：

```typescript
// src/model/lottery-resource.ts
import {EntityModel} from "@midwayjs/typegoose";
import {Prop} from "@typegoose/typegoose";

@EntityModel()
export class LotteryResource {
    @Prop({required: true, unique: true, type: () => String})
    public resourceId: string;
    // ... 其他字段
}
```

```typescript
// src/service/lottery-resource-service.ts
import {InjectEntityModel} from "@midwayjs/typegoose";
import {ReturnModelType} from "@typegoose/typegoose";

@Provide()
export class LotteryResourceService {
    @InjectEntityModel(LotteryResource)
    lotteryResourceDao: ReturnModelType<typeof LotteryResource>;

    async list(...) {
        // 使用 dao 进行查询
        return await this.lotteryResourceDao.find(condition);
    }
}
```

## ❓ 常见问题

### Q: 如何连接远程 MongoDB？
A: 修改连接字符串：
```javascript
const uri = 'mongodb://username:password@host:port/database';
```

### Q: 事务为什么无法运行？
A: 事务需要副本集或分片集群，单机 MongoDB 不支持。可以使用 Docker 搭建副本集。

### Q: TypeScript 示例如何运行？
A: 需要先编译 TypeScript：
```bash
tsc examples/06-typegoose-practice.ts
node examples/06-typegoose-practice.js
```

### Q: 如何查看查询性能？
A: 使用 `explain()` 方法：
```javascript
db.collection.find({}).explain('executionStats');
```
