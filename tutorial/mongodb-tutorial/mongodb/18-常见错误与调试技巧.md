# 第十八章：常见错误与调试技巧

## 18.1 连接错误

### 错误 1：无法连接到 MongoDB

```javascript
// 错误信息
MongoServerError: connect ECONNREFUSED 127.0.0.1:27017

// 原因
// 1. MongoDB 服务未启动
// 2. 端口被占用
// 3. 防火墙阻止连接

// 解决方案
// Windows
net start MongoDB

// Linux
sudo systemctl start mongod

// 检查端口
netstat -an | findstr 27017  // Windows
netstat -an | grep 27017     // Linux
```

### 错误 2：认证失败

```javascript
// 错误信息
MongoServerError: Authentication failed

// 原因
// 1. 用户名或密码错误
// 2. 数据库名称错误
// 3. 用户权限不足

// 解决方案
// 1. 检查连接字符串
mongodb://username:password@localhost:27017/dbname

// 2. 检查用户权限
use admin
db.getUser("username")

// 3. 重新创建用户
db.createUser({
  user: "username",
  pwd: "password",
  roles: [{ role: "readWrite", db: "dbname" }]
})
```

### 错误 3：副本集未初始化

```javascript
// 错误信息
MongoServerError: This node was not started with replication enabled

// 原因
// MongoDB 配置了副本集，但未初始化

// 解决方案
// 1. 初始化副本集
rs.initiate({
  _id: "rs0",
  members: [{ _id: 0, host: "localhost:27017" }]
})

// 2. 或移除副本集配置
// 编辑 mongod.cfg，删除 replication 配置
```

## 18.2 查询错误

### 错误 1：ObjectId 格式错误

```javascript
// 错误信息
BSONError: input must be a 24 character hex string

// 原因
// ObjectId 字符串格式不正确

// ❌ 错误示例
db.users.find({ _id: "invalid-id" })

// ✅ 正确示例
db.users.find({ _id: ObjectId("507f1f77bcf86cd799439011") })

// 验证 ObjectId
ObjectId.isValid("507f1f77bcf86cd799439011")  // true
```

### 错误 2：字段不存在

```javascript
// 错误信息
// 查询返回空结果（不是错误，但可能不符合预期）

// 原因
// 1. 字段名拼写错误
// 2. 字段不存在
// 3. 字段值为 null

// 解决方案
// 1. 检查字段是否存在
db.users.findOne({ name: "张三" })

// 2. 使用 $exists
db.users.find({ email: { $exists: true } })

// 3. 检查字段类型
db.users.find({ age: { $type: "int" } })
```

### 错误 3：正则表达式错误

```javascript
// 错误信息
SyntaxError: Invalid regular expression

// 原因
// 正则表达式语法错误

// ❌ 错误示例
db.users.find({ name: /[unclosed/ })

// ✅ 正确示例
db.users.find({ name: /closed/ })
```

## 18.3 更新错误

### 错误 1：忘记使用 $set

```javascript
// ❌ 错误：会替换整个文档
db.users.updateOne(
  { name: "张三" },
  { age: 26 }  // 错误：会删除其他字段
)

// ✅ 正确：使用 $set
db.users.updateOne(
  { name: "张三" },
  { $set: { age: 26 } }
)
```

### 错误 2：更新多个文档

```javascript
// ❌ 错误：updateOne 只更新第一个匹配的文档
db.users.updateOne(
  { status: "inactive" },
  { $set: { status: "active" } }
)

// ✅ 正确：使用 updateMany
db.users.updateMany(
  { status: "inactive" },
  { $set: { status: "active" } }
)
```

### 错误 3：数组操作错误

```javascript
// ❌ 错误：直接赋值会替换整个数组
db.users.updateOne(
  { name: "张三" },
  { hobbies: ["新爱好"] }
)

// ✅ 正确：使用 $push
db.users.updateOne(
  { name: "张三" },
  { $push: { hobbies: "新爱好" } }
)
```

## 18.4 索引错误

### 错误 1：索引键大小限制

```javascript
// 错误信息
MongoServerError: index key too large to index

// 原因
// 索引键超过 1024 字节限制

// 解决方案
// 1. 使用部分索引
db.users.createIndex(
  { description: 1 },
  { partialFilterExpression: { description: { $exists: true } } }
)

// 2. 使用哈希索引
db.users.createIndex({ description: "hashed" })

// 3. 索引字段的前缀
db.users.createIndex({ "description": "text" })
```

### 错误 2：重复键错误

```javascript
// 错误信息
MongoServerError: E11000 duplicate key error

// 原因
// 违反唯一索引约束

// 解决方案
// 1. 检查重复数据
db.users.aggregate([
  { $group: { _id: "$email", count: { $sum: 1 } } },
  { $match: { count: { $gt: 1 } } }
])

// 2. 删除重复数据
db.users.aggregate([
  { $group: { _id: "$email", ids: { $push: "$_id" } } },
  { $match: { ids: { $size: { $gt: 1 } } } }
]).forEach(doc => {
  doc.ids.shift();  // 保留第一个
  db.users.deleteMany({ _id: { $in: doc.ids } });
});
```

## 18.5 聚合错误

### 错误 1：内存限制

```javascript
// 错误信息
MongoServerError: Exceeded memory limit

// 原因
// 聚合管道处理的数据量超过内存限制（默认 100MB）

// 解决方案
// 1. 使用 allowDiskUse
db.users.aggregate([
  { $group: { ... } }
], { allowDiskUse: true })

// 2. 优化聚合管道
// - 尽早使用 $match 过滤
// - 使用 $project 减少字段
// - 使用 $limit 限制结果
```

### 错误 2：字段路径错误

```javascript
// 错误信息
MongoServerError: FieldPath field names may not start with '$'

// 原因
// 字段路径语法错误

// ❌ 错误示例
db.users.aggregate([
  { $project: { "$name": 1 } }
])

// ✅ 正确示例
db.users.aggregate([
  { $project: { name: 1 } }
])

// 使用变量时
db.users.aggregate([
  { $project: { name: "$name" } }
])
```

## 18.6 事务错误

### 错误 1：事务需要副本集

```javascript
// 错误信息
MongoServerError: Transaction numbers are only allowed on a replica set member

// 原因
// 单节点 MongoDB 不支持事务

// 解决方案
// 1. 配置副本集
rs.initiate({
  _id: "rs0",
  members: [{ _id: 0, host: "localhost:27017" }]
})

// 2. 或使用单文档操作（不需要事务）
```

### 错误 2：事务超时

```javascript
// 错误信息
MongoServerError: Transaction 1 has been aborted

// 原因
// 事务执行时间过长

// 解决方案
// 1. 增加超时时间
const session = client.startSession();
session.startTransaction({
  maxTimeMS: 30000  // 30 秒
});

// 2. 优化事务内的操作
// - 减少操作数量
// - 使用批量操作
```

## 18.7 调试技巧

### 1. 启用调试日志

```typescript
// Mongoose
mongoose.set('debug', true);

// 原生驱动
const client = new MongoClient(uri, {
  loggerLevel: 'debug'
});
```

### 2. 使用 explain 分析查询

```javascript
// 查看查询计划
db.users.find({ name: "张三" }).explain()

// 详细执行统计
db.users.find({ name: "张三" }).explain("executionStats")

// 分析性能
const explain = db.users.find({ name: "张三" }).explain("executionStats");
console.log("执行时间:", explain.executionStats.executionTimeMillis);
console.log("扫描文档数:", explain.executionStats.totalDocsExamined);
console.log("返回文档数:", explain.executionStats.nReturned);
```

### 3. 使用日志

```typescript
// 记录查询日志
async function findUser(id: string) {
  console.log('查询用户:', id);
  try {
    const user = await User.findById(id);
    console.log('查询结果:', user ? '找到' : '未找到');
    return user;
  } catch (error) {
    console.error('查询错误:', error);
    throw error;
  }
}
```

### 4. 验证数据

```javascript
// 验证文档结构
db.users.find().forEach(doc => {
  if (!doc.name || typeof doc.name !== 'string') {
    print('无效文档:', doc._id);
  }
});

// 检查数据类型
db.users.aggregate([
  {
    $project: {
      nameType: { $type: "$name" },
      ageType: { $type: "$age" }
    }
  }
]);
```

### 5. 性能分析

```javascript
// 启用性能分析
db.setProfilingLevel(1, { slowms: 100 });

// 查看慢查询
db.system.profile.find().sort({ ts: -1 }).limit(10).pretty();

// 分析查询模式
db.system.profile.aggregate([
  {
    $group: {
      _id: "$command.find",
      count: { $sum: 1 },
      avgDuration: { $avg: "$duration" }
    }
  },
  { $sort: { avgDuration: -1 } }
]);
```

## 18.8 常见错误速查表

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| `ECONNREFUSED` | 服务未启动 | 启动 MongoDB 服务 |
| `Authentication failed` | 认证失败 | 检查用户名密码 |
| `duplicate key error` | 唯一索引冲突 | 检查重复数据 |
| `index key too large` | 索引键过大 | 使用部分索引或哈希索引 |
| `Transaction numbers are only allowed on a replica set` | 单节点不支持事务 | 配置副本集 |
| `Exceeded memory limit` | 聚合内存超限 | 使用 `allowDiskUse: true` |
| `FieldPath field names may not start with '$'` | 字段路径错误 | 检查字段名语法 |
| `input must be a 24 character hex string` | ObjectId 格式错误 | 验证 ObjectId 格式 |

## 18.10 最佳实践

### 1. 错误处理

```typescript
// ✅ 好：完整的错误处理
async function findUser(id: string) {
  try {
    if (!ObjectId.isValid(id)) {
      throw new Error('Invalid ObjectId');
    }
    const user = await User.findById(id);
    if (!user) {
      throw new NotFoundError('User not found');
    }
    return user;
  } catch (error) {
    logger.error('查找用户失败', { id, error });
    throw error;
  }
}
```

