# 第二十一章：MongoDB 分片集群详解

## 21.1 分片集群基础

### 什么是分片？

分片（Sharding）是 MongoDB 的水平扩展方案，将数据分布到多个服务器（分片）上，实现数据的分布式存储和查询。

### 分片集群组件

```
┌─────────────┐
│  客户端应用  │
└──────┬──────┘
       │
┌──────▼──────┐
│  Mongos     │ ← 路由服务器（可以有多个）
│  (Router)   │
└──────┬──────┘
       │
   ┌───┴───┐
   │       │
┌──▼──┐ ┌─▼──┐
│分片1 │ │分片2│ ← 数据分片（副本集）
└─────┘ └────┘
   │       │
┌──▼──┐ ┌─▼──┐
│配置服务器│ │配置服务器│ ← 配置服务器（副本集）
└─────┘ └────┘
```

### 分片集群组件说明

| 组件 | 说明 | 数量 |
|------|------|------|
| **Mongos** | 路由服务器，客户端连接入口 | 多个（高可用） |
| **Shard** | 数据分片，存储实际数据 | 多个（副本集） |
| **Config Server** | 配置服务器，存储集群元数据 | 3个（副本集） |

## 21.2 分片键（Shard Key）

### 什么是分片键？

分片键是用于将数据分布到不同分片的字段或字段组合。

### 分片键选择原则

1. **高基数**：值种类多，分布均匀
2. **低频率**：不会频繁更新
3. **查询模式**：匹配常用查询模式
4. **避免热点**：避免数据倾斜

### 分片键类型

```javascript
// 单字段分片键
sh.shardCollection("mydb.users", { userId: 1 })

// 复合分片键
sh.shardCollection("mydb.orders", { userId: 1, orderDate: 1 })

// 哈希分片键（均匀分布）
sh.shardCollection("mydb.logs", { _id: "hashed" })
```

### 分片键示例

```javascript
// ✅ 好：用户ID（高基数，分布均匀）
sh.shardCollection("mydb.users", { userId: 1 })

// ✅ 好：订单ID（唯一，分布均匀）
sh.shardCollection("mydb.orders", { orderId: 1 })

// ⚠️ 一般：时间戳（可能造成热点）
sh.shardCollection("mydb.events", { timestamp: 1 })

// ❌ 差：状态字段（低基数，分布不均）
sh.shardCollection("mydb.orders", { status: 1 })
```

## 21.3 分片集群部署

### 部署步骤

```bash
# 1. 启动配置服务器副本集
mongod --configsvr --replSet configReplSet --dbpath /data/configdb --port 27019

# 2. 初始化配置服务器
mongosh --port 27019
rs.initiate({
  _id: "configReplSet",
  members: [
    { _id: 0, host: "localhost:27019" }
  ]
})

# 3. 启动分片服务器（副本集）
mongod --shardsvr --replSet shardReplSet --dbpath /data/shard1 --port 27018

# 4. 初始化分片副本集
mongosh --port 27018
rs.initiate({
  _id: "shardReplSet",
  members: [
    { _id: 0, host: "localhost:27018" }
  ]
})

# 5. 启动 Mongos 路由服务器
mongos --configdb configReplSet/localhost:27019 --port 27017

# 6. 连接到 Mongos 并配置分片
mongosh --port 27017
sh.addShard("shardReplSet/localhost:27018")
sh.enableSharding("mydb")
sh.shardCollection("mydb.users", { userId: 1 })
```

## 21.4 分片操作

### 启用分片

```javascript
// 启用数据库分片
sh.enableSharding("mydb")

// 对集合进行分片
sh.shardCollection("mydb.users", { userId: 1 })
```

### 查看分片状态

```javascript
// 查看分片列表
sh.status()

// 查看分片信息
sh.status(true)  // 详细信息

// 查看集合分片信息
sh.status().databases.find(db => db.database === "mydb")
```

### 添加分片

```javascript
// 添加新分片
sh.addShard("shardReplSet2/localhost:27020")

// 查看分片列表
sh.status().shards
```

### 移除分片

```javascript
// 1. 迁移数据
sh.disableBalancing("mydb.users")
sh.moveChunk("mydb.users", { userId: MinKey }, "shardReplSet2")

// 2. 移除分片
sh.removeShard("shardReplSet2")
```

## 21.5 数据分布

### 块（Chunk）

```javascript
// 查看块分布
sh.status().collections.find(coll => coll._id === "mydb.users")

// 块大小（默认 64MB）
sh.getBalancerState()
sh.setBalancerState(false)  // 禁用平衡器
sh.setBalancerState(true)   // 启用平衡器
```

### 数据迁移

```javascript
// 手动迁移块
sh.moveChunk(
  "mydb.users",
  { userId: ObjectId("...") },
  "shardReplSet2"
)

// 拆分块
sh.splitAt("mydb.users", { userId: ObjectId("...") })

// 合并块
sh.mergeChunks(
  "mydb.users",
  { userId: ObjectId("...") },
  { userId: ObjectId("...") }
)
```

## 21.6 查询路由

### 定向查询（Targeted Query）

```javascript
// 包含分片键的查询 → 路由到特定分片
db.users.find({ userId: "user123" })  // 高效

// 范围查询包含分片键前缀
db.users.find({ userId: "user123", orderDate: { $gte: ... } })  // 高效
```

### 分散查询（Scatter-Gather Query）

```javascript
// 不包含分片键的查询 → 查询所有分片
db.users.find({ name: "张三" })  // 低效

// 排序不包含分片键
db.users.find().sort({ createdAt: -1 })  // 低效
```

### 查询优化

```javascript
// ✅ 好：查询包含分片键
db.users.find({ userId: "user123" })

// ⚠️ 一般：范围查询
db.users.find({ userId: { $gte: "user100", $lte: "user200" } })

// ❌ 差：不包含分片键
db.users.find({ name: "张三" })
```

## 21.7 实际应用场景

### 场景 1：用户数据分片

```javascript
// 按用户ID分片
sh.enableSharding("socialdb")
sh.shardCollection("socialdb.users", { userId: 1 })
sh.shardCollection("socialdb.posts", { userId: 1, postId: 1 })
sh.shardCollection("socialdb.comments", { userId: 1, commentId: 1 })

// 查询用户相关数据（高效）
db.posts.find({ userId: "user123" })
db.comments.find({ userId: "user123" })
```

### 场景 2：时间序列数据分片

```javascript
// 按时间分片
sh.enableSharding("logsdb")
sh.shardCollection("logsdb.events", { timestamp: 1, eventId: 1 })

// 查询特定时间范围（高效）
db.events.find({
  timestamp: {
    $gte: ISODate("2024-01-01"),
    $lt: ISODate("2024-02-01")
  }
})
```

### 场景 3：多租户应用分片

```javascript
// 按租户ID分片
sh.enableSharding("multitenantdb")
sh.shardCollection("multitenantdb.tenants", { tenantId: 1 })
sh.shardCollection("multitenantdb.data", { tenantId: 1, dataId: 1 })

// 查询租户数据（高效）
db.data.find({ tenantId: "tenant123" })
```

## 21.9 最佳实践

### 1. 选择合适的分片键

```javascript
// ✅ 好：高基数、分布均匀
sh.shardCollection("mydb.users", { userId: 1 })

// ❌ 差：低基数、分布不均
sh.shardCollection("mydb.orders", { status: 1 })
```

### 2. 避免热点

```javascript
// ✅ 好：使用复合分片键避免热点
sh.shardCollection("mydb.events", { 
  timestamp: 1, 
  eventId: 1 
})

// ❌ 差：单一时间戳可能造成热点
sh.shardCollection("mydb.events", { timestamp: 1 })
```

### 3. 查询模式匹配

```javascript
// ✅ 好：分片键匹配常用查询
// 常用查询：db.users.find({ userId: "..." })
sh.shardCollection("mydb.users", { userId: 1 })

// ❌ 差：分片键不匹配查询
// 常用查询：db.users.find({ email: "..." })
sh.shardCollection("mydb.users", { userId: 1 })  // 错误
```

### 4. 监控和调优

```javascript
// ✅ 好：定期检查数据分布
sh.status()

// ✅ 好：监控平衡器
sh.getBalancerState()

// ✅ 好：调整块大小（如果需要）
use config
db.settings.save({ _id: "chunksize", value: 128 })  // 128MB
```

## 21.10 注意事项

### 1. 分片键不可变

```javascript
// ⚠️ 注意：分片键一旦设置，不能修改

```

```javascript
// ⚠️ 注意：平衡器迁移数据时可能影响性能
// 可以在低峰期禁用平衡器

// 执行维护操作
sh.setBalancerState(true)
```
