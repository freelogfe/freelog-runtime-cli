## 主要变更

### 配置文件拆分
原来的单一配置文件 `freelog.config.*` 已拆分为：

1. **freelog.resource.config.*** - 资源级别信息
   - resourceId, resourceName, resourceType
   - intro, coverImages, tags
   
2. **freelog.version.config.*** - 版本级别信息
   - version, fileSha1, filename
   - dependencies, description
   - buildPath, fileTarget

### 新增命令

```bash
# 创建资源
freelog-cli create

# 更新资源信息
freelog-cli update --intro "介绍" --cover "url1,url2"
```

### 增强命令

```bash
# sync 命令增强
freelog-cli sync                    # 同步资源和版本信息
freelog-cli sync <resourceId>       # 指定资源同步
freelog-cli sync -v 1.0.0           # 同步指定版本
freelog-cli sync --resource-only    # 仅同步资源信息
freelog-cli sync --version-only     # 仅同步版本信息

# 依赖命令统一到 dep 子命令
freelog-cli dep add <resourceId>    # 添加依赖
freelog-cli dep remove <resourceId> # 移除依赖
freelog-cli dep list                # 列出依赖
freelog-cli dep update <resourceId> # 更新依赖
freelog-cli dep sync                # 同步所有依赖
```

```bash

```
自动生成 `freelog.resource.config.ts` 和 `freelog.version.config.ts`

### 开发流程
```bash

# 3. 发布版本
freelog-cli publish

# 4. 更新资源介绍

# 5. 同步配置
```
