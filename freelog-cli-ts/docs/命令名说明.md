# ⚠️ 重要：命令名说明

## 使用 `freelog-cli2` 而不是 `freelog-cli`

### 原因
系统中已经安装了旧版本的 `freelog-cli`（4.0.0），为了避免冲突，新版本使用 `freelog-cli2` 作为命令名。

### 命令对比

```bash
# 旧版本（4.0.0）
freelog-cli -v
# 输出: freelog notice cli 4.0.0

# 新版本（1.0.0 - TypeScript 重写）
freelog-cli2 -v
# 输出: 1.0.0
```

---

## 如何使用新版本

### 方式 1: 使用 freelog-cli2（推荐）

所有测试文档中的命令都使用 `freelog-cli2`：

```bash
freelog-cli2 -v
freelog-cli2 --help
freelog-cli2 login
freelog-cli2 init
freelog-cli2 dep add <resourceId>
# ... 等等
```

### 方式 2: 创建别名

如果你想使用 `freelog-cli` 这个名字，可以创建别名：

**PowerShell:**
```powershell
Set-Alias freelog-cli freelog-cli2
```

**Bash/Zsh:**
```bash
alias freelog-cli='freelog-cli2'
```

### 方式 3: 直接运行（不需要全局安装）

```bash
# 每次使用完整路径
node D:\appinside\freelog-runtime-cli\freelog-cli-ts\dist\index.js -v

# 或者在当前目录
cd D:\appinside\freelog-runtime-cli\freelog-cli-ts
node dist/index.js -v
```

## 卸载旧版本（可选）

如果你想使用 `freelog-cli` 作为新版本的命令名，可以先卸载旧版本：

### 检查旧版本安装方式

```bash
# 查看 freelog-cli 的路径
where freelog-cli   # Windows
which freelog-cli   # Linux/Mac
```

### 卸载旧版本

如果是用 npm/pnpm 全局安装的：
```bash
npm uninstall -g freelog-cli
# 或
pnpm uninstall -g freelog-cli
```

### 然后修改 package.json

卸载旧版本后，修改 `package.json`：

```json
{
  "bin": {
    "freelog-cli": "./dist/bin/index.js"
  }
}
```

重新链接：
```bash
cd D:\appinside\freelog-runtime-cli\freelog-cli-ts
pnpm unlink --global
pnpm link --global
```

这样就可以使用 `freelog-cli` 命令了。
