# 开发设计：分期与验收

> 无旧命令兼容期 · API 细节 → [API/](./API/) · 草稿自测亦见 [04-草稿转换层](./04-草稿转换层.md)

## 1. API 前置（阻塞）

1. 按 [API/Console资源页API对照表.md](./API/Console资源页API对照表.md) 修错并移植。  
2. create / createBatch 响应带回 `userId` / `username` 并写入 config。  
3. info（getResourceDetailsById）用于 pull / status / ensureOwner。  
4. 错误结构对齐 `ret` / `errCode` / `msg` / `data`。  
5. 不 npm 依赖 tools-lib；CLI 侧复刻同签名。  
6. drafts：`save` 用 **POST**；补齐 **DELETE**；见草稿文档 A0。

详见 [API/API迁移清单.md](./API/API迁移清单.md)。

## 2. 分期

| 阶段 | 内容 | 验收锚点 |
|------|------|----------|
| **0** | API 修错；config owner；create 写 owner；字段约束校验；`--from-file` policy | 非法字段 exit 4；非交互 create |
| **1** | ensureOwner；auto-pull；退出码；`status --json`；publish 守卫 + exit 5；online=resourceOnline；`pull`；删除 syncr/syncv/publish --draft 入口 | 换号 exit 2；未授权 exit 5；CI `--yes` 跑通 |
| **1b** | drafts API + adapter + `draft *` + 冲突/`--force` + status 草稿行 + `--upload` | 草稿文档自测 1–14；Console 可续编 |
| **2** | `--from-dir` / `--cwd`；删除 `batch *` 用户入口 | 扁平目录可发行 |
| **3** | 合集 item/publish；`--display-*`；collect-rules；rss | 合集+RSS 可跑通 |
| **4** | `version edit`；冻结拒绝 | 冻结 publish 被拒 |
| **5** | `dep auth --policy-map`；可选 contract/logs；合集发版草稿 adapter | 声明式授权 |
