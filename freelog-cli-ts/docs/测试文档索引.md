## 🎯 推荐测试流程

### 第一轮：快速验证（30分钟）

1. 阅读 **[快速开始测试.md](./快速开始测试.md)**
2. 执行最小测试流程
3. 在 **[测试问题追踪.md](./测试问题追踪.md)** 记录问题
4. 快速修复阻塞性问题

**目标**: 确保核心功能基本可用

---

### 第二轮：深度测试（2-3小时）

1. 阅读 **[测试流程文档.md](./测试流程文档.md)**
2. 按照文档逐个测试所有命令
3. 测试各种边界情况
4. 记录所有发现的问题
5. 更新问题追踪表

**目标**: 全面测试所有功能，发现潜在问题

---

### 第三轮：修复验证（持续）

1. 从问题追踪表选择高优先级问题
2. 修复问题
3. 重新测试相关功能
4. 更新问题状态
5. 回归测试相关功能

**目标**: 修复所有问题，确保稳定性

## 💡 测试技巧

### 快速定位问题
1. **看错误堆栈**: 定位具体代码行
2. **检查配置文件**: 确认格式正确
3. **查看网络请求**: 确认 API 调用
4. **添加日志**: 在关键位置打印日志

### 使用开发模式
```bash
# 启动 watch 模式，修改后自动编译
pnpm run build -- --watch
```

### 快速重新测试
```bash
# 清理测试数据
cd D:\
Remove-Item -Recurse -Force test-freelog-cli
mkdir test-freelog-cli

# 重新编译
cd D:\appinside\freelog-runtime-cli\freelog-cli-ts
pnpm run build

# 开始测试
cd D:\test-freelog-cli
```
