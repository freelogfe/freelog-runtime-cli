# 依赖管理（dep）

为单品版本声明依赖，写入 `freelog.version.config` 的 `dependencies` 字段。

通用选项：`-c, --config <path>` 指定版本配置文件。

## 命令

| 命令 | 说明 |
|------|------|
| `dep add <idOrName>` | 添加依赖；支持 `id@1.0.0` 格式 |
| `dep remove <idOrName>` | 移除依赖 |
| `dep list` | 查看依赖列表；`--tree` 树形显示 |
| `dep update <idOrName>` | 修改版本范围；`-v, --version <range>` 指定范围 |

添加依赖时会走签约流程。版本范围示例：`1.0.0`、`^1.0.0`、`~2.3.0`、`*`。

## 数据结构

```typescript
interface Dependency {
  resourceId: string;
  resourceName?: string;
  versionRange: string;
}
```
