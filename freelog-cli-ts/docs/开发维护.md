# 开发维护

## 本地开发

### 环境

- Node.js ≥ 16（建议 20 LTS）
- pnpm ≥ 8，在 `freelog-cli-ts` 下执行命令

| 环境变量 | 说明 |
|---------|------|
| `FREELOG_ENV=development` | 等同 `--test`，访问测试网 API |
| `FREELOG_AUTH_PATH_GLOBAL` | 覆盖全局认证文件路径 |
| `FREELOG_AUTH_PATH_WORKSPACE` | 覆盖工作区认证文件路径 |

### 启动

```bash
cd freelog-cli-ts
pnpm install --ignore-workspace
pnpm dev                    # watch 编译
pnpm link --global          # 全局调试（Windows 需管理员）
freelog-cli --test login
```

### 目录

- `src/commands/` — 命令实现
- `src/services/` — 业务逻辑
- `src/api/` — 平台 API
- `public/` — 配置类型定义与模板

### 排障

| 问题 | 处理 |
|------|------|
| 未登录 | 检查 `.freelog-auth`，重新 `login` |
| API 报错 | 看返回的 `msg` 字段 |
| 命令不生效 | 确认 `pnpm dev` 在跑，`dist/` 是最新的 |

---

## 命令名说明

`package.json` 同时注册了 `freelog-cli` 和 `freelog-cli2`。若系统已安装旧版 `freelog-cli`（4.x），请用 **`freelog-cli2`** 调用本仓库版本。

```bash
freelog-cli2 -v
freelog-cli2 --help
```

---

## 发布 npm 包

```bash
cd freelog-cli-ts
pnpm build
pnpm pub
```

若遇到 403 Two-factor authentication required：

1. 在 [npmjs.com](https://www.npmjs.com/) 启用 2FA
2. 重新 `npm login`
3. 确认 `pnpm whoami --registry https://registry.npmjs.org`

模板包发布：在 `templates/vite-*` 目录执行 `pnpm pub`。

## 测试

```bash
pnpm test              # 全部
pnpm test:unit         # 单元测试
pnpm test:integration  # 集成测试
```

本地 link 后手动验证核心流程：

```bash
freelog-cli2 login
freelog-cli2 init test-project
freelog-cli2 create
freelog-cli2 publish
```
