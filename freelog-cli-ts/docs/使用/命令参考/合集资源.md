# 合集资源（collection）

合集 = 一个平台资源 + 多个单品（`items`）。CLI 用两个配置文件协作：

| 文件 | 作用 |
|------|------|
| `freelog.collection.config` | 合集元信息、`items`、`catalogueProperty` |
| `freelog.batch-resources.config` | 批量创建/发布单品 |

## 典型流程

```bash
freelog-cli init my-collection     # 选「合集（含批量管理单品资源）」
freelog-cli collection create
freelog-cli batch create && batch publish
freelog-cli batch add-to-collection
freelog-cli collection policy add    # 可选
freelog-cli collection publish
```

## collection 命令

通用选项：`-c, --config <path>`。

| 命令 | 说明 |
|------|------|
| `collection init [name]` | 初始化合集配置 |
| `collection create [name]` | 在平台创建合集，回填 `resourceId` |
| `collection update [resource]` | 更新 intro / 封面 / 标签 / 状态 / catalogueProperty |
| `collection item add <idOrName>` | 添加单品（含签约流程） |
| `collection item remove <idOrName>` | 移除单品 |
| `collection dep add <idOrName>` | 为合集添加依赖 |
| `collection policy add` | 添加授权策略 |
| `collection policy list` | 查看策略 |
| `collection publish` | 上架合集 |
| `collection unpublish` | 下架合集 |

多单品目标态见新方案 §9（`--from-dir` / `--cwd`）。旧 `batch *` 见 [归档](../../archive/命令参考-批量资源.md)（不采用）。

## 合集配置要点

```javascript
module.exports = {
  resourceId: '',           // collection create 后回填
  resourceName: 'my-collection',
  resourceType: ['合集'],
  resourceTypeCode: '...',
  resourceTitle: '我的合集',
  intro: '',
  coverImages: [],
  tags: [],
  policies: [],
  catalogueProperty: {},    // 合集展示属性
  items: [                  // batch add-to-collection 写入
    { resourceId: '...', resourceName: '...', versionId: '...' },
  ],
};
```

## 常见问题

**单品必须先创建吗？**  
可以。`batch create` 创建单品 → `batch publish` 发布 → `batch add-to-collection` 关联到合集。

**跳过某个单品？**  
在 `freelog.batch-resources.config` 中设 `skip: true`。

**两个配置文件的关系？**  
batch 管单品生命周期；collection 管合集本身。`add-to-collection` 会把已发布单品同步到 `items`。
