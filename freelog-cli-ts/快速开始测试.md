# 🚀 快速开始测试

## 一键准备测试环境

### 1. 构建并链接
```bash
cd D:\appinside\freelog-runtime-cli\freelog-cli-ts
pnpm install
pnpm run build
pnpm link --global
```

### 2. 验证安装
```bash
freelog-cli --version
freelog-cli --help
```

如果 `pnpm link --global` 不工作，使用别名：
```bash
# PowerShell
Set-Alias freelog-cli "node D:\appinside\freelog-runtime-cli\freelog-cli-ts\dist\index.js"

# 或者直接使用
node D:\appinside\freelog-runtime-cli\freelog-cli-ts\dist\index.js --help
```

## 快速测试流程

### 步骤 1: 登录
```bash
freelog-cli login
# 输入用户名和密码
```

### 步骤 2: 测试 init（最重要）
```bash
# 创建测试目录
mkdir D:\test-freelog-cli
cd D:\test-freelog-cli

# 测试初始化主题
mkdir test-theme
cd test-theme
freelog-cli init my-theme
# 选择：主题
# 选择：TypeScript

# 检查生成的文件
dir
cat freelog.resource.config.ts
cat freelog.version.config.ts
```

### 步骤 3: 测试 dep add（核心功能）
```bash
# 添加一个依赖（需要一个真实的 resourceId）
freelog-cli dep add <真实的resourceId>

# 查看依赖列表
freelog-cli dep list
```

### 步骤 4: 测试 sync
```bash
# 同步配置
freelog-cli sync

# 或指定 resourceId
freelog-cli sync <resourceId>
```

### 步骤 5: 测试 publish（需要准备文件）
```bash
# 创建测试文件
mkdir build
echo "test" > build\index.html

# 修改 freelog.version.config.ts
# 设置 buildPath: './build'

# 发布
freelog-cli publish
```

1. **login** ⭐⭐⭐⭐⭐ - 必须先能登录

## 💡 测试技巧

### 1. 开启开发模式
编译时使用 watch 模式，修改后自动重新编译：
```bash
cd D:\appinside\freelog-runtime-cli\freelog-cli-ts
pnpm run build -- --watch
```

### 2. 查看完整错误堆栈
设置环境变量显示详细错误：
```bash
# PowerShell
$env:DEBUG = "*"
freelog-cli <command>
```

### 3. 使用 JSON 配置测试
如果 TypeScript 配置有问题，先用 JSON 格式测试：
```bash
freelog-cli init --format json
```

### 4. 快速清理测试数据
```bash
# 清理测试目录
cd D:\
Remove-Item -Recurse -Force test-freelog-cli
mkdir test-freelog-cli
cd test-freelog-cli
```
