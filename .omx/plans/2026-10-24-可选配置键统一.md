# 可选配置键与 Console 统一

用户确认：两端操作同一数据，最终保存须统一；Console 仓库禁止修改。Console@1feacfa7 实际编辑器以 options_ + key.replace('options_', '') 保存。新建没有 defaultData 时前缀也是 options_。本任务不恢复登录取消诊断，不发版，不改属性键、依赖、策略及其它业务规则。

范围：单资源 option add/set 的真实保存键、确认预览和冲突；合集显式 form set 的 options 键；两端 schema/字段/使用说明；共用小函数，不新建框架。读取/拉取与最终提交保持稿中实际键，不偷偷改其它旧配置或线上数据。明确编辑旧条目时才按 Console 转换并展示原/新键。set/rm 仍用列表中的完整现有键定位，拒绝模糊匹配。

有限验收：普通短键/已前缀/前缀内部出现/数字或下划线开头的短键、22/23字符短键及30/31字符完整键、空尾键/非法字符；标准化幂等（一般规范键）、转换后属性/配置/系统冲突；取消/拒绝零落盘；属性键不变；编辑旧配置仅改选中条目；合集 JSON 转换后去重及命名空间，拉取原键不变；提交映射、API读回与Console回显使用完整键。先红再修，不把既有旧完整键 fixture 全局替换以掩盖读保真。

分工：主代理负责共用键函数、单资源实现/测试、正式设计/说明/集成；独立任务仅负责 collection/form.ts 与其测试；另一任务负责验收装置输入/独立预期的规范新键接线。并行任务互不回退他人更改。最后定向、根verify、独立双审，必要时固定包真实dev/网页；原失败保留。

停止条件：保存键与Console规则一致、定向与根检查通过、独立复核问题解决。平台或浏览器条件不足只记具体缺口；不得通过改Console、放宽oracle、重写未知写入或无穷审计凑闭环。已有线上旧数据不在本轮批量迁移。
