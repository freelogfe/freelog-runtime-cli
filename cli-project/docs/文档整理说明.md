## 🎨 文档命名规范

### 英文文档
- 使用大写英文和下划线: `QUICK_START.md`
- 便于在目录中快速识别
- 符合国际化标准

### 中文文档
- 使用中文和标点: `更新说明.md`
- 放在 `zh-CN/` 目录下
- 便于中文用户理解

### 特殊文档
- `README.md` - 各目录的索引文件
- 使用小写，表示默认首页

## 🔄 文档维护

### 添加新文档
1. 确定文档类型（指南/技术/更新/中文）
2. 放入对应目录
3. 更新 `docs/README.md` 索引
4. 必要时更新根目录 `README.md`

### 更新现有文档
1. 直接编辑对应文件
2. 更新文档中的"最后更新"时间
3. 如果是重大更新，在索引中注明

### 删除过时文档
1. 确认文档已过时
2. 删除文件
3. 更新索引移除链接
4. 在更新日志中记录
