## 🎯 设计亮点

### ⭐ 公共方法完全抽取

所有命令都复用核心模块，**零重复代码**：

```javascript
// ❌ 不好的做法：每个命令都重复实现
function executeCommand1() {
  // 检查登录...
  // 读取配置...
  // 发送请求...
}

function executeCommand2() {
  // 又检查登录...  ← 重复代码
  // 又读取配置...  ← 重复代码
  // 又发送请求...  ← 重复代码
}

// ✅ 好的做法：复用核心模块
function executeCommand1() {
  const auth = requireAuth();      // 复用
  const config = readConfig();     // 复用
  await api.someMethod();          // 复用
}

function executeCommand2() {
  const auth = requireAuth();      // 复用
  const config = readConfig();     // 复用
  await api.anotherMethod();       // 复用
}
```

### ⭐ 清晰的分层架构

```
│   使用 ↓                     │

├─────────────────────────────┤

└─────────────────────────────┘
```

## 💡 使用示例

### 场景1：创建并发布新项目

```bash
# 1. 创建项目
freelog-cli init my-app -t vite-react
cd my-app

# 2. 开发...
npm run dev

# 3. 登录
freelog-cli login -g

# 4. 构建并发布
npm run build
freelog-cli publish --patch -m "初始版本"
```

### 场景2：管理依赖

```bash
# 添加依赖
freelog-cli add ui-library@2.0.0

# 查看依赖
freelog-cli dep list

# 删除依赖
freelog-cli remove old-dependency
```

### 场景3：同步线上配置

```bash
# 同步所有信息
freelog-cli sync -a -v latest

# 交互式选择同步内容
freelog-cli sync
```
