# 支付功能说明

## 📋 功能概述

在添加依赖时，如果资源需要付费授权，CLI 会自动引导您完成支付流程。支付密码输入时会使用星号掩码保护隐私。

---

## 🔄 完整流程

### 1. 添加依赖并选择策略

```bash
freelog-cli dep add my-resource
```

系统会显示可用的策略列表，包括免费和付费策略。

### 2. 签约

选择策略后，系统会自动签约并检查授权状态。

### 3. 支付（如需要）

如果策略需要付费，系统会显示支付信息：

```
⚠ 未获得授权，需要支付费用

支付信息:
  合约ID: 5f8a7b3c2d1e4f9a8b7c6d5e
  资源: Premium Resource
  费用: 99.99 元
  策略: 标准授权

? 是否立即支付? (Y/n)
```

### 4. 输入支付信息

确认支付后，需要输入：

#### 账户ID
```
? 请输入付款账户ID: acc_123456789
```

#### 支付密码（掩码显示）
```
? 请输入支付密码（6位数字）: ******
```

密码要求：
- ✅ 必须是 6 位数字
- ✅ 输入时显示为星号 `*`
- ✅ 不会记录到日志

### 5. 支付处理

```
⠋ 正在处理支付...
✓ 支付成功
✓ 已获得授权
```

## 💡 使用示例

### 示例 1: 免费资源

免费资源会自动授权，无需支付：

```bash
$ freelog-cli dep add free-resource

✓ 签约成功
✓ 授权状态检查完成
✓ 已获得授权
✓ 依赖添加成功: free-resource@latest
```

### 示例 2: 付费资源（支付成功）

```bash
$ freelog-cli dep add premium-resource

# ... 选择策略 ...

✓ 签约成功
⚠ 未获得授权，需要支付费用

支付信息:
  合约ID: 5f8a7b3c2d1e4f9a8b7c6d5e
  资源: Premium Resource
  费用: 99.99 元
  策略: 标准授权

? 是否立即支付? Yes
? 请输入付款账户ID: acc_123456789
? 请输入支付密码（6位数字）: ******
⠋ 正在处理支付...
✓ 支付成功
✓ 已获得授权
✓ 依赖添加成功: premium-resource@latest
```

### 示例 3: 支付失败（余额不足）

```bash
? 请输入支付密码（6位数字）: ******
⠋ 正在处理支付...
✗ 支付失败
✗ 支付错误: 交易失败
✗ 余额不足，请充值后重试
⚠ 将以未授权状态添加依赖
```

### 示例 4: 取消支付

```bash
支付信息:
  费用: 99.99 元

? 是否立即支付? No
ℹ 跳过支付，将以未授权状态添加依赖
✓ 依赖添加成功: premium-resource@latest
```

---

## ⚠️ 常见错误

### 1. 余额不足
```
✗ 余额不足，请充值后重试
```
**解决方法**: 请充值账户后重新尝试

### 2. 密码错误
```
✗ 支付密码错误，请重新输入
```
**解决方法**: 检查密码是否正确，重新执行命令

### 3. 账户被冻结
```
✗ 账户被冻结，请联系客服
```
**解决方法**: 联系 Freelog 客服处理

### 4. 账户不存在
```
✗ 账户未找到，请检查账户ID
```
**解决方法**: 确认账户ID是否正确

## 🔐 安全性

### 密码保护
- ✅ 输入时使用 `*` 星号掩码
- ✅ 不会显示在终端历史
- ✅ 不会记录到日志文件
- ✅ 通过 HTTPS 加密传输

### 密码规则
- 必须是 6 位数字
- 格式: `123456`（示例）

---

## 📊 支付状态说明

| 状态 | 说明 | 后续操作 |
|------|------|----------|
| ✓ 支付成功 | 已获得授权 | 可以正常使用依赖 |
| ⠋ 支付确认中 | 正在处理 | 等待确认，稍后查看状态 |
| ✗ 支付失败 | 支付未成功 | 检查错误信息，重新支付 |
| ℹ 跳过支付 | 用户取消 | 以未授权状态添加 |

---

## 🎯 注意事项

1. **授权状态**: 未授权的依赖可能无法正常使用
2. **支付确认**: 部分支付可能需要时间确认
3. **重试机会**: 支付失败后可以重新执行命令
4. **账户准备**: 请提前准备好账户ID和支付密码

---

## 📞 获取帮助

如果遇到问题：

1. 查看错误提示信息
2. 检查账户余额和状态
3. 确认支付密码正确
4. 联系 Freelog 客服
